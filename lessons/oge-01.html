1. Определение результата выполнения программы

В задачах ОГЭ часто нужно определить, что выведет программа при выполнении.

Задача ОГЭ 1: Что выведет программа?

Программа:
a = 5
b = 3
c = a + b
print(c)

Что выведет программа?

Решение:
1. a = 5 (переменной a присваивается значение 5)
2. b = 3 (переменной b присваивается значение 3)
3. c = a + b = 5 + 3 = 8
4. print(c) выводит значение c

Ответ: 8

Проверка в Python:
a = 5
b = 3
c = a + b
print(c)  # 8

Задача ОГЭ 2: Анализ с условиями

Программа:
x = 10
if x > 5:
    print("Больше 5")
else:
    print("Не больше 5")

Что выведет программа?

Решение:
1. x = 10
2. Проверка условия: x > 5 → 10 > 5 → True
3. Выполняется блок if: print("Больше 5")

Ответ: Больше 5

Проверка в Python:
x = 10
if x > 5:
    print("Больше 5")
else:
    print("Не больше 5")  # Больше 5

2. Отслеживание изменений переменных

Нужно пошагово отслеживать, как изменяются переменные в программе.

Задача ОГЭ 3: Изменение переменной в цикле

Программа:
s = 0
for i in range(1, 4):
    s = s + i
print(s)

Что выведет программа?

Решение пошагово:
1. s = 0
2. Цикл for i in range(1, 4):
   - i = 1: s = 0 + 1 = 1
   - i = 2: s = 1 + 2 = 3
   - i = 3: s = 3 + 3 = 6
3. print(s) выводит 6

Ответ: 6

Проверка в Python:
s = 0
for i in range(1, 4):
    s = s + i
    print(f"i={i}, s={s}")  # Для отладки
print(s)  # 6

Задача ОГЭ 4: Вложенные циклы

Программа:
count = 0
for i in range(2):
    for j in range(3):
        count = count + 1
print(count)

Что выведет программа?

Решение:
Внешний цикл: i = 0, 1 (2 итерации)
Внутренний цикл: j = 0, 1, 2 (3 итерации)

Итерации:
- i=0: j=0 → count=1, j=1 → count=2, j=2 → count=3
- i=1: j=0 → count=4, j=1 → count=5, j=2 → count=6

Ответ: 6

Проверка в Python:
count = 0
for i in range(2):
    for j in range(3):
        count = count + 1
        print(f"i={i}, j={j}, count={count}")
print(count)  # 6

3. Анализ циклов и условий

Важно понимать, сколько раз выполнится цикл и какие условия сработают.

Задача ОГЭ 5: Цикл while

Программа:
n = 5
k = 0
while n > 0:
    k = k + 1
    n = n - 2
print(k)

Что выведет программа?

Решение пошагово:
1. n = 5, k = 0
2. Итерация 1: n > 0 (5 > 0) → True
   k = 0 + 1 = 1
   n = 5 - 2 = 3
3. Итерация 2: n > 0 (3 > 0) → True
   k = 1 + 1 = 2
   n = 3 - 2 = 1
4. Итерация 3: n > 0 (1 > 0) → True
   k = 2 + 1 = 3
   n = 1 - 2 = -1
5. Итерация 4: n > 0 (-1 > 0) → False, цикл завершается
6. print(k) выводит 3

Ответ: 3

Проверка в Python:
n = 5
k = 0
while n > 0:
    k = k + 1
    n = n - 2
    print(f"k={k}, n={n}")
print(k)  # 3

Задача ОГЭ 6: Условие в цикле

Программа:
s = 0
for i in range(1, 6):
    if i % 2 == 0:
        s = s + i
print(s)

Что выведет программа?

Решение:
Цикл перебирает i от 1 до 5:
- i=1: 1 % 2 = 1 ≠ 0 → условие False, s не меняется
- i=2: 2 % 2 = 0 → условие True, s = 0 + 2 = 2
- i=3: 3 % 2 = 1 ≠ 0 → условие False, s не меняется
- i=4: 4 % 2 = 0 → условие True, s = 2 + 4 = 6
- i=5: 5 % 2 = 1 ≠ 0 → условие False, s не меняется

Ответ: 6 (сумма четных чисел от 1 до 5)

Проверка в Python:
s = 0
for i in range(1, 6):
    if i % 2 == 0:
        s = s + i
        print(f"i={i} четное, s={s}")
print(s)  # 6

4. Поиск ошибок в коде

Иногда нужно найти ошибку в программе или определить, что программа делает неправильно.

Задача ОГЭ 7: Поиск ошибки

Программа должна вычислить сумму чисел от 1 до 5:
s = 0
for i in range(1, 5):
    s = s + i
print(s)

Что выведет программа? Есть ли ошибка?

Решение:
1. s = 0
2. Цикл for i in range(1, 5):
   - i = 1: s = 0 + 1 = 1
   - i = 2: s = 1 + 2 = 3
   - i = 3: s = 3 + 3 = 6
   - i = 4: s = 6 + 4 = 10
3. print(s) выводит 10

Ошибка: range(1, 5) не включает 5!
Должно быть range(1, 6) для суммы от 1 до 5.

Правильный ответ: программа выведет 10, но должна вывести 15 (1+2+3+4+5)

Проверка в Python:
# Неправильная версия
s = 0
for i in range(1, 5):
    s = s + i
print(f"Неправильно: {s}")  # 10

# Правильная версия
s = 0
for i in range(1, 6):
    s = s + i
print(f"Правильно: {s}")  # 15

7. Типичные ошибки

Ошибка 1: Неправильное понимание range()

# НЕПРАВИЛЬНО - путаница с range
# range(1, 5) включает числа: 1, 2, 3, 4 (НЕ включает 5!)
# range(5) включает числа: 0, 1, 2, 3, 4

# ПРАВИЛЬНО - помни границы
# range(1, 6) включает: 1, 2, 3, 4, 5
# range(5) включает: 0, 1, 2, 3, 4

Ошибка 2: Неучет начального значения

# НЕПРАВИЛЬНО - забыли начальное значение
s = 0
for i in range(1, 4):
    s = s + i
# Неправильно думать, что s начинается с 1

# ПРАВИЛЬНО - учитывай начальное значение
s = 0  # Начальное значение
for i in range(1, 4):
    s = s + i  # s = 0 + 1 = 1, затем 1 + 2 = 3, затем 3 + 3 = 6

Ошибка 3: Неправильный подсчет итераций

# НЕПРАВИЛЬНО - неправильный подсчет
# for i in range(2, 5):
# Неправильно: думать, что это 5 итераций

# ПРАВИЛЬНО - считай правильно
# range(2, 5) включает: 2, 3, 4 (всего 3 итерации)
# range(5) включает: 0, 1, 2, 3, 4 (всего 5 итераций)

9. Резюме урока

  • Анализ программ - нужно пошагово выполнять код и отслеживать изменения переменных
  • range() - помни, что range(a, b) включает числа от a до b-1
  • Циклы - считай количество итераций и отслеживай изменения переменных
  • Условия - проверяй, когда условие True, а когда False
  • Вложенные циклы - количество итераций = внешний цикл × внутренний цикл
  • Начальные значения - всегда учитывай начальное значение переменных
  • Пошаговый анализ - записывай значения переменных на каждом шаге
  • Проверка - всегда проверяй ответ, запустив программу
