1. Задачи на перебор и поиск

В таких задачах нужно перебрать элементы и найти те, которые удовлетворяют условию.

Задача ЕГЭ 1: Поиск максимального элемента

Условие: Дан список чисел. Напишите программу, которая находит максимальный элемент в списке.
Список: [5, 2, 8, 1, 9, 3]

Решение:
a = [5, 2, 8, 1, 9, 3]
max_value = a[0]
for i in range(1, len(a)):
    if a[i] > max_value:
        max_value = a[i]
print(max_value)

Ответ: 9

Проверка в Python:
a = [5, 2, 8, 1, 9, 3]
max_value = a[0]
for i in range(1, len(a)):
    if a[i] > max_value:
        max_value = a[i]
    print(f"i={i}, a[{i}]={a[i]}, max_value={max_value}")
print(f"Максимальный элемент: {max_value}")  # 9

Задача ЕГЭ 2: Поиск элемента по условию

Условие: Дан список чисел. Напишите программу, которая находит первое число, большее 10.
Список: [5, 12, 8, 15, 3, 20]

Решение:
a = [5, 12, 8, 15, 3, 20]
result = None
for i in range(len(a)):
    if a[i] > 10:
        result = a[i]
        break
print(result)

Ответ: 12

Проверка в Python:
a = [5, 12, 8, 15, 3, 20]
result = None
for i in range(len(a)):
    if a[i] > 10:
        result = a[i]
        print(f"Найдено число {result} на позиции {i}")
        break
print(f"Результат: {result}")  # 12

2. Задачи на подсчет элементов

В таких задачах нужно подсчитать количество элементов, удовлетворяющих условию.

Задача ЕГЭ 3: Подсчет четных чисел

Условие: Дан список чисел. Напишите программу, которая подсчитывает количество четных чисел.
Список: [1, 2, 3, 4, 5, 6, 7, 8]

Решение:
a = [1, 2, 3, 4, 5, 6, 7, 8]
count = 0
for i in range(len(a)):
    if a[i] % 2 == 0:
        count = count + 1
print(count)

Ответ: 4

Проверка в Python:
a = [1, 2, 3, 4, 5, 6, 7, 8]
count = 0
for i in range(len(a)):
    if a[i] % 2 == 0:
        count = count + 1
        print(f"Найдено четное: a[{i}]={a[i]}, всего: {count}")
print(f"Итого четных чисел: {count}")  # 4

Задача ЕГЭ 4: Подсчет элементов в диапазоне

Условие: Дан список чисел. Напишите программу, которая подсчитывает количество чисел в диапазоне от 10 до 20.
Список: [5, 15, 8, 12, 25, 18, 3, 11]

Решение:
a = [5, 15, 8, 12, 25, 18, 3, 11]
count = 0
for i in range(len(a)):
    if 10 <= a[i] <= 20:
        count = count + 1
print(count)

Ответ: 4

Проверка в Python:
a = [5, 15, 8, 12, 25, 18, 3, 11]
count = 0
for i in range(len(a)):
    if 10 <= a[i] <= 20:
        count = count + 1
        print(f"Найдено число в диапазоне: a[{i}]={a[i]}, всего: {count}")
print(f"Итого чисел в диапазоне [10, 20]: {count}")  # 4

3. Задачи на работу со списками

В таких задачах нужно обработать список: найти сумму, среднее, изменить элементы.

Задача ЕГЭ 5: Сумма элементов списка

Условие: Дан список чисел. Напишите программу, которая вычисляет сумму всех элементов.
Список: [10, 20, 30, 40]

Решение:
a = [10, 20, 30, 40]
s = 0
for i in range(len(a)):
    s = s + a[i]
print(s)

Ответ: 100

Проверка в Python:
a = [10, 20, 30, 40]
s = 0
for i in range(len(a)):
    s = s + a[i]
    print(f"i={i}, a[{i}]={a[i]}, s={s}")
print(f"Итоговая сумма: {s}")  # 100

Задача ЕГЭ 6: Среднее арифметическое

Условие: Дан список чисел. Напишите программу, которая вычисляет среднее арифметическое.
Список: [10, 20, 30, 40]

Решение:
a = [10, 20, 30, 40]
s = 0
for i in range(len(a)):
    s = s + a[i]
average = s / len(a)
print(average)

Ответ: 25.0

Проверка в Python:
a = [10, 20, 30, 40]
s = 0
for i in range(len(a)):
    s = s + a[i]
average = s / len(a)
print(f"Сумма: {s}, количество: {len(a)}")
print(f"Среднее арифметическое: {average}")  # 25.0

4. Задачи на работу со строками

В таких задачах нужно обработать строку: найти символы, подсчитать их, изменить строку.

Задача ЕГЭ 7: Подсчет символов в строке

Условие: Дана строка. Напишите программу, которая подсчитывает количество букв 'a' в строке.
Строка: "banana"

Решение:
s = "banana"
count = 0
for i in range(len(s)):
    if s[i] == 'a':
        count = count + 1
print(count)

Ответ: 3

Проверка в Python:
s = "banana"
count = 0
for i in range(len(s)):
    if s[i] == 'a':
        count = count + 1
        print(f"Найдена 'a' на позиции {i}, всего: {count}")
print(f"Итого букв 'a': {count}")  # 3

Задача ЕГЭ 8: Проверка строки

Условие: Дана строка. Напишите программу, которая проверяет, содержит ли строка только цифры.
Строка: "12345"

Решение:
s = "12345"
only_digits = True
for i in range(len(s)):
    if not s[i].isdigit():
        only_digits = False
        break
print(only_digits)

Ответ: True

Проверка в Python:
s = "12345"
only_digits = True
for i in range(len(s)):
    if not s[i].isdigit():
        only_digits = False
        print(f"Найден не-цифровой символ '{s[i]}' на позиции {i}")
        break
print(f"Только цифры: {only_digits}")  # True

5. Комплексные задачи

Задачи, сочетающие несколько элементов.

Задача ЕГЭ 9: Поиск и подсчет

Условие: Дан список чисел. Напишите программу, которая находит количество чисел, больших среднего арифметического.
Список: [10, 20, 30, 40, 50]

Решение:
a = [10, 20, 30, 40, 50]
# Сначала находим среднее
s = 0
for i in range(len(a)):
    s = s + a[i]
average = s / len(a)

# Затем считаем числа, большие среднего
count = 0
for i in range(len(a)):
    if a[i] > average:
        count = count + 1
print(count)

Решение:
1. Среднее: (10+20+30+40+50)/5 = 30
2. Числа больше 30: 40, 50
3. Количество: 2

Ответ: 2

Проверка в Python:
a = [10, 20, 30, 40, 50]
s = 0
for i in range(len(a)):
    s = s + a[i]
average = s / len(a)
print(f"Среднее арифметическое: {average}")

count = 0
for i in range(len(a)):
    if a[i] > average:
        count = count + 1
        print(f"Число {a[i]} больше среднего, всего: {count}")
print(f"Итого чисел больше среднего: {count}")  # 2

Задача ЕГЭ 10: Работа с двумя списками

Условие: Даны два списка одинаковой длины. Напишите программу, которая находит количество позиций, где элементы совпадают.
Списки: [1, 2, 3, 4, 5] и [1, 2, 5, 4, 5]

Решение:
a = [1, 2, 3, 4, 5]
b = [1, 2, 5, 4, 5]
count = 0
for i in range(len(a)):
    if a[i] == b[i]:
        count = count + 1
print(count)

Решение:
Позиции, где элементы совпадают:
- i=0: a[0]=1, b[0]=1, совпадают
- i=1: a[1]=2, b[1]=2, совпадают
- i=2: a[2]=3, b[2]=5, не совпадают
- i=3: a[3]=4, b[3]=4, совпадают
- i=4: a[4]=5, b[4]=5, совпадают

Ответ: 4

Проверка в Python:
a = [1, 2, 3, 4, 5]
b = [1, 2, 5, 4, 5]
count = 0
for i in range(len(a)):
    if a[i] == b[i]:
        count = count + 1
        print(f"Позиция {i}: a[{i}]={a[i]}, b[{i}]={b[i]}, совпадают, всего: {count}")
print(f"Итого совпадений: {count}")  # 4

8. Типичные ошибки

Ошибка 1: Неправильная инициализация для поиска максимума

# НЕПРАВИЛЬНО - инициализация нулем
a = [5, 2, 8, 1, 9]
max_value = 0  # Если все элементы отрицательные, это даст неправильный результат!

# ПРАВИЛЬНО - инициализируй первым элементом
a = [5, 2, 8, 1, 9]
max_value = a[0]  # Используй первый элемент как начальное значение
for i in range(1, len(a)):
    if a[i] > max_value:
        max_value = a[i]

Ошибка 2: Забыли инициализировать счетчик

# НЕПРАВИЛЬНО - счетчик не инициализирован
a = [1, 2, 3, 4, 5]
for i in range(len(a)):
    count = count + 1  # Ошибка! count не определена

# ПРАВИЛЬНО - инициализируй счетчик перед циклом
a = [1, 2, 3, 4, 5]
count = 0
for i in range(len(a)):
    count = count + 1

Ошибка 3: Неправильное условие для диапазона

# НЕПРАВИЛЬНО - неправильная логика
a = [15]
if a[i] > 10 and a[i] < 20:  # Это правильно, но можно проще

# ПРАВИЛЬНО - используй цепочку сравнений
a = [15]
if 10 <= a[i] <= 20:  # Более читаемо и понятно

10. Резюме урока

  • Поиск максимума/минимума - инициализируй первым элементом, сравнивай с остальными
  • Подсчет элементов - используй счетчик и условие в цикле
  • Сумма элементов - накапливай сумму в переменной, проходя по всем элементам
  • Среднее арифметическое - сумма / количество элементов
  • Работа со строками - используй индексацию s[i] и методы isdigit(), isupper() и др.
  • Сравнение списков - сравнивай элементы на одинаковых позициях
  • Инициализация - всегда инициализируй переменные перед использованием
  • Условия - используй правильные операторы сравнения (==, !=, <, >, <=, >=)
  • Практика - решай задачи пошагово, проверяй на разных входных данных
