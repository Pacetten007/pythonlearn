1. Работа с элементами списка

В Python списки (массивы) индексируются с нуля. Важно помнить это при работе с задачами ОГЭ.

Задача ОГЭ 1: Доступ к элементам

Условие: Дан список a = [10, 20, 30, 40, 50]. Что выведет программа?
print(a[0])
print(a[2])
print(a[-1])

Решение:
a = [10, 20, 30, 40, 50]
a[0] = 10  (первый элемент, индекс 0)
a[2] = 30  (третий элемент, индекс 2)
a[-1] = 50 (последний элемент, отрицательный индекс)

Ответ:
10
30
50

Проверка в Python:
a = [10, 20, 30, 40, 50]
print(f"a[0] = {a[0]}")   # 10
print(f"a[2] = {a[2]}")   # 30
print(f"a[-1] = {a[-1]}") # 50

Задача ОГЭ 2: Изменение элемента

Условие: Дан список a = [1, 2, 3, 4, 5]. Выполняется команда a[2] = 10.
Что будет в списке?

Решение:
a = [1, 2, 3, 4, 5]
a[2] = 10  # Изменяем элемент с индексом 2 (третий элемент)
# Список станет: [1, 2, 10, 4, 5]

Ответ: [1, 2, 10, 4, 5]

Проверка в Python:
a = [1, 2, 3, 4, 5]
print(f"До изменения: {a}")
a[2] = 10
print(f"После изменения: {a}")  # [1, 2, 10, 4, 5]

2. Поиск элементов в списке

Часто нужно найти элемент в списке или проверить его наличие.

Задача ОГЭ 3: Поиск максимального элемента

Условие: Напишите программу, которая находит максимальный элемент в списке [5, 2, 8, 1, 9].

Решение:
a = [5, 2, 8, 1, 9]
max_value = a[0]  # Предполагаем, что первый элемент максимальный
for i in range(1, len(a)):
    if a[i] > max_value:
        max_value = a[i]
print(max_value)

Решение пошагово:
1. max_value = 5
2. i=1: a[1]=2, 2 > 5? Нет, max_value остается 5
3. i=2: a[2]=8, 8 > 5? Да, max_value = 8
4. i=3: a[3]=1, 1 > 8? Нет, max_value остается 8
5. i=4: a[4]=9, 9 > 8? Да, max_value = 9

Ответ: 9

Проверка в Python:
a = [5, 2, 8, 1, 9]
max_value = a[0]
for i in range(1, len(a)):
    if a[i] > max_value:
        max_value = a[i]
    print(f"i={i}, a[{i}]={a[i]}, max_value={max_value}")
print(f"Максимальный элемент: {max_value}")  # 9

Задача ОГЭ 4: Подсчет элементов

Условие: Напишите программу, которая подсчитывает количество четных чисел в списке [1, 2, 3, 4, 5, 6].

Решение:
a = [1, 2, 3, 4, 5, 6]
count = 0
for i in range(len(a)):
    if a[i] % 2 == 0:
        count = count + 1
print(count)

Решение пошагово:
1. count = 0
2. i=0: a[0]=1, 1 % 2 = 1 ≠ 0, count остается 0
3. i=1: a[1]=2, 2 % 2 = 0, count = 1
4. i=2: a[2]=3, 3 % 2 = 1 ≠ 0, count остается 1
5. i=3: a[3]=4, 4 % 2 = 0, count = 2
6. i=4: a[4]=5, 5 % 2 = 1 ≠ 0, count остается 2
7. i=5: a[5]=6, 6 % 2 = 0, count = 3

Ответ: 3

Проверка в Python:
a = [1, 2, 3, 4, 5, 6]
count = 0
for i in range(len(a)):
    if a[i] % 2 == 0:
        count = count + 1
        print(f"Найдено четное: a[{i}]={a[i]}, всего: {count}")
print(f"Итого четных чисел: {count}")  # 3

3. Обработка списков в циклах

Циклы позволяют обработать все элементы списка.

Задача ОГЭ 5: Сумма элементов

Условие: Напишите программу, которая вычисляет сумму всех элементов списка [1, 2, 3, 4, 5].

Решение:
a = [1, 2, 3, 4, 5]
s = 0
for i in range(len(a)):
    s = s + a[i]
print(s)

Решение пошагово:
1. s = 0
2. i=0: s = 0 + 1 = 1
3. i=1: s = 1 + 2 = 3
4. i=2: s = 3 + 3 = 6
5. i=3: s = 6 + 4 = 10
6. i=4: s = 10 + 5 = 15

Ответ: 15

Проверка в Python:
a = [1, 2, 3, 4, 5]
s = 0
for i in range(len(a)):
    s = s + a[i]
    print(f"i={i}, a[{i}]={a[i]}, s={s}")
print(f"Итоговая сумма: {s}")  # 15

Задача ОГЭ 6: Поиск индекса элемента

Условие: Напишите программу, которая находит индекс первого элемента, равного 5, в списке [2, 5, 3, 5, 7].

Решение:
a = [2, 5, 3, 5, 7]
index = -1
for i in range(len(a)):
    if a[i] == 5:
        index = i
        break
print(index)

Решение пошагово:
1. index = -1
2. i=0: a[0]=2, 2 ≠ 5, index остается -1
3. i=1: a[1]=5, 5 == 5, index = 1, break (выход из цикла)

Ответ: 1

Проверка в Python:
a = [2, 5, 3, 5, 7]
index = -1
for i in range(len(a)):
    if a[i] == 5:
        index = i
        print(f"Найден элемент 5 на позиции {i}")
        break
print(f"Индекс: {index}")  # 1

4. Изменение элементов списка

В задачах ОГЭ часто нужно изменить элементы списка по определенному правилу.

Задача ОГЭ 7: Удвоение элементов

Условие: Напишите программу, которая удваивает каждый элемент списка [1, 2, 3, 4].

Решение:
a = [1, 2, 3, 4]
for i in range(len(a)):
    a[i] = a[i] * 2
print(a)

Решение пошагово:
1. i=0: a[0] = 1 * 2 = 2, список: [2, 2, 3, 4]
2. i=1: a[1] = 2 * 2 = 4, список: [2, 4, 3, 4]
3. i=2: a[2] = 3 * 2 = 6, список: [2, 4, 6, 4]
4. i=3: a[3] = 4 * 2 = 8, список: [2, 4, 6, 8]

Ответ: [2, 4, 6, 8]

Проверка в Python:
a = [1, 2, 3, 4]
print(f"До изменения: {a}")
for i in range(len(a)):
    a[i] = a[i] * 2
    print(f"i={i}, a[{i}]={a[i]}, список: {a}")
print(f"После изменения: {a}")  # [2, 4, 6, 8]

Задача ОГЭ 8: Замена элементов

Условие: Напишите программу, которая заменяет все отрицательные числа на 0 в списке [5, -2, 3, -1, 4].

Решение:
a = [5, -2, 3, -1, 4]
for i in range(len(a)):
    if a[i] < 0:
        a[i] = 0
print(a)

Решение пошагово:
1. i=0: a[0]=5, 5 < 0? Нет, список: [5, -2, 3, -1, 4]
2. i=1: a[1]=-2, -2 < 0? Да, a[1]=0, список: [5, 0, 3, -1, 4]
3. i=2: a[2]=3, 3 < 0? Нет, список: [5, 0, 3, -1, 4]
4. i=3: a[3]=-1, -1 < 0? Да, a[3]=0, список: [5, 0, 3, 0, 4]
5. i=4: a[4]=4, 4 < 0? Нет, список: [5, 0, 3, 0, 4]

Ответ: [5, 0, 3, 0, 4]

Проверка в Python:
a = [5, -2, 3, -1, 4]
print(f"До изменения: {a}")
for i in range(len(a)):
    if a[i] < 0:
        a[i] = 0
        print(f"i={i}, заменено на 0, список: {a}")
print(f"После изменения: {a}")  # [5, 0, 3, 0, 4]

5. Комплексные задачи

Задачи, сочетающие несколько операций со списками.

Задача ОГЭ 9: Среднее значение

Условие: Напишите программу, которая вычисляет среднее арифметическое элементов списка [10, 20, 30, 40].

Решение:
a = [10, 20, 30, 40]
s = 0
for i in range(len(a)):
    s = s + a[i]
average = s / len(a)
print(average)

Решение:
1. s = 0
2. Суммируем: s = 10 + 20 + 30 + 40 = 100
3. average = 100 / 4 = 25.0

Ответ: 25.0

Проверка в Python:
a = [10, 20, 30, 40]
s = 0
for i in range(len(a)):
    s = s + a[i]
    print(f"i={i}, a[{i}]={a[i]}, s={s}")
average = s / len(a)
print(f"Среднее арифметическое: {average}")  # 25.0

Задача ОГЭ 10: Поиск минимального и максимального

Условие: Напишите программу, которая находит минимальный и максимальный элементы в списке [7, 3, 9, 1, 5].

Решение:
a = [7, 3, 9, 1, 5]
min_value = a[0]
max_value = a[0]
for i in range(1, len(a)):
    if a[i] < min_value:
        min_value = a[i]
    if a[i] > max_value:
        max_value = a[i]
print(min_value, max_value)

Ответ: 1 9

Проверка в Python:
a = [7, 3, 9, 1, 5]
min_value = a[0]
max_value = a[0]
for i in range(1, len(a)):
    if a[i] < min_value:
        min_value = a[i]
    if a[i] > max_value:
        max_value = a[i]
    print(f"i={i}, a[{i}]={a[i]}, min={min_value}, max={max_value}")
print(f"Минимум: {min_value}, Максимум: {max_value}")  # 1, 9

8. Типичные ошибки

Ошибка 1: Выход за границы списка

# НЕПРАВИЛЬНО - выход за границы
a = [1, 2, 3]
print(a[3])  # Ошибка! Индексы: 0, 1, 2 (всего 3 элемента)

# ПРАВИЛЬНО - проверяй границы
a = [1, 2, 3]
if len(a) > 3:
    print(a[3])
else:
    print("Индекс вне диапазона")

Ошибка 2: Неправильная инициализация

# НЕПРАВИЛЬНО - неправильная инициализация для поиска максимума
a = [5, 2, 8, 1]
max_value = 0  # Если все элементы отрицательные, это даст неправильный результат!

# ПРАВИЛЬНО - инициализируй первым элементом
a = [5, 2, 8, 1]
max_value = a[0]  # Используй первый элемент как начальное значение
for i in range(1, len(a)):
    if a[i] > max_value:
        max_value = a[i]

Ошибка 3: Изменение списка во время итерации

# НЕПРАВИЛЬНО - изменение размера списка во время итерации
a = [1, 2, 3, 4, 5]
for i in range(len(a)):
    if a[i] % 2 == 0:
        a.remove(a[i])  # Опасно! Может пропустить элементы

# ПРАВИЛЬНО - создай новый список или используй индексы
a = [1, 2, 3, 4, 5]
result = []
for i in range(len(a)):
    if a[i] % 2 != 0:  # Оставляем только нечетные
        result.append(a[i])
print(result)

10. Резюме урока

  • Индексация - списки индексируются с 0, последний элемент имеет индекс -1
  • Доступ к элементам - используй a[i] для доступа к элементу с индексом i
  • Изменение элементов - a[i] = значение для изменения элемента
  • Поиск максимума/минимума - инициализируй первым элементом, сравнивай с остальными
  • Подсчет элементов - используй счетчик и условие в цикле
  • Сумма элементов - накапливай сумму в переменной, проходя по всем элементам
  • Циклы по списку - используй for i in range(len(a)) для перебора всех элементов
  • Границы - всегда проверяй, что индекс не выходит за границы списка
  • Практика - решай задачи пошагово, отслеживай изменения списка
