Урок 9: Арифметические операции

Введение в Python • 30 минут

Введение

Python - это не только язык программирования, но и мощный калькулятор! С помощью арифметических операций ты можешь выполнять любые математические вычисления: от простого сложения до сложных формул.

В этом уроке мы освоим семь арифметических операторов Python. Некоторые из них ты знаешь из математики, но есть и особенные операторы, которые могут тебя удивить!

Зачем изучать арифметические операции?

  • Создавать калькуляторы и программы для вычислений
  • Обрабатывать числовые данные (баллы в играх, цены, расстояния)
  • Решать математические задачи автоматически
  • Писать формулы для научных расчетов
  • Проверять четность чисел, вычислять остатки

Семь арифметических операторов

1. Сложение (+)

Оператор + складывает два числа. Все просто, как в математике!

# Сложение чисел
print(5 + 3)           # 8
print(10 + 20)         # 30
print(100 + 1)         # 101

# С переменными
a = 15
b = 25
sum_result = a + b
print(sum_result)      # 40

# С отрицательными числами
print(10 + (-5))       # 5
print(-3 + (-7))       # -10

Особенность: сложение работает и для строк!

# Конкатенация (объединение) строк
first_name = "Иван"
last_name = "Петров"
full_name = first_name + " " + last_name
print(full_name)       # "Иван Петров"

# Объединение текста
greeting = "Привет" + ", " + "мир" + "!"
print(greeting)        # "Привет, мир!"

Важно: нельзя складывать число и строку! 5 + "3" вызовет ошибку.

2. Вычитание (-)

Оператор - вычитает одно число из другого.

# Вычитание чисел
print(10 - 4)          # 6
print(50 - 20)         # 30
print(100 - 1)         # 99

# С переменными
total = 100
spent = 35
remaining = total - spent
print(remaining)       # 65

# Отрицательные результаты
print(5 - 10)          # -5
print(0 - 8)           # -8

3. Умножение (*)

Оператор * умножает числа. В программировании используется звездочка, а не × или ·

# Умножение чисел
print(3 * 7)           # 21
print(5 * 5)           # 25
print(12 * 2)          # 24

# С переменными
price = 250
quantity = 3
total_cost = price * quantity
print(total_cost)      # 750

# С дробными числами
print(2.5 * 4)         # 10.0
print(1.5 * 1.5)       # 2.25

Особенность: умножение работает и для строк!

# Повторение строк
print("Ha" * 3)        # "HaHaHa"
print("Python " * 2)   # "Python Python "
print("=" * 20)        # "===================="

# Полезно для рисования:
line = "-" * 30
print(line)            # ------------------------------

Строка, умноженная на число N, повторяется N раз!

4. Деление (/)

Оператор / делит одно число на другое. ВАЖНО: всегда возвращает float!

# Деление чисел
print(10 / 2)          # 5.0 (не 5, а 5.0!)
print(15 / 3)          # 5.0
print(7 / 2)           # 3.5

# Результат всегда float
print(type(10 / 2))    # <class 'float'>
print(type(9 / 3))     # <class 'float'>

# Деление с дробными числами
print(10 / 3)          # 3.3333333333333335
print(100 / 7)         # 14.285714285714286

# С переменными
total_score = 95
tests_count = 5
average = total_score / tests_count
print(average)         # 19.0

Деление на ноль - ошибка!

# Это вызовет ошибку ZeroDivisionError:
# print(10 / 0)

# Важно проверять делитель:
divisor = 0
if divisor != 0:
    result = 10 / divisor
else:
    print("Делить на ноль нельзя!")

5. Целочисленное деление (//)

Оператор // делит и отбрасывает остаток, оставляя только целую часть.

# Целочисленное деление
print(7 // 2)          # 3 (не 3.5!)
print(10 // 3)         # 3 (не 3.333...)
print(15 // 4)         # 3 (не 3.75)

# Даже если делится нацело
print(10 // 2)         # 5 (тип int, если оба операнда int)
print(9 // 3)          # 3

# С отрицательными числами (округление к меньшему!)
print(7 // 2)          # 3
print(-7 // 2)         # -4 (не -3!)

# Практическое применение
total_apples = 23
people = 5
apples_per_person = total_apples // people
print(apples_per_person)  # 4 (каждому по 4 яблока)

Разница между / и //

print(10 / 3)      # 3.3333333333333335 (точное деление)
print(10 // 3)     # 3 (только целая часть)

print(7 / 2)       # 3.5
print(7 // 2)      # 3

print(10 / 2)      # 5.0 (float)
print(10 // 2)     # 5 (int)

Правило: Используй / для точного деления, // когда нужна только целая часть.

6. Остаток от деления (%)

Оператор % (модуло) возвращает остаток от деления. Очень полезен!

# Остаток от деления
print(7 % 2)           # 1 (7 = 2*3 + 1)
print(10 % 3)          # 1 (10 = 3*3 + 1)
print(15 % 4)          # 3 (15 = 4*3 + 3)

# Если делится нацело - остаток 0
print(10 % 2)          # 0
print(9 % 3)           # 0

# Проверка четности
number = 17
if number % 2 == 0:
    print("Четное")
else:
    print("Нечетное")  # Выведет это

# Проверка кратности
number = 15
if number % 5 == 0:
    print("Кратно 5")  # Выведет это

Практическое применение % (модуло):

# 1. Проверка четности/нечетности
num = 42
is_even = (num % 2 == 0)
print(is_even)         # True

# 2. Распределение по группам
student_number = 17
group = student_number % 3  # Группы 0, 1, 2
print("Группа:", group)     # Группа: 2

# 3. Получение последней цифры числа
number = 12345
last_digit = number % 10
print(last_digit)      # 5

# 4. Подсчет остатка яблок
total_apples = 23
people = 5
leftover = total_apples % people
print("Остаток:", leftover)  # Остаток: 3

7. Возведение в степень (**)

Оператор ** возводит число в степень. Не путай с * (умножение)!

# Возведение в степень
print(2 ** 3)          # 8 (2 в кубе)
print(5 ** 2)          # 25 (5 в квадрате)
print(10 ** 3)         # 1000 (10 в третьей степени)

# С переменными
base = 3
exponent = 4
result = base ** exponent
print(result)          # 81 (3^4)

# Дробные степени (корни!)
print(9 ** 0.5)        # 3.0 (квадратный корень из 9)
print(8 ** (1/3))      # 2.0 (кубический корень из 8)
print(16 ** 0.25)      # 2.0 (корень 4-й степени)

# Отрицательные степени (дроби)
print(2 ** -1)         # 0.5 (1/2)
print(10 ** -2)        # 0.01 (1/100)

Степень vs. Умножение:

print(2 * 3)       # 6 (умножение)
print(2 ** 3)      # 8 (степень: 2*2*2)

print(5 * 2)       # 10 (умножение)
print(5 ** 2)      # 25 (степень: 5*5)

# Запомни:
# * - это умножение
# ** - это степень

Порядок операций (приоритет)

Когда в одном выражении несколько операторов, Python выполняет их в определенном порядке - как в математике (правило PEMDAS).

Приоритет операторов (от высшего к низшему):

  1. ** - возведение в степень
  2. *, /, //, % - умножение, деление, остаток
  3. +, - - сложение, вычитание

Скобки ( ) имеют наивысший приоритет и выполняются первыми!

# Примеры с приоритетом
print(2 + 3 * 4)           # 14 (сначала 3*4=12, потом +2)
print((2 + 3) * 4)         # 20 (сначала скобки: 5, потом *4)

print(10 - 2 * 3)          # 4 (сначала 2*3=6, потом 10-6)
print((10 - 2) * 3)        # 24 (сначала 10-2=8, потом *3)

# Степень выполняется первой
print(2 + 3 ** 2)          # 11 (3**2=9, потом +2)
print((2 + 3) ** 2)        # 25 (сначала 2+3=5, потом 5**2)

# Сложное выражение
print(10 + 2 * 3 ** 2)     # 28
# Порядок: 3**2=9, 2*9=18, 10+18=28

# Используй скобки для ясности!
result = (100 + 50) / (3 * 2)
print(result)              # 25.0

Всегда используй скобки, если не уверен!

# Неясно без скобок:
a = 5 + 3 * 2 ** 2 / 4 - 1

# Яснее со скобками:
b = 5 + ((3 * (2 ** 2)) / 4) - 1

print(a)  # 7.0
print(b)  # 7.0
# Результат тот же, но второе легче понять!

Практические применения

1. Площадь прямоугольника

# Вычисление площади
length = 15
width = 8
area = length * width
print("Площадь прямоугольника:", area, "кв. м")  # 120 кв. м

2. Конвертер температуры (Цельсий → Фаренгейт)

# Формула: F = C * 9/5 + 32
celsius = 25
fahrenheit = celsius * 9 / 5 + 32
print(celsius, "°C =", fahrenheit, "°F")  # 25 °C = 77.0 °F

# С другой температурой
celsius = 0
fahrenheit = celsius * 9 / 5 + 32
print(celsius, "°C =", fahrenheit, "°F")  # 0 °C = 32.0 °F

3. Среднее арифметическое

# Средний балл за 4 теста
test1 = 85
test2 = 92
test3 = 78
test4 = 88

average = (test1 + test2 + test3 + test4) / 4
print("Средний балл:", average)  # 85.75

4. Расчет времени в играх

# Сколько полных часов и минут в 142 минутах?
total_minutes = 142

hours = total_minutes // 60      # Целая часть
minutes = total_minutes % 60     # Остаток

print(hours, "часов", minutes, "минут")  # 2 часов 22 минут

Типичные ошибки начинающих

Ошибка 1: Путаница / и //

# НЕПРАВИЛЬНО: хотели целое число, но получили float
apples = 10
people = 3
per_person = apples / people  # 3.3333... (дробное!)

# ПРАВИЛЬНО:
per_person = apples // people  # 3 (целое число)

Используй // когда нужно целое число (деление предметов, людей)!

Ошибка 2: Забыли про скобки

# НЕПРАВИЛЬНО:
average = 10 + 20 + 30 / 3  # 40.0 (только 30 разделили!)

# ПРАВИЛЬНО:
average = (10 + 20 + 30) / 3  # 20.0 (сумма, потом деление)

Скобки контролируют порядок вычислений!

Ошибка 3: Путаница * и **

# НЕПРАВИЛЬНО:
square = 5 * 2      # 10 (умножение)

# ПРАВИЛЬНО (если хотели квадрат):
square = 5 ** 2     # 25 (степень)

# Запомни:
# * (одна звездочка) - умножение
# ** (две звездочки) - степень

Ошибка 4: Деление на ноль

# НЕПРАВИЛЬНО:
result = 10 / 0  # ZeroDivisionError!

# ПРАВИЛЬНО: проверка перед делением
divisor = 0
if divisor != 0:
    result = 10 / divisor
    print(result)
else:
    print("Ошибка: деление на ноль!")

Ошибка 5: Неправильный порядок операций

# Вычисли: (5 + 3) × 2
# НЕПРАВИЛЬНО:
result = 5 + 3 * 2  # 11 (умножение сначала!)

# ПРАВИЛЬНО:
result = (5 + 3) * 2  # 16 (скобки сначала!)

Ошибка 6: Округление vs отбрасывание

# int() ОТБРАСЫВАЕТ дробную часть:
print(int(3.9))     # 3 (не 4!)
print(int(5.1))     # 5

# Для округления используй round():
print(round(3.9))   # 4
print(round(5.1))   # 5

# 7 // 2 тоже отбрасывает:
print(7 / 2)        # 3.5
print(7 // 2)       # 3 (отбрасывание!)

Арифметические операции - основа для многих задач на экзаменах:

  • ОГЭ: Задание 6 (анализ алгоритмов с вычислениями), Задание 14 (программы с арифметическими операциями)

  • Особенно важны операторы % (проверка четности, кратности) и // (целочисленное деление)
  • На экзаменах часто встречаются задачи на перевод времени, систем счисления, поиск делителей - везде нужны эти операторы!

Резюме урока

  • + - сложение чисел (также объединение строк)
  • - - вычитание чисел
  • * - умножение (также повторение строк)
  • / - деление (ВСЕГДА возвращает float!)
  • // - целочисленное деление (отбрасывает остаток)
  • % - остаток от деления (для проверки четности, кратности)
  • ** - возведение в степень
  • Приоритет: ** → *, /, //, % → +, -
  • Скобки () имеют наивысший приоритет
  • Деление на ноль вызывает ошибку
  • 10 / 2 = 5.0 (float), а 10 // 2 = 5 (int)
