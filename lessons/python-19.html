Урок 24: Параметры функций

Функции • 50 минут

Введение

В прошлом уроке мы создавали простые функции без входных данных. Но что если функция должна работать с разными значениями? Представь функцию "приготовить пиццу" - она должна знать размер пиццы, начинку, количество сыра! Параметры позволяют передавать данные в функции, делая их гибкими и мощными.

С параметрами функция становится по-настоящему универсальной - один раз написал, используй с любыми данными!

Что изучим в этом уроке:

  • Что такое параметры и аргументы
  • Функции с одним параметром
  • Функции с несколькими параметрами
  • Позиционные параметры
  • Параметры со значениями по умолчанию
  • Именованные аргументы (keyword arguments)
  • Смешивание позиционных и именованных аргументов

Параметры vs Аргументы

Сначала разберем терминологию - это важно!

def greet(name):  # 'name' - это ПАРАМЕТР
    """Приветствует пользователя по имени."""
    print(f"Привет, {name}!")

# Вызываем функцию
greet("Иван")  # "Иван" - это АРГУМЕНТ

В чем разница?

  • Параметр - переменная в определении функции (внутри скобок после def)
  • Аргумент - конкретное значение, которое передаем при вызове
  • Параметр - как пустая коробка с именем
  • Аргумент - что мы кладем в эту коробку
def square(n):  # n - параметр (переменная)
    """Выводит квадрат числа."""
    result = n * n
    print(result)

square(5)   # 5 - аргумент (значение) → Выведет: 25
square(10)  # 10 - аргумент → Выведет: 100
square(3)   # 3 - аргумент → Выведет: 9

# Одна функция, разные аргументы - разные результаты!

Функция с одним параметром

Самый простой случай - функция принимает одно значение:

# Функция приветствия с именем
def greet(name):
    """Приветствует пользователя по имени."""
    print(f"Здравствуй, {name}!")
    print(f"Рад тебя видеть, {name}!")

greet("Мария")  # Здравствуй, Мария! Рад тебя видеть, Мария!
greet("Петр")   # Здравствуй, Петр! Рад тебя видеть, Петр!

# Функция вывода числа в квадрате
def print_square(number):
    """Выводит квадрат числа."""
    print(f"{number}² = {number ** 2}")

print_square(7)   # 7² = 49
print_square(12)  # 12² = 144

# Функция повторения текста
def repeat_text(text):
    """Повторяет текст 3 раза."""
    for i in range(3):
        print(text)

Параметр может быть любого типа

# Число
def double(n):
    print(n * 2)

double(5)  # 10

# Строка
def shout(text):
    print(text.upper())

shout("привет")  # ПРИВЕТ

# Список
def print_list(items):
    for item in items:
        print(f"- {item}")

print_list(["яблоко", "банан", "апельсин"])

Функция с несколькими параметрами

Функция может принимать 2, 3, 5, 10 параметров! Разделяем их запятыми:

# Два параметра
def add(a, b):
    """Выводит сумму двух чисел."""
    result = a + b
    print(f"{a} + {b} = {result}")

add(5, 3)    # 5 + 3 = 8
add(10, 20)  # 10 + 20 = 30
add(7, 15)   # 7 + 15 = 22

# Три параметра
def show_person(name, age, city):
    """Выводит информацию о человеке."""
    print(f"Имя: {name}")
    print(f"Возраст: {age} лет")
    print(f"Город: {city}")

show_person("Иван", 16, "Москва")
# Имя: Иван
# Возраст: 16 лет
# Город: Москва

# Четыре параметра
def calculate_rectangle(width, height, unit, name):
    """Вычисляет площадь прямоугольника."""
    area = width * height
    perimeter = 2 * (width + height)
    print(f"{name}:")
    print(f"  Площадь: {area} {unit}²")
    print(f"  Периметр: {perimeter} {unit}")

calculate_rectangle(10, 5, "см", "Прямоугольник A")

Позиционные параметры

По умолчанию Python сопоставляет аргументы с параметрами по позиции (порядку):

def subtract(a, b):
    """Вычитает b из a."""
    result = a - b
    print(f"{a} - {b} = {result}")

subtract(10, 3)  # a=10, b=3 → 10 - 3 = 7
subtract(3, 10)  # a=3, b=10 → 3 - 10 = -7

# Порядок ВАЖЕН!
# Первый аргумент → первый параметр (a)
# Второй аргумент → второй параметр (b)

def divide(dividend, divisor):
    """Делит dividend на divisor."""
    result = dividend / divisor
    print(f"{dividend} / {divisor} = {result}")

divide(20, 4)  # dividend=20, divisor=4 → 20 / 4 = 5.0
divide(4, 20)  # dividend=4, divisor=20 → 4 / 20 = 0.2

Важно!

Количество аргументов должно совпадать с количеством параметров!

def greet(name, age):
    print(f"{name}, {age} лет")

# greet("Иван")  # ERROR! Не хватает одного аргумента
# greet("Иван", 16, "Москва")  # ERROR! Слишком много аргументов

greet("Иван", 16)  # Правильно!

Параметры по умолчанию

Можно задать значение по умолчанию - если аргумент не передан, используется это значение:

def greet(name, greeting="Привет"):
    """Приветствует с заданным приветствием."""
    print(f"{greeting}, {name}!")

# Используем значение по умолчанию
greet("Иван")  # Привет, Иван!

# Переопределяем значение по умолчанию
greet("Мария", "Здравствуй")  # Здравствуй, Мария!
greet("Петр", "Добрый день")  # Добрый день, Петр!

# Еще примеры
def power(number, exponent=2):
    """Возводит число в степень (по умолчанию в квадрат)."""
    result = number ** exponent
    print(f"{number}^{exponent} = {result}")

power(5)     # 5^2 = 25 (используем значение по умолчанию)
power(5, 3)  # 5^3 = 125
power(2, 10) # 2^10 = 1024

Правила параметров по умолчанию

  • Параметры по умолчанию должны идти после обязательных
  • Можно сделать все параметры с умолчаниями
  • Можно сделать только последние параметры с умолчаниями
# ПРАВИЛЬНО
def func1(a, b=2, c=3):
    pass

def func2(a=1, b=2, c=3):
    pass

# НЕПРАВИЛЬНО
# def func3(a=1, b, c):  # SyntaxError!
#     pass

# Параметр с умолчанием ПЕРЕД обязательным - ошибка!

def print_banner(text, width=40, symbol="="):

Именованные аргументы (Keyword Arguments)

Можно передавать аргументы по имени параметра, а не по позиции:

def show_student(name, age, grade, city):
    """Выводит информацию о студенте."""
    print(f"Студент: {name}")
    print(f"Возраст: {age} лет")
    print(f"Класс: {grade}")
    print(f"Город: {city}")

# Позиционные аргументы (по порядку)
show_student("Иван", 16, 10, "Москва")

# Именованные аргументы (порядок не важен!)
show_student(name="Мария", city="Санкт-Петербург", age=15, grade=9)

# Можно в любом порядке!
show_student(grade=11, name="Петр", city="Казань", age=17)

# Это читаемо и понятно
show_student(
    name="Анна",
    age=16,
    grade=10,
    city="Новосибирск"
)

Преимущества именованных аргументов

  • Читаемость: Сразу видно что означает каждый аргумент
  • Порядок не важен: Можно передавать в любой последовательности
  • Безопасность: Меньше шансов перепутать параметры
  • Самодокументирование: Код объясняет сам себя
# Сравни читаемость:

# Непонятно
draw_rectangle(10, 20, "красный", True, 2)

# Понятно!
draw_rectangle(
    width=10,
    height=20,
    color="красный",
    filled=True,
    border=2
)

Смешивание позиционных и именованных

Можно комбинировать! Но ВАЖНО: позиционные должны идти ПЕРЕД именованными:

def create_user(name, age, city="Москва", active=True):
    """Создает пользователя."""
    print(f"Пользователь: {name}, {age} лет")
    print(f"Город: {city}")
    print(f"Активен: {active}")

# ПРАВИЛЬНО - позиционные, потом именованные
create_user("Иван", 16)  # Используем умолчания
create_user("Мария", 15, city="Казань")
create_user("Петр", 17, active=False)
create_user("Анна", 16, city="Санкт-Петербург", active=True)

# НЕПРАВИЛЬНО - именованный ПЕРЕД позиционным
# create_user(name="Иван", 16)  # SyntaxError!
# create_user(city="Москва", "Мария", 15)  # SyntaxError!

# ПРАВИЛЬНЫЙ порядок:
# 1. Позиционные аргументы
# 2. Именованные аргументы

Практический пример - форматирование вывода

def format_price(price, currency="₽", decimals=2, show_label=True):
    """Форматирует цену для вывода."""
    formatted = f"{price:.{decimals}f}"
    if show_label:
        return f"Цена: {formatted} {currency}"
    return f"{formatted} {currency}"

# Разные варианты вызова
print(format_price(1250))
# Цена: 1250.00 ₽

print(format_price(99.99, "$"))
# Цена: 99.99 $

print(format_price(1500, decimals=0))
# Цена: 1500 ₽

print(format_price(45.5, show_label=False))
# 45.50 ₽

print(format_price(price=2000, currency="€", decimals=0, show_label=False))
# 2000 €

def calculate(operation, a, b):
    """Выполняет математическую операцию."""
    if operation == "+":
        print(f"{a} + {b} = {a + b}")
    elif operation == "-":
        print(f"{a} - {b} = {a - b}")
    elif operation == "*":
        print(f"{a} * {b} = {a * b}")
    elif operation == "/":
        if b != 0:
            print(f"{a} / {b} = {a / b}")
        else:
            print("Ошибка: деление на ноль!")
    else:
        print("Неизвестная операция!")

calculate("+", 10, 5)  # 10 + 5 = 15
calculate("*", 7, 3)   # 7 * 3 = 21
calculate("/", 20, 4)  # 20 / 4 = 5.0

Пример 2: Генератор таблицы умножения

def print_times_table(number, max_multiplier=10):
    """Выводит таблицу умножения для числа."""
    print(f"Таблица умножения на {number}:")
    for i in range(1, max_multiplier + 1):
        print(f"{number} × {i} = {number * i}")

print_times_table(5)       # До 10
print_times_table(7, 5)    # До 5
print_times_table(number=9, max_multiplier=12)  # До 12

Связь с ОГЭ и ЕГЭ

Параметры функций - ключевой элемент программирования на экзаменах:

  • ОГЭ Задание 14: Написание функций с параметрами для обработки данных
  • ЕГЭ Задания 24-27: Сложные функции с множеством параметров
  • ЕГЭ Задание 16: Анализ рекурсивных функций с параметрами
  • Применение на экзаменах:
    • Функции обработки массивов - принимают список как параметр
    • Функции валидации - проверяют данные через параметры
    • Рекурсивные функции - передают измененные параметры
    • Функции-фильтры - критерий фильтрации как параметр
  • Важно понимать разницу позиционных и именованных аргументов
  • Знание параметров по умолчанию делает код компактнее
  • Правильное использование параметров = чистый, читаемый код

Резюме урока

  • Параметр - переменная в определении функции (в def)
  • Аргумент - значение при вызове функции
  • Синтаксис: def func(param1, param2):
  • Позиционные: порядок аргументов важен
  • По умолчанию: def func(a, b=5): - b необязателен
  • Именованные: func(name="Иван", age=16) - порядок не важен
  • Порядок в вызове: сначала позиционные, потом именованные
  • Порядок в определении: сначала обязательные, потом с умолчаниями
  • Количество: количество аргументов должно совпадать (кроме умолчаний)
  • Гибкость: параметры делают функции универсальными
  • Читаемость: именованные аргументы улучшают понимание кода
