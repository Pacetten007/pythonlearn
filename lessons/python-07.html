Урок 12: Логические операции

Введение в Python • 40 минут

Введение

В прошлом уроке мы научились использовать if для проверки простых условий: age >= 18, password == "secret". Но что делать, когда нужно проверить несколько условий одновременно?

Например: "Разрешить вход, если возраст >= 18 И есть билет". Или: "Скидка действует, если ты студент ИЛИ пенсионер". Для этого существуют логические операции!

Что мы изучим:

  • Логический тип данных: True и False
  • Оператор and (И) - все условия должны быть истинны
  • Оператор or (ИЛИ) - хотя бы одно условие истинно
  • Оператор not (НЕ) - инверсия значения
  • Таблицы истинности для каждого оператора
  • Приоритет операторов и использование скобок
  • Короткое вычисление (short-circuit evaluation)

Логический тип данных: bool

В Python есть специальный тип данных для логических значений - bool (boolean). У него всего два возможных значения:

# Два логических значения
print(True)   # Истина (первая буква ОБЯЗАТЕЛЬНО заглавная!)
print(False)  # Ложь (первая буква ОБЯЗАТЕЛЬНО заглавная!)

# Проверка типа
print(type(True))   # <class 'bool'>
print(type(False))  # <class 'bool'>

# Результат сравнения - это bool
print(5 > 3)        # True
print(10 == 100)    # False

Важно: регистр имеет значение!

# ПРАВИЛЬНО:
is_ready = True
is_active = False

# НЕПРАВИЛЬНО:
is_ready = true    # NameError! (маленькая буква)
is_active = false  # NameError! (маленькая буква)

Оператор and (И) - Логическое "И"

Оператор and возвращает True только если ОБА условия истинны. Если хотя бы одно ложно - результат False.

# Пример: вход в клуб - нужен возраст И билет
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("Добро пожаловать в клуб!")
else:
    print("Вход запрещен")

# Оба условия True → результат True → выполнится if

Таблица истинности для and

Рассмотрим все возможные комбинации:

Условие 1 Условие 2 Результат (and)
True True True
True False False
False True False
False False False 
# Примеры с and
print(True and True)    # True - оба истинны
print(True and False)   # False - второе ложно
print(False and True)   # False - первое ложно
print(False and False)  # False - оба ложны

# Реальный пример
age = 25
income = 50000

if age >= 21 and income >= 30000:
    print("Кредит одобрен!")
else:
    print("Кредит не одобрен")

Оператор or (ИЛИ) - Логическое "ИЛИ"

Оператор or возвращает True, если хотя бы одно условие истинно. Только если оба ложны - результат False.

# Пример: скидка для студентов ИЛИ пенсионеров
is_student = True
is_senior = False

if is_student or is_senior:
    print("Вы получаете скидку 20%!")
else:
    print("Полная цена")

# Хотя бы одно True → результат True → выполнится if

Таблица истинности для or

Рассмотрим все возможные комбинации:

Условие 1 Условие 2 Результат (or)
True True True
True False True
False True True
False False False 
# Примеры с or
print(True or True)     # True - оба истинны
print(True or False)    # True - первое истинно
print(False or True)    # True - второе истинно
print(False or False)   # False - оба ложны

# Реальный пример - выходной день
is_saturday = False
is_sunday = True

if is_saturday or is_sunday:
    print("Сегодня выходной!")
else:
    print("Сегодня рабочий день")

Оператор not (НЕ) - Логическое отрицание

Оператор not инвертирует (переворачивает) логическое значение: True становится False, а False становится True.

# Примеры с not
print(not True)   # False
print(not False)  # True

# Практический пример
is_raining = False

if not is_raining:
    print("Можно идти гулять!")
else:
    print("Лучше остаться дома")

# not False → True → выполнится if

Таблица истинности для not

Условие Результат (not)
True False
False True 
# Примеры использования not
is_logged_in = False

if not is_logged_in:
    print("Пожалуйста, войдите в систему")

# Двойное отрицание
print(not not True)   # True
print(not not False)  # False

Комбинирование условий

Можно создавать сложные условия, комбинируя несколько логических операторов:

# Пример 1: Диапазон значений
age = 25

if age >= 18 and age <= 65:
    print("Работоспособный возраст")

# Пример 2: Проверка на недопустимые значения
score = 150

if score < 0 or score > 100:
    print("Ошибка! Балл должен быть от 0 до 100")

# Пример 3: Сложное условие
age = 20
has_license = True
has_car = False

if age >= 18 and (has_license or has_car):
    print("Можешь водить машину")

# Пример 4: Проверка допустимого диапазона
x = 50

if not (x < 0 or x > 100):
    print("x находится в диапазоне 0-100")
    # Это то же самое, что: if x >= 0 and x <= 100:

Приоритет логических операторов

Когда в одном выражении несколько операторов, важен порядок их выполнения:

Приоритет (от высшего к низшему):

  1. not - выполняется первым
  2. and - выполняется вторым
  3. or - выполняется последним

Совет: Используй скобки для ясности, даже если они не обязательны!

# Примеры приоритета
# Без скобок
result = True or False and False
# False and False → False
# True or False → True
print(result)  # True

# Со скобками (меняем порядок)
result = (True or False) and False
# (True or False) → True
# True and False → False
print(result)  # False

# not имеет высший приоритет
result = not True or False
# not True → False
# False or False → False
print(result)  # False

# Всегда используй скобки для ясности!
age = 25
is_student = True

# Непонятно:
if age >= 18 and is_student or age < 12:
    pass

# Понятно:
if (age >= 18 and is_student) or (age < 12):
    pass

Короткое вычисление (Short-circuit evaluation)

Python использует "ленивое" вычисление логических выражений - если результат уже известен, дальнейшие проверки не выполняются.

Правила короткого вычисления:

  • and: Если первое условие False, второе не проверяется (результат уже False)
  • or: Если первое условие True, второе не проверяется (результат уже True)
# Пример с and
x = 5
# Первое условие False → второе не проверяется
if x > 10 and x < 20:
    print("Не выведется")

# Пример с or
is_admin = True
# Первое условие True → второе не проверяется
if is_admin or has_permission:  # has_permission даже не определена!
    print("Доступ разрешен")

# Практическое применение - защита от деления на ноль
divisor = 0
if divisor != 0 and 100 / divisor > 5:
    # divisor != 0 проверяется первым
    # Если divisor == 0, деление не выполнится (ошибки не будет)
    print("Результат больше 5")

# Порядок важен!
# НЕПРАВИЛЬНО:
# if 100 / divisor > 5 and divisor != 0:
#     # Сначала попытается разделить на 0 → ошибка!

Практические примеры

# Программа 1: Контроль доступа
age = int(input("Введи свой возраст: "))
has_ticket = input("Есть билет? (да/нет): ").lower() == "да"

if age >= 18 and has_ticket:
    print("✓ Добро пожаловать!")
elif age < 18:
    print("✗ Вход только для совершеннолетних")
else:
    print("✗ Нужен билет для входа")

# Программа 2: Калькулятор скидок
is_student = input("Ты студент? (да/нет): ").lower() == "да"
is_senior = input("Тебе 65+ лет? (да/нет): ").lower() == "да"
price = 1000

if is_student or is_senior:
    discount = 0.2  # 20% скидка
    final_price = price * (1 - discount)
    print(f"Скидка 20%! Цена: {final_price} руб.")
else:
    print(f"Полная цена: {price} руб.")

# Программа 3: Валидация ввода
number = int(input("Введи число от 1 до 100: "))

if number >= 1 and number <= 100:
    print("✓ Корректное число!")
    print(f"Квадрат числа: {number ** 2}")
else:
    print("✗ Ошибка! Число должно быть от 1 до 100")

# Программа 4: Игровая логика (есть ключ И дверь не заперта)
has_key = True
door_locked = False

if has_key and not door_locked:
    print("Ты открыл дверь и прошел дальше!")
elif not has_key:
    print("Нужен ключ!")
else:
    print("Дверь заперта изнутри!")

Типичные ошибки начинающих

Ошибка 1: Путаница and и or

# НЕПРАВИЛЬНО - пропускает всех!
age = 15
has_ticket = False

if age >= 18 or has_ticket:  # or вместо and!
    print("Добро пожаловать")
# 15-летний без билета пройдет? НЕТ!

# ПРАВИЛЬНО:
if age >= 18 and has_ticket:
    print("Добро пожаловать")

# Запомни:
# and - нужны ОБА условия
# or - нужно ХОТЯ БЫ ОДНО

Ошибка 2: Неправильная проверка диапазона

# НЕПРАВИЛЬНО:
x = 50
if 0 < x < 100:  # В Python это работает!
    # Но лучше явно:
    pass

# ПРАВИЛЬНО и понятно:
if x > 0 and x < 100:
    print("x в диапазоне")

# НЕПРАВИЛЬНО - синтаксическая ошибка!
if x > 0 and < 100:  # SyntaxError!
    pass

# Нужно повторять переменную:
if x > 0 and x < 100:  # Правильно!

Ошибка 3: Забыли скобки в сложных условиях

# НЕПРАВИЛЬНО - непонятный порядок
if age >= 18 and is_student or is_senior:
    # Что здесь проверяется?
    # (age >= 18 and is_student) or is_senior
    # Но это неочевидно!
    pass

# ПРАВИЛЬНО - понятно:
if (age >= 18 and is_student) or is_senior:
    print("Скидка")

# Или:
if age >= 18 and (is_student or is_senior):
    print("Скидка")

Ошибка 4: True/False с маленькой буквы

# НЕПРАВИЛЬНО:
is_ready = true   # NameError!
is_done = false   # NameError!

# ПРАВИЛЬНО (первая буква заглавная!):
is_ready = True   # ✓
is_done = False   # ✓

# В других языках может быть true/false
# В Python ТОЛЬКО True/False

Ошибка 5: Двойное отрицание

# ПЛОХОЙ стиль (хоть и работает):
is_not_ready = True

if not is_not_ready:  # Двойное отрицание - путает!
    print("Готов")

# ХОРОШИЙ стиль:
is_ready = False

if not is_ready:  # Понятно!
    print("Не готов")

# ИЛИ ЕЩЕ ЛУЧШЕ:
is_ready = True

if is_ready:  # Самый понятный вариант!
    print("Готов")

Ошибка 6: Неправильный порядок в short-circuit

# ОПАСНО:
divisor = 0
if 100 / divisor > 5 and divisor != 0:
    # Сначала деление → ошибка!
    print("Результат большой")

# ПРАВИЛЬНО:
if divisor != 0 and 100 / divisor > 5:
    # Сначала проверка → деление только если != 0
    print("Результат большой")

# Порядок условий важен для безопасности!

Связь с ОГЭ и ЕГЭ

Логические операции - ключевая тема на экзаменах по информатике:

  • ОГЭ: Задание 2 (анализ логических выражений), Задание 6 (программы с логическими условиями), Задание 14 (программирование с and/or)
  • ЕГЭ: Задание 2 (таблицы истинности), Задание 15 (логические уравнения), Задания 24-27 (программы со сложными условиями)
  • На ЕГЭ часто встречаются задачи на построение таблиц истинности и упрощение логических выражений
  • Важно знать законы де Моргана: not (A and B) = (not A) or (not B)
  • Короткое вычисление (short-circuit) может быть использовано для оптимизации кода на экзамене
  • Понимание приоритета операторов критично для правильного анализа программ

Резюме урока

  • bool: логический тип с двумя значениями - True и False (заглавные!)
  • and (И): возвращает True, только если ОБА условия True
  • or (ИЛИ): возвращает True, если ХОТЯ БЫ ОДНО условие True
  • not (НЕ): инвертирует значение (True → False, False → True)
  • Приоритет: not → and → or (используй скобки для ясности!)
  • Short-circuit: and останавливается на первом False, or на первом True
  • Таблицы истинности: помогают понять все комбинации условий
  • Комбинирование: можно создавать сложные условия из простых
  • Скобки: делают код понятнее и контролируют порядок вычисления
