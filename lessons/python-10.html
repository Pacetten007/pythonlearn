Урок 15: Строки

Введение в Python • 50 минут

Введение

Строки (strings) - это один из самых важных типов данных в программировании! Текст повсюду: имена пользователей, сообщения, email-адреса, содержимое файлов. Python предоставляет мощные инструменты для работы со строками.

До этого мы уже использовали строки с print() и input(). Теперь изучим их подробно: как обращаться к отдельным символам, вырезать части строк, изменять регистр и многое другое!

Что мы изучим:

  • Создание строк: одинарные и двойные кавычки
  • Операции со строками: сложение и умножение
  • Длина строки: функция len()
  • Индексация: доступ к отдельным символам
  • Срезы (slicing): вырезание частей строки
  • Методы строк: upper(), lower(), replace() и др.
  • Перебор символов в цикле
  • Неизменяемость строк (immutability)

Создание строк

Строку можно создать с помощью одинарных '...' или двойных "..." кавычек. Разницы почти нет - выбирай, что удобнее!

# Одинарные кавычки
text1 = 'Привет, мир!'
print(text1)

# Двойные кавычки
text2 = "Python - это круто"
print(text2)

# Оба способа дают одинаковый результат
print('Привет')  # Привет
print("Привет")  # Привет

Когда использовать одинарные vs двойные кавычки?

  • Если в тексте есть апостроф: "I'm happy" (двойные кавычки удобнее)
  • Если в тексте есть кавычки: 'Он сказал "Привет"' (одинарные удобнее)
  • В остальных случаях - без разницы! Выбирай один стиль и придерживайся его
# Примеры с апострофом и кавычками
text1 = "I'm learning Python"  # Апостроф внутри - используем двойные кавычки
text2 = 'Он сказал "Привет"'   # Кавычки внутри - используем одинарные

print(text1)  # I'm learning Python
print(text2)  # Он сказал "Привет"

Операции со строками

1. Сложение строк (конкатенация)

Оператор + склеивает (конкатенирует) строки:

# Сложение строк
first_name = "Иван"
last_name = "Иванов"
full_name = first_name + " " + last_name
print(full_name)  # Иван Иванов

# Примеры
greeting = "Привет, " + "как дела?"
print(greeting)  # Привет, как дела?

# Можно складывать много строк
message = "Я" + " " + "изучаю" + " " + "Python"
print(message)  # Я изучаю Python

2. Умножение строк

Оператор * повторяет строку несколько раз:

# Умножение строк
print("Ha" * 3)        # HaHaHa
print("=" * 20)        # ====================
print("Python! " * 4)  # Python! Python! Python! Python!

# Практическое применение - линии разделители
separator = "-" * 40
print(separator)
print("Заголовок")
print(separator)

# Вывод:
# ----------------------------------------
# Заголовок
# ----------------------------------------

Длина строки: len()

Функция len() возвращает количество символов в строке (включая пробелы!):

# Длина строки
text = "Python"
print(len(text))  # 6

text = "Привет, мир!"
print(len(text))  # 12 (пробелы и знаки препинания считаются!)

# Пустая строка
empty = ""
print(len(empty))  # 0

# Применение в условиях
password = input("Введи пароль: ")
if len(password) < 8:
    print("Пароль слишком короткий! Минимум 8 символов")
else:
    print("Пароль принят")

Индексация строк

Каждый символ в строке имеет свой номер (индекс). Python считает с 0!

# Индексация строк
text = "Python"

# Доступ по индексу: text[индекс]
print(text[0])  # P (первый символ)
print(text[1])  # y (второй символ)
print(text[2])  # t
print(text[5])  # n (последний символ)

# Схема индексов:
#  P   y   t   h   o   n
#  0   1   2   3   4   5  (положительные индексы)
# -6  -5  -4  -3  -2  -1  (отрицательные индексы)

Отрицательные индексы

Python позволяет считать с конца с помощью отрицательных индексов:

# Отрицательные индексы
text = "Python"

print(text[-1])  # n (последний символ)
print(text[-2])  # o (предпоследний)
print(text[-6])  # P (первый символ = text[0])

# Это очень удобно для доступа к концу строки!
email = "user@example.com"
print(email[-3:])  # com (последние 3 символа)

Ошибка: IndexError

Если индекс выходит за границы строки, получишь ошибку!

text = "Python"  # Индексы: 0, 1, 2, 3, 4, 5
# print(text[10])  # IndexError! Индекса 10 не существует
# print(text[6])   # IndexError! Последний индекс - 5

# Безопасная проверка
if len(text) > 10:
    print(text[10])
else:
    print("Индекс слишком большой")

Срезы (Slicing)

Срезы позволяют получить часть строки (подстроку). Синтаксис: строка[start:end]

Синтаксис срезов:

  • text[start:end] - от start до end-1 (end НЕ включается!)
  • text[:end] - с начала до end-1
  • text[start:] - от start до конца
  • text[:] - вся строка (копия)
  • text[start:end:step] - с шагом step
# Срезы строк
text = "Python Programming"

# [start:end] - от start до end-1
print(text[0:6])    # Python (символы 0, 1, 2, 3, 4, 5)
print(text[7:18])   # Programming

# [:end] - с начала до end-1
print(text[:6])     # Python (то же, что text[0:6])

# [start:] - от start до конца
print(text[7:])     # Programming

# [:] - вся строка
print(text[:])      # Python Programming

# Примеры
email = "user@example.com"
username = email[:4]      # user (первые 4 символа)
domain = email[5:]        # example.com (с 5-го до конца)
print(username)  # user
print(domain)    # example.com

Срезы с шагом

Третий параметр среза - шаг. Можно брать каждый второй символ, или идти в обратном порядке!

# Срезы с шагом [start:end:step]
text = "Python"

# Каждый второй символ
print(text[::2])    # Pto (индексы 0, 2, 4)

# Каждый второй с 1-го индекса
print(text[1::2])   # yhn (индексы 1, 3, 5)

# Обратный порядок (шаг -1)
print(text[::-1])   # nohtyP (переворот строки!)

# Практика: проверка палиндрома
word = "radar"
if word == word[::-1]:
    print(f"{word} - палиндром!")
else:
    print(f"{word} - не палиндром")

# Вывод: radar - палиндром!

Методы строк

Строки имеют множество встроенных методов для обработки текста. Метод вызывается так: строка.метод()

1. Изменение регистра

# upper() - ВСЕ ЗАГЛАВНЫЕ
text = "Python"
print(text.upper())  # PYTHON

# lower() - все строчные
text = "HELLO WORLD"
print(text.lower())  # hello world

# capitalize() - Первая заглавная, остальные строчные
text = "python programming"
print(text.capitalize())  # Python programming

# title() - Каждое Слово С Заглавной
text = "python programming language"
print(text.title())  # Python Programming Language

# swapcase() - Инверсия регистра
text = "PyThOn"
print(text.swapcase())  # pYtHoN

2. Поиск и проверка

# find() - найти позицию подстроки (-1 если не найдено)
text = "Python Programming"
print(text.find("Pro"))     # 7 (начало подстроки)
print(text.find("Java"))    # -1 (не найдено)

# count() - подсчитать количество вхождений
text = "banana"
print(text.count("a"))      # 3
print(text.count("na"))     # 2

# startswith() - начинается ли строка с подстроки
email = "admin@example.com"
print(email.startswith("admin"))  # True
print(email.startswith("user"))   # False

# endswith() - заканчивается ли строка подстрокой
filename = "document.pdf"
print(filename.endswith(".pdf"))   # True
print(filename.endswith(".txt"))   # False

# in - проверка наличия подстроки (оператор, а не метод)
text = "Hello, World!"
print("World" in text)      # True
print("Python" in text)     # False

3. Изменение содержимого

# replace() - замена подстроки
text = "Hello, World!"
new_text = text.replace("World", "Python")
print(new_text)  # Hello, Python!

# Заменить все вхождения
text = "banana"
print(text.replace("a", "o"))  # bonono

# strip() - удалить пробелы в начале и конце
text = "   Python   "
print(text.strip())       # "Python"
print(text.lstrip())      # "Python   " (только слева)
print(text.rstrip())      # "   Python" (только справа)

# split() - разбить строку на список слов
text = "Python is awesome"
words = text.split()      # Разбить по пробелам
print(words)              # ['Python', 'is', 'awesome']

# split() с разделителем
email = "user@example.com"
parts = email.split("@")
print(parts)              # ['user', 'example.com']

# join() - объединить список в строку
words = ["Python", "is", "cool"]
text = " ".join(words)
print(text)               # "Python is cool"

separator = "-"
print(separator.join(words))  # "Python-is-cool"

4. Проверочные методы (возвращают True/False)

# isdigit() - все символы цифры?
print("123".isdigit())      # True
print("12.3".isdigit())     # False (точка - не цифра)
print("abc".isdigit())      # False

# isalpha() - все символы буквы?
print("Python".isalpha())   # True
print("Python3".isalpha())  # False (есть цифра)
print("Hello World".isalpha())  # False (есть пробел)

# isalnum() - все символы буквы или цифры?
print("Python3".isalnum())  # True
print("Hello123".isalnum()) # True
print("Hello 123".isalnum())  # False (есть пробел)

# islower() - все буквы строчные?
print("python".islower())   # True
print("Python".islower())   # False

# isupper() - все буквы заглавные?
print("PYTHON".isupper())   # True
print("Python".isupper())   # False

# isspace() - только пробельные символы?
print("   ".isspace())      # True
print(" a ".isspace())      # False

Неизменяемость строк (Immutability)

ВАЖНО: строки в Python неизменяемые! Нельзя изменить отдельный символ напрямую.

# Строки неизменяемые!
text = "Python"
# text[0] = "J"  # TypeError! Нельзя изменить символ!

# Правильный способ - создать новую строку
text = "Python"
new_text = "J" + text[1:]  # "J" + "ython"
print(new_text)  # Jython

# Методы не меняют исходную строку!
text = "python"
upper_text = text.upper()
print(text)       # python (не изменилась!)
print(upper_text) # PYTHON (новая строка)

# Чтобы "изменить" строку, нужно присвоить результат:
text = "python"
text = text.upper()  # Переприсваиваем
print(text)  # PYTHON

Перебор строки в цикле

Строку можно перебрать символ за символом с помощью цикла for:

# Перебор символов
text = "Python"

for char in text:
    print(char)

# Вывод:
# P
# y
# t
# h
# o
# n

# Практика: подсчет гласных
text = "Hello World"
vowels = "aeiouAEIOU"
count = 0

for char in text:
    if char in vowels:
        count += 1

print(f"Гласных букв: {count}")  # 3

# С индексами (enumerate)
text = "Python"
for index, char in enumerate(text):
    print(f"Индекс {index}: символ '{char}'")

Форматирование строк (f-strings)

Мы уже видели f-strings в уроке Ввод и вывод. Вспомним подробнее:

# f-strings - современный способ форматирования
name = "Иван"
age = 15
print(f"Меня зовут {name}, мне {age} лет")

# Можно вставлять выражения
x = 10
y = 5
print(f"{x} + {y} = {x + y}")  # 10 + 5 = 15

# Вызов методов внутри {}
text = "python"
print(f"Заглавными: {text.upper()}")  # Заглавными: PYTHON

# Форматирование чисел
pi = 3.14159265
print(f"Число π ≈ {pi:.2f}")  # Число π ≈ 3.14 (2 знака)

Специальные символы (escape-последовательности)

# \n - переход на новую строку
print("Первая строка\nВторая строка")
# Вывод:
# Первая строка
# Вторая строка

# \t - табуляция
print("Имя:\tИван\nВозраст:\t15")
# Вывод:
# Имя:    Иван
# Возраст:    15

# \\ - обратный слеш
print("Путь: C:\\Users\\Documents")
# Вывод: Путь: C:\Users\Documents

# \' и \" - кавычки внутри строки
print("Он сказал: \"Привет!\"")
# Вывод: Он сказал: "Привет!"

Многострочные строки

# Тройные кавычки для многострочных строк
poem = """Розы красные,

Практические примеры

# Пример 1: Анализатор текста
text = input("Введи текст: ")

print(f"Длина текста: {len(text)} символов")
print(f"Слов: {len(text.split())}")
print(f"Заглавными: {text.upper()}")
print(f"Строчными: {text.lower()}")
print(f"Первая буква заглавная: {text.capitalize()}")

# Пример 2: Валидация email
email = input("Введи email: ")

if "@" in email and "." in email:
    parts = email.split("@")
    if len(parts) == 2:
        username = parts[0]
        domain = parts[1]
        print(f"✓ Email корректный")
        print(f"  Имя пользователя: {username}")
        print(f"  Домен: {domain}")
    else:
        print("✗ Некорректный email")
else:
    print("✗ Email должен содержать @ и точку")

# Пример 3: Цензор нецензурных слов
text = "Это плохое слово и еще одно плохое"
bad_words = ["плохое"]

censored = text
for word in bad_words:
    censored = censored.replace(word, "***")

print(censored)  # Это *** слово и еще одно ***

# Пример 4: Инициалы
full_name = input("Введи полное имя: ")
parts = full_name.split()

if len(parts) >= 2:
    first_name = parts[0]
    last_name = parts[1]
    initials = first_name[0] + "." + last_name[0] + "."
    print(f"Инициалы: {initials}")
else:
    print("Введи имя и фамилию")

# Пример 5: Палиндром
word = input("Введи слово: ").lower()
reversed_word = word[::-1]

if word == reversed_word:
    print(f"'{word}' - палиндром!")
else:
    print(f"'{word}' - не палиндром")

Типичные ошибки начинающих

Ошибка 1: Попытка изменить строку напрямую

# НЕПРАВИЛЬНО - строки неизменяемые!
text = "Python"
# text[0] = "J"  # TypeError!

# ПРАВИЛЬНО - создать новую строку
text = "Python"
text = "J" + text[1:]  # "Jython"
print(text)

Ошибка 2: Забыли присвоить результат метода

# НЕПРАВИЛЬНО - методы не изменяют исходную строку!
text = "python"
text.upper()  # Результат не сохранен!
print(text)   # python (не изменилась!)

# ПРАВИЛЬНО - присвоить результат
text = "python"
text = text.upper()  # Сохраняем результат
print(text)  # PYTHON

Ошибка 3: Выход за границы индекса

# НЕПРАВИЛЬНО
text = "Python"  # Индексы 0-5
# print(text[10])  # IndexError!

# ПРАВИЛЬНО - проверка перед доступом
if len(text) > 10:
    print(text[10])
else:
    print("Индекс слишком большой")

# Или использовать срезы (они не дают ошибку)
print(text[10:])  # "" (пустая строка, если индекс больше)

Ошибка 4: Путаница срезов [start:end]

# end НЕ включается!
text = "Python"

# Хочу "Pyt" (индексы 0, 1, 2)
print(text[0:3])  # ПРАВИЛЬНО: Pyt
# print(text[0:2])  # НЕПРАВИЛЬНО: Py (без t)

# Запомни: text[0:3] дает символы 0, 1, 2 (3 не включен!)

Ошибка 5: Сравнение строк с числами

# НЕПРАВИЛЬНО
age = input("Возраст: ")  # input возвращает СТРОКУ!
# if age > 18:  # TypeError! Нельзя сравнить строку и число

# ПРАВИЛЬНО - преобразовать в число
age = int(input("Возраст: "))
if age > 18:
    print("Совершеннолетний")

Ошибка 6: Использование + для строки и числа

# НЕПРАВИЛЬНО
age = 15
# print("Мне " + age + " лет")  # TypeError!

# ПРАВИЛЬНО - преобразовать число в строку
age = 15
print("Мне " + str(age) + " лет")

# ИЛИ использовать f-string (лучше!)
print(f"Мне {age} лет")

  • ЕГЭ: Задание 6 (анализ программ), Задание 9 (обработка текстовых файлов), Задания 24-27 (обработка строк, поиск подстрок)
  • На экзаменах часто встречаются задачи на:
    • Подсчет символов и подстрок
    • Поиск и замену текста
    • Разбиение строк на части
    • Проверку палиндромов
  • Важно знать индексацию (с 0!) и срезы [start:end]
  • Методы строк: upper(), lower(), replace(), split(), find()
  • Неизменяемость строк часто проверяется в заданиях на анализ кода

Резюме урока

  • Создание: одинарные 'text' или двойные "text" кавычки
  • Операции: + (сложение), * (умножение)
  • len(text): длина строки (количество символов)
  • Индексация: text[0] - первый символ, text[-1] - последний
  • Срезы: text[start:end] - от start до end-1, text[::-1] - переворот
  • Методы изменения регистра: upper(), lower(), capitalize(), title()
  • Методы поиска: find(), count(), startswith(), endswith()
  • Методы изменения: replace(), strip(), split(), join()
  • Проверки: isdigit(), isalpha(), isalnum(), islower(), isupper()
  • Неизменяемость: нельзя изменить символ напрямую, методы создают новую строку
  • Перебор: for char in text - проход по каждому символу
  • f-strings: f"Привет, {name}!" - форматирование строк
