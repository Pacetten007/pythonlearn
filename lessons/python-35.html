1. Короткое замыкание (Short-Circuit Evaluation)

Python использует короткое замыкание для логических операций. Это означает, что Python не вычисляет правую часть выражения, если результат уже известен из левой части.

1.1. Операция AND

Для операции and: если левая часть равна False, правая часть не вычисляется.

Пример короткого замыкания с AND:

# Пример 1: Левая часть False
result = False and some_function()
# some_function() НЕ будет вызвана, так как результат уже известен

# Пример 2: Левая часть True
result = True and some_function()
# some_function() БУДЕТ вызвана, так как нужно проверить правую часть

# Практический пример
def divide(a, b):
    return a / b

# Безопасная проверка деления
x = 0
y = 5

# Если x == 0, деление не выполнится (избежим ошибки!)
if x != 0 and divide(y, x) > 10:
    print("Результат больше 10")
else:
    print("Деление не выполнено или результат <= 10")

1.2. Операция OR

Для операции or: если левая часть равна True, правая часть не вычисляется.

Пример короткого замыкания с OR:

# Пример 1: Левая часть True
result = True or some_function()
# some_function() НЕ будет вызвана, так как результат уже известен

# Пример 2: Левая часть False
result = False or some_function()
# some_function() БУДЕТ вызвана, так как нужно проверить правую часть

# Практический пример
def get_default_value():
    print("Вычисление значения по умолчанию")
    return 42

x = 10

# Если x уже задан, значение по умолчанию не вычисляется
value = x or get_default_value()
print(f"Значение: {value}")  # 10 (get_default_value не вызвана)

x = 0
value = x or get_default_value()
print(f"Значение: {value}")  # 42 (get_default_value вызвана)

2. Логические значения различных типов данных

В Python все объекты имеют логическое значение. Некоторые считаются "ложными" (falsy), остальные - "истинными" (truthy).

Falsy значения (считаются False):

# Следующие значения считаются False:
False           # Логическое False
None            # Отсутствие значения
0               # Ноль (любой числовой тип)
0.0             # Ноль с плавающей точкой
0j              # Комплексный ноль
""              # Пустая строка
[]              # Пустой список
()              # Пустой кортеж
{}              # Пустой словарь
set()           # Пустое множество

# Проверка
falsy_values = [False, None, 0, 0.0, "", [], (), {}, set()]

for value in falsy_values:
    print(f"{repr(value):15} -> {bool(value)}")

Truthy значения (считаются True):

# Все остальные значения считаются True:
True            # Логическое True
1, -1, 100      # Любое ненулевое число
"hello"         # Непустая строка
[1, 2, 3]       # Непустой список
(1, 2)          # Непустой кортеж
{"a": 1}        # Непустой словарь
{1, 2, 3}       # Непустое множество

# Проверка
truthy_values = [True, 1, -1, "hello", [1], (1,), {"a": 1}, {1}]

for value in truthy_values:
    print(f"{repr(value):15} -> {bool(value)}")

3. Возвращаемые значения логических операций

В Python логические операции and и or возвращают не обязательно True или False, а последнее вычисленное значение!

Операция AND:

# AND возвращает:
# - Первое falsy значение (если есть)
# - Или последнее значение (если все truthy)

print(True and 5)        # 5 (последнее значение)
print(False and 5)       # False (первое falsy)
print(0 and 5)           # 0 (первое falsy)
print(3 and 5)           # 5 (последнее значение)
print("" and "hello")    # "" (первое falsy)
print("hi" and "hello")  # "hello" (последнее значение)

Операция OR:

# OR возвращает:
# - Первое truthy значение (если есть)
# - Или последнее значение (если все falsy)

print(True or 5)         # True (первое truthy)
print(False or 5)        # 5 (первое truthy)
print(0 or 5)            # 5 (первое truthy)
print(3 or 5)            # 3 (первое truthy)
print("" or "hello")      # "hello" (первое truthy)
print("hi" or "hello")    # "hi" (первое truthy)
print(0 or "" or None)   # None (последнее значение, все falsy)

Практическое применение:

# Установка значения по умолчанию
def greet(name=None):
    name = name or "Гость"
    print(f"Привет, {name}!")

greet("Иван")    # Привет, Иван!
greet()          # Привет, Гость!

# Проверка и получение значения
def get_first_item(items):
    return items and items[0]  # Вернет первый элемент или None

print(get_first_item([1, 2, 3]))  # 1
print(get_first_item([]))          # None (пустой список)

4. Использование логики в условиях

Логические операции широко используются в условиях для проверки различных условий.

Пример 1: Проверка множественных условий

# Проверка, что число в диапазоне и четное
number = 8

if 1 <= number <= 10 and number % 2 == 0:
    print(f"Число {number} в диапазоне [1, 10] и четное")

# Проверка, что строка не пустая и содержит только буквы
text = "Hello"

if text and text.isalpha():
    print(f"Строка '{text}' не пустая и содержит только буквы")

Пример 2: Использование OR для значений по умолчанию

# Функция с необязательным параметром
def process_data(data=None):
    data = data or []  # Если data не передан, используем пустой список
    print(f"Обработка {len(data)} элементов")

process_data([1, 2, 3])  # Обработка 3 элементов
process_data()           # Обработка 0 элементов

# Проверка наличия значения
user_name = ""
display_name = user_name or "Анонимный пользователь"
print(display_name)  # Анонимный пользователь

Пример 3: Проверка списка перед доступом

# Безопасный доступ к элементу списка
def get_item(items, index):
    # Проверяем, что список не пустой И индекс в допустимых пределах
    if items and 0 <= index < len(items):
        return items[index]
    return None

my_list = [1, 2, 3]
print(get_item(my_list, 1))    # 2
print(get_item(my_list, 10))    # None
print(get_item([], 0))          # None

5. Использование логики в циклах

Логические операции также используются в циклах для контроля выполнения.

Пример 1: Цикл с условием

# Продолжать цикл, пока список не пустой И есть элементы для обработки
items = [1, 2, 3, 4, 5]
processed = []

while items and len(processed) < 3:
    item = items.pop(0)
    processed.append(item)
    print(f"Обработан элемент: {item}")

print(f"Обработано элементов: {len(processed)}")

Пример 2: Поиск с использованием логики

# Найти первый элемент, удовлетворяющий условию
numbers = [1, 3, 5, 8, 9, 12]

# Найти первое четное число
found = None
for num in numbers:
    if num % 2 == 0:
        found = num
        break

# Или более элегантно с использованием генератора
found = next((num for num in numbers if num % 2 == 0), None)

if found:
    print(f"Найдено четное число: {found}")
else:
    print("Четных чисел не найдено")

6. Практические паттерны программирования

Паттерн 1: Значение по умолчанию

# Использование OR для установки значения по умолчанию
def calculate_total(items=None, discount=0):
    items = items or []  # Если items не передан, используем пустой список
    total = sum(items)
    return total * (1 - discount)

print(calculate_total([10, 20, 30], 0.1))  # 54.0
print(calculate_total())                   # 0.0

Паттерн 2: Проверка перед выполнением

# Выполнить действие только если условие выполнено
def safe_divide(a, b):
    # Используем короткое замыкание для безопасного деления
    return b != 0 and a / b

result = safe_divide(10, 2)
if result:
    print(f"Результат: {result}")  # Результат: 5.0

result = safe_divide(10, 0)
if not result:
    print("Деление на ноль невозможно")

Паттерн 3: Фильтрация данных

# Отфильтровать список, оставив только валидные элементы
def is_valid(item):
    # Элемент валиден, если он не None и не пустой
    return item is not None and item != ""

data = ["hello", "", None, "world", "   ", "python"]

# Фильтрация с использованием логики
valid_data = [item for item in data if is_valid(item)]
print(f"Валидные данные: {valid_data}")  # ['hello', 'world', 'python']

9. Типичные ошибки

Ошибка 1: Путаница между == и is

# НЕПРАВИЛЬНО - использование == для сравнения с None
if value == None:
    print("Значение отсутствует")

# ПРАВИЛЬНО - использование is для сравнения с None
if value is None:
    print("Значение отсутствует")

# Примечание: для других значений используй ==
if value == 0:
    print("Значение равно нулю")

Ошибка 2: Неправильное использование and/or для значений по умолчанию

# НЕПРАВИЛЬНО - если 0 это валидное значение
def process_number(num):
    num = num or 10  # Если num = 0, заменится на 10!
    return num * 2

# ПРАВИЛЬНО - явная проверка на None
def process_number(num):
    if num is None:
        num = 10
    return num * 2

# Или с использованием тернарного оператора
def process_number(num):
    num = 10 if num is None else num
    return num * 2

Ошибка 3: Игнорирование короткого замыкания

# НЕПРАВИЛЬНО - может вызвать ошибку
def get_item(items, index):
    if items[index] and items[index] > 0:  # Ошибка, если index вне диапазона
        return items[index]

# ПРАВИЛЬНО - используй короткое замыкание
def get_item(items, index):
    if 0 <= index < len(items) and items[index] > 0:
        return items[index]
    return None

Ошибка 4: Неправильное понимание возвращаемых значений

# НЕПРАВИЛЬНО - ожидание True/False
result = "hello" and "world"
if result == True:  # Это никогда не будет True!
    print("Ошибка!")

# ПРАВИЛЬНО - понимание, что возвращается последнее значение
result = "hello" and "world"
if result:  # Проверяем truthiness
    print(f"Результат: {result}")  # Результат: world

11. Резюме урока

  • Короткое замыкание - Python не вычисляет правую часть, если результат уже известен
  • Falsy значения - False, None, 0, "", [], (), {}, set() считаются False
  • Truthy значения - все остальные значения считаются True
  • AND возвращает - первое falsy значение или последнее значение
  • OR возвращает - первое truthy значение или последнее значение
  • Практическое применение - установка значений по умолчанию, безопасные проверки, фильтрация
  • Сравнение с None - используй is None, а не == None
  • Осторожность с 0 - если 0 это валидное значение, не используй or для значения по умолчанию
  • Эффективность - короткое замыкание помогает избежать ненужных вычислений
