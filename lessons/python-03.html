Урок 8: Типы данных

Введение в Python • 25 минут

Введение

Компьютеры работают с разными видами информации: числами, текстом, логическими значениями. Каждый вид информации имеет свой тип данных. Понимание типов данных - это фундамент программирования!

Представь библиотеку: книги сортируются по жанрам (фантастика, детективы, учебники). Так же и в программировании - данные разделяются на типы, и каждый тип имеет свои особенности и возможности.

Почему типы данных важны?

  • Числа можно складывать и умножать
  • Текст можно объединять и искать в нем слова
  • Логические значения используются для принятия решений
  • Python автоматически определяет тип, но ты должен понимать, как это работает!

Четыре основных типа данных

В Python есть множество типов данных, но начнем с четырех самых важных:

1. int (целые числа)

int (от англ. integer - целое число) - это тип для целых чисел без дробной части.

# Примеры целых чисел
age = 15
year = 2024
temperature = -5
points = 0
population = 1000000

Характеристики int:

  • Целые числа: без десятичной точки
  • Могут быть отрицательными: -100, -5, 0, 5, 100
  • Неограниченный диапазон: в Python 3 целые числа могут быть сколь угодно большими!
  • Применение: возраст, год, количество, индексы, счетчики

Когда использовать int:

student_count = 30        # Количество учеников
floor_number = 5          # Номер этажа
lives_remaining = 3       # Количество жизней в игре
score = 1250              # Счет в игре

2. float (вещественные числа)

float (от англ. floating point - плавающая точка) - это тип для чисел с дробной частью.

# Примеры вещественных чисел
price = 99.99
temperature = 36.6
pi = 3.14159
height = 1.75
coefficient = 0.5

Характеристики float:

  • Числа с точкой: обязательно присутствует десятичная точка (не запятая!)
  • Дробная часть: может быть любой длины
  • Научная нотация: можно писать 1.5e3 (это 1500.0)
  • Применение: цены, измерения, координаты, научные вычисления

Важно! Точность float ограничена

Компьютеры хранят вещественные числа с ограниченной точностью. Иногда возникают небольшие неточности:

print(0.1 + 0.2)  # Выведет: 0.30000000000000004
# Это нормально! Такова особенность работы компьютеров

Когда использовать float:

product_price = 149.99    # Цена товара
body_temp = 36.6          # Температура тела
distance = 5.8            # Расстояние в км
tax_rate = 0.13           # Процент налога

3. str (строки - текст)

str (от англ. string - строка) - это тип для текстовых данных.

# Примеры строк
name = "Иван"
message = 'Привет!'
city = "Москва"
email = "student@example.com"
text = "Я изучаю Python"

Характеристики str:

  • Текст в кавычках: можно использовать "двойные" или 'одинарные'
  • Любые символы: буквы, цифры, пробелы, знаки препинания
  • Неизменяемость: нельзя изменить отдельный символ, только создать новую строку
  • Применение: имена, сообщения, адреса, любой текст

Различные способы создания строк:

# Одинарные кавычки
greeting = 'Привет'

# Двойные кавычки
farewell = "До свидания"

# Кавычки внутри строки
quote = "Он сказал: 'Привет!'"
another = 'Книга "Python для начинающих"'

# Многострочный текст
poem = """Строка 1
Строка 2
Строка 3"""

Строки могут содержать цифры!

age_number = 15      # Это число int
age_text = "15"      # Это строка str

# Будь внимателен:
print(age_number + 5)  # 20 (математическое сложение)
print(age_text + "5")  # "155" (объединение строк)

4. bool (логический тип)

bool (от англ. boolean - логический) - это тип для истинности или ложности утверждений.

# Примеры логических значений
is_student = True
has_license = False
game_over = False
is_adult = True
is_raining = False

Характеристики bool:

  • Только два значения: True (истина) или False (ложь)
  • Пишутся с большой буквы: именно True и False, не true или false
  • Результат сравнений: 5 > 3 даст True, 2 > 10 даст False
  • Применение: флаги, условия, проверки, да/нет вопросы

Когда использовать bool:

is_logged_in = True       # Пользователь вошел?
has_permission = False    # Есть разрешение?
is_premium = True         # Премиум аккаунт?
game_running = True       # Игра запущена?

# Bool часто получается из сравнений:
is_adult = age >= 18      # True если возраст 18 или больше
is_passing = score >= 60  # True если набрано 60+ очков

Функция type() - проверка типа

Как узнать, какого типа переменная? Используй функцию type()!

# Проверяем типы разных значений
print(type(42))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("Hello"))    # <class 'str'>
print(type(True))       # <class 'bool'>

# Проверяем типы переменных
age = 15
name = "Иван"
print(type(age))        # <class 'int'>
print(type(name))       # <class 'str'>

Важные примеры с type():

# Внимание на эти случаи!
print(type(5))      # int - целое число
print(type(5.0))    # float - есть точка!
print(type("5"))    # str - в кавычках!

# Даже если в строке число, это строка!
number_text = "123"
print(type(number_text))  # str

# True и False - это bool
print(type(True))   # bool
print(type(False))  # bool

Преобразование типов

Иногда нужно изменить тип данных. Например, превратить строку в число или число в строку. Это называется преобразованием типов.

int() - преобразование в целое число

# Из строки в int
age_text = "15"
age_number = int(age_text)
print(age_number)       # 15
print(type(age_number)) # <class 'int'>

# Из float в int (дробная часть отбрасывается!)
price = 99.99
price_int = int(price)
print(price_int)        # 99 (не округление, а отбрасывание!)

# Еще примеры
print(int("123"))       # 123
print(int(5.7))         # 5
print(int(5.2))         # 5
print(int(-3.9))        # -3

Ошибки при преобразовании в int:

# Эти команды вызовут ошибку:
# int("hello")      # ValueError: нельзя превратить текст в число
# int("3.14")       # ValueError: нельзя напрямую из строки с точкой
# int("12abc")      # ValueError: смешанное содержимое

# Правильный способ для "3.14":
print(int(float("3.14")))  # Сначала в float, потом в int: 3

Правило: int() работает только со строками, содержащими целые числа, или с числами типа float.

float() - преобразование в вещественное число

# Из строки в float
price_text = "99.99"
price_number = float(price_text)
print(price_number)       # 99.99
print(type(price_number)) # <class 'float'>

# Из int в float
count = 5
count_float = float(count)
print(count_float)        # 5.0

# Еще примеры
print(float("3.14"))      # 3.14
print(float("100"))       # 100.0
print(float(42))          # 42.0
print(float("-5.5"))      # -5.5

str() - преобразование в строку

# Из int в str
age = 15
age_text = str(age)
print(age_text)           # "15"
print(type(age_text))     # <class 'str'>

# Из float в str
price = 99.99
price_text = str(price)
print(price_text)         # "99.99"

# Из bool в str
flag = True
flag_text = str(flag)
print(flag_text)          # "True"

# Еще примеры
print(str(123))           # "123"
print(str(3.14))          # "3.14"
print(str(False))         # "False"

Зачем преобразовывать в строку?

Чтобы объединять с другим текстом:

age = 15

# Это вызовет ошибку:
# message = "Мне " + age + " лет"  # TypeError!

# Правильно:
message = "Мне " + str(age) + " лет"
print(message)  # "Мне 15 лет"

bool() - преобразование в логический тип

Любое значение в Python можно преобразовать в bool. Есть простое правило:

Что становится False:

  • Число 0 (ноль)
  • Пустая строка ""
  • None (специальное значение "ничего")
  • Пустые коллекции (изучим позже)

Все остальное становится True!

# Что дает False
print(bool(0))          # False
print(bool(0.0))        # False
print(bool(""))         # False (пустая строка)

# Что дает True
print(bool(1))          # True
print(bool(-5))         # True
print(bool(3.14))       # True
print(bool("Hello"))    # True
print(bool("0"))        # True (непустая строка!)

Когда нужно преобразовывать типы?

1. Пользовательский ввод - всегда строка!

Функция input() (которую мы изучим подробно позже) всегда возвращает строку:

# Вводим возраст
age = input("Сколько тебе лет? ")
# age - это строка! Даже если ввели "15"

# Чтобы использовать как число, нужно преобразовать:
age_number = int(age)
next_year = age_number + 1
print("Через год тебе будет", next_year)

2. Вычисления требуют чисел

a = "10"
b = "20"

# Это не сработает как ожидается:
print(a + b)      # "1020" (объединение строк)

# Правильно:
print(int(a) + int(b))  # 30 (математическое сложение)

3. Вывод требует строк (или автоматически преобразует)

score = 100

# Так можно (print сам преобразует):
print("Счет:", score)

# Но если объединяем строки, нужно преобразовать:
message = "Твой счет: " + str(score) + " очков"
print(message)

Типичные ошибки начинающих

Ошибка 1: Сложение строки и числа

# НЕПРАВИЛЬНО:
age = 15
print("Мне " + age + " лет")  # TypeError!

# ПРАВИЛЬНО:
print("Мне " + str(age) + " лет")
# ИЛИ (еще проще):
print("Мне", age, "лет")

Python не может автоматически преобразовать число в строку при использовании оператора + для строк.

Ошибка 2: int() с дробными числами в строке

# НЕПРАВИЛЬНО:
price = "99.99"
price_int = int(price)  # ValueError!

# ПРАВИЛЬНО:
price_int = int(float(price))  # Сначала в float, потом в int
print(price_int)  # 99

Ошибка 3: Путаница между 3.0 и 3

# Это разные типы!
a = 3      # int
b = 3.0    # float

print(type(a))  # <class 'int'>
print(type(b))  # <class 'float'>

# Но значения равны:
print(a == b)   # True

Наличие десятичной точки делает число типом float, даже если дробная часть равна нулю!

Ошибка 4: true/false вместо True/False

# НЕПРАВИЛЬНО:
is_student = true   # NameError: имя 'true' не определено

# ПРАВИЛЬНО:
is_student = True   # С большой буквы!

В Python логические значения пишутся с заглавной буквы: True и False.

Ошибка 5: int() отбрасывает, а не округляет!

# Внимание!
print(int(3.9))    # 3, не 4!
print(int(5.1))    # 5
print(int(7.99))   # 7

# int() просто отбрасывает дробную часть
# Для округления используй round():
print(round(3.9))  # 4
print(round(5.1))  # 5

Ошибка 6: Забыли, что "5" + 5 не работает

# НЕПРАВИЛЬНО:
text = "5"
result = text + 5  # TypeError!

# ПРАВИЛЬНО (зависит от цели):
result1 = int(text) + 5    # 10 (математика)
result2 = text + str(5)    # "55" (объединение строк)

Резюме урока

  • int - целые числа: 15, -5, 0, 1000
  • float - числа с десятичной точкой: 3.14, 99.99, -0.5
  • str - текст в кавычках: "Hello", 'Python', "123"
  • bool - логические значения: True или False (с большой буквы!)
  • type() - функция для проверки типа переменной
  • int() - преобразует в целое число (отбрасывает дробную часть!)
  • float() - преобразует в вещественное число
  • str() - преобразует в строку
  • bool() - преобразует в логический тип (0 и "" дают False, остальное True)
  • Нельзя складывать строку и число без преобразования
  • 3.0 и 3 - это разные типы (float и int), но равные значения
