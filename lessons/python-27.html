Введение

CSV (Comma-Separated Values) - один из самых популярных форматов для хранения табличных данных. Его используют везде:

  • Excel и Google Таблицы - экспортируют и импортируют CSV
  • Базы данных - выгрузка данных в CSV
  • Научные данные - результаты экспериментов
  • Веб-приложения - обмен данными
  • Машинное обучение - датасеты часто в CSV

  • Установи Python локально

Что такое CSV?

CSV - это текстовый формат, где:

  • Значения разделены запятыми (или другими символами)
  • Каждая строка - одна запись
  • Первая строка часто содержит заголовки

Пример CSV-файла:

# students.csv
Имя,Возраст,Оценка
Иван,15,5
Мария,16,4
Петр,15,5
Анна,16,3

Это таблица:

Имя Возраст Оценка
Иван 15 5
Мария 16 4
Петр 15 5
Анна 16 3

Ручное чтение CSV через split()

Простейший способ - использовать метод split(","):

with open("students.csv", "r", encoding="utf-8") as file:
    # Читаем заголовок
    headers = file.readline().strip().split(",")
    print("Заголовки:", headers)

    # Читаем данные
    for line in file:
        values = line.strip().split(",")
        name, age, grade = values
        print(f"{name}: возраст {age}, оценка {grade}")

Вывод:

Заголовки: ['Имя', 'Возраст', 'Оценка']
Иван: возраст 15, оценка 5
Мария: возраст 16, оценка 4
Петр: возраст 15, оценка 5
Анна: возраст 16, оценка 3

⚠️ Ограничения split():

  • Не работает, если в данных есть запятые
  • Не обрабатывает кавычки правильно
  • Для простых CSV - подходит, для сложных - используй модуль csv

Модуль csv - Чтение файлов

Модуль csv - правильный способ работы с CSV:

import csv

with open("students.csv", "r", encoding="utf-8") as file:
    reader = csv.reader(file)

    # Читаем заголовок
    headers = next(reader)
    print("Заголовки:", headers)

    # Читаем данные
    for row in reader:
        name, age, grade = row
        print(f"{name}: возраст {age}, оценка {grade}")

Преимущества csv.reader():

  • Правильно обрабатывает кавычки - "Иванов, Иван" не разобьется
  • Работает с разными разделителями
  • Экранирует специальные символы
  • Стандартный и надежный

csv.DictReader - Чтение со словарями

DictReader автоматически создает словари из строк:

import csv

with open("students.csv", "r", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for row in reader:
        # row - это словарь!
        print(f"{row['Имя']}: возраст {row['Возраст']}, оценка {row['Оценка']}")

Зачем DictReader?

  • Доступ по именам - row['Имя'] вместо row[0]
  • Понятнее код - сразу видно, что это
  • Порядок не важен - можно менять колонки
  • Удобно для больших таблиц

Запись CSV - csv.writer()

Для записи используем csv.writer():

import csv

data = [
    ["Имя", "Возраст", "Город"],
    ["Иван", 25, "Москва"],
    ["Мария", 30, "Санкт-Петербург"],
    ["Петр", 28, "Казань"]
]

with open("people.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(data)  # Записываем все строки сразу

print("Файл people.csv создан!")

⚠️ Важный параметр newline=""!

В Windows без newline="" будут лишние пустые строки!

# ПРАВИЛЬНО
with open("file.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)

Запись построчно:

import csv

with open("grades.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)

    # Записываем заголовок
    writer.writerow(["Студент", "Предмет", "Оценка"])

    # Записываем данные
    writer.writerow(["Иван", "Математика", 5])
    writer.writerow(["Мария", "Физика", 4])
    writer.writerow(["Петр", "Информатика", 5])

csv.DictWriter - Запись со словарями

DictWriter позволяет писать словари:

import csv

data = [
    {"name": "Иван", "age": 25, "city": "Москва"},
    {"name": "Мария", "age": 30, "city": "СПб"},
    {"name": "Петр", "age": 28, "city": "Казань"}
]

with open("people.csv", "w", encoding="utf-8", newline="") as file:
    # Указываем названия полей
    fieldnames = ["name", "age", "city"]
    writer = csv.DictWriter(file, fieldnames=fieldnames)

    # Записываем заголовок
    writer.writeheader()

    # Записываем данные
    writer.writerows(data)

Разные разделители

Не всегда используется запятая. Популярны:

  • Точка с запятой (;) - в Excel на русском
  • Табуляция (\t) - TSV файлы
  • Вертикальная черта (|) - иногда в БД

Чтение с другим разделителем:

import csv

# Файл с разделителем "точка с запятой"
with open("data.csv", "r", encoding="utf-8") as file:
    reader = csv.reader(file, delimiter=";")
    for row in reader:
        print(row)

Запись с другим разделителем:

import csv

with open("data.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file, delimiter=";")
    writer.writerow(["Имя", "Город"])
    writer.writerow(["Иван", "Москва"])

Кодировка для русского текста

Всегда используй encoding="utf-8" для русского:

# ПРАВИЛЬНО - UTF-8 для русского
with open("data.csv", "r", encoding="utf-8") as file:
    reader = csv.reader(file)

# Для старых файлов Excel может понадобиться cp1251
with open("old_excel.csv", "r", encoding="cp1251") as file:
    reader = csv.reader(file)

Практические примеры

Пример 1: Таблица оценок студентов

import csv

# Создаем таблицу оценок
grades = [
    ["Студент", "Математика", "Физика", "Информатика"],
    ["Иван Петров", 5, 4, 5],
    ["Мария Сидорова", 4, 5, 5],
    ["Петр Иванов", 5, 5, 4],
    ["Анна Смирнова", 3, 4, 4]
]

# Записываем в файл
with open("grades.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(grades)

# Читаем и анализируем
with open("grades.csv", "r", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for row in reader:
        name = row['Студент']
        avg = (int(row['Математика']) + int(row['Физика']) +
               int(row['Информатика'])) / 3
        print(f"{name}: средний балл {avg:.1f}")

Пример 2: Инвентарь товаров

import csv

# Товары
products = [
    {"id": 1, "name": "Ноутбук", "price": 50000, "quantity": 10},
    {"id": 2, "name": "Мышь", "price": 500, "quantity": 50},
    {"id": 3, "name": "Клавиатура", "price": 1500, "quantity": 30},
    {"id": 4, "name": "Монитор", "price": 15000, "quantity": 15}
]

# Записываем
with open("inventory.csv", "w", encoding="utf-8", newline="") as file:
    fieldnames = ["id", "name", "price", "quantity"]
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(products)

# Читаем и подсчитываем общую стоимость
total_value = 0
with open("inventory.csv", "r", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    print("Товары на складе:")
    for row in reader:
        value = int(row['price']) * int(row['quantity'])
        total_value += value
        print(f"{row['name']}: {row['quantity']} шт, "
              f"стоимость {value:,} руб")

print(f"\nОбщая стоимость: {total_value:,} руб")

Пример 3: Результаты опроса

import csv

# Сбор результатов опроса
survey_results = []

print("Опрос: Ваш любимый язык программирования?")
print("Введите 'стоп' для завершения")

while True:
    name = input("Ваше имя: ")
    if name.lower() == "стоп":
        break

    language = input("Любимый язык: ")
    experience = input("Опыт (лет): ")

    survey_results.append([name, language, experience])

# Сохраняем результаты
with open("survey.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Имя", "Язык", "Опыт"])
    writer.writerows(survey_results)

print(f"\nСохранено {len(survey_results)} ответов в survey.csv")

Типичные ошибки начинающих

Ошибка 1: Забыл newline="" при записи

# НЕПРАВИЛЬНО - будут пустые строки в Windows
with open("data.csv", "w", encoding="utf-8") as file:
    writer = csv.writer(file)

# ПРАВИЛЬНО - всегда указывай newline=""
with open("data.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)

Ошибка 2: Не указал кодировку

# НЕПРАВИЛЬНО - проблемы с русским текстом
with open("data.csv", "r") as file:
    reader = csv.reader(file)

# ПРАВИЛЬНО - указывай encoding="utf-8"
with open("data.csv", "r", encoding="utf-8") as file:
    reader = csv.reader(file)

Ошибка 3: Неправильный разделитель

# Файл использует точку с запятой
# НЕПРАВИЛЬНО - будет одна колонка
reader = csv.reader(file)

# ПРАВИЛЬНО - указывай delimiter
reader = csv.reader(file, delimiter=";")

Ошибка 4: Используешь split() для сложных CSV

# Данные: "Иванов, Иван",25,Москва
# НЕПРАВИЛЬНО - разобьет имя на части
values = line.split(",")  # ["Иванов", " Иван\"", "25", "Москва"]

# ПРАВИЛЬНО - используй модуль csv
reader = csv.reader(file)  # Правильно обработает кавычки

Ошибка 5: Забыл про заголовок при чтении

# НЕПРАВИЛЬНО - первая строка попадет в данные
for row in csv.reader(file):
    process(row)  # Заголовок обработается как данные!

# ПРАВИЛЬНО - пропусти заголовок
reader = csv.reader(file)
next(reader)  # Пропускаем заголовок
for row in reader:
    process(row)

Ошибка 6: Не закрыл файл при записи

# НЕПРАВИЛЬНО - данные могут не записаться
file = open("data.csv", "w", encoding="utf-8", newline="")
writer = csv.writer(file)
writer.writerow(["test"])
# Забыли file.close()!

# ПРАВИЛЬНО - используй with
with open("data.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["test"])
# Автоматически закроется!

Резюме урока
