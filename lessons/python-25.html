Урок 30: Запись в файлы

Работа с файлами • 40 минут

Введение

В прошлом уроке мы научились читать файлы. Но что если нужно сохранить данные? Записать результаты работы программы, создать отчет, сохранить настройки пользователя? Для этого используется запись в файлы!

Запись в файлы позволяет:

  • Сохранять результаты - программа может создавать отчеты и логи
  • Хранить данные постоянно - информация не теряется после закрытия программы
  • Экспортировать данные - для использования в других программах
  • Создавать конфигурационные файлы - настройки приложения
  • Вести журналы - логирование действий пользователя

⚠️ Важно для Skulpt!

Запись в файлы в браузерном редакторе Skulpt не поддерживается. Для работы с файлами тебе нужно запускать код локально на своем компьютере с установленным Python.

Но изучать синтаксис и понимать принципы работы можно прямо здесь!

Что изучим в этом уроке:

  • Режимы записи: "w", "a", "x"
  • Метод write() - запись строк
  • Метод writelines() - запись списка строк
  • Опасность режима "w" - перезапись файла!
  • Режим "a" - добавление в конец файла
  • Запись разных типов данных
  • Создание новых файлов
  • Лучшие практики при записи

Режимы записи файлов

При открытии файла для записи используются следующие режимы:

Режим Название Поведение
"w" Write (запись) Создает новый или ПЕРЕЗАПИСЫВАЕТ существующий!
"a" Append (добавление) Добавляет в конец, НЕ удаляя содержимое
"x" Exclusive create Создает новый, ошибка если файл существует

⚠️ ОПАСНОСТЬ режима "w"!

Режим "w" УДАЛЯЕТ все содержимое файла при открытии! Будь осторожен!

Метод write() - Запись строки

Метод write() записывает строку в файл:

# Запись в файл
with open("output.txt", "w", encoding="utf-8") as file:
    file.write("Привет, мир!\n")
    file.write("Это вторая строка.\n")

# Файл output.txt теперь содержит:
# Привет, мир!
# Это вторая строка.

Важно знать про write():

  • НЕ добавляет \n автоматически - нужно добавлять вручную!
  • Принимает только строки - другие типы нужно конвертировать
  • Возвращает количество записанных символов
  • Можно вызывать многократно - строки добавляются по порядку

Примеры write():

# Пример 1: Простая запись
with open("hello.txt", "w", encoding="utf-8") as file:
    file.write("Привет!\n")

# Пример 2: Несколько строк
with open("poem.txt", "w", encoding="utf-8") as file:
    file.write("У лукоморья дуб зелёный,\n")
    file.write("Златая цепь на дубе том.\n")
    file.write("И днём и ночью кот учёный\n")
    file.write("Всё ходит по цепи кругом.\n")

# Пример 3: Без \n (всё в одну строку!)
with open("oneline.txt", "w", encoding="utf-8") as file:
    file.write("Первая часть ")
    file.write("Вторая часть ")
    file.write("Третья часть")
# Файл содержит: Первая часть Вторая часть Третья часть

Метод writelines() - Запись списка строк

Метод writelines() записывает список строк в файл:

lines = [
    "Первая строка\n",
    "Вторая строка\n",
    "Третья строка\n"
]

with open("output.txt", "w", encoding="utf-8") as file:
    file.writelines(lines)

Важно про writelines():

  • Тоже НЕ добавляет \n - нужно включить в строки списка!
  • Принимает любой итерируемый объект - список, кортеж, и т.д.
  • Быстрее чем много write() - для большого количества строк
# Пример: Сохранить список студентов
students = ["Иван Петров", "Мария Сидорова", "Петр Иванов"]

with open("students.txt", "w", encoding="utf-8") as file:
    # Добавляем \n к каждому имени
    lines = [name + "\n" for name in students]
    file.writelines(lines)

# Или короче с генератором:
with open("students.txt", "w", encoding="utf-8") as file:
    file.writelines(name + "\n" for name in students)

Режим "w" - Перезапись файла

Режим "w" создает новый файл или ПОЛНОСТЬЮ ПЕРЕЗАПИСЫВАЕТ существующий!

# Создаем файл с данными
with open("important.txt", "w", encoding="utf-8") as file:
    file.write("Важные данные\n")
    file.write("Не удалять!\n")

# ОПАСНО! Это УДАЛИТ предыдущее содержимое!
with open("important.txt", "w", encoding="utf-8") as file:
    file.write("Новые данные\n")

# Теперь файл содержит только "Новые данные"
# Старые данные потеряны навсегда!

⚠️ Будь осторожен с "w"!

Режим "w":

  • Немедленно УДАЛЯЕТ все содержимое при открытии
  • Даже если ты ничего не запишешь, файл станет пустым!
  • Нет способа вернуть удаленные данные
  • Используй "a" если хочешь добавить, а не заменить

Когда использовать "w":

  • Создание нового файла - когда файла точно нет
  • Полная перезапись - когда старые данные не нужны
  • Генерация отчетов - каждый раз создается заново
  • Временные файлы - которые регулярно пересоздаются

Режим "a" - Добавление в конец

Режим "a" (append) добавляет данные в конец файла, не удаляя существующее содержимое:

# Создаем файл с начальными данными
with open("log.txt", "w", encoding="utf-8") as file:
    file.write("=== Лог программы ===\n")

# Добавляем записи (НЕ удаляя предыдущее!)
with open("log.txt", "a", encoding="utf-8") as file:
    file.write("Программа запущена\n")

# Добавляем еще записи
with open("log.txt", "a", encoding="utf-8") as file:
    file.write("Пользователь вошел в систему\n")
    file.write("Файл загружен\n")

# Файл log.txt содержит:
# === Лог программы ===
# Программа запущена
# Пользователь вошел в систему
# Файл загружен

Когда использовать "a":

  • Логи - постоянное добавление записей
  • Накопление данных - сбор информации со временем
  • Дополнение файла - когда нужно сохранить старое
  • Журналы - история событий

✅ Безопасность режима "a":

Режим "a" безопасен - он НИКОГДА не удаляет существующие данные. Если файл не существует, он будет создан.

Режим "x" - Эксклюзивное создание

Режим "x" создает файл только если его еще НЕ существует. Если файл есть - выдает ошибку:

try:
    with open("newfile.txt", "x", encoding="utf-8") as file:
        file.write("Это новый файл\n")
    print("Файл успешно создан!")
except FileExistsError:
    print("Файл уже существует!")

Когда использовать "x":

  • Защита от перезаписи - гарантия, что не удалишь существующий файл
  • Уникальные файлы - когда нужна гарантия новизны
  • Критичные данные - безопасность от случайного удаления

Запись разных типов данных

Метод write() принимает только строки! Другие типы нужно конвертировать:

Запись чисел:

number = 42
price = 99.99

with open("numbers.txt", "w", encoding="utf-8") as file:
    # НЕПРАВИЛЬНО - ошибка!
    # file.write(number)  # TypeError!

    # ПРАВИЛЬНО - конвертируем в строку
    file.write(str(number) + "\n")
    file.write(str(price) + "\n")

    # Или с f-строками:
    file.write(f"Число: {number}\n")
    file.write(f"Цена: {price} руб.\n")

Запись списков:

scores = [85, 92, 78, 95, 88]

with open("scores.txt", "w", encoding="utf-8") as file:
    # Способ 1: По одному элементу
    for score in scores:
        file.write(str(score) + "\n")

    # Способ 2: Все в одну строку
    file.write(" ".join(map(str, scores)) + "\n")

    # Способ 3: С описанием
    for i, score in enumerate(scores, 1):
        file.write(f"Тест {i}: {score} баллов\n")

Запись словарей:

config = {
    "username": "admin",
    "port": 8080,
    "debug": True
}

with open("config.txt", "w", encoding="utf-8") as file:
    for key, value in config.items():
        file.write(f"{key}={value}\n")

Создание новых файлов

Режимы "w", "a" и "x" создают файл автоматически, если он не существует:

# Режим "w" - создает или перезаписывает
with open("new_file.txt", "w", encoding="utf-8") as file:
    file.write("Новый файл создан!\n")

# Режим "a" - создает или добавляет
with open("log_file.txt", "a", encoding="utf-8") as file:
    file.write("Первая запись в логе\n")

# Режим "x" - создает, ошибка если существует
try:
    with open("unique_file.txt", "x", encoding="utf-8") as file:
        file.write("Уникальный файл\n")
except FileExistsError:
    print("Файл уже есть!")

Практические примеры

Пример 1: Сохранение списка покупок

shopping_list = [
    "Молоко - 2 литра",
    "Хлеб - 1 батон",
    "Яйца - 10 штук",
    "Сыр - 500 грамм"
]

# Сохраняем список в файл
with open("shopping.txt", "w", encoding="utf-8") as file:
    file.write("=== Список покупок ===\n\n")
    for i, item in enumerate(shopping_list, 1):
        file.write(f"{i}. {item}\n")

print("Список покупок сохранен в shopping.txt")

Пример 2: Журнал событий (лог)

from datetime import datetime

def log_event(message):
    """Добавляет событие в лог-файл"""
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

    with open("events.log", "a", encoding="utf-8") as file:
        file.write(f"[{timestamp}] {message}\n")

# Использование
log_event("Программа запущена")
log_event("Пользователь вошел в систему")
log_event("Файл загружен успешно")
log_event("Программа завершена")

Пример 3: Сохранение результатов теста

students = [
    {"name": "Иван", "score": 85},
    {"name": "Мария", "score": 92},
    {"name": "Петр", "score": 78},
    {"name": "Анна", "score": 95}
]

# Сохраняем отчет
with open("results.txt", "w", encoding="utf-8") as file:
    file.write("=== Результаты тестирования ===\n\n")

    for student in students:
        name = student["name"]
        score = student["score"]

        # Определяем оценку
        if score >= 90:
            grade = "Отлично"
        elif score >= 80:
            grade = "Хорошо"
        elif score >= 70:
            grade = "Удовлетворительно"
        else:
            grade = "Неудовлетворительно"

        file.write(f"{name}: {score} баллов ({grade})\n")

    # Добавляем статистику
    avg_score = sum(s["score"] for s in students) / len(students)
    file.write(f"\nСредний балл: {avg_score:.2f}\n")

print("Результаты сохранены в results.txt")

Лучшие практики

✅ Рекомендации при записи в файлы:

  • Всегда используй with - гарантирует закрытие файла
  • Указывай encoding="utf-8" - для русского текста
  • Добавляй \n вручную - write() не делает это автоматически
  • Используй "a" для логов - безопасное добавление
  • Проверяй существование для "w" - чтобы не удалить важные данные
  • Конвертируй типы в строки - используй str() или f-strings

Проверка существования файла:

import os

filename = "important.txt"

# Проверка перед перезаписью
if os.path.exists(filename):
    response = input(f"Файл {filename} существует. Перезаписать? (да/нет): ")
    if response.lower() != "да":
        print("Отмена.")
        exit()

# Теперь безопасно записываем
with open(filename, "w", encoding="utf-8") as file:
    file.write("Новые данные\n")

Типичные ошибки начинающих

Ошибка 1: Забыл добавить \n

# НЕПРАВИЛЬНО - все в одну строку!
with open("text.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка")
    file.write("Вторая строка")
# Файл содержит: Первая строкаВторая строка

# ПРАВИЛЬНО - добавляем \n
with open("text.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка\n")
    file.write("Вторая строка\n")

Ошибка 2: Используешь "w" вместо "a"

# НЕПРАВИЛЬНО - каждый раз перезаписывает файл!
for i in range(10):
    with open("log.txt", "w", encoding="utf-8") as file:
        file.write(f"Итерация {i}\n")
# В файле останется только "Итерация 9"

# ПРАВИЛЬНО - используй "a" для добавления
for i in range(10):
    with open("log.txt", "a", encoding="utf-8") as file:
        file.write(f"Итерация {i}\n")

Ошибка 3: Не конвертируешь в строку

# НЕПРАВИЛЬНО - write() принимает только строки!
number = 42
with open("num.txt", "w") as file:
    file.write(number)  # TypeError!

# ПРАВИЛЬНО - конвертируй в строку
with open("num.txt", "w", encoding="utf-8") as file:
    file.write(str(number) + "\n")

Ошибка 4: Случайно удалил важный файл режимом "w"

# ОПАСНО - удаляет все данные!
with open("important_data.txt", "w", encoding="utf-8") as file:
    # Даже если ничего не запишешь, файл стал пустым!
    pass

# БЕЗОПАСНЕЕ - используй "x" или проверяй существование
import os
if not os.path.exists("important_data.txt"):
    with open("important_data.txt", "w", encoding="utf-8") as file:
        file.write("Новые данные\n")

# НЕПРАВИЛЬНО - проблемы с русским текстом

with open("russian.txt", "w", encoding="utf-8") as file:

Ошибка 6: Лишние \n в writelines()

# НЕПРАВИЛЬНО - двойные переводы строк!
lines = ["Первая\n", "Вторая\n", "Третья\n"]
with open("text.txt", "w", encoding="utf-8") as file:
    for line in lines:
        file.writelines(line + "\n")  # Лишний \n!

# ПРАВИЛЬНО - \n уже в строках
lines = ["Первая\n", "Вторая\n", "Третья\n"]
with open("text.txt", "w", encoding="utf-8") as file:
    file.writelines(lines)

Резюме урока

  • Режим "w" - перезаписывает файл (ОПАСНО!)
  • Режим "a" - добавляет в конец (безопасно)
  • Режим "x" - создает новый, ошибка если существует
  • write(string) - записывает строку (НЕ добавляет \n!)
  • writelines(list) - записывает список строк
  • Конвертация типов - используй str() или f-strings
  • Всегда with - автоматически закрывает файл
  • encoding="utf-8" - для русского текста
  • Добавляй \n вручную - write() не делает это автоматически
  • "a" для логов - безопасное накопление данных
