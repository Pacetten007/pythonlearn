1. Работа с символами строки

В Python строки можно обрабатывать как последовательности символов. Каждый символ имеет свой индекс.

Задача ОГЭ 1: Доступ к символам

Условие: Данная строка s = "Python". Что выведет программа?
print(s[0])
print(s[2])
print(s[-1])

Решение:
s = "Python"
s[0] = 'P'  (первый символ, индекс 0)
s[2] = 't'  (третий символ, индекс 2)
s[-1] = 'n' (последний символ, отрицательный индекс)

Ответ:
P
t
n

Проверка в Python:
s = "Python"
print(f"s[0] = '{s[0]}'")   # P
print(f"s[2] = '{s[2]}'")   # t
print(f"s[-1] = '{s[-1]}'") # n

Задача ОГЭ 2: Длина строки

Условие: Данная строка s = "Hello". Что выведет программа?
print(len(s))

Решение:
s = "Hello"
Длина строки = количество символов = 5

Ответ: 5

Проверка в Python:
s = "Hello"
print(f"Длина строки '{s}': {len(s)}")  # 5

2. Поиск и подсчет символов

В задачах ОГЭ часто нужно найти или подсчитать определенные символы в строке.

Задача ОГЭ 3: Подсчет символов

Условие: Напишите программу, которая подсчитывает количество букв 'a' в строке "banana".

Решение:
s = "banana"
count = 0
for i in range(len(s)):
    if s[i] == 'a':
        count = count + 1
print(count)

Решение пошагово:
1. count = 0
2. i=0: s[0]='b', 'b' != 'a', count остается 0
3. i=1: s[1]='a', 'a' == 'a', count = 1
4. i=2: s[2]='n', 'n' != 'a', count остается 1
5. i=3: s[3]='a', 'a' == 'a', count = 2
6. i=4: s[4]='n', 'n' != 'a', count остается 2
7. i=5: s[5]='a', 'a' == 'a', count = 3

Ответ: 3

Проверка в Python:
s = "banana"
count = 0
for i in range(len(s)):
    if s[i] == 'a':
        count = count + 1
        print(f"Найдена 'a' на позиции {i}, всего: {count}")
print(f"Итого букв 'a': {count}")  # 3

Задача ОГЭ 4: Поиск символа

Условие: Напишите программу, которая находит индекс первого вхождения символа 'o' в строке "Hello".

Решение:
s = "Hello"
index = -1
for i in range(len(s)):
    if s[i] == 'o':
        index = i
        break
print(index)

Решение пошагово:
1. index = -1
2. i=0: s[0]='H', 'H' != 'o', index остается -1
3. i=1: s[1]='e', 'e' != 'o', index остается -1
4. i=2: s[2]='l', 'l' != 'o', index остается -1
5. i=3: s[3]='l', 'l' != 'o', index остается -1
6. i=4: s[4]='o', 'o' == 'o', index = 4, break

Ответ: 4

Проверка в Python:
s = "Hello"
index = -1
for i in range(len(s)):
    if s[i] == 'o':
        index = i
        print(f"Найден 'o' на позиции {i}")
        break
print(f"Индекс: {index}")  # 4

Задача ОГЭ 6: Проверка условия для символов

Условие: Напишите программу, которая подсчитывает количество цифр в строке "abc123def456".

Решение:
s = "abc123def456"
count = 0
for i in range(len(s)):
    if s[i].isdigit():
        count = count + 1
print(count)

Решение пошагово:
1. count = 0
2. Перебираем все символы:
   - 'a', 'b', 'c' - не цифры
   - '1', '2', '3' - цифры, count = 3
   - 'd', 'e', 'f' - не цифры
   - '4', '5', '6' - цифры, count = 6

Ответ: 6

Проверка в Python:
s = "abc123def456"
count = 0
for i in range(len(s)):
    if s[i].isdigit():
        count = count + 1
        print(f"Найдена цифра '{s[i]}' на позиции {i}, всего: {count}")
print(f"Итого цифр: {count}")  # 6

4. Методы работы со строками

В Python есть встроенные методы для работы со строками.

Задача ОГЭ 7: Подсчет заглавных букв

Условие: Напишите программу, которая подсчитывает количество заглавных букв в строке "Hello World".

Решение:
s = "Hello World"
count = 0
for i in range(len(s)):
    if s[i].isupper():
        count = count + 1
print(count)

Решение:
1. count = 0
2. Перебираем символы:
   - 'H' - заглавная, count = 1
   - 'e', 'l', 'l', 'o' - строчные
   - ' ' - пробел
   - 'W' - заглавная, count = 2
   - 'o', 'r', 'l', 'd' - строчные

Ответ: 2

Проверка в Python:
s = "Hello World"
count = 0
for i in range(len(s)):
    if s[i].isupper():
        count = count + 1
        print(f"Найдена заглавная '{s[i]}' на позиции {i}, всего: {count}")
print(f"Итого заглавных букв: {count}")  # 2

Задача ОГЭ 8: Проверка на букву

Условие: Напишите программу, которая проверяет, содержит ли строка "Hello123" только буквы.

Решение:
s = "Hello123"
only_letters = True
for i in range(len(s)):
    if not s[i].isalpha():
        only_letters = False
        break
print(only_letters)

Решение:
1. only_letters = True
2. Перебираем символы:
   - 'H', 'e', 'l', 'l', 'o' - буквы
   - '1' - не буква, only_letters = False, break

Ответ: False

Проверка в Python:
s = "Hello123"
only_letters = True
for i in range(len(s)):
    if not s[i].isalpha():
        only_letters = False
        print(f"Найден не-буквенный символ '{s[i]}' на позиции {i}")
        break
print(f"Только буквы: {only_letters}")  # False

Задача ОГЭ 9: Подсчет гласных

Условие: Напишите программу, которая подсчитывает количество гласных букв в строке "Hello".

Решение:
s = "Hello"
vowels = "aeiouAEIOU"
count = 0
for i in range(len(s)):

        count = count + 1
print(count)

Решение:
1. count = 0
2. Перебираем символы:
   - 'H' - не гласная
   - 'e' - гласная, count = 1
   - 'l' - не гласная
   - 'l' - не гласная
   - 'o' - гласная, count = 2

Ответ: 2

Проверка в Python:
s = "Hello"
vowels = "aeiouAEIOU"
count = 0
for i in range(len(s)):
    if s[i] in vowels:
        count = count + 1
        print(f"Найдена гласная '{s[i]}' на позиции {i}, всего: {count}")
print(f"Итого гласных: {count}")  # 2

Задача ОГЭ 10: Обратная строка

Условие: Напишите программу, которая создает обратную строку для "Python".

Решение:
s = "Python"
reverse = ""
for i in range(len(s) - 1, -1, -1):
    reverse = reverse + s[i]
print(reverse)

Решение пошагово:
1. reverse = ""
2. Цикл идет от последнего индекса к первому:
   - i=5: s[5]='n', reverse = "" + 'n' = "n"
   - i=4: s[4]='o', reverse = "n" + 'o' = "no"
   - i=3: s[3]='h', reverse = "no" + 'h' = "noh"
   - i=2: s[2]='t', reverse = "noh" + 't' = "noht"
   - i=1: s[1]='y', reverse = "noht" + 'y' = "nohty"
   - i=0: s[0]='P', reverse = "nohty" + 'P' = "nohtyP"

Ответ: nohtyP

Проверка в Python:
s = "Python"
reverse = ""
for i in range(len(s) - 1, -1, -1):
    reverse = reverse + s[i]
    print(f"i={i}, s[{i}]='{s[i]}', reverse='{reverse}'")
print(f"Обратная строка: {reverse}")  # nohtyP

8. Типичные ошибки

Ошибка 1: Выход за границы строки

# НЕПРАВИЛЬНО - выход за границы
s = "Hello"
print(s[5])  # Ошибка! Индексы: 0, 1, 2, 3, 4 (всего 5 символов)

# ПРАВИЛЬНО - проверяй границы
s = "Hello"
if len(s) > 5:
    print(s[5])
else:
    print("Индекс вне диапазона")

Ошибка 2: Путаница с регистром

# НЕПРАВИЛЬНО - не учитываешь регистр
s = "Hello"
if s[0] == 'h':  # 'H' != 'h'
    print("Найдено")

# ПРАВИЛЬНО - учитывай регистр или используй методы
s = "Hello"
if s[0] == 'H':  # Правильно
    print("Найдено")

# Или используй lower() для сравнения без учета регистра
if s[0].lower() == 'h':  # 'H'.lower() = 'h'
    print("Найдено")

Ошибка 3: Неправильное использование методов

# НЕПРАВИЛЬНО - вызываешь метод на числе
s = "Hello"
for i in range(len(s)):
    if i.isalpha():  # Ошибка! i - это число, а не строка
        print(s[i])

# ПРАВИЛЬНО - вызывай метод на символе строки
s = "Hello"
for i in range(len(s)):
    if s[i].isalpha():  # Правильно: s[i] - это символ (строка)
        print(s[i])

10. Резюме урока

  • Индексация - строки индексируются с 0, последний символ имеет индекс -1
  • Доступ к символам - используй s[i] для доступа к символу с индексом i
  • Длина строки - len(s) возвращает количество символов
  • Подсчет символов - используй счетчик и условие в цикле
  • Поиск символа - перебирай символы и сравнивай с искомым
  • Методы строк - isdigit(), isalpha(), isupper(), islower() для проверки символов
  • Циклы по строке - используй for i in range(len(s)) для перебора всех символов
  • Границы - всегда проверяй, что индекс не выходит за границы строки
  • Регистр - учитывай регистр при сравнении символов
  • Практика - решай задачи пошагово, отслеживай изменения переменных
