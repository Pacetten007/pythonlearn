Операторы сравнения

Перед изучением if нужно научиться сравнивать значения. Операторы сравнения возвращают True (истина) или False (ложь).

# Шесть операторов сравнения
print(5 == 5)    # True (равно)
print(5 != 3)    # True (не равно)
print(5 > 3)     # True (больше)
print(5 < 10)    # True (меньше)
print(5 >= 5)    # True (больше или равно)
print(5 <= 4)    # False (меньше или равно)

Все операторы сравнения:

  • == равно (два знака равно!)
  • != не равно
  • > больше
  • < меньше
  • >= больше или равно
  • <= меньше или равно

Частая ошибка: = vs ==

# НЕПРАВИЛЬНО:
if x = 5:  # Ошибка! = это присваивание, а не сравнение!

# ПРАВИЛЬНО:
if x == 5:  # == это сравнение!

= присваивает значение, == сравнивает!

Простой оператор if

Базовая конструкция: "если условие истинно, выполни код".

# Синтаксис if
age = 20

if age >= 18:
    print("Ты совершеннолетний")
    print("Можешь голосовать")

print("Программа продолжается")

# Вывод:
# Ты совершеннолетний
# Можешь голосовать
# Программа продолжается

Важные элементы синтаксиса if:

  1. Ключевое слово if
  2. Условие (выражение, которое дает True или False)
  3. Двоеточие : в конце строки (ОБЯЗАТЕЛЬНО!)
  4. Отступ (4 пробела) для кода внутри if
# Примеры простого if
number = 10

if number > 0:
    print("Число положительное")

# Можно использовать переменные
password = "secret123"
user_input = "secret123"

if password == user_input:
    print("Доступ разрешен")

# Проверка четности
num = 42
if num % 2 == 0:
    print(f"{num} - четное число")

Оператор if-else

else (иначе) выполняется, когда условие if ложно. Это позволяет выбирать между двумя путями.

# Синтаксис if-else
age = 15

if age >= 18:
    print("Взрослый")
else:
    print("Ребенок")

# Выведет: Ребенок

# Еще примеры
temperature = 25

if temperature > 30:
    print("Жарко!")
else:
    print("Нормальная температура")

# Выведет: Нормальная температура

Практический пример: проверка пароля

correct_password = "python123"
user_password = input("Введите пароль: ")

if user_password == correct_password:
    print("✓ Доступ разрешен")
    print("Добро пожаловать!")
else:
    print("✗ Неверный пароль")
    print("Доступ запрещен")

Оператор if-elif-else

elif (сокращение от "else if") позволяет проверить несколько условий последовательно. Выполняется только ПЕРВОЕ истинное условие!

# Синтаксис if-elif-else
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Оценка: {grade}")
# Выведет: Оценка: B

Как работает if-elif-else:

  1. Проверяется первое условие if
  2. Если True - выполняется его блок, остальные пропускаются
  3. Если False - проверяется следующий elif
  4. Если все условия False - выполняется else (если есть)

Важно: Выполняется ТОЛЬКО ОДИН блок - первый истинный!

Пример: определение возрастной категории

age = int(input("Введите возраст: "))

if age < 0:
    print("Ошибка: возраст не может быть отрицательным")
elif age < 3:
    print("Младенец")
elif age < 7:
    print("Дошкольник")
elif age < 18:
    print("Школьник")
elif age < 65:
    print("Взрослый")
else:
    print("Пенсионер")

Пример: система оценок

points = int(input("Количество баллов (0-100): "))

if points < 0 or points > 100:
    print("Ошибка: баллы должны быть от 0 до 100")
elif points >= 90:
    print("Отлично! Оценка: 5")
elif points >= 75:
    print("Хорошо! Оценка: 4")
elif points >= 60:
    print("Удовлетворительно. Оценка: 3")
else:
    print("Неудовлетворительно. Оценка: 2")

Вложенные условия

Можно размещать if внутри другого if. Это называется вложенные условия.

# Вложенный if
age = 20
has_license = True

if age >= 18:
    print("Ты совершеннолетний")

    if has_license:
        print("Можешь водить машину")
    else:
        print("Нужны права для вождения")
else:
    print("Ты несовершеннолетний")
    print("Водить машину нельзя")

Пример: цена билета с учетом скидок

age = int(input("Возраст: "))
is_student = input("Студент? (да/нет): ").lower() == "да"

base_price = 500

if age < 7:
    price = 0
    print("Детям до 7 лет - бесплатно")
elif age < 18:
    price = base_price * 0.5
    print(f"Детский билет: {price} руб.")
else:
    if is_student:
        price = base_price * 0.7
        print(f"Студенческий билет: {price} руб.")
    else:
        price = base_price
        print(f"Взрослый билет: {price} руб.")

Отступы в Python - КРИТИЧЕСКИ ВАЖНО!

В Python отступы (пробелы в начале строки) определяют структуру программы. Это не просто красота - это синтаксис!

Почему отступы важны?

Python использует отступы для определения блоков кода. Другие языки используют фигурные скобки {}, но Python - отступы!

# ПРАВИЛЬНО:
if age >= 18:
    print("Взрослый")    # 4 пробела
    print("Доступ есть") # 4 пробела

# НЕПРАВИЛЬНО:
if age >= 18:
print("Взрослый")  # IndentationError!

Правила отступов:

  • Стандарт: 4 пробела (не Tab!)
  • Весь код в блоке должен иметь одинаковые отступы
  • Вложенные блоки имеют дополнительные отступы (8, 12 и т.д.)
  • Неправильные отступы вызывают IndentationError
# Правильные отступы
age = 25

if age >= 18:                    # 0 пробелов
    print("Взрослый")            # 4 пробела

    if age >= 65:                # 4 пробела
        print("Пенсионер")       # 8 пробелов
        print("Льготы есть")     # 8 пробелов
    else:                        # 4 пробела
        print("Работоспособный") # 8 пробелов

print("Конец проверки")          # 0 пробелов

Типичные ошибки начинающих

Ошибка 1: Путаница = и ==

# НЕПРАВИЛЬНО:
if x = 5:  # SyntaxError!
    print("x равно 5")

# ПРАВИЛЬНО:
if x == 5:  # Сравнение
    print("x равно 5")

# Запомни:
# = это присваивание
# == это сравнение

Ошибка 2: Забыли двоеточие

# НЕПРАВИЛЬНО:
if age >= 18  # SyntaxError!
    print("Взрослый")

# ПРАВИЛЬНО:
if age >= 18:  # Двоеточие обязательно!
    print("Взрослый")

Ошибка 3: Неправильные отступы

# НЕПРАВИЛЬНО:
if age >= 18:
print("Взрослый")  # IndentationError!

# НЕПРАВИЛЬНО:
if age >= 18:
  print("Строка 1")   # 2 пробела
    print("Строка 2") # 4 пробела - IndentationError!

# ПРАВИЛЬНО:
if age >= 18:
    print("Строка 1")  # 4 пробела
    print("Строка 2")  # 4 пробела

Ошибка 4: elif без if

# НЕПРАВИЛЬНО:
elif age > 18:  # SyntaxError! elif без if
    print("Взрослый")

# ПРАВИЛЬНО:
if age < 18:
    print("Ребенок")
elif age == 18:
    print("18 лет")
else:
    print("Взрослый")

Ошибка 5: Неправильный порядок условий

# НЕПРАВИЛЬНО:
if score >= 60:
    print("D")
elif score >= 80:  # Никогда не выполнится!
    print("B")

# Если score=85, выведет "D", а не "B"!

# ПРАВИЛЬНО (от большего к меньшему):
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 60:
    print("D")

Ошибка 6: Использование = вместо == в условии

# НЕПРАВИЛЬНО:
password = "secret"
if password = "admin":  # SyntaxError!
    print("Админ")

# ПРАВИЛЬНО:
password = "secret"
if password == "admin":  # Сравнение
    print("Админ")

  • На экзаменах часто проверяют умение читать код с условиями и предсказывать результат

Резюме урока

  • Операторы сравнения: ==, !=, >, <, >=, <= (возвращают True/False)
  • if: выполняет код, если условие истинно
  • if-else: два пути - одно для True, другое для False
  • if-elif-else: множественный выбор, выполняется ПЕРВОЕ истинное
  • Вложенные if: условия внутри условий
  • Двоеточие : обязательно после if/elif/else
  • Отступы: 4 пробела, определяют блоки кода
  • IndentationError: ошибка при неправильных отступах
  • = vs ==: присваивание vs сравнение
