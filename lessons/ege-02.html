1. Работа с несколькими списками

В таких задачах нужно обрабатывать несколько списков одновременно или сравнивать их.

Задача ЕГЭ 1: Поиск общих элементов

Условие: Даны два списка. Напишите программу, которая находит количество общих элементов.
Списки: [1, 2, 3, 4, 5] и [3, 4, 5, 6, 7]

Решение:
a = [1, 2, 3, 4, 5]
b = [3, 4, 5, 6, 7]
count = 0
for i in range(len(a)):
    if a[i] in b:
        count = count + 1
print(count)

Решение:
Общие элементы: 3, 4, 5
Количество: 3

Ответ: 3

Проверка в Python:
a = [1, 2, 3, 4, 5]
b = [3, 4, 5, 6, 7]
count = 0
for i in range(len(a)):
    if a[i] in b:
        count = count + 1
        print(f"Найден общий элемент: {a[i]}, всего: {count}")
print(f"Итого общих элементов: {count}")  # 3

Задача ЕГЭ 2: Сравнение списков по позициям

Условие: Даны два списка одинаковой длины. Напишите программу, которая находит количество позиций, где элементы первого списка больше элементов второго.
Списки: [5, 3, 8, 2] и [3, 4, 5, 1]

Решение:
a = [5, 3, 8, 2]
b = [3, 4, 5, 1]
count = 0
for i in range(len(a)):
    if a[i] > b[i]:
        count = count + 1
print(count)

Решение пошагово:
- i=0: a[0]=5, b[0]=3, 5 > 3 → count = 1
- i=1: a[1]=3, b[1]=4, 3 > 4 → нет
- i=2: a[2]=8, b[2]=5, 8 > 5 → count = 2
- i=3: a[3]=2, b[3]=1, 2 > 1 → count = 3

Ответ: 3

Проверка в Python:
a = [5, 3, 8, 2]
b = [3, 4, 5, 1]
count = 0
for i in range(len(a)):
    if a[i] > b[i]:
        count = count + 1
        print(f"Позиция {i}: {a[i]} > {b[i]}, всего: {count}")
print(f"Итого позиций: {count}")  # 3

2. Обработка строк и поиск подстрок

В таких задачах нужно искать подстроки, анализировать структуру строк.

Задача ЕГЭ 3: Поиск подстроки

Условие: Дана строка. Напишите программу, которая находит количество вхождений подстроки "ab" в строке.
Строка: "abracadabra"

Решение:
s = "abracadabra"
substring = "ab"
count = 0
for i in range(len(s) - len(substring) + 1):
    if s[i:i+len(substring)] == substring:
        count = count + 1
print(count)

Решение пошагово:
- i=0: s[0:2] = "ab" → совпадает, count = 1
- i=1: s[1:3] = "br" → не совпадает
- i=2: s[2:4] = "ra" → не совпадает
- i=3: s[3:5] = "ac" → не совпадает
- i=4: s[4:6] = "ad" → не совпадает
- i=5: s[5:7] = "ab" → совпадает, count = 2
- и т.д.

Ответ: 2

Проверка в Python:
s = "abracadabra"
substring = "ab"
count = 0
for i in range(len(s) - len(substring) + 1):
    if s[i:i+len(substring)] == substring:
        count = count + 1
        print(f"Найдено на позиции {i}, всего: {count}")
print(f"Итого вхождений '{substring}': {count}")  # 2

Задача ЕГЭ 4: Анализ структуры строки

Условие: Дана строка. Напишите программу, которая проверяет, является ли строка палиндромом (читается одинаково слева направо и справа налево).
Строка: "radar"

Решение:
s = "radar"
is_palindrome = True
for i in range(len(s) // 2):
    if s[i] != s[len(s) - 1 - i]:
        is_palindrome = False
        break
print(is_palindrome)

Решение:
- i=0: s[0]='r', s[4]='r', совпадают
- i=1: s[1]='a', s[3]='a', совпадают
- i=2: s[2]='d', s[2]='d', совпадают (середина)

Ответ: True

Проверка в Python:
s = "radar"
is_palindrome = True
for i in range(len(s) // 2):
    if s[i] != s[len(s) - 1 - i]:
        is_palindrome = False
        print(f"Не совпадают: s[{i}]='{s[i]}', s[{len(s)-1-i}]='{s[len(s)-1-i]}'")
        break
    else:
        print(f"Совпадают: s[{i}]='{s[i]}', s[{len(s)-1-i}]='{s[len(s)-1-i]}'")
print(f"Палиндром: {is_palindrome}")  # True

3. Работа с вложенными структурами

В таких задачах нужно обрабатывать списки списков или другие вложенные структуры.

Задача ЕГЭ 5: Обработка матрицы

Условие: Дана матрица (список списков). Напишите программу, которая находит сумму всех элементов матрицы.
Матрица: [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

Решение:
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
s = 0
for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        s = s + matrix[i][j]
print(s)

Решение:
1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 + 9 = 45

Ответ: 45

Проверка в Python:
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
s = 0
for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        s = s + matrix[i][j]
        print(f"matrix[{i}][{j}]={matrix[i][j]}, s={s}")
print(f"Итоговая сумма: {s}")  # 45

Задача ЕГЭ 6: Поиск в матрице

Условие: Дана матрица. Напишите программу, которая находит максимальный элемент в матрице.
Матрица: [[5, 2, 8], [1, 9, 3], [4, 7, 6]]

Решение:
matrix = [[5, 2, 8], [1, 9, 3], [4, 7, 6]]
max_value = matrix[0][0]
for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        if matrix[i][j] > max_value:
            max_value = matrix[i][j]
print(max_value)

Ответ: 9

Проверка в Python:
matrix = [[5, 2, 8], [1, 9, 3], [4, 7, 6]]
max_value = matrix[0][0]
for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        if matrix[i][j] > max_value:
            max_value = matrix[i][j]
            print(f"Новый максимум: matrix[{i}][{j}]={matrix[i][j]}")
print(f"Максимальный элемент: {max_value}")  # 9

4. Поиск паттернов и последовательностей

В таких задачах нужно найти определенные паттерны или последовательности в данных.

Задача ЕГЭ 7: Поиск возрастающей последовательности

Условие: Дан список чисел. Напишите программу, которая находит длину самой длинной возрастающей последовательности.
Список: [1, 3, 2, 4, 5, 3, 6]

Решение:
a = [1, 3, 2, 4, 5, 3, 6]
max_length = 1
current_length = 1

for i in range(1, len(a)):
    if a[i] > a[i-1]:
        current_length = current_length + 1
    else:
        if current_length > max_length:
            max_length = current_length
        current_length = 1

if current_length > max_length:
    max_length = current_length

print(max_length)

Решение пошагово:
- i=1: a[1]=3 > a[0]=1, current_length = 2
- i=2: a[2]=2 < a[1]=3, сохраняем max_length=2, current_length = 1
- i=3: a[3]=4 > a[2]=2, current_length = 2
- i=4: a[4]=5 > a[3]=4, current_length = 3
- i=5: a[5]=3 < a[4]=5, сохраняем max_length=3, current_length = 1
- i=6: a[6]=6 > a[5]=3, current_length = 2

Ответ: 3

Проверка в Python:
a = [1, 3, 2, 4, 5, 3, 6]
max_length = 1
current_length = 1

for i in range(1, len(a)):
    if a[i] > a[i-1]:
        current_length = current_length + 1
        print(f"i={i}, возрастает, длина={current_length}")
    else:
        if current_length > max_length:
            max_length = current_length
        current_length = 1
        print(f"i={i}, не возрастает, max_length={max_length}")

if current_length > max_length:
    max_length = current_length

print(f"Максимальная длина: {max_length}")  # 3

Задача ЕГЭ 8: Поиск повторяющихся элементов

Условие: Дан список чисел. Напишите программу, которая находит количество элементов, которые встречаются более одного раза.
Список: [1, 2, 3, 2, 4, 2, 5, 3]

Решение:
a = [1, 2, 3, 2, 4, 2, 5, 3]
count = 0
seen = []

for i in range(len(a)):
    if a[i] not in seen:
        # Проверяем, есть ли еще такие элементы
        occurrences = 0
        for j in range(len(a)):
            if a[j] == a[i]:
                occurrences = occurrences + 1
        if occurrences > 1:
            count = count + 1
            seen.append(a[i])

print(count)

Решение:
- Элемент 1: встречается 1 раз → не считаем
- Элемент 2: встречается 3 раза → считаем
- Элемент 3: встречается 2 раза → считаем
- Элемент 4: встречается 1 раз → не считаем
- Элемент 5: встречается 1 раз → не считаем

Ответ: 2

Проверка в Python:
a = [1, 2, 3, 2, 4, 2, 5, 3]
count = 0
seen = []

for i in range(len(a)):
    if a[i] not in seen:
        occurrences = 0
        for j in range(len(a)):
            if a[j] == a[i]:
                occurrences = occurrences + 1
        if occurrences > 1:
            count = count + 1
            seen.append(a[i])
            print(f"Элемент {a[i]} встречается {occurrences} раз(а)")

print(f"Итого элементов, встречающихся более 1 раза: {count}")  # 2

5. Комплексные задачи

Задачи, сочетающие несколько техник.

Задача ЕГЭ 9: Обработка строк и списков

Условие: Дан список строк. Напишите программу, которая находит количество строк, содержащих подстроку "ab".
Список: ["abc", "def", "abab", "xyz", "cab"]

Решение:
strings = ["abc", "def", "abab", "xyz", "cab"]
count = 0
substring = "ab"

for i in range(len(strings)):
    found = False
    for j in range(len(strings[i]) - len(substring) + 1):
        if strings[i][j:j+len(substring)] == substring:
            found = True
            break
    if found:
        count = count + 1

print(count)

Решение:
- "abc": содержит "ab" → count = 1
- "def": не содержит "ab"
- "abab": содержит "ab" → count = 2
- "xyz": не содержит "ab"
- "cab": содержит "ab" → count = 3

Ответ: 3

Проверка в Python:
strings = ["abc", "def", "abab", "xyz", "cab"]
count = 0
substring = "ab"

for i in range(len(strings)):
    found = False
    for j in range(len(strings[i]) - len(substring) + 1):
        if strings[i][j:j+len(substring)] == substring:
            found = True
            break
    if found:
        count = count + 1
        print(f"Строка '{strings[i]}' содержит '{substring}', всего: {count}")

print(f"Итого строк с '{substring}': {count}")  # 3

Задача ЕГЭ 10: Работа с условиями и циклами

Условие: Дан список чисел. Напишите программу, которая находит количество локальных максимумов (элементов, которые больше обоих соседей).
Список: [1, 3, 2, 5, 4, 6, 3]

Решение:
a = [1, 3, 2, 5, 4, 6, 3]
count = 0

for i in range(1, len(a) - 1):
    if a[i] > a[i-1] and a[i] > a[i+1]:
        count = count + 1

print(count)

Решение:
- i=1: a[1]=3, a[0]=1, a[2]=2, 3 > 1 и 3 > 2 → локальный максимум, count = 1
- i=2: a[2]=2, a[1]=3, a[3]=5, 2 не больше 3 → нет
- i=3: a[3]=5, a[2]=2, a[4]=4, 5 > 2 и 5 > 4 → локальный максимум, count = 2
- i=4: a[4]=4, a[3]=5, a[5]=6, 4 не больше 5 → нет
- i=5: a[5]=6, a[4]=4, a[6]=3, 6 > 4 и 6 > 3 → локальный максимум, count = 3

Ответ: 3

Проверка в Python:
a = [1, 3, 2, 5, 4, 6, 3]
count = 0

for i in range(1, len(a) - 1):
    if a[i] > a[i-1] and a[i] > a[i+1]:
        count = count + 1
        print(f"Локальный максимум на позиции {i}: {a[i]} > {a[i-1]} и {a[i]} > {a[i+1]}, всего: {count}")

print(f"Итого локальных максимумов: {count}")  # 3

8. Типичные ошибки

Ошибка 1: Выход за границы при поиске подстроки

# НЕПРАВИЛЬНО - выход за границы
s = "abc"
substring = "ab"
for i in range(len(s)):  # i может быть len(s)-1
    if s[i:i+len(substring)] == substring:  # Ошибка, если i+len(substring) > len(s)
        print("Найдено")

# ПРАВИЛЬНО - учитывай длину подстроки
s = "abc"
substring = "ab"
for i in range(len(s) - len(substring) + 1):  # Правильный диапазон
    if s[i:i+len(substring)] == substring:
        print("Найдено")

Ошибка 2: Неправильная обработка границ в локальных максимумах

# НЕПРАВИЛЬНО - проверка границ
a = [1, 3, 2]
for i in range(len(a)):  # i=0 и i=len(a)-1 не имеют обоих соседей!
    if a[i] > a[i-1] and a[i] > a[i+1]:  # Ошибка на границах
        count += 1

# ПРАВИЛЬНО - пропускай границы
a = [1, 3, 2]
for i in range(1, len(a) - 1):  # Пропускаем первый и последний элементы
    if a[i] > a[i-1] and a[i] > a[i+1]:
        count += 1

Ошибка 3: Неправильная работа с вложенными циклами

# НЕПРАВИЛЬНО - путаница с индексами
matrix = [[1, 2], [3, 4]]
for i in range(len(matrix)):
    for j in range(len(matrix)):  # Неправильно! Должно быть len(matrix[i])
        print(matrix[i][j])

# ПРАВИЛЬНО - используй правильную длину для внутреннего цикла
matrix = [[1, 2], [3, 4]]
for i in range(len(matrix)):
    for j in range(len(matrix[i])):  # Правильно: длина текущей строки
        print(matrix[i][j])

10. Резюме урока

  • Работа с несколькими списками - используй вложенные циклы или оператор in для сравнения
  • Поиск подстроки - диапазон цикла: range(len(s) - len(substring) + 1)
  • Палиндром - сравнивай символы с начала и конца, до середины
  • Работа с матрицами - используй вложенные циклы, проверяй границы
  • Локальные максимумы - пропускай границы, проверяй оба соседа
  • Поиск паттернов - отслеживай текущее состояние и обновляй максимум
  • Границы - всегда проверяй, что индексы не выходят за границы
  • Вложенные циклы - используй правильную длину для внутреннего цикла
  • Практика - решай задачи пошагово, проверяй на разных входных данных
