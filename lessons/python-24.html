Урок 29: Чтение файлов

Работа с файлами • 45 минут

Введение

До сих пор все наши программы работали только с данными, которые мы вводили с клавиатуры или хранили в переменных. Но что если данных очень много? Что если нужно сохранить результаты работы программы? Для этого существуют файлы!

Файлы позволяют:

  • Сохранять данные постоянно - не теряются после завершения программы
  • Работать с большими объемами информации - не нужно вводить каждый раз вручную
  • Обмениваться данными - между программами и пользователями
  • Анализировать логи - записи о работе программ и систем
  • Обрабатывать документы - тексты, таблицы, конфигурации

⚠️ Важно для Skulpt!

Работа с файлами в браузерном редакторе Skulpt не поддерживается. Чтобы запустить примеры с файлами, тебе нужно:

  • Установить Python на свой компьютер (скачай с python.org)
  • Сохранить код в файл с расширением .py
  • Запустить через терминал: python filename.py

Но изучать синтаксис и примеры можно прямо здесь! Просто знай, что для реального использования понадобится локальная установка Python.

Что изучим в этом уроке:

  • Функция open() - открытие файла
  • Режимы открытия файлов (r, rb, и другие)
  • Метод read() - чтение всего файла
  • Метод readline() - чтение одной строки
  • Метод readlines() - чтение всех строк в список
  • Закрытие файлов с close()
  • Оператор with - автоматическое закрытие
  • Итерация по строкам файла
  • Обработка ошибок при работе с файлами
  • Кодировки текста (UTF-8)

Функция open()

Чтобы работать с файлом, его нужно сначала открыть с помощью функции open():

file = open("filename.txt", "r")
# file - переменная с объектом файла
# "filename.txt" - имя файла (или путь)
# "r" - режим открытия (read - чтение)

Параметры open():

Параметр Описание Пример
filename Имя файла или путь "text.txt", "data/file.txt"
mode Режим открытия "r", "w", "a"
encoding Кодировка текста "utf-8", "cp1251"

Режимы открытия файлов

Режим определяет, что можно делать с файлом:

Режим Название Описание
"r" Read (чтение) Только чтение. Файл ДОЛЖЕН существовать!
"rb" Read Binary Чтение в бинарном режиме
"w" Write (запись) Запись (о нём в следующем уроке)
"a" Append (добавление) Добавление в конец файла

⚠️ Режим "r" требует существующий файл!

Если файл не существует, получишь ошибку FileNotFoundError. Обрабатывай её с помощью try-except!

Метод read() - Чтение всего файла

Метод read() читает весь файл целиком как одну строку:

# Открыть файл
file = open("text.txt", "r", encoding="utf-8")

# Прочитать содержимое
content = file.read()
print(content)

# Закрыть файл (ОБЯЗАТЕЛЬНО!)
file.close()

Пример:

# Файл poem.txt содержит:
# Я памятник себе воздвиг нерукотворный,
# К нему не зарастет народная тропа.

file = open("poem.txt", "r", encoding="utf-8")
content = file.read()
file.close()

print(content)
# Выведет:
# Я памятник себе воздвиг нерукотворный,
# К нему не зарастет народная тропа.

Когда использовать read():

  • Файл небольшой (помещается в память)
  • Нужно обработать весь текст сразу
  • Поиск или замена во всем файле
  • Анализ всего документа

Метод readline() - Чтение одной строки

Метод readline() читает файл построчно - по одной строке за раз:

file = open("text.txt", "r", encoding="utf-8")

# Читаем первую строку
line1 = file.readline()
print("Первая строка:", line1)

# Читаем вторую строку
line2 = file.readline()
print("Вторая строка:", line2)

# Читаем третью строку
line3 = file.readline()
print("Третья строка:", line3)

file.close()

Пример с циклом while:

file = open("text.txt", "r", encoding="utf-8")

line = file.readline()
while line:  # Пока строка не пустая
    print(line.strip())  # strip() убирает \n
    line = file.readline()  # Читаем следующую

file.close()

Когда использовать readline():

  • Файл очень большой (не помещается в память)
  • Обработка построчно
  • Поиск конкретной строки
  • Чтение до определенного места

Метод readlines() - Чтение всех строк в список

Метод readlines() читает весь файл и возвращает список строк:

file = open("text.txt", "r", encoding="utf-8")

# Получаем список всех строк
lines = file.readlines()
file.close()

print(f"Всего строк: {len(lines)}")

# Обходим список
for i, line in enumerate(lines, 1):
    print(f"Строка {i}: {line.strip()}")

Пример:

# Файл students.txt содержит:
# Иван Петров
# Мария Сидорова
# Петр Иванов

file = open("students.txt", "r", encoding="utf-8")
students = file.readlines()
file.close()

print("Список студентов:")
for i, student in enumerate(students, 1):
    print(f"{i}. {student.strip()}")

# Выведет:
# Список студентов:
# 1. Иван Петров
# 2. Мария Сидорова
# 3. Петр Иванов

Сравнение методов чтения

Метод Что возвращает Когда использовать
read() Одна большая строка Небольшие файлы
readline() Одна строка Большие файлы, поиск
readlines() Список строк Средние файлы, индексация

Закрытие файлов - close()

После работы с файлом его ОБЯЗАТЕЛЬНО нужно закрыть методом close()!

file = open("text.txt", "r")
content = file.read()
file.close()  # ВАЖНО! Освобождаем ресурсы

Почему важно закрывать файлы:

  • Освобождение ресурсов - операционная система ограничивает количество открытых файлов
  • Сохранение изменений - данные из буфера записываются на диск
  • Избежание блокировок - другие программы смогут работать с файлом
  • Предотвращение утечек памяти - файловые дескрипторы занимают память

⚠️ Проблема с забытым close():

# ПЛОХО - если произойдет ошибка, файл не закроется!
file = open("text.txt", "r")
content = file.read()
result = process(content)  # Если здесь ошибка...
file.close()  # ...это не выполнится!

Оператор with - Лучший способ!

Оператор with автоматически закрывает файл, даже если произошла ошибка!

with open("text.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
# Файл автоматически закрыт после блока with!

Преимущества with:

  • Автоматическое закрытие - не нужно помнить про close()
  • Безопасность - файл закроется даже при ошибке
  • Читаемость - ясно, где работа с файлом начинается и заканчивается
  • Рекомендуется всегда - это "правильный" способ работы с файлами

✅ Лучшая практика:

# ВСЕГДА используй with:
with open("text.txt", "r", encoding="utf-8") as file:
    content = file.read()
    # Работа с содержимым

# Файл уже закрыт автоматически!

Итерация по строкам файла

Самый элегантный способ - использовать файл как итератор в цикле for:

with open("text.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())  # strip() убирает \n в конце

Преимущества итерации:

  • Простота - самый короткий и понятный код
  • Эффективность - читает по одной строке (экономит память)
  • Автоматизм - не нужно вручную вызывать readline()
  • Подходит для больших файлов - не загружает весь файл в память

Примеры с итерацией:

# Пример 1: Подсчет строк
count = 0
with open("text.txt", "r", encoding="utf-8") as file:
    for line in file:
        count += 1
print(f"Строк в файле: {count}")

# Пример 2: Нумерованный вывод
with open("text.txt", "r", encoding="utf-8") as file:
    for i, line in enumerate(file, 1):
        print(f"{i}: {line.strip()}")

# Пример 3: Поиск текста
search_word = "Python"
with open("text.txt", "r", encoding="utf-8") as file:
    for i, line in enumerate(file, 1):
        if search_word in line:
            print(f"Найдено в строке {i}: {line.strip()}")

Обработка ошибок при работе с файлами

При работе с файлами могут возникать ошибки. Обрабатывай их с помощью try-except:

# Обработка FileNotFoundError
try:
    with open("missing.txt", "r", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    print("Ошибка: Файл не найден!")
    print("Проверь имя файла и путь.")

Типичные ошибки:

Ошибка Причина Решение
FileNotFoundError Файл не существует Проверь путь и имя
PermissionError Нет прав доступа Измени права файла
UnicodeDecodeError Неверная кодировка Укажи правильную encoding

Полная обработка ошибок:

filename = "text.txt"

try:
    with open(filename, "r", encoding="utf-8") as file:
        content = file.read()
        print(content)
except FileNotFoundError:
    print(f"Файл '{filename}' не найден!")
except PermissionError:
    print(f"Нет прав для чтения '{filename}'!")
except UnicodeDecodeError:
    print(f"Ошибка кодировки в файле '{filename}'!")
except Exception as e:
    print(f"Неизвестная ошибка: {e}")

Кодировки текста

Кодировка определяет, как символы хранятся в файле. Для русского текста используй UTF-8!

# Правильно для русского текста:
with open("text.txt", "r", encoding="utf-8") as file:
    content = file.read()

# Если файл в старой кодировке Windows:
with open("old_file.txt", "r", encoding="cp1251") as file:
    content = file.read()

Популярные кодировки:

Кодировка Описание Когда использовать
utf-8 Универсальная кодировка ВСЕГДА (рекомендуется)
cp1251 Windows Cyrillic Старые файлы Windows
ascii Только английские символы Простые англоязычные файлы

⚠️ Проблемы с кодировкой:

Если видишь "кракозябры" вместо русского текста:

  • Попробуй encoding="utf-8"
  • Попробуй encoding="cp1251"
  • Спроси, в какой кодировке создан файл

Практические примеры

Пример 1: Подсчет статистики файла

filename = "text.txt"

try:
    with open(filename, "r", encoding="utf-8") as file:
        lines = 0
        words = 0
        chars = 0

        for line in file:
            lines += 1
            words += len(line.split())
            chars += len(line)

        print(f"Статистика файла '{filename}':")
        print(f"  Строк: {lines}")
        print(f"  Слов: {words}")
        print(f"  Символов: {chars}")
except FileNotFoundError:
    print(f"Файл '{filename}' не найден!")

Пример 2: Поиск в файле

search_word = "Python"
filename = "text.txt"

try:
    with open(filename, "r", encoding="utf-8") as file:
        found = False
        for i, line in enumerate(file, 1):
            if search_word in line:
                print(f"Строка {i}: {line.strip()}")
                found = True

        if not found:
            print(f"Слово '{search_word}' не найдено.")
except FileNotFoundError:
    print(f"Файл '{filename}' не найден!")

Пример 3: Чтение конфигурации

# Файл config.txt содержит:
# username=admin
# password=12345
# server=localhost

config = {}

try:
    with open("config.txt", "r", encoding="utf-8") as file:
        for line in file:
            line = line.strip()
            if "=" in line:
                key, value = line.split("=", 1)
                config[key] = value

    print("Конфигурация загружена:")
    print(f"  Username: {config.get('username')}")
    print(f"  Server: {config.get('server')}")
except FileNotFoundError:
    print("Файл конфигурации не найден!")

Пример 4: Фильтрация строк

# Прочитать только непустые строки
non_empty_lines = []

try:
    with open("text.txt", "r", encoding="utf-8") as file:
        for line in file:
            line = line.strip()
            if line:  # Если строка не пустая
                non_empty_lines.append(line)

    print("Непустые строки:")
    for line in non_empty_lines:
        print(f"  {line}")
except FileNotFoundError:
    print("Файл не найден!")

Типичные ошибки начинающих

Ошибка 1: Забыл закрыть файл

# НЕПРАВИЛЬНО - файл не закрыт!
file = open("text.txt", "r")
content = file.read()
print(content)
# Забыли file.close()!

# ПРАВИЛЬНО - используй with
with open("text.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
# Файл закрыт автоматически!

Ошибка 2: Неправильный режим

# НЕПРАВИЛЬНО - режим "w" для чтения!
file = open("text.txt", "w")  # Удалит содержимое!
content = file.read()  # Ошибка!

# ПРАВИЛЬНО - режим "r" для чтения
with open("text.txt", "r", encoding="utf-8") as file:
    content = file.read()

Ошибка 3: Забыл указать кодировку

# НЕПРАВИЛЬНО - может быть проблема с русским текстом
with open("text.txt", "r") as file:  # Кодировка по умолчанию
    content = file.read()

# ПРАВИЛЬНО - явно указываем UTF-8
with open("text.txt", "r", encoding="utf-8") as file:
    content = file.read()

Ошибка 4: Не обработал исключения

# НЕПРАВИЛЬНО - программа упадет, если файла нет
with open("missing.txt", "r") as file:
    content = file.read()

# ПРАВИЛЬНО - обрабатываем ошибку
try:
    with open("missing.txt", "r", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    print("Файл не найден!")

Ошибка 5: Неверный путь к файлу

# НЕПРАВИЛЬНО - путь зависит от ОС
file = open("folder\file.txt", "r")  # \ для Windows

# ПРАВИЛЬНО - используй / (работает везде)
with open("folder/file.txt", "r", encoding="utf-8") as file:
    content = file.read()

# Или используй модуль os.path:
import os
path = os.path.join("folder", "file.txt")
with open(path, "r", encoding="utf-8") as file:
    content = file.read()

Ошибка 6: Читаешь весь огромный файл сразу

# НЕПРАВИЛЬНО - файл может быть гигабайты!
with open("huge_file.txt", "r") as file:
    content = file.read()  # Занимает всю память!

# ПРАВИЛЬНО - читай построчно
with open("huge_file.txt", "r", encoding="utf-8") as file:
    for line in file:  # Читает по одной строке
        process(line)

Ошибка 7: Забыл про strip()

# НЕПРАВИЛЬНО - в конце каждой строки \n
with open("text.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line)  # Лишние пустые строки!

# ПРАВИЛЬНО - убираем \n с помощью strip()
with open("text.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())

  • try-except - обрабатывай FileNotFoundError
  • encoding="utf-8" - используй для русского текста
  • strip() - убирает \n в конце строк
