1. Задачи на перевод между системами счисления

Это самый частый тип задач в ЕГЭ. Нужно перевести число из одной системы в другую.

Задача 1: Перевод из двоичной в десятичную

Условие: Переведите число 101101₂ в десятичную систему счисления.

Решение:
101101₂ = 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 0×2¹ + 1×2⁰
        = 1×32 + 0×16 + 1×8 + 1×4 + 0×2 + 1×1
        = 32 + 0 + 8 + 4 + 0 + 1
        = 45₁₀

Проверка в Python:
binary = "101101"
decimal = int(binary, 2)
print(decimal)  # 45

Задача 2: Перевод из десятичной в восьмеричную

Условие: Переведите число 125₁₀ в восьмеричную систему счисления.

Решение методом деления:
125 ÷ 8 = 15 (остаток 5)
 15 ÷ 8 =  1 (остаток 7)
  1 ÷ 8 =  0 (остаток 1)

Читаем остатки снизу вверх: 175₈

Проверка в Python:
decimal = 125
octal = oct(decimal)[2:]
print(octal)  # 175

Обратная проверка:
octal_str = "175"
decimal_check = int(octal_str, 8)
print(decimal_check)  # 125

Задача 3: Перевод через промежуточную систему

Условие: Переведите число 175₈ в шестнадцатеричную систему.

Решение через десятичную:
1. 175₈ → десятичная:
   175₈ = 1×8² + 7×8¹ + 5×8⁰ = 64 + 56 + 5 = 125₁₀

2. 125₁₀ → шестнадцатеричная:
   125 ÷ 16 = 7 (остаток 13 = D)
    7 ÷ 16 = 0 (остаток 7)
   
   Результат: 7D₁₆

Проверка в Python:
octal = "175"
decimal = int(octal, 8)
hexadecimal = hex(decimal)[2:].upper()
print(hexadecimal)  # 7D

2. Задачи на поиск основания системы счисления

В таких задачах нужно найти основание системы счисления, при котором равенство верно.

Задача 4: Найти основание системы

Условие: В системе счисления с некоторым основанием число 12 записывается как 110.
Найдите это основание.

Решение:
Пусть основание = x
110ₓ = 1×x² + 1×x¹ + 0×x⁰ = x² + x

По условию: x² + x = 12
x² + x - 12 = 0

Решаем квадратное уравнение:
D = 1 + 48 = 49
x = (-1 + 7) / 2 = 3

Ответ: основание = 3

Проверка в Python:
def find_base(number_str, decimal_value):
    """Находит основание системы счисления"""
    for base in range(2, 17):  # Проверяем основания от 2 до 16
        try:
            if int(number_str, base) == decimal_value:
                return base
        except:
            continue
    return None

base = find_base("110", 12)
print(f"Основание: {base}")  # 3
print(f"Проверка: 110₃ = {int('110', 3)}₁₀")  # 12

Задача 5: Найти основание по равенству

Условие: В некоторой системе счисления 23 + 25 = 52. Найдите основание этой системы.

Решение:
Пусть основание = x
23ₓ + 25ₓ = 52ₓ

Переведем в десятичную:
(2x + 3) + (2x + 5) = 5x + 2
4x + 8 = 5x + 2
x = 6

Ответ: основание = 6

Проверка в Python:
def solve_equation():
    for base in range(3, 17):
        num1 = int("23", base)
        num2 = int("25", base)
        result = int("52", base)
        if num1 + num2 == result:
            return base
    return None

base = solve_equation()
print(f"Основание: {base}")  # 6
print(f"Проверка: 23₆ + 25₆ = {int('23', 6) + int('25', 6)}₁₀ = {int('52', 6)}₁₀")

3. Задачи на арифметику в системах счисления

Нужно выполнить арифметические операции в различных системах счисления.

Задача 6: Сложение в двоичной системе

Условие: Вычислите сумму чисел 1011₂ + 1101₂. Ответ запишите в двоичной системе.

Решение столбиком:
   1011
 + 1101
 ------
  11000

Проверка в Python:
a = int("1011", 2)
b = int("1101", 2)
result = a + b
binary_result = bin(result)[2:]
print(f"1011₂ + 1101₂ = {binary_result}₂")
print(f"Проверка: {a}₁₀ + {b}₁₀ = {result}₁₀ = {binary_result}₂")

Задача 7: Вычитание в восьмеричной системе

Условие: Вычислите разность 443₈ - 175₈. Ответ запишите в восьмеричной системе.

Решение:
Переводим в десятичную, вычитаем, переводим обратно:
443₈ = 291₁₀
175₈ = 125₁₀
291 - 125 = 166₁₀ = 246₈

Проверка в Python:
a = int("443", 8)
b = int("175", 8)
result = a - b
octal_result = oct(result)[2:]
print(f"443₈ - 175₈ = {octal_result}₈")
print(f"Проверка: {a}₁₀ - {b}₁₀ = {result}₁₀ = {octal_result}₈")

4. Задачи на количество цифр

Нужно найти, сколько цифр потребуется для записи числа в определенной системе счисления.

Задача 8: Количество цифр в записи числа

Условие: Сколько цифр в двоичной записи числа 255?

Решение:
Нужно найти наименьшую степень двойки, которая больше 255:
2⁷ = 128 < 255
2⁸ = 256 > 255

Значит, для записи числа 255 в двоичной системе нужно 8 цифр.

Проверка:
255₁₀ = 11111111₂ (8 цифр)

Проверка в Python:
number = 255
binary = bin(number)[2:]
print(f"Число {number}₁₀ в двоичной системе: {binary}₂")
print(f"Количество цифр: {len(binary)}")  # 8

Задача 9: Общая формула для количества цифр

Условие: Сколько цифр в восьмеричной записи числа 1000?

Решение:
Нужно найти наименьшую степень 8, которая больше 1000:
8³ = 512 < 1000
8⁴ = 4096 > 1000

Значит, нужно 4 цифры.

Общая формула:
Количество цифр = ⌊log_base(N)⌋ + 1

Проверка в Python:
import math

def count_digits(number, base):
    """Считает количество цифр в записи числа в системе с основанием base"""
    if number == 0:
        return 1
    return int(math.log(number, base)) + 1

number = 1000
octal = oct(number)[2:]
digits_count = count_digits(number, 8)
print(f"Число {number}₁₀ в восьмеричной системе: {octal}₈")
print(f"Количество цифр: {digits_count} (проверка: {len(octal)})")

5. Комплексные задачи

Задачи, сочетающие несколько типов.

Задача 10: ЕГЭ-типичная задача

Условие: Сколько единиц в двоичной записи числа 1025?

Решение:
Переводим 1025 в двоичную систему:
1025 ÷ 2 = 512 (остаток 1)
 512 ÷ 2 = 256 (остаток 0)
 256 ÷ 2 = 128 (остаток 0)
 128 ÷ 2 =  64 (остаток 0)
  64 ÷ 2 =  32 (остаток 0)
  32 ÷ 2 =  16 (остаток 0)
  16 ÷ 2 =   8 (остаток 0)
   8 ÷ 2 =   4 (остаток 0)
   4 ÷ 2 =   2 (остаток 0)
   2 ÷ 2 =   1 (остаток 0)
   1 ÷ 2 =   0 (остаток 1)

1025₁₀ = 10000000001₂

Считаем единицы: их 2.

Проверка в Python:
number = 1025
binary = bin(number)[2:]
ones_count = binary.count('1')
print(f"Число {number}₁₀ = {binary}₂")
print(f"Количество единиц: {ones_count}")  # 2

Задача 11: Задача на диапазон

Условие: Сколько существует чисел, двоичная запись которых содержит ровно 5 единиц,
а десятичная запись оканчивается на 0?

Решение в Python:
def count_numbers():
    count = 0
    for num in range(1, 10000):  # Проверяем числа до 10000
        binary = bin(num)[2:]
        # Проверяем: 5 единиц в двоичной и оканчивается на 0 в десятичной
        if binary.count('1') == 5 and num % 10 == 0:
            count += 1
            print(f"Найдено: {num}₁₀ = {binary}₂")
    return count

result = count_numbers()
print(f"\nВсего таких чисел: {result}")

8. Типичные ошибки в задачах ЕГЭ

Ошибка 1: Неправильный порядок остатков

# НЕПРАВИЛЬНО - читаем остатки сверху вниз
125 ÷ 8 = 15 (остаток 5) ← это НЕ старший разряд!
 15 ÷ 8 =  1 (остаток 7)
  1 ÷ 8 =  0 (остаток 1)

# ПРАВИЛЬНО - читаем остатки снизу вверх
# Последний остаток (1) - старший разряд
# Первый остаток (5) - младший разряд
# Результат: 175₈

Ошибка 2: Забыли про буквы в шестнадцатеричной системе

# НЕПРАВИЛЬНО - использовали неправильные символы
hex_num = "1G5"  # G не существует!
# int(hex_num, 16) выдаст ошибку

# ПРАВИЛЬНО - используем только 0-9 и A-F
hex_num = "1A5"  # A = 10
decimal = int(hex_num, 16)
print(decimal)  # 421

Ошибка 3: Неправильное решение уравнения для поиска основания

# НЕПРАВИЛЬНО - неправильно составили уравнение
# Для 110ₓ = 12₁₀
# Неправильно: 1 + 1 + 0 = 12 (это не так!)

# ПРАВИЛЬНО - учитываем позиции разрядов
# 110ₓ = 1×x² + 1×x¹ + 0×x⁰ = x² + x
# x² + x = 12
# x² + x - 12 = 0
# x = 3

Ошибка 4: Неправильный подсчет количества цифр

# НЕПРАВИЛЬНО - неправильная формула
# Для числа 255 в двоичной системе
# Неправильно: log₂(255) ≈ 7.99, значит 7 цифр

# ПРАВИЛЬНО - формула: ⌊log_base(N)⌋ + 1
# log₂(255) ≈ 7.99, значит ⌊7.99⌋ + 1 = 7 + 1 = 8 цифр
# Проверка: 255₁₀ = 11111111₂ (8 цифр)

10. Резюме урока

  • Перевод между системами - используй int(), bin(), oct(), hex() для проверки
  • Поиск основания - составь уравнение, учитывая позиции разрядов

  • Количество цифр - формула: ⌊log_base(N)⌋ + 1, или просто len(bin(N)[2:])
  • Количество единиц - используй bin(N)[2:].count('1')
  • Порядок остатков - при делении читай остатки снизу вверх
  • Буквы в hex - помни, что A=10, B=11, C=12, D=13, E=14, F=15
  • Проверка ответов - всегда проверяй решение с помощью Python
  • Типичные ошибки - неправильный порядок остатков, забытые буквы, неправильные уравнения
