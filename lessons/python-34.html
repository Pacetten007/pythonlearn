1. Построение логических выражений

Логическое выражение — это комбинация логических операций, которая возвращает True или False.

Примеры простых выражений:

# Простые логические выражения
x = 5
y = 10

# Сравнения возвращают логические значения
print(x > 3)        # True
print(y < 5)        # False
print(x == 5)       # True
print(x != y)       # True

# Комбинации с логическими операциями
print(x > 3 and y < 15)   # True and True = True
print(x > 3 or y < 5)     # True or False = True
print(not x > 10)          # not False = True

2. Сложные логические выражения

Сложные выражения содержат несколько логических операций. Важно правильно расставлять скобки!

Пример 1: Проверка диапазона

# Проверка, что число в диапазоне [10, 20]
number = 15

# Способ 1: с использованием AND
in_range = number >= 10 and number <= 20
print(f"Число {number} в диапазоне [10, 20]: {in_range}")  # True

# Способ 2: более читаемый вариант
in_range = (number >= 10) and (number <= 20)
print(f"Число {number} в диапазоне [10, 20]: {in_range}")  # True

Пример 2: Проверка нескольких условий

# Проверка, что число четное И положительное
number = 8

is_even_positive = (number > 0) and (number % 2 == 0)
print(f"Число {number} четное и положительное: {is_even_positive}")  # True

# Проверка, что число отрицательное ИЛИ равно нулю
number = -5
is_non_positive = (number < 0) or (number == 0)
print(f"Число {number} отрицательное или равно нулю: {is_non_positive}")  # True

Пример 3: Сложное условие

# Проверка, что число делится на 3 ИЛИ на 5, но НЕ на 15
number = 9

condition = ((number % 3 == 0) or (number % 5 == 0)) and (number % 15 != 0)
print(f"Число {number} делится на 3 или 5, но не на 15: {condition}")  # True

# Проверка для числа 15
number = 15
condition = ((number % 3 == 0) or (number % 5 == 0)) and (number % 15 != 0)
print(f"Число {number} делится на 3 или 5, но не на 15: {condition}")  # False

3. Таблицы истинности для сложных выражений

Таблицы истинности помогают понять, когда сложное выражение истинно, а когда ложно.

Таблица истинности для (A AND B) OR C:

A     B     C     A AND B    (A AND B) OR C
True  True  True  True       True
True  True  False True       True
True  False True  False      True
True  False False False      False
False True  True  False      True
False True  False False      False
False False True  False      True
False False False False      False

Таблица истинности для NOT (A OR B):

A     B     A OR B    NOT (A OR B)
True  True  True      False
True  False True      False
False True  True      False
False False False     True

4. Законы де Моргана

Законы де Моргана позволяют упрощать логические выражения:

Закон 1: NOT (A AND B) = (NOT A) OR (NOT B)

# Эти выражения эквивалентны:
# not (A and B) = (not A) or (not B)

A = True
B = False

result1 = not (A and B)
result2 = (not A) or (not B)

print(f"not (A and B) = {result1}")        # True
print(f"(not A) or (not B) = {result2}")   # True
print(f"Они равны: {result1 == result2}")  # True

Закон 2: NOT (A OR B) = (NOT A) AND (NOT B)

# Эти выражения эквивалентны:
# not (A or B) = (not A) and (not B)

A = True
B = False

result1 = not (A or B)
result2 = (not A) and (not B)

print(f"not (A or B) = {result1}")          # False
print(f"(not A) and (not B) = {result2}")  # False
print(f"Они равны: {result1 == result2}")  # True

Практическое применение законов де Моргана:

# Условие: число НЕ в диапазоне [10, 20]
number = 25

# Способ 1: прямое условие
not_in_range1 = not (number >= 10 and number <= 20)

# Способ 2: используя закон де Моргана
not_in_range2 = (number < 10) or (number > 20)

print(f"Число {number} не в диапазоне [10, 20]: {not_in_range1}")  # True
print(f"Число {number} не в диапазоне [10, 20]: {not_in_range2}")  # True
print(f"Они равны: {not_in_range1 == not_in_range2}")  # True

5. Упрощение логических выражений

Упрощение делает код более читаемым и понятным.

Пример 1: Упрощение с использованием законов

# Исходное выражение: not (x > 5 and y < 10)
x = 3
y = 7

# Упрощенное: (x <= 5) or (y >= 10)
result1 = not (x > 5 and y < 10)
result2 = (x <= 5) or (y >= 10)

print(f"not (x > 5 and y < 10) = {result1}")  # True
print(f"(x <= 5) or (y >= 10) = {result2}")   # True

Пример 2: Упрощение двойного отрицания

# Двойное отрицание: not (not A) = A
A = True

result1 = not (not A)
print(f"not (not A) = {result1}")  # True
print(f"A = {A}")                  # True
print(f"Они равны: {result1 == A}")  # True

6. Применение в программировании

Пример 1: Валидация данных

# Проверка, что пароль валиден
password = "MyPass123"
min_length = 8
has_upper = any(c.isupper() for c in password)
has_lower = any(c.islower() for c in password)
has_digit = any(c.isdigit() for c in password)

# Сложное условие: все требования должны быть выполнены
is_valid = (len(password) >= min_length and 
            has_upper and 
            has_lower and 
            has_digit)

print(f"Пароль валиден: {is_valid}")  # True

# Проверка, что пароль НЕ валиден
is_invalid = not is_valid
# Или используя закон де Моргана:
is_invalid2 = (len(password) < min_length or 
               not has_upper or 
               not has_lower or 
               not has_digit)

print(f"Пароль не валиден: {is_invalid}")   # False
print(f"Пароль не валиден: {is_invalid2}")  # False

Пример 2: Проверка условий в цикле

# Продолжать цикл, пока число в диапазоне И не равно 0
number = 5

# Условие для продолжения цикла
while (number >= 1 and number <= 10) and number != 0:
    print(f"Число: {number}")
    number -= 1
    if number < 1:
        break

# Упрощенное условие (так как number != 0 избыточно, если number >= 1)
number = 5
while number >= 1 and number <= 10:
    print(f"Число: {number}")
    number -= 1
    if number < 1:
        break

Пример 3: Фильтрация данных

# Найти числа, которые четные ИЛИ делятся на 3, но НЕ делятся на 6
numbers = [2, 3, 4, 6, 8, 9, 12, 15]

filtered = []
for num in numbers:
    # Условие: (четное ИЛИ делится на 3) И НЕ делится на 6
    condition = ((num % 2 == 0) or (num % 3 == 0)) and (num % 6 != 0)
    if condition:
        filtered.append(num)

print(f"Исходный список: {numbers}")
print(f"Отфильтрованный: {filtered}")  # [2, 3, 4, 8, 9, 15]

9. Типичные ошибки

Ошибка 1: Неправильный приоритет операций

# НЕПРАВИЛЬНО - может дать неожиданный результат
result = x > 5 and y < 10 or z == 0
# Непонятно, что выполнится первым: (x > 5 and y < 10) or z == 0
# или x > 5 and (y < 10 or z == 0)

# ПРАВИЛЬНО - используй скобки для ясности
result = (x > 5 and y < 10) or z == 0
# Или
result = x > 5 and (y < 10 or z == 0)

Ошибка 2: Неправильное применение закона де Моргана

# НЕПРАВИЛЬНО - забыли изменить операции сравнения
# not (x > 5 and y < 10)
# Неправильно: (x > 5) or (y < 10)  # Это не эквивалентно!

# ПРАВИЛЬНО - нужно изменить операции сравнения
# not (x > 5 and y < 10)
# Правильно: (x <= 5) or (y >= 10)

Ошибка 3: Избыточные условия

# НЕПРАВИЛЬНО - избыточное условие
# (x > 0) and (x != 0)
# Если x > 0, то x != 0 автоматически

# ПРАВИЛЬНО - упрости выражение
# x > 0  # Этого достаточно

Ошибка 4: Путаница между AND и OR

# НЕПРАВИЛЬНО - неправильная логика
# "Число в диапазоне [10, 20]"
in_range = (number >= 10) or (number <= 20)
# Это вернет True для ЛЮБОГО числа!

# ПРАВИЛЬНО - используй AND для обязательных условий
in_range = (number >= 10) and (number <= 20)
# Число должно быть >= 10 И <= 20 одновременно

11. Резюме урока

  • Логическое выражение - комбинация логических операций, возвращающая True или False
  • Сложные выражения - содержат несколько операций, требуют правильной расстановки скобок
  • Таблицы истинности - помогают понять результат сложных выражений
  • Законы де Моргана:
    • NOT (A AND B) = (NOT A) OR (NOT B)
    • NOT (A OR B) = (NOT A) AND (NOT B)
  • Упрощение - делает код более читаемым и понятным
  • Приоритет операций - not (высший), and (средний), or (низший)
  • Скобки - всегда используй скобки в сложных выражениях для ясности
  • Изменение операций - при применении законов де Моргана не забывай менять операции сравнения
  • Практика - логические выражения используются везде: в условиях, циклах, фильтрации данных
