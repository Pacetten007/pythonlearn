Построчная обработка файлов

Самый эффективный способ обработки файлов - читать по одной строке. Это экономит память и позволяет работать даже с огромными файлами:

with open("file.txt", "r", encoding="utf-8") as file:
    for line in file:
        # Обрабатываем каждую строку
        line = line.strip()  # Убираем \n
        print(line)

Почему построчно лучше?

Метод Преимущества Недостатки
read() Простота, весь файл сразу Требует много памяти
readlines() Список всех строк Весь файл в память
for line in file Мало памяти, работает с большими файлами Нет прямого доступа к строкам

Задача 1: Подсчет строк, слов, символов

Классическая задача - аналог утилиты wc (word count) в Linux:

def count_statistics(filename):
    """Подсчитывает строки, слова и символы в файле"""
    lines = 0
    words = 0
    chars = 0

    try:
        with open(filename, "r", encoding="utf-8") as file:
            for line in file:
                lines += 1
                chars += len(line)
                words += len(line.split())

        print(f"Статистика файла '{filename}':")
        print(f"  Строк: {lines}")
        print(f"  Слов: {words}")
        print(f"  Символов: {chars}")

    except FileNotFoundError:
        print(f"Файл '{filename}' не найден!")

# Использование
count_statistics("text.txt")

Как это работает:

  • lines += 1 - увеличиваем счетчик строк
  • chars += len(line) - добавляем длину строки
  • words += len(line.split()) - split() разбивает строку на слова
  • Обрабатываем построчно - не загружаем весь файл!

Задача 2: Поиск текста с номерами строк

Найдем все строки, содержащие определенный текст, и выведем с номерами:

def search_in_file(filename, search_text, ignore_case=True):
    """Ищет текст в файле и выводит совпадения с номерами строк"""
    found_count = 0

    try:
        with open(filename, "r", encoding="utf-8") as file:
            for line_num, line in enumerate(file, start=1):
                # Подготавливаем для сравнения
                check_line = line.lower() if ignore_case else line
                check_text = search_text.lower() if ignore_case else search_text

                if check_text in check_line:
                    print(f"Строка {line_num}: {line.strip()}")
                    found_count += 1

        print(f"\nНайдено совпадений: {found_count}")

    except FileNotFoundError:
        print(f"Файл '{filename}' не найден!")

# Использование
search_in_file("log.txt", "ERROR")

Полезные приемы:

  • enumerate(file, start=1) - получаем номер строки
  • line.lower() - поиск без учета регистра
  • line.strip() - убираем лишние пробелы
  • Параметр ignore_case - настраиваем поведение

Задача 3: Замена текста в файле

Чтобы заменить текст, нужно прочитать файл, изменить и записать обратно:

def replace_in_file(filename, old_text, new_text):
    """Заменяет текст в файле"""
    try:
        # Шаг 1: Читаем файл
        with open(filename, "r", encoding="utf-8") as file:
            content = file.read()

        # Шаг 2: Заменяем текст
        new_content = content.replace(old_text, new_text)

        # Шаг 3: Записываем обратно
        with open(filename, "w", encoding="utf-8") as file:
            file.write(new_content)

        # Считаем количество замен
        count = content.count(old_text)
        print(f"Заменено {count} вхождений '{old_text}' на '{new_text}'")

    except FileNotFoundError:
        print(f"Файл '{filename}' не найден!")

# Использование
replace_in_file("config.txt", "localhost", "127.0.0.1")

⚠️ Осторожно с заменой!

Метод replace() заменяет все вхождения. Если нужна выборочная замена:

  • Используй регулярные выражения (модуль re)
  • Обрабатывай построчно с условиями
  • Создавай резервную копию перед изменениями!

Задача 4: Фильтрация строк

Удалим пустые строки и комментарии из файла:

def filter_file(input_file, output_file):
    """Удаляет пустые строки и комментарии (начинающиеся с #)"""
    filtered_lines = 0

    try:
        with open(input_file, "r", encoding="utf-8") as infile:
            with open(output_file, "w", encoding="utf-8") as outfile:
                for line in infile:
                    # Убираем пробелы
                    clean_line = line.strip()

                    # Пропускаем пустые строки и комментарии
                    if clean_line and not clean_line.startswith("#"):
                        outfile.write(line)  # Пишем оригинальную строку
                    else:
                        filtered_lines += 1

        print(f"Фильтрация завершена!")
        print(f"Удалено строк: {filtered_lines}")
        print(f"Результат сохранен в '{output_file}'")

    except FileNotFoundError:
        print(f"Файл '{input_file}' не найден!")

# Использование
filter_file("code.py", "code_clean.py")

Работа с двумя файлами одновременно:

  • Вложенные with открывают оба файла
  • Читаем из input_file построчно
  • Записываем в output_file только нужные строки
  • Оба файла автоматически закроются

Задача 5: Частотный анализ слов

Подсчитаем, сколько раз каждое слово встречается в тексте (используя словарь!):

def word_frequency(filename, top_n=10):
    """Подсчитывает частоту слов в файле"""
    word_count = {}

    try:
        with open(filename, "r", encoding="utf-8") as file:
            for line in file:
                # Разбиваем на слова и очищаем от знаков препинания
                words = line.lower().split()

                for word in words:
                    # Убираем знаки препинания
                    clean_word = word.strip(".,!?;:()[]\"'")

                    if clean_word:  # Если слово не пустое
                        # Увеличиваем счетчик
                        word_count[clean_word] = word_count.get(clean_word, 0) + 1

        # Сортируем по частоте (от большего к меньшему)
        sorted_words = sorted(word_count.items(), key=lambda x: x[1], reverse=True)

        # Выводим топ-N слов
        print(f"Топ-{top_n} самых частых слов:")
        for i, (word, count) in enumerate(sorted_words[:top_n], 1):
            print(f"{i}. '{word}' - {count} раз")

    except FileNotFoundError:
        print(f"Файл '{filename}' не найден!")

# Использование
word_frequency("book.txt", top_n=15)

Разбор алгоритма:

  • word_count = {} - словарь для подсчета
  • line.lower() - приводим к нижнему регистру
  • word.strip(".,!?") - убираем знаки препинания
  • word_count.get(clean_word, 0) + 1 - увеличиваем счетчик
  • sorted(..., key=lambda x: x[1]) - сортируем по частоте

Пример 1: Анализатор лог-файлов

def analyze_log(filename):
    """Анализирует лог-файл и выводит статистику"""
    stats = {
        'INFO': 0,
        'WARNING': 0,
        'ERROR': 0,
        'CRITICAL': 0
    }
    errors = []

    try:
        with open(filename, "r", encoding="utf-8") as file:
            for line_num, line in enumerate(file, 1):
                # Подсчитываем типы сообщений
                for level in stats:
                    if level in line:
                        stats[level] += 1
                        if level == 'ERROR' or level == 'CRITICAL':
                            errors.append((line_num, line.strip()))

        # Выводим статистику
        print("=== Статистика логов ===")
        for level, count in stats.items():
            print(f"{level}: {count}")

        # Выводим ошибки
        if errors:
            print("\n=== Найденные ошибки ===")
            for line_num, line in errors:
                print(f"Строка {line_num}: {line}")

    except FileNotFoundError:
        print(f"Файл '{filename}' не найден!")

analyze_log("server.log")

Пример 2: Калькулятор текстовой статистики

def text_stats(filename):
    """Расширенная статистика текста"""
    total_lines = 0
    non_empty_lines = 0
    total_words = 0
    total_chars = 0
    longest_line = ""
    shortest_line = None

    try:
        with open(filename, "r", encoding="utf-8") as file:
            for line in file:
                total_lines += 1
                total_chars += len(line)

                clean_line = line.strip()
                if clean_line:
                    non_empty_lines += 1
                    total_words += len(clean_line.split())

                    # Ищем самую длинную строку
                    if len(clean_line) > len(longest_line):
                        longest_line = clean_line

                    # Ищем самую короткую непустую строку
                    if shortest_line is None or len(clean_line) < len(shortest_line):
                        shortest_line = clean_line

        # Выводим результаты
        print(f"=== Статистика файла '{filename}' ===")
        print(f"Всего строк: {total_lines}")
        print(f"Непустых строк: {non_empty_lines}")
        print(f"Слов: {total_words}")
        print(f"Символов: {total_chars}")
        print(f"Среднее слов в строке: {total_words / non_empty_lines:.1f}")
        print(f"\nСамая длинная строка ({len(longest_line)} символов):")
        print(f"  {longest_line[:50]}...")  # Первые 50 символов
        if shortest_line:
            print(f"\nСамая короткая строка ({len(shortest_line)} символов):")
            print(f"  {shortest_line}")

    except FileNotFoundError:
        print(f"Файл '{filename}' не найден!")
    except ZeroDivisionError:
        print("Файл пустой!")

text_stats("article.txt")

Пример 3: Инструмент поиска и замены

def find_and_replace(input_file, output_file, replacements):
    """
    Множественная замена текста
    replacements - словарь вида {"старый текст": "новый текст"}
    """
    replaced_total = 0

    try:
        with open(input_file, "r", encoding="utf-8") as infile:
            with open(output_file, "w", encoding="utf-8") as outfile:
                for line in infile:
                    new_line = line

                    # Применяем все замены
                    for old, new in replacements.items():
                        count = new_line.count(old)
                        replaced_total += count
                        new_line = new_line.replace(old, new)

                    outfile.write(new_line)

        print(f"Замен выполнено: {replaced_total}")
        print(f"Результат сохранен в '{output_file}'")

    except FileNotFoundError:
        print(f"Файл '{input_file}' не найден!")

# Пример использования
replacements = {
    "Python 2": "Python 3",
    "print ": "print(",
    "raw_input": "input"
}
find_and_replace("old_code.py", "new_code.py", replacements)

Пример 4: Простой счетчик слов

def simple_word_counter(filename):
    """Подсчитывает уникальные слова и общее количество"""
    all_words = []
    unique_words = set()

    try:
        with open(filename, "r", encoding="utf-8") as file:
            for line in file:
                words = line.lower().split()
                for word in words:
                    # Очищаем от знаков препинания
                    clean = word.strip(".,!?;:()[]\"'-")
                    if clean:
                        all_words.append(clean)
                        unique_words.add(clean)

        print(f"Всего слов: {len(all_words)}")
        print(f"Уникальных слов: {len(unique_words)}")
        print(f"Повторяемость: {len(all_words) / len(unique_words):.2f}")

    except FileNotFoundError:
        print(f"Файл '{filename}' не найден!")
    except ZeroDivisionError:
        print("Файл не содержит слов!")

simple_word_counter("text.txt")

Эффективная обработка больших файлов

Когда файл очень большой (гигабайты), важно обрабатывать его правильно:

# ПЛОХО - загружает весь файл в память
with open("huge_file.txt", "r") as file:
    content = file.read()  # Может занять всю память!
    # обработка...

# ХОРОШО - обрабатывает построчно
with open("huge_file.txt", "r", encoding="utf-8") as file:
    for line in file:  # Читает по одной строке
        # обработка строки
        process(line)

Советы по работе с большими файлами:

  • Всегда используй построчное чтение
  • Не загружай весь файл в память
  • Используй генераторы вместо списков
  • Обрабатывай данные сразу, не накапливай
  • Если нужна сортировка - используй внешнюю сортировку

Ошибка 1: Загружаешь весь большой файл в память

# НЕПРАВИЛЬНО - файл может быть огромным!
with open("big_file.txt", "r") as file:
    content = file.read()  # Вся память!
    for line in content.split('\n'):
        process(line)

# ПРАВИЛЬНО - читай построчно
with open("big_file.txt", "r", encoding="utf-8") as file:
    for line in file:  # По одной строке
        process(line.strip())

Ошибка 2: Не убираешь \n при обработке строк

# НЕПРАВИЛЬНО - в конце каждой строки \n
with open("file.txt", "r", encoding="utf-8") as file:
    for line in file:
        if line == "конец":  # Не сработает!
            break

# ПРАВИЛЬНО - используй strip()
with open("file.txt", "r", encoding="utf-8") as file:
    for line in file:
        if line.strip() == "конец":  # Работает!
            break

Ошибка 3: Не обрабатываешь кодировку

# НЕПРАВИЛЬНО - может быть ошибка с русским текстом

    content = file.read()  # UnicodeDecodeError!

# ПРАВИЛЬНО - указывай encoding
with open("file.txt", "r", encoding="utf-8") as file:
    content = file.read()

Ошибка 4: Перезаписываешь входной файл

# ОПАСНО - может потерять данные!
with open("data.txt", "r") as file:
    lines = file.readlines()

with open("data.txt", "w") as file:  # Удалит файл!
    # Если тут ошибка - данные потеряны!

        file.write(line.upper())

# БЕЗОПАСНЕЕ - используй другой файл
with open("data.txt", "r", encoding="utf-8") as infile:
    with open("data_new.txt", "w", encoding="utf-8") as outfile:
        for line in infile:
            outfile.write(line.upper())

Ошибка 5: Неправильно считаешь слова

# НЕПРАВИЛЬНО - считает знаки препинания как части слов

# ПРАВИЛЬНО - очищай от знаков препинания
text = "Hello, world!"
words = [word.strip(".,!?;:") for word in text.split()]
print(words)  # ['Hello', 'world']

Ошибка 6: Забываешь про регистр при поиске

    print("Найдено!")

Ошибка 7: Не используешь enumerate для номеров строк

with open("file.txt", "r", encoding="utf-8") as file:
    for line_num, line in enumerate(file, start=1):
        print(f"{line_num}: {line.strip()}")

  • Построчная обработка - лучший способ для больших файлов
  • for line in file - эффективная итерация
  • line.strip() - убирает \n и пробелы
  • line.split() - разбивает строку на слова
  • enumerate(file, start=1) - получение номера строки
  • Словари - отлично для подсчета частоты
  • Вложенные with - работа с двумя файлами сразу
  • str.replace() - замена текста
  • line.lower() - поиск без учета регистра
  • Обработка ошибок - try/except для FileNotFoundError
  • Кодировка utf-8 - для русского текста
