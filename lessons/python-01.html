Что такое Python?

Python - это один из самых популярных языков программирования в мире. Его используют в Google, Instagram, Spotify, NASA и тысячах других компаний.

Почему Python так популярен?

  • Простой и понятный синтаксис - код читается почти как английский текст
  • Мощный и универсальный - можно создавать игры, сайты, приложения, работать с данными
  • Огромное сообщество - легко найти помощь и готовые решения
  • Отличный для обучения - идеально подходит для начинающих
  • Востребован на работе - Python-программисты очень нужны компаниям

Твоя первая программа: Hello, World!

По традиции первая программа любого программиста выводит на экран приветствие. Давай и мы начнем с классики!

print("Hello, World!")

Вот и все! Одна строка кода - и ты уже программист! Эта программа выведет на экран текст: Hello, World!

Интересный факт

Традиция начинать обучение с программы "Hello, World!" появилась в 1978 году благодаря книге Брайана Кернигана и Денниса Ритчи о языке C. С тех пор миллионы программистов по всему миру начинали свой путь именно с этой программы!

Функция print()

Главная функция, которую мы сегодня изучим, называется print(). Это твой способ общаться с пользователем программы!

Базовый синтаксис

Самый простой способ использования:

print("Привет!")
print("Я изучаю Python!")
print("Это очень интересно!")

Результат:

Привет!
Я изучаю Python!
Это очень интересно!

Обрати внимание!

  • Текст (строка) заключается в кавычки: "текст" или 'текст'
  • После print обязательно идут круглые скобки ()
  • Каждый print() выводит текст на новой строке

Вывод нескольких значений

Функция print() может выводить несколько значений сразу. Просто перечисли их через запятую:

print("Меня зовут", "Иван")
print("Мне", 15, "лет")
print("Я", "учусь", "в", "9", "классе")

Результат:

Меня зовут Иван
Мне 15 лет
Я учусь в 9 классе

Заметь: между значениями автоматически добавляется пробел!

Параметр sep (разделитель)

Можешь сам выбрать, что будет между словами! Используй параметр sep:

print("Python", "JavaScript", "C++", sep=" | ")
print("2024", "11", "14", sep="-")
print("Раз", "два", "три", sep="...")
print("A", "B", "C", "D", sep="")

Результат:

Python | JavaScript | C++
2024-11-14
Раз...два...три
ABCD

Параметр end (окончание строки)

По умолчанию print() после вывода переходит на новую строку. Но ты можешь изменить это поведение параметром end:

print("Привет", end=" ")
print("мир", end="!")
print()  # Пустой print для перехода на новую строку

print("Раз", end=", ")
print("два", end=", ")
print("три!")

Результат:

Привет мир!
Раз, два, три!

Комментарии в коде

Комментарии - это текст в программе, который Python игнорирует. Они нужны для того, чтобы объяснять, что делает код.

Однострочные комментарии

Используй символ # для создания комментария:

# Это комментарий - Python его не выполняет
print("А это код")  # Комментарий может быть и в конце строки

# Комментарии помогают понять, что делает программа
# Особенно полезны для сложного кода

Зачем нужны комментарии?

  • Объяснять сложные участки кода - чтобы потом вспомнить, что ты делал
  • Оставлять заметки - для себя или других программистов
  • Временно отключать код - закомментировать строку, которую не хочешь выполнять
  • Документировать программу - описывать алгоритм работы

Примеры хороших комментариев:

# Вычисляем площадь прямоугольника
print("Площадь =", 5 * 10)

# TODO: Добавить проверку на отрицательные числа
# FIXME: Исправить ошибку с делением на ноль

Плохие комментарии - избегай их!

# Выводим текст
print("Привет")  # Плохо! Очевидно из кода

# a = 5  # Плохо! Непонятное название переменной

# Этот код работает не знаю как но работает  # Плохо! Нужно разобраться!

Правило: Комментарии должны объяснять "ЗАЧЕМ" и "ПОЧЕМУ", а не "ЧТО" (это и так видно из кода).

Типичные ошибки начинающих

Изучи эти ошибки, чтобы не совершать их самому!

Ошибка 1: Забыли кавычки

# НЕПРАВИЛЬНО:
print(Привет)  # Ошибка! Python думает, что Привет - это переменная

# ПРАВИЛЬНО:
print("Привет")  # Текст должен быть в кавычках!

Ошибка 2: Забыли скобки

# НЕПРАВИЛЬНО:
print "Привет"  # Ошибка! Нужны круглые скобки

# ПРАВИЛЬНО:
print("Привет")  # После print обязательно ()

Ошибка 3: Неправильные кавычки

# НЕПРАВИЛЬНО:
print("Привет')  # Ошибка! Разные кавычки

# ПРАВИЛЬНО:
print("Привет")  # Или оба раза "
print('Привет')  # Или оба раза '

Ошибка 4: Русские буквы в названиях

# ПЛОХАЯ ПРАКТИКА:
принт("текст")  # Работать не будет! print - это английское слово

# ПРАВИЛЬНО:
print("текст")  # Команды всегда на английском!

Запомни: Команды Python всегда пишутся на английском языке, но текст внутри кавычек может быть на русском!
