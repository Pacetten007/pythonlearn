1. Чтение данных из файлов

В ЕГЭ часто нужно читать данные из файла и обрабатывать их.

Задача ЕГЭ 1: Подсчет строк в файле

Условие: Дан файл с числами, по одному на строку. Напишите программу, которая подсчитывает количество строк в файле.
Файл "data.txt":
10
20
30
40
50

Решение:
f = open("data.txt", "r")
count = 0
for line in f:
    count = count + 1
f.close()
print(count)

Решение пошагово:
1. Открываем файл для чтения
2. Читаем каждую строку
3. Увеличиваем счетчик
4. Закрываем файл
5. Выводим результат

Ответ: 5

Проверка в Python:
# Создаем тестовый файл
f = open("data.txt", "w")
f.write("10\n20\n30\n40\n50\n")
f.close()

# Читаем и подсчитываем
f = open("data.txt", "r")
count = 0
for line in f:
    count = count + 1
    print(f"Строка {count}: {line.strip()}")
f.close()
print(f"Всего строк: {count}")  # 5

Задача ЕГЭ 2: Сумма чисел из файла

Условие: Дан файл с числами, по одному на строку. Напишите программу, которая находит сумму всех чисел.
Файл "numbers.txt":
5
10
15
20

Решение:
f = open("numbers.txt", "r")
s = 0
for line in f:
    num = int(line.strip())
    s = s + num
f.close()
print(s)

Решение пошагово:
1. Открываем файл
2. Инициализируем сумму = 0
3. Читаем каждую строку
4. Преобразуем в число (убираем пробелы)
5. Добавляем к сумме
6. Закрываем файл

Ответ: 50 (5+10+15+20)

Проверка в Python:
# Создаем тестовый файл
f = open("numbers.txt", "w")
f.write("5\n10\n15\n20\n")
f.close()

# Читаем и суммируем
f = open("numbers.txt", "r")
s = 0
for line in f:
    num = int(line.strip())
    s = s + num
    print(f"Число: {num}, сумма: {s}")
f.close()
print(f"Итоговая сумма: {s}")  # 50

Задача ЕГЭ 3: Максимальное число из файла

Условие: Дан файл с числами. Напишите программу, которая находит максимальное число.
Файл "data.txt":
12
45
23
67
34

Решение:
f = open("data.txt", "r")
max_num = None
for line in f:
    num = int(line.strip())
    if max_num == None or num > max_num:
        max_num = num
f.close()
print(max_num)

Решение пошагово:
1. Открываем файл
2. Инициализируем max_num = None
3. Читаем каждую строку
4. Преобразуем в число
5. Если это первое число или больше текущего максимума, обновляем
6. Закрываем файл

Ответ: 67

Проверка в Python:
# Создаем тестовый файл
f = open("data.txt", "w")
f.write("12\n45\n23\n67\n34\n")
f.close()

# Находим максимум
f = open("data.txt", "r")
max_num = None
for line in f:
    num = int(line.strip())
    if max_num == None or num > max_num:
        max_num = num
    print(f"Число: {num}, максимум: {max_num}")
f.close()
print(f"Максимальное число: {max_num}")  # 67

2. Запись данных в файлы

В ЕГЭ часто нужно записывать результаты обработки в файл.

Задача ЕГЭ 4: Запись результатов

Условие: Дан файл с числами. Напишите программу, которая записывает в новый файл только четные числа.
Входной файл "input.txt":
1
2
3
4
5
6

Решение:
# Читаем из входного файла
f_in = open("input.txt", "r")
even_numbers = []
for line in f_in:
    num = int(line.strip())
    if num % 2 == 0:
        even_numbers.append(num)
f_in.close()

# Записываем в выходной файл
f_out = open("output.txt", "w")
for num in even_numbers:
    f_out.write(str(num) + "\n")
f_out.close()

Решение пошагово:
1. Открываем входной файл для чтения
2. Читаем числа и отбираем четные
3. Закрываем входной файл
4. Открываем выходной файл для записи
5. Записываем четные числа
6. Закрываем выходной файл

Выходной файл "output.txt":
2
4
6

Проверка в Python:
# Создаем входной файл
f = open("input.txt", "w")
f.write("1\n2\n3\n4\n5\n6\n")
f.close()

# Обрабатываем
f_in = open("input.txt", "r")
even_numbers = []
for line in f_in:
    num = int(line.strip())
    if num % 2 == 0:
        even_numbers.append(num)
        print(f"Четное число: {num}")
f_in.close()

# Записываем результат
f_out = open("output.txt", "w")
for num in even_numbers:
    f_out.write(str(num) + "\n")
f_out.close()
print(f"Записано чисел: {len(even_numbers)}")  # 3

Задача ЕГЭ 5: Подсчет и запись статистики

Условие: Дан файл с числами. Напишите программу, которая записывает в файл статистику: количество, сумму, среднее.
Входной файл "data.txt":
10
20
30
40

Решение:
# Читаем данные
f_in = open("data.txt", "r")
numbers = []
for line in f_in:
    numbers.append(int(line.strip()))
f_in.close()

# Вычисляем статистику
count = len(numbers)
s = 0
for num in numbers:
    s = s + num
average = s / count

# Записываем результат
f_out = open("result.txt", "w")
f_out.write(f"Количество: {count}\n")
f_out.write(f"Сумма: {s}\n")
f_out.write(f"Среднее: {average}\n")
f_out.close()

Выходной файл "result.txt":
Количество: 4
Сумма: 100
Среднее: 25.0

Проверка в Python:
# Создаем входной файл
f = open("data.txt", "w")
f.write("10\n20\n30\n40\n")
f.close()

# Обрабатываем
f_in = open("data.txt", "r")
numbers = []
for line in f_in:
    numbers.append(int(line.strip()))
f_in.close()

count = len(numbers)
s = 0
for num in numbers:
    s = s + num
average = s / count

# Записываем
f_out = open("result.txt", "w")
f_out.write(f"Количество: {count}\n")
f_out.write(f"Сумма: {s}\n")
f_out.write(f"Среднее: {average}\n")
f_out.close()
print(f"Статистика записана: {count} чисел, сумма {s}, среднее {average}")

3. Обработка данных из файлов

В таких задачах нужно читать данные, обрабатывать их и записывать результаты.

Задача ЕГЭ 6: Фильтрация данных

Условие: Дан файл с числами. Напишите программу, которая записывает в новый файл числа, большие заданного значения.
Входной файл "input.txt", порог: 25
15
30
20
40
10
35

Решение:
threshold = 25
f_in = open("input.txt", "r")
result = []
for line in f_in:
    num = int(line.strip())
    if num > threshold:
        result.append(num)
f_in.close()

f_out = open("output.txt", "w")
for num in result:
    f_out.write(str(num) + "\n")
f_out.close()

Выходной файл "output.txt":
30
40
35

Проверка в Python:
# Создаем входной файл
f = open("input.txt", "w")
f.write("15\n30\n20\n40\n10\n35\n")
f.close()

# Фильтруем
threshold = 25
f_in = open("input.txt", "r")
result = []
for line in f_in:
    num = int(line.strip())
    if num > threshold:
        result.append(num)
        print(f"Число {num} > {threshold}")
f_in.close()

# Записываем
f_out = open("output.txt", "w")
for num in result:
    f_out.write(str(num) + "\n")

Задача ЕГЭ 7: Поиск элементов по условию

Условие: Дан файл с числами. Напишите программу, которая находит количество чисел, кратных заданному.
Входной файл "data.txt", делитель: 3
12
15
20
18
25
21

Решение:
divisor = 3
f = open("data.txt", "r")
count = 0
for line in f:
    num = int(line.strip())
    if num % divisor == 0:
        count = count + 1
f.close()
print(count)

Решение пошагово:
1. Открываем файл
2. Инициализируем счетчик = 0
3. Читаем каждое число
4. Проверяем, делится ли на 3
5. Если да, увеличиваем счетчик
6. Закрываем файл

Ответ: 4 (12, 15, 18, 21)

Проверка в Python:
# Создаем файл
f = open("data.txt", "w")
f.write("12\n15\n20\n18\n25\n21\n")
f.close()

# Подсчитываем
divisor = 3
f = open("data.txt", "r")
count = 0
for line in f:

        count = count + 1
        print(f"Число {num} кратно {divisor}, всего: {count}")
f.close()
print(f"Итого кратных {divisor}: {count}")  # 4

4. Работа с большими файлами

В ЕГЭ часто нужно обрабатывать файлы построчно, не загружая все в память.

Задача ЕГЭ 8: Обработка построчно

Условие: Дан большой файл с числами. Напишите программу, которая находит сумму всех чисел, обрабатывая файл построчно.
Файл "bigdata.txt" (может быть очень большим)

Решение:
f = open("bigdata.txt", "r")
s = 0
count = 0
for line in f:
    num = int(line.strip())
    s = s + num
    count = count + 1
f.close()
print(f"Сумма: {s}, количество: {count}")

Важно: Обрабатываем построчно, не загружая весь файл в память!

Проверка в Python:
# Создаем тестовый файл
f = open("bigdata.txt", "w")
for i in range(1, 101):
    f.write(str(i) + "\n")
f.close()

# Обрабатываем построчно
f = open("bigdata.txt", "r")
s = 0
count = 0
for line in f:
    num = int(line.strip())
    s = s + num
    count = count + 1
    if count <= 5:
        print(f"Число {num}, сумма: {s}")
f.close()
print(f"Итого: сумма {s}, количество {count}")  # сумма 5050, количество 100

Задача ЕГЭ 9: Поиск максимума в большом файле

Условие: Дан большой файл с числами. Напишите программу, которая находит максимальное число, обрабатывая файл построчно.
Файл "numbers.txt"

Решение:
f = open("numbers.txt", "r")
max_num = None
for line in f:
    num = int(line.strip())
    if max_num == None or num > max_num:
        max_num = num
f.close()
print(max_num)

Важно: Не нужно хранить все числа в памяти, обрабатываем по одному!

Проверка в Python:
# Создаем файл
f = open("numbers.txt", "w")
f.write("45\n12\n78\n23\n56\n90\n34\n")
f.close()

# Находим максимум
f = open("numbers.txt", "r")
max_num = None
for line in f:
    num = int(line.strip())
    if max_num == None or num > max_num:
        max_num = num
        print(f"Новый максимум: {max_num}")
f.close()
print(f"Максимальное число: {max_num}")  # 90

Входной файл "data.txt":
1
2
3
4
5
6
7
8

Решение:
f_in = open("data.txt", "r")
even_count = 0
odd_count = 0
for line in f_in:
    num = int(line.strip())
    if num % 2 == 0:
        even_count = even_count + 1
    else:
        odd_count = odd_count + 1
f_in.close()

f_out = open("result.txt", "w")
f_out.write(f"Четных: {even_count}\n")
f_out.write(f"Нечетных: {odd_count}\n")
f_out.close()

Выходной файл "result.txt":
Четных: 4
Нечетных: 4

Проверка в Python:
# Создаем входной файл
f = open("data.txt", "w")
f.write("1\n2\n3\n4\n5\n6\n7\n8\n")
f.close()

# Анализируем
f_in = open("data.txt", "r")
even_count = 0
odd_count = 0
for line in f_in:
    num = int(line.strip())
    if num % 2 == 0:
        even_count = even_count + 1
    else:
        odd_count = odd_count + 1

# Записываем результат
f_out = open("result.txt", "w")
f_out.write(f"Четных: {even_count}\n")
f_out.write(f"Нечетных: {odd_count}\n")
f_out.close()
print(f"Четных: {even_count}, нечетных: {odd_count}")

8. Типичные ошибки

Ошибка 1: Забыли закрыть файл

# НЕПРАВИЛЬНО - файл не закрыт
f = open("data.txt", "r")
for line in f:
    print(line)
# Файл остался открытым!

# ПРАВИЛЬНО - всегда закрывай файл
f = open("data.txt", "r")
for line in f:
    print(line)
f.close()  # Важно!

Ошибка 2: Не убрали символ новой строки

# НЕПРАВИЛЬНО - остался символ \n
f = open("data.txt", "r")
for line in f:
    num = int(line)  # Ошибка! line содержит "10\n"

# ПРАВИЛЬНО - используй strip()
f = open("data.txt", "r")
for line in f:
    num = int(line.strip())  # Убираем пробелы и \n

Ошибка 3: Неправильная инициализация для поиска максимума

# НЕПРАВИЛЬНО - инициализация нулем может быть неправильной
f = open("data.txt", "r")
max_num = 0  # Что если все числа отрицательные?
for line in f:
    num = int(line.strip())
    if num > max_num:
        max_num = num

# ПРАВИЛЬНО - используй None или первое число
f = open("data.txt", "r")
max_num = None
for line in f:
    num = int(line.strip())
    if max_num == None or num > max_num:
        max_num = num

Ошибка 4: Забыли преобразовать строку в число

# НЕПРАВИЛЬНО - строка вместо числа
f = open("data.txt", "r")
s = 0
for line in f:
    s = s + line  # Ошибка! line - это строка

# ПРАВИЛЬНО - преобразуй в число
f = open("data.txt", "r")
s = 0
for line in f:
    num = int(line.strip())
    s = s + num

10. Резюме урока

  • Открытие файлов - используй open("filename", "r") для чтения, open("filename", "w") для записи
  • Чтение построчно - используй цикл for line in f для обработки больших файлов
  • Обработка строк - всегда используй strip() для удаления пробелов и символа новой строки
  • Преобразование - используй int() для преобразования строк в числа
  • Закрытие файлов - всегда закрывай файлы с помощью close() после работы
  • Запись в файл - преобразуй числа в строки с помощью str() перед записью
  • Инициализация - используй None для поиска максимума/минимума, если не знаешь диапазон
  • Большие файлы - обрабатывай построчно, не загружай весь файл в память
  • Практика - всегда проверяй работу программы на тестовых данных
