1. Основные логические операции

В логике есть три основные операции, которые работают с булевыми значениями (True/False):

1.1. Операция И (AND, ∧)

Результат равен True только когда оба операнда равны True.

Таблица истинности для И:

A     B     A AND B
True  True  True
True  False False
False True  False
False False False

Примеры из жизни:

  • "Идти в кино" = "Есть деньги" И "Есть время"
  • "Получить пятерку" = "Выучить урок" И "Написать контрольную"

1.2. Операция ИЛИ (OR, ∨)

Результат равен True, если хотя бы один операнд равен True.

Таблица истинности для ИЛИ:

A     B     A OR B
True  True  True
True  False True
False True  True
False False False

Примеры из жизни:

  • "Выйти на улицу" = "Надеть куртку" ИЛИ "Надеть пальто"
  • "Сдать экзамен" = "Выучить билеты" ИЛИ "Списать" (хотя списывать не рекомендуется!)

1.3. Операция НЕ (NOT, ¬)

Инвертирует значение: True становится False, False становится True.

Таблица истинности для НЕ:

A     NOT A
True  False
False True

Примеры из жизни:

  • "Не идти в школу" = НЕ "Идти в школу"
  • "Не спать" = НЕ "Спать"

2. Логические операции в Python

В Python логические операции записываются словами: and, or, not.

Примеры использования:

# Операция AND (И)
print(True and True)   # True
print(True and False)  # False
print(False and True)  # False
print(False and False) # False

# Операция OR (ИЛИ)
print(True or True)    # True
print(True or False)   # True
print(False or True)   # True
print(False or False)  # False

# Операция NOT (НЕ)
print(not True)        # False
print(not False)       # True

# Комбинации
print(True and not False)  # True
print((True or False) and True)  # True

3. Логические операции с числами

В Python числа тоже можно использовать в логических операциях:

  • 0 считается False
  • Любое ненулевое число считается True

Примеры:

# Числа в логических операциях
print(5 and 3)    # 3 (возвращает последнее True значение)
print(0 and 5)    # 0 (возвращает первое False значение)
print(5 or 3)     # 5 (возвращает первое True значение)
print(0 or 5)     # 5 (возвращает первое True значение)
print(not 0)      # True
print(not 5)      # False

# Проверка условий
age = 18
if age >= 18 and age < 65:
    print("Можно работать")

score = 85
if score >= 90 or score < 60:
    print("Особый случай")

4. Приоритет операций

Порядок выполнения логических операций (от высшего к низшему):

  1. not (самый высокий приоритет)
  2. and
  3. or (самый низкий приоритет)

Примеры приоритета:

# Без скобок
result1 = not True and False
# Выполняется как: (not True) and False = False and False = False
print(result1)  # False

# Со скобками для ясности
result2 = (not True) and False
print(result2)  # False

# Сложное выражение
result3 = True or False and True
# Выполняется как: True or (False and True) = True or False = True
print(result3)  # True

# Рекомендуется использовать скобки для ясности
result4 = (True or False) and True
print(result4)  # True

Важно!

Всегда используй скобки в сложных логических выражениях, чтобы избежать ошибок и сделать код понятнее!

5. Практические примеры

Пример 1: Проверка возраста

age = 20
has_license = True

# Можно водить машину, если возраст >= 18 И есть права
can_drive = age >= 18 and has_license
print(f"Можно водить: {can_drive}")  # True

# Нельзя водить, если возраст < 18 ИЛИ нет прав
cannot_drive = age < 18 or not has_license
print(f"Нельзя водить: {cannot_drive}")  # False

Пример 2: Проверка оценки

score = 85

# Отлично: оценка >= 90
# Хорошо: оценка >= 75 и < 90
# Удовлетворительно: оценка >= 60 и < 75
# Неудовлетворительно: оценка < 60

is_excellent = score >= 90
is_good = score >= 75 and score < 90
is_satisfactory = score >= 60 and score < 75
is_unsatisfactory = score < 60

print(f"Отлично: {is_excellent}")        # False
print(f"Хорошо: {is_good}")              # True
print(f"Удовлетворительно: {is_satisfactory}")  # False
print(f"Неудовлетворительно: {is_unsatisfactory}")  # False

Пример 3: Проверка пароля

password = "MyPass123"
min_length = 8
has_upper = any(c.isupper() for c in password)
has_lower = any(c.islower() for c in password)
has_digit = any(c.isdigit() for c in password)

# Пароль валиден, если:
# длина >= 8 И есть заглавная буква И есть строчная буква И есть цифра
is_valid = (len(password) >= min_length and 
            has_upper and 
            has_lower and 
            has_digit)

print(f"Пароль валиден: {is_valid}")  # True

8. Типичные ошибки

Ошибка 1: Использование & и | вместо and и or

# НЕПРАВИЛЬНО - & и | это побитовые операции, не логические!
result = True & False  # Работает, но это побитовая операция
result = True | False  # Работает, но это побитовая операция

# ПРАВИЛЬНО - используй and и or для логических операций
result = True and False
result = True or False

Ошибка 2: Неправильный приоритет операций

# НЕПРАВИЛЬНО - может дать неожиданный результат
result = not True and False
# Выполняется как: (not True) and False = False and False = False

# ПРАВИЛЬНО - используй скобки для ясности
result = not (True and False)
# Выполняется как: not (False) = True

Ошибка 3: Сравнение с True/False

# НЕПРАВИЛЬНО - избыточное сравнение
if (age >= 18) == True:
    print("Совершеннолетний")

# ПРАВИЛЬНО - просто используй результат сравнения
if age >= 18:
    print("Совершеннолетний")

# Или если нужно явно проверить на True
if age >= 18 is True:  # Тоже избыточно, но работает
    print("Совершеннолетний")

Ошибка 4: Путаница между AND и OR

# НЕПРАВИЛЬНО - неправильная логика
# "Можно водить, если возраст >= 18 ИЛИ есть права"
can_drive = age >= 18 or has_license
# Это неправильно! Можно водить только если ОБА условия выполнены

# ПРАВИЛЬНО - используй AND для обязательных условий
can_drive = age >= 18 and has_license
# Можно водить только если возраст >= 18 И есть права

10. Резюме урока

  • AND (И) - возвращает True только когда оба операнда True
  • OR (ИЛИ) - возвращает True, если хотя бы один операнд True
  • NOT (НЕ) - инвертирует значение (True → False, False → True)
  • Приоритет - not (высший), and (средний), or (низший)
  • Скобки - всегда используй скобки в сложных выражениях для ясности
  • Числа - 0 считается False, любое ненулевое число - True
  • Синтаксис Python - используй слова and, or, not (не символы &, |, !)
  • Таблицы истинности - помогают понять результат логических операций
  • Практика - логические операции используются везде: в условиях, циклах, проверках
