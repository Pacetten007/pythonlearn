1. Задачи на вычисления

Самые простые задачи - это вычисления по формулам.

Задача ОГЭ 1: Вычисление площади

Условие: Напишите программу, которая вычисляет площадь прямоугольника.
Длина = 5, ширина = 3.

Решение:
a = 5
b = 3
s = a * b
print(s)

Ответ: 15

Проверка в Python:
a = 5
b = 3
s = a * b
print(f"Площадь прямоугольника: {s}")  # 15

b = 20

a = 10

3. Задачи с циклами

Задачи, где нужно использовать циклы для обработки данных.

Задача ОГЭ 6: Сумма чисел

Условие: Напишите программу, которая вычисляет сумму чисел от 1 до 5.

Решение:
s = 0
for i in range(1, 6):
    s = s + i
print(s)

Ответ: 15

Проверка в Python:
s = 0
for i in range(1, 6):
    s = s + i
    print(f"i={i}, s={s}")
print(f"Итоговая сумма: {s}")  # 15

Задача ОГЭ 7: Подсчет четных чисел

count = 0

Ответ: 5

Проверка в Python:
count = 0

Задача ОГЭ 8: Факториал

Условие: Напишите программу, которая вычисляет факториал числа 5.
Факториал n = 1 × 2 × 3 × ... × n

Решение:

Ответ: 120

Проверка в Python:

4. Задачи на работу с числами

Задачи, где нужно работать с цифрами числа, проверять свойства чисел.

Задача ОГЭ 9: Сумма цифр числа

Условие: Напишите программу, которая вычисляет сумму цифр числа 123.

Решение:
n = 123
s = 0
while n > 0:
    s = s + n % 10
    n = n // 10
print(s)

Решение пошагово:
1. n = 123, s = 0
2. n % 10 = 3, s = 0 + 3 = 3, n = 123 // 10 = 12
3. n % 10 = 2, s = 3 + 2 = 5, n = 12 // 10 = 1
4. n % 10 = 1, s = 5 + 1 = 6, n = 1 // 10 = 0
5. n = 0, цикл завершается

Ответ: 6

Проверка в Python:
n = 123
s = 0
while n > 0:
    digit = n % 10
    s = s + digit
    n = n // 10
    print(f"Цифра: {digit}, сумма: {s}, осталось: {n}")
print(f"Итоговая сумма цифр: {s}")  # 6

Задача ОГЭ 10: Проверка на простое число

Условие: Напишите программу, которая проверяет, является ли число 7 простым.

Решение:
n = 7
is_prime = True
if n < 2:
    is_prime = False
else:
    for i in range(2, n):
        if n % i == 0:
            is_prime = False
            break

if is_prime:
    print("Простое")
else:
    print("Не простое")

Ответ: Простое

Проверка в Python:
n = 7
is_prime = True
if n < 2:
    is_prime = False
else:
    for i in range(2, n):
        if n % i == 0:
            is_prime = False
            break
        print(f"Проверка делителя {i}: {n} % {i} = {n % i}")

if is_prime:
    print(f"{n} - простое число")
else:
    print(f"{n} - не простое число")  # 7 - простое число

5. Комплексные задачи

Задачи, сочетающие несколько элементов.

Задача ОГЭ 11: Сумма четных чисел в диапазоне

Условие: Напишите программу, которая вычисляет сумму всех четных чисел от 2 до 10 включительно.

Решение:
s = 0
for i in range(2, 11):
    if i % 2 == 0:
        s = s + i
print(s)

Решение пошагово:
- i = 2: четное, s = 0 + 2 = 2
- i = 3: нечетное, пропускаем
- i = 4: четное, s = 2 + 4 = 6
- i = 5: нечетное, пропускаем
- i = 6: четное, s = 6 + 6 = 12
- i = 7: нечетное, пропускаем
- i = 8: четное, s = 12 + 8 = 20
- i = 9: нечетное, пропускаем
- i = 10: четное, s = 20 + 10 = 30

Ответ: 30

Проверка в Python:
s = 0
for i in range(2, 11):
    if i % 2 == 0:
        s = s + i
        print(f"Четное число: {i}, сумма: {s}")
print(f"Итоговая сумма четных: {s}")  # 30

8. Типичные ошибки

Ошибка 1: Неправильный range()

# НЕПРАВИЛЬНО - забыли, что range(1, 5) не включает 5
for i in range(1, 5):
    print(i)  # Выведет: 1, 2, 3, 4 (без 5!)

# ПРАВИЛЬНО - используй range(1, 6) для чисел от 1 до 5
for i in range(1, 6):
    print(i)  # Выведет: 1, 2, 3, 4, 5

Ошибка 2: Неправильное условие для диапазона

# НЕПРАВИЛЬНО - неправильная логика
n = 15
if n > 10 and n < 20:  # Это правильно, но можно проще
    print("В диапазоне")

# ПРАВИЛЬНО - используй цепочку сравнений
n = 15
if 10 <= n <= 20:  # Более читаемо
    print("В диапазоне")

Ошибка 3: Забыли инициализировать переменную

# НЕПРАВИЛЬНО - переменная s не инициализирована
for i in range(1, 6):
    s = s + i  # Ошибка! s не определена

# ПРАВИЛЬНО - инициализируй переменную перед циклом
s = 0
for i in range(1, 6):
    s = s + i
print(s)

10. Резюме урока

  • Вычисления - используй арифметические операции для вычислений
  • Условия - if/else для проверки условий и выполнения разных действий
  • Циклы - for для перебора значений, while для повторения до условия
  • range() - помни, что range(a, b) включает числа от a до b-1
  • Инициализация - всегда инициализируй переменные перед использованием
  • Работа с числами - используй % для остатка, // для целочисленного деления
  • Пошаговое выполнение - отслеживай изменения переменных на каждом шаге
  • Проверка - всегда проверяй программу на разных входных данных
