Урок 19: Кортежи (Tuples)

Структуры данных • 40 минут

Введение

Кортеж (tuple) - это как список, но неизменяемый (immutable)! После создания кортежа ты не можешь изменить, добавить или удалить его элементы. Зачем это нужно? Для защиты данных, которые не должны меняться: координаты точки, RGB цвет, дата рождения, размеры экрана.

Кортежи работают быстрее списков и занимают меньше памяти. Их можно использовать как ключи в словарях (списки - нельзя!). Это важная структура данных в Python!

Что мы изучим:

  • Создание кортежей (круглые скобки или без них)
  • Важность запятой для одноэлементного кортежа!
  • Зачем использовать кортежи вместо списков
  • Доступ к элементам (как в списках)
  • Почему нельзя изменять элементы
  • Методы кортежей: count() и index()
  • Распаковка кортежей и обмен значений
  • Когда использовать кортеж, а когда список

Создание кортежей

Кортежи создаются с помощью круглых скобок () или просто через запятую:

# Создание кортежа с круглыми скобками
point = (10, 20)
print(point)  # (10, 20)
print(type(point))  # 

# Кортеж из разных типов данных
person = ("Иван", 16, "Москва")
print(person)  # ('Иван', 16, 'Москва')

# Создание без скобок (тоже кортеж!)
coordinates = 5, 15, 25
print(coordinates)  # (5, 15, 25)
print(type(coordinates))  # 

# Пустой кортеж
empty = ()
print(empty)  # ()
print(len(empty))  # 0

ВАЖНО: Кортеж из одного элемента!

Для создания кортежа с одним элементом ОБЯЗАТЕЛЬНА запятая после элемента!

# НЕПРАВИЛЬНО - это НЕ кортеж!
not_tuple = (5)
print(type(not_tuple))  #  - это просто число в скобках!

# ПРАВИЛЬНО - кортеж с одним элементом
single_tuple = (5,)  # Запятая обязательна!
print(type(single_tuple))  # 
print(single_tuple)  # (5,)

# Или без скобок
single_tuple = 5,
print(type(single_tuple))  # 

# Еще примеры одноэлементных кортежей
name_tuple = ("Иван",)  # С запятой - кортеж
colors = ("red",)       # С запятой - кортеж

Зачем нужны кортежи?

Может показаться, что списки удобнее (можно менять). Но у кортежей есть важные преимущества:

Преимущества кортежей:

  • Защита данных: невозможно случайно изменить важные данные
  • Скорость: кортежи работают быстрее списков
  • Память: занимают меньше места в памяти
  • Ключи словарей: можно использовать как ключи (списки нельзя!)
  • Множественное присваивание: удобно возвращать несколько значений из функции
  • Константы: когда данные не должны меняться (дни недели, месяцы и т.д.)
# Примеры использования кортежей

# 1. Координаты (не должны меняться)
point = (100, 200)

# 2. RGB цвет (фиксированные значения)
red = (255, 0, 0)
green = (0, 255, 0)

# 3. Дата (день, месяц, год не меняются)
birthday = (15, 3, 2008)

# 4. Размеры экрана
screen_size = (1920, 1080)

# 5. Константы дней недели
weekdays = ("Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс")

# 6. Версия программы
version = (2, 1, 5)  # версия 2.1.5

Доступ к элементам кортежа

Доступ к элементам кортежа точно такой же, как у списков:

# Индексация кортежа
fruits = ("яблоко", "банан", "апельсин", "груша")

print(fruits[0])   # яблоко (первый элемент)
print(fruits[1])   # банан
print(fruits[-1])  # груша (последний элемент)
print(fruits[-2])  # апельсин

# Срезы
print(fruits[1:3])   # ('банан', 'апельсин')
print(fruits[:2])    # ('яблоко', 'банан')
print(fruits[2:])    # ('апельсин', 'груша')
print(fruits[::-1])  # ('груша', 'апельсин', 'банан', 'яблоко')

# Длина кортежа
print(len(fruits))  # 4

# Проверка принадлежности
print("банан" in fruits)  # True
print("киви" in fruits)   # False

Неизменяемость кортежей

Главное отличие от списков - кортежи НЕЛЬЗЯ изменить после создания:

# Кортеж нельзя изменить
point = (10, 20)

# Попытка изменить элемент
# point[0] = 999  # TypeError: 'tuple' object does not support item assignment

# Нельзя добавлять элементы
# point.append(30)  # AttributeError: 'tuple' object has no attribute 'append'

# Нельзя удалять элементы
# del point[0]  # TypeError: 'tuple' object doesn't support item deletion

# НО можно создать новый кортеж
point = (100, 200)  # Переприсвоили переменную - это разрешено
print(point)  # (100, 200)

# Список для сравнения (изменяемый)
my_list = [10, 20]
my_list[0] = 999  # Можно изменить
print(my_list)  # [999, 20]

Внимание: кортеж со списком внутри

# Кортеж может содержать изменяемые объекты
mixed = (1, 2, [3, 4])

# Сам кортеж изменить нельзя
# mixed[0] = 999  # TypeError!

# НО можно изменить список внутри кортежа!
mixed[2][0] = 999  # Это разрешено
print(mixed)  # (1, 2, [999, 4])

# Кортеж защищает свою структуру, но не содержимое изменяемых объектов

Методы кортежей

У кортежей всего 2 метода (у списков их было много!). Это потому, что кортеж неизменяемый:

1. count() - подсчитать количество

# count(элемент) - сколько раз встречается элемент
numbers = (1, 2, 3, 2, 4, 2, 5, 2)

count_2 = numbers.count(2)
print(count_2)  # 4 (число 2 встречается 4 раза)

count_5 = numbers.count(5)
print(count_5)  # 1

count_9 = numbers.count(9)
print(count_9)  # 0 (элемента нет)

# Практика: подсчет цветов
colors = ("red", "blue", "red", "green", "red", "blue")
print(f"Красных: {colors.count('red')}")    # 3
print(f"Синих: {colors.count('blue')}")     # 2
print(f"Зеленых: {colors.count('green')}")  # 1

2. index() - найти позицию

# index(элемент) - индекс первого вхождения
fruits = ("яблоко", "банан", "апельсин", "банан")

pos = fruits.index("банан")
print(pos)  # 1 (первое вхождение)

pos = fruits.index("апельсин")
print(pos)  # 2

# ВАЖНО: если элемента нет - ошибка!
# pos = fruits.index("киви")  # ValueError!

# Безопасный поиск
if "киви" in fruits:
    pos = fruits.index("киви")
else:
    print("Элемента 'киви' нет в кортеже")

Распаковка кортежей

Одна из самых полезных возможностей кортежей - распаковка (unpacking):

# Распаковка кортежа в переменные
point = (10, 20)
x, y = point  # Распаковка!
print(f"x = {x}, y = {y}")  # x = 10, y = 20

# Распаковка данных о человеке
person = ("Иван", 16, "Москва")
name, age, city = person
print(f"{name}, {age} лет, город {city}")

# Обмен значений переменных (классический трюк Python!)
a = 5
b = 10
print(f"До: a = {a}, b = {b}")

# В других языках нужна временная переменная
# В Python - одна строка!
a, b = b, a
print(f"После: a = {a}, b = {b}")  # a = 10, b = 5

# Распаковка RGB цвета
color = (255, 128, 64)
red, green, blue = color
print(f"R: {red}, G: {green}, B: {blue}")

# Распаковка с игнорированием элементов
person = ("Иван", 16, "Москва", "ivanov@mail.ru")
name, age, _, email = person  # _ означает "игнорируем"
print(f"{name}: {email}")

Распаковка с оператором *

# Распаковка с "остатком"
numbers = (1, 2, 3, 4, 5)
first, *rest = numbers  # * собирает остальные элементы в список!
print(first)  # 1
print(rest)   # [2, 3, 4, 5] - это список!

# Первый и последний элементы
numbers = (10, 20, 30, 40, 50)
first, *middle, last = numbers
print(first)   # 10
print(middle)  # [20, 30, 40] - список
print(last)    # 50

# Практика: разделить на части
data = (1, 2, 3, 4, 5, 6, 7, 8, 9)
head, *body, tail = data
print(f"Начало: {head}, конец: {tail}, середина: {body}")

Преобразования между кортежами и списками

# Из списка в кортеж
my_list = [1, 2, 3, 4, 5]
my_tuple = tuple(my_list)
print(my_tuple)  # (1, 2, 3, 4, 5)
print(type(my_tuple))  # 

# Из кортежа в список
my_tuple = (10, 20, 30)
my_list = list(my_tuple)
print(my_list)  # [10, 20, 30]
print(type(my_list))  # 

# Из строки в кортеж
text = "Python"
letters = tuple(text)
print(letters)  # ('P', 'y', 't', 'h', 'o', 'n')

# Практика: отсортировать кортеж
numbers = (5, 2, 8, 1, 9)
sorted_list = sorted(numbers)  # sorted() возвращает список!
print(sorted_list)  # [1, 2, 5, 8, 9]

# Чтобы получить отсортированный кортеж
sorted_tuple = tuple(sorted(numbers))
print(sorted_tuple)  # (1, 2, 5, 8, 9)

Когда использовать кортеж, а когда список?

Используй кортеж когда:

  • Данные не должны меняться (константы, координаты, даты)
  • Нужен ключ для словаря (списки нельзя использовать как ключи)
  • Возвращаешь несколько значений из функции
  • Нужна максимальная производительность
  • Защита от случайного изменения данных

Используй список когда:

  • Данные будут меняться (добавление, удаление, изменение)
  • Нужны методы списков (append, remove, sort и т.д.)
  • Количество элементов не фиксировано
  • Работаешь с коллекцией однотипных элементов
# Примеры правильного выбора

# КОРТЕЖ - фиксированные координаты
start_position = (0, 0)
end_position = (100, 100)

# СПИСОК - изменяемый список игроков
players = ["Иван", "Мария"]
players.append("Петр")  # Можем добавлять

# КОРТЕЖ - RGB цвет (3 фиксированных значения)
background_color = (255, 255, 255)

# СПИСОК - изменяемый список оценок
grades = [5, 4, 5]
grades.append(4)  # Добавляем оценку

# КОРТЕЖ - размеры окна (не меняются после создания)
window_size = (1920, 1080)

# СПИСОК - история действий (постоянно растет)
history = []
history.append("Открыл файл")
history.append("Изменил текст")

Практические примеры

Пример 1: Координаты точек

# Работа с координатами точек
point1 = (10, 20)
point2 = (30, 40)
point3 = (50, 60)

# Вычислить расстояние между точками
x1, y1 = point1
x2, y2 = point2

distance_x = abs(x2 - x1)
distance_y = abs(y2 - y1)
print(f"Расстояние: Δx={distance_x}, Δy={distance_y}")

# Список точек треугольника
triangle = [(0, 0), (10, 0), (5, 10)]
print("Координаты треугольника:")
for i, point in enumerate(triangle):
    x, y = point
    print(f"Точка {i+1}: ({x}, {y})")

Пример 2: Данные о студентах

# База данных студентов (кортежи - данные не меняются!)
students = [
    ("Иван Иванов", 16, "10А", 4.5),
    ("Мария Петрова", 15, "9Б", 4.8),
    ("Петр Сидоров", 17, "11В", 4.2)
]

# Вывести информацию о студентах
print("Список студентов:")
for student in students:
    name, age, class_name, gpa = student  # Распаковка
    print(f"{name}, {age} лет, класс {class_name}, средний балл: {gpa}")

# Найти студента с наивысшим баллом
best_student = max(students, key=lambda s: s[3])
name, age, class_name, gpa = best_student
print(f"\nЛучший студент: {name} (балл {gpa})")

Пример 3: Даты и время

# Работа с датами (кортежи идеальны для дат!)
birthday = (15, 3, 2008)  # день, месяц, год
day, month, year = birthday

months = ("янв", "фев", "мар", "апр", "май", "июн",
          "июл", "авг", "сен", "окт", "ноя", "дек")

print(f"Дата рождения: {day} {months[month-1]} {year}")

# Сравнение дат
date1 = (15, 3, 2008)
date2 = (20, 5, 2007)

# Кортежи можно сравнивать!
if date1 > date2:
    print("Первая дата позже")
else:
    print("Вторая дата позже")

Типичные ошибки начинающих

Ошибка 1: Забыли запятую в одноэлементном кортеже

# НЕПРАВИЛЬНО - это не кортеж!
single = (5)
print(type(single))  #  - просто число!

# ПРАВИЛЬНО - кортеж с одним элементом
single = (5,)  # Запятая обязательна!
print(type(single))  # 

# Или без скобок, но с запятой
single = 5,
print(type(single))  #

Ошибка 2: Попытка изменить кортеж

# НЕПРАВИЛЬНО - кортеж неизменяемый!
point = (10, 20)
# point[0] = 999  # TypeError!

# ПРАВИЛЬНО - создать новый кортеж
point = (999, 20)  # Переприсваивание разрешено
print(point)  # (999, 20)

# Или преобразовать в список, изменить, обратно в кортеж
point = (10, 20)
temp_list = list(point)
temp_list[0] = 999
point = tuple(temp_list)
print(point)  # (999, 20)

Ошибка 3: Путаница в распаковке

# НЕПРАВИЛЬНО - количество переменных не совпадает!
point = (10, 20, 30)
# x, y = point  # ValueError! 3 значения, 2 переменные

# ПРАВИЛЬНО - количество переменных совпадает
x, y, z = point
print(f"x={x}, y={y}, z={z}")

# Или используй * для остатка
x, *rest = point
print(f"x={x}, остальное={rest}")

Ошибка 4: Использование методов списка

# НЕПРАВИЛЬНО - у кортежа нет метода append!
numbers = (1, 2, 3)
# numbers.append(4)  # AttributeError!

# ПРАВИЛЬНО - создать новый кортеж
numbers = numbers + (4,)  # Конкатенация
print(numbers)  # (1, 2, 3, 4)

# Или преобразовать в список
numbers = (1, 2, 3)
numbers_list = list(numbers)
numbers_list.append(4)
numbers = tuple(numbers_list)
print(numbers)  # (1, 2, 3, 4)

Ошибка 5: Путаница кортежа и скобок в выражениях

# Скобки в математическом выражении
result = (2 + 3) * 4
print(result)  # 20 (это число, не кортеж!)
print(type(result))  # 

# Кортеж нужна запятая
result = (2 + 3,) * 4
print(result)  # (5, 5, 5, 5) - кортеж повторился 4 раза
print(type(result))  #

Ошибка 6: Сортировка кортежа

# НЕПРАВИЛЬНО - у кортежа нет метода sort!
numbers = (5, 2, 8, 1)
# numbers.sort()  # AttributeError!

# ПРАВИЛЬНО - sorted() возвращает список
sorted_list = sorted(numbers)
print(sorted_list)  # [1, 2, 5, 8] - это список!

# Если нужен кортеж
sorted_tuple = tuple(sorted(numbers))
print(sorted_tuple)  # (1, 2, 5, 8) - кортеж

Резюме урока

  • Кортеж: неизменяемая (immutable) последовательность элементов
  • Создание: (1, 2, 3) или 1, 2, 3 или tuple([1, 2, 3])
  • Один элемент: (5,) - запятая обязательна!
  • Доступ: как у списков - t[0], t[-1], t[1:3]
  • Неизменяемость: нельзя менять, добавлять, удалять элементы
  • Методы: только count() и index()
  • Распаковка: x, y = (10, 20) или first, *rest = tuple
  • Обмен: a, b = b, a - через кортеж!
  • Когда использовать: константы, координаты, ключи словарей, возврат из функций
  • Преобразование: tuple(list) и list(tuple)
