Урок 7: Переменные

Введение в Python • 25 минут

Введение

Представь, что ты пишешь программу для игры. Тебе нужно запомнить имя игрока, его счет, количество жизней. Как это сделать? Вот для этого и нужны переменные!

Переменная - это как коробка с наклейкой. В коробку ты можешь положить данные, а на наклейке написать, что там лежит. В любой момент ты можешь открыть коробку, посмотреть что там, или положить что-то новое.

Что такое переменная?

Переменная - это имя, которое указывает на место в памяти компьютера, где хранится какое-то значение.

Думай о переменной как о контейнере с ярлыком:

  • Имя переменной - это ярлык на коробке (например, "score", "name", "age")
  • Значение переменной - это то, что лежит внутри (число, текст, и т.д.)
  • Ты можешь в любой момент изменить содержимое коробки
  • Ты можешь использовать содержимое коробки в вычислениях

Создание переменных

В Python создать переменную очень просто! Используется оператор присваивания =:

# Создаем переменные
name = "Анна"
age = 15
city = "Москва"
score = 100

Вот что происходит:

  • name = "Анна" - создает переменную name и кладет туда текст "Анна"
  • age = 15 - создает переменную age и кладет туда число 15
  • city = "Москва" - создает переменную city и кладет туда текст "Москва"
  • score = 100 - создает переменную score и кладет туда число 100

Важно понимать!

Оператор = в программировании - это НЕ "равно" из математики!

= означает "присвоить значение" или "положить в коробку".

Читай x = 5 как: "в переменную x положить значение 5" или "x получает значение 5".

Использование переменных

После создания переменной ты можешь использовать её значение:

name = "Иван"
age = 14

print("Привет, меня зовут", name)
print("Мне", age, "лет")
print(name, "учится в школе")

Результат:

Привет, меня зовут Иван
Мне 14 лет
Иван учится в школе

Переменные в вычислениях

Переменные можно использовать в математических операциях:

price = 50
quantity = 3
total = price * quantity

print("Цена:", price, "руб")
print("Количество:", quantity, "шт")
print("Итого:", total, "руб")

Результат:

Цена: 50 руб
Количество: 3 шт
Итого: 150 руб

Изменение значения переменной

Содержимое "коробки" можно менять сколько угодно раз:

score = 0
print("Начальный счет:", score)

score = 10
print("После первого уровня:", score)

score = 25
print("После второго уровня:", score)

score = 50
print("Финальный счет:", score)

Результат:

Начальный счет: 0
После первого уровня: 10
После второго уровня: 25
Финальный счет: 50

Изменение переменной на основе её текущего значения

Очень частая операция - увеличить или уменьшить значение переменной:

score = 100
print("Начальный счет:", score)

score = score + 50  # Добавляем 50 к текущему значению
print("После бонуса:", score)

score = score - 20  # Отнимаем 20 от текущего значения
print("После штрафа:", score)

Результат:

Начальный счет: 100
После бонуса: 150
После штрафа: 130

Разберем score = score + 50:

  1. Берется текущее значение score (100)
  2. К нему прибавляется 50, получается 150
  3. Результат (150) кладется обратно в score

Сокращенная запись операций

Python позволяет писать операции изменения короче:

x = 10

# Вместо x = x + 5 можно написать:
x += 5   # x теперь равен 15

# Аналогично для других операций:
x -= 3   # x = x - 3, теперь x равен 12
x *= 2   # x = x * 2, теперь x равен 24
x /= 4   # x = x / 4, теперь x равен 6

Правила именования переменных

Не любое имя подойдет для переменной! В Python есть строгие правила:

Правило 1: Разрешенные символы

  • Буквы латинского алфавита: a-z, A-Z
  • Цифры: 0-9 (но НЕ в начале имени!)
  • Символ подчеркивания: _

Правильные имена:

name = "Иван"
student_age = 15
score2 = 100
_temp = 42
myVariable = "данные"

Неправильные имена:

2score = 100      # ОШИБКА: начинается с цифры
my-age = 15       # ОШИБКА: дефис запрещен
имя = "Иван"      # НЕ РЕКОМЕНДУЕТСЯ: русские буквы
my variable = 10  # ОШИБКА: пробел запрещен

Правило 2: Регистр важен!

Python различает строчные и заглавные буквы. Это разные переменные:

age = 15
Age = 20
AGE = 25

print(age)   # 15
print(Age)   # 20
print(AGE)   # 25

Правило 3: Зарезервированные слова

Нельзя использовать слова, которые Python использует для своих команд:

Запрещенные имена (ключевые слова Python):

# ЭТИ СЛОВА НЕЛЬЗЯ ИСПОЛЬЗОВАТЬ КАК ИМЕНА ПЕРЕМЕННЫХ:
if, else, elif, while, for, break, continue,
def, class, return, import, from, as,
True, False, None, and, or, not, is, in,
try, except, finally, raise, with, pass, lambda

Правило 4: Используй понятные имена

Технически x, a, qwerty - правильные имена. Но они непонятные!

Плохие имена (непонятные):

a = 15
x = "Москва"
qwerty = 100

Хорошие имена (понятные):

student_age = 15
city_name = "Москва"
total_score = 100

Стили именования в Python

В Python принято использовать snake_case для имен переменных:

  • Все буквы строчные
  • Слова разделяются подчеркиванием _
  • Примеры: student_name, total_price, max_score

Обмен значениями переменных

Интересная задача: как поменять местами значения двух переменных?

Способ 1: С временной переменной

Представь, что у тебя два стакана: один с водой, другой с соком. Как поменять их содержимое? Нужен третий, пустой стакан!

a = 5
b = 10
print("До обмена: a =", a, ", b =", b)

# Обмен значениями через временную переменную
temp = a    # temp = 5
a = b       # a = 10
b = temp    # b = 5

print("После обмена: a =", a, ", b =", b)

Результат:

До обмена: a = 5 , b = 10
После обмена: a = 10 , b = 5

Способ 2: Python magic! (Одновременное присваивание)

В Python есть элегантный способ обмена значениями:

a = 5
b = 10
print("До обмена: a =", a, ", b =", b)

# Обмен одной строкой!
a, b = b, a

print("После обмена: a =", a, ", b =", b)

Результат:

До обмена: a = 5 , b = 10
После обмена: a = 10 , b = 5

Конструкция a, b = b, a - это особенность Python. Правая часть вычисляется полностью, затем присваивается левой части.

Типичные ошибки начинающих

Ошибка 1: Использование переменной до создания

# НЕПРАВИЛЬНО:
print(name)  # Ошибка! Переменная name еще не создана
name = "Иван"

# ПРАВИЛЬНО:
name = "Иван"
print(name)  # Сначала создаем, потом используем

Запомни: Переменную нужно сначала создать (присвоить значение), и только потом использовать!

Ошибка 2: Путаница с оператором =

# ОШИБОЧНОЕ ПОНИМАНИЕ:
x = 5
# Это НЕ означает "x равен 5"
# Это означает "положить 5 в переменную x"

# Поэтому такое возможно:
x = x + 1  # Берем текущее значение x, добавляем 1, кладем обратно в x

В математике выражение x = x + 1 бессмысленно. В программировании - это обычная операция!

Ошибка 3: Забыли кавычки для текста

# НЕПРАВИЛЬНО:
name = Иван  # Ошибка! Python думает, что Иван - это переменная

# ПРАВИЛЬНО:
name = "Иван"  # Текст всегда в кавычках!

Ошибка 4: Неправильные имена переменных

# НЕПРАВИЛЬНО:
2name = "Иван"       # Ошибка: начинается с цифры
my-age = 15          # Ошибка: дефис запрещен
for = 100            # Ошибка: for - зарезервированное слово

# ПРАВИЛЬНО:
name2 = "Иван"
my_age = 15
counter = 100

Ошибка 5: Непонятные имена

# ПЛОХО (работает, но непонятно):
a = 15
b = "Москва"
x = 1000

# ХОРОШО (понятно что хранится):
student_age = 15
city_name = "Москва"
total_score = 1000

Резюме урока

  • Переменная - это контейнер для хранения данных с именем-ярлыком
  • Оператор = присваивает значение переменной (не проверяет равенство!)
  • Создание переменной: name = "значение"
  • Переменную можно изменять сколько угодно раз
  • Переменную можно использовать в вычислениях
  • Сокращенные операторы: +=, -=, *=, /=
  • Правила именования: латинские буквы, цифры (не в начале), подчеркивание
  • Регистр важен: age и Age - разные переменные
  • Используй понятные имена: student_age лучше чем x
  • Обмен значений: классический способ (через temp) или Python способ (a, b = b, a)
