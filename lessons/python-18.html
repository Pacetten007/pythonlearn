Урок 23: Создание функций

Функции • 45 минут

Введение

Представь, что ты строишь дом. Вместо того чтобы каждый раз заново делать окно, ты используешь готовые оконные рамы. Функции в программировании работают точно так же - это готовые блоки кода, которые можно использовать снова и снова!

До этого момента мы писали программы линейно - строка за строкой. Но при создании больших программ это становится неудобно. Функции позволяют разбить программу на логические части, сделать код читаемым и избежать повторений.

Зачем нужны функции?

  • Переиспользование кода: Написал один раз - используй везде
  • Организация: Большая задача разбивается на маленькие понятные части
  • DRY принцип: Don't Repeat Yourself - не повторяйся
  • Читаемость: Код с функциями легче понять
  • Тестирование: Легче найти и исправить ошибки
  • Командная работа: Разные программисты пишут разные функции

Что такое функция?

Функция - это именованный блок кода, который выполняет определенную задачу. Ты уже использовал встроенные функции Python: print(), len(), input(), range(). Теперь научимся создавать свои!

# Аналогия из жизни:
# "Приготовить пиццу" - это функция
# Каждый раз когда нужна пицца - ты её "вызываешь"
# Не нужно каждый раз описывать весь процесс!

Базовый синтаксис функции

Вот самая простая функция:

# Определение функции (создание)
def greet():
    print("Привет!")
    print("Как дела?")

# Вызов функции (использование)
greet()  # Выведет: Привет! Как дела?

# Можно вызвать много раз!
greet()  # Привет! Как дела?
greet()  # Привет! Как дела?

Разбор синтаксиса по частям:

1. Ключевое слово def

def - от английского "define" (определить). Сообщает Python: "Сейчас я создам функцию!"

2. Имя функции

После def идет имя функции. Правила те же, что для переменных:

  • Только буквы, цифры и подчеркивание
  • Начинается с буквы или подчеркивания (не с цифры!)
  • Регистр важен: greet и Greet - разные функции
  • Используй понятные имена: calculate_area, а не func1

3. Скобки ()

Обязательны даже если функция без параметров! Скобки отличают функцию от переменной.

def my_function():  # Правильно - со скобками
    print("Работаю!")

# def my_function  # Ошибка! Нет скобок

4. Двоеточие :

После скобок обязательно двоеточие. Оно показывает начало блока кода функции.

5. Тело функции (отступ 4 пробела)

Весь код функции должен быть с отступом 4 пробела (или Tab). Это важно в Python!

def correct_function():
    print("Строка 1")  # 4 пробела
    print("Строка 2")  # 4 пробела
    print("Строка 3")  # 4 пробела

# def wrong_function():
# print("Ошибка!")  # Нет отступа - IndentationError!

Как работают функции?

Определение vs Вызов

Важно понимать разницу!

# ОПРЕДЕЛЕНИЕ - создаем функцию (код не выполняется!)
def say_hello():
    print("Привет, мир!")

# Пока ничего не произошло! Функция создана, но не вызвана.

# ВЫЗОВ - используем функцию (код выполняется!)
say_hello()  # Теперь выведет: Привет, мир!

Важно!

Определение функции (def) само по себе не выполняет код внутри неё. Функция выполняется только когда её вызывают!

Соглашения об именовании

Хороший программист использует понятные имена функций:

# ХОРОШО - понятно что делает
def print_menu():
    print("1. Начать игру")
    print("2. Выход")

def calculate_sum():
    result = 5 + 3
    print(result)

def draw_line():
    print("-" * 30)

# ПЛОХО - непонятно что делает
def func1():
    print("1. Начать игру")

def f():
    result = 5 + 3
    print(result)

def aaa():
    print("-" * 30)

Соглашения Python (PEP 8):

  • Используй строчные буквы: my_function
  • Слова разделяй подчеркиванием: calculate_average
  • Используй глаголы для действий: print_report, calculate_tax, draw_circle
  • Делай имена описательными: validate_email лучше чем check

Документирование функций (Docstrings)

Профессиональные программисты документируют свои функции. Для этого используются строки документации - docstrings:

def greet():
    """Выводит приветствие на экран."""
    print("Привет!")

def calculate_area():
    """
    Вычисляет площадь прямоугольника.
    Использует фиксированные значения ширины и высоты.
    """
    width = 10
    height = 5
    area = width * height
    print(f"Площадь: {area}")

# Docstring пишется сразу после def, в тройных кавычках
# Можно однострочный """ текст """
# Или многострочный для длинных описаний

Зачем нужны docstrings?

  • Объясняют что делает функция
  • Помогают другим программистам (и тебе через месяц!)
  • Встроенная справка: help(function_name)
  • Хороший тон в профессиональном программировании

Несколько вызовов функции

Одну и ту же функцию можно вызывать сколько угодно раз:

def print_star_line():
    """Выводит линию из звездочек."""
    print("*" * 40)

# Вызываем 5 раз
print_star_line()
print("Заголовок")
print_star_line()
print("Текст")
print_star_line()
print("Подвал")
print_star_line()

# Результат:
# ****************************************
# Заголовок
# ****************************************
# Текст
# ****************************************
# Подвал
# ****************************************

Функции вызывают другие функции

Функции могут вызывать другие функции! Это помогает разбивать сложные задачи:

def print_line():
    """Выводит разделительную линию."""
    print("-" * 50)

def print_double_line():
    """Выводит двойную разделительную линию."""
    print("=" * 50)

def show_menu():
    """Отображает главное меню программы."""
    print_double_line()
    print("           ГЛАВНОЕ МЕНЮ")
    print_double_line()
    print("1. Новая игра")
    print("2. Загрузить игру")
    print("3. Настройки")
    print("4. Выход")
    print_line()

# Вызываем главную функцию
show_menu()

# show_menu() внутри вызывает print_double_line() и print_line()!

Пример 5: Игровой интерфейс

def show_health_bar():
    """Отображает полоску здоровья."""
    health = 70  # 70%
    hearts = "♥" * (health // 10)
    empty = "♡" * (10 - health // 10)
    print(f"Здоровье: [{hearts}{empty}] {health}%")

def show_level_info():
    """Отображает информацию об уровне."""
    print("Уровень: 5")
    print("Опыт: 450/500")

def show_game_screen():
    """Отображает игровой экран."""
    print("\n" + "=" * 35)
    print("       ПРИКЛЮЧЕНИЕ - Игра")
    print("=" * 35)
    show_health_bar()
    show_level_info()
    print("=" * 35)
    print("Ты стоишь перед темной пещерой...")
    print("Что будешь делать?")
    print("=" * 35)

show_game_screen()

Пример 6: Утилиты для работы с текстом

def print_header(text):
    """Выводит текст как заголовок."""
    length = len(text)
    print("=" * (length + 4))
    print(f"  {text}")
    print("=" * (length + 4))

def print_centered():
    """Выводит центрированный текст."""
    text = "Python"
    spaces = " " * 17  # Центрирование
    print(f"{spaces}{text}")

def print_box():
    """Выводит текст в рамке."""
    print("┌─────────────────────┐")
    print("│   Важное сообщение  │")
    print("└─────────────────────┘")

# Демонстрация
print_header("Глава 1")
print()
print_centered()
print()
print_box()

Типичные ошибки начинающих

Ошибка 1: Забыли скобки при вызове

def say_hello():
    print("Привет!")

# НЕПРАВИЛЬНО - нет скобок
say_hello  # Не вызовет функцию! Просто ссылка на неё

# ПРАВИЛЬНО - со скобками
say_hello()  # Вызовет и выведет "Привет!"

Объяснение: Без скобок Python думает что ты просто обращаешься к объекту функции, но не вызываешь её.

Ошибка 2: Неправильный отступ

# НЕПРАВИЛЬНО - нет отступа
# def wrong():
# print("Ошибка!")  # IndentationError

# НЕПРАВИЛЬНО - разные отступы
# def also_wrong():
#     print("Строка 1")  # 4 пробела
#       print("Строка 2")  # 6 пробелов - IndentationError!

# ПРАВИЛЬНО - одинаковые отступы 4 пробела
def correct():
    print("Строка 1")  # 4 пробела
    print("Строка 2")  # 4 пробела
    print("Строка 3")  # 4 пробела

Ошибка 3: Забыли двоеточие после def

# НЕПРАВИЛЬНО - нет двоеточия
# def my_function()
#     print("Привет")  # SyntaxError

# ПРАВИЛЬНО - есть двоеточие
def my_function():
    print("Привет")

Ошибка 4: Вызов до определения

# НЕПРАВИЛЬНО - вызов ДО определения
# greet()  # NameError: name 'greet' is not defined
#
# def greet():
#     print("Привет!")

# ПРАВИЛЬНО - сначала определяем, потом вызываем
def greet():
    print("Привет!")

greet()  # Теперь работает!

Запомни: Python читает файл сверху вниз. Определяй функции в начале файла, вызывай в конце.

Ошибка 5: Путаница с print внутри функции

def calculate():
    result = 10 + 5
    # Забыли print - ничего не выведется!

calculate()  # Функция выполнится, но ничего не покажет

# Правильно:
def calculate():
    result = 10 + 5
    print(f"Результат: {result}")

calculate()  # Выведет: Результат: 15

Важно: Код внутри функции выполняется, но если нет print - ничего не выводится на экран.

Ошибка 6: Опечатки в имени функции

def calculate_sum():
    print(5 + 3)

# НЕПРАВИЛЬНО - опечатка
# calculateSum()  # NameError: name 'calculateSum' is not defined

# ПРАВИЛЬНО - точное имя
calculate_sum()  # Работает!

# Python различает регистр!
# Calculate_Sum() - тоже не сработает

Ошибка 7: Пустая функция без pass

# НЕПРАВИЛЬНО - пустая функция
# def my_function():
#     # SyntaxError: тело функции не может быть пустым

# ПРАВИЛЬНО - используй pass для пустой функции
def my_function():
    pass  # Заглушка, ничего не делает

# Или добавь docstring
def my_function():
    """Эта функция пока ничего не делает."""
    pass
