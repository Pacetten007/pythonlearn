1. Построчная обработка файлов

При работе с большими файлами нельзя загружать весь файл в память. Нужно обрабатывать данные построчно.

Задача ЕГЭ 1: Подсчет строк в большом файле

Условие: В файле input.txt содержится очень много строк. Напишите программу, которая подсчитывает количество строк, не загружая весь файл в память.

Решение:
count = 0
with open('input.txt', 'r', encoding='utf-8') as f:
    for line in f:
        count = count + 1
print(count)

Объяснение:
- Используем with open() для автоматического закрытия файла
- Читаем файл построчно с помощью цикла for
- Каждая строка обрабатывается отдельно, не загружая весь файл
- Счетчик увеличивается на каждой итерации

Проверка в Python:
# Создаем тестовый файл
with open('test.txt', 'w', encoding='utf-8') as f:
    for i in range(1000):
        f.write(f"Строка {i}\n")

# Подсчитываем строки
count = 0
with open('test.txt', 'r', encoding='utf-8') as f:
    for line in f:
        count = count + 1
print(f"Количество строк: {count}")  # 1000

Задача ЕГЭ 2: Поиск максимума в большом файле

Условие: В файле numbers.txt каждая строка содержит одно число. Напишите программу, которая находит максимальное число, не загружая все числа в память.

Решение:
max_num = None
with open('numbers.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        if max_num is None or num > max_num:
            max_num = num
print(max_num)

Объяснение:
- Инициализируем max_num как None
- Читаем файл построчно
- Преобразуем каждую строку в число
- Обновляем максимум при необходимости
- Используем только одну переменную для хранения максимума

Проверка в Python:
# Создаем тестовый файл
with open('numbers.txt', 'w', encoding='utf-8') as f:
    for i in range(10000):
        f.write(f"{i}\n")

# Находим максимум
max_num = None
with open('numbers.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        if max_num is None or num > max_num:
            max_num = num
print(f"Максимальное число: {max_num}")  # 9999

2. Эффективные алгоритмы

Для больших данных нужно выбирать алгоритмы с минимальной сложностью и использовать эффективные структуры данных.

Задача ЕГЭ 3: Подсчет уникальных элементов

Условие: В файле data.txt каждая строка содержит число. Напишите программу, которая подсчитывает количество уникальных чисел, используя минимальную память.

Решение:
unique = set()
with open('data.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        unique.add(num)
print(len(unique))

Объяснение:
- Используем множество (set) для хранения уникальных элементов
- Множество автоматически удаляет дубликаты
- Читаем файл построчно, не загружая все данные
- len(unique) дает количество уникальных элементов

Проверка в Python:
# Создаем тестовый файл с повторяющимися числами
with open('data.txt', 'w', encoding='utf-8') as f:
    for i in range(1000):
        f.write(f"{i % 100}\n")  # Числа от 0 до 99 повторяются

# Подсчитываем уникальные
unique = set()
with open('data.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        unique.add(num)
print(f"Уникальных чисел: {len(unique)}")  # 100

Объяснение:

- Читаем файл построчно
- Добавляем каждое число к сумме
- Не храним все числа в списке

with open('numbers.txt', 'w', encoding='utf-8') as f:

4. Агрегация данных

При обработке больших данных часто нужно вычислять статистику: среднее, минимум, максимум, количество.

Задача ЕГЭ 7: Вычисление среднего значения

Условие: В файле numbers.txt каждая строка содержит число. Напишите программу, которая вычисляет среднее арифметическое всех чисел.

Решение:
total = 0
count = 0
with open('numbers.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        total = total + num
        count = count + 1
if count > 0:
    average = total / count
    print(average)
else:
    print(0)

Объяснение:
- Используем две переменные: total (сумма) и count (количество)
- Читаем файл построчно
- Накапливаем сумму и количество
- Вычисляем среднее как total / count
- Проверяем деление на ноль

Проверка в Python:
# Создаем тестовый файл
with open('numbers.txt', 'w', encoding='utf-8') as f:
    for i in range(1, 101):
        f.write(f"{i}\n")

# Вычисляем среднее
total = 0
count = 0
with open('numbers.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        total = total + num
        count = count + 1
if count > 0:
    average = total / count
    print(f"Среднее значение: {average}")  # 50.5

Задача ЕГЭ 8: Поиск минимума и максимума

Условие: В файле numbers.txt каждая строка содержит число. Напишите программу, которая находит минимальное и максимальное число.

Решение:
min_num = None
max_num = None
with open('numbers.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        if min_num is None or num < min_num:
            min_num = num
        if max_num is None or num > max_num:
            max_num = num
print(f"Минимум: {min_num}, Максимум: {max_num}")

Объяснение:
- Используем две переменные для минимума и максимума
- Инициализируем их как None
- Обновляем при чтении каждого числа
- Не сохраняем все числа в память

Проверка в Python:
# Создаем тестовый файл
with open('numbers.txt', 'w', encoding='utf-8') as f:
    for i in [5, 2, 8, 1, 9, 3, 7, 4, 6]:
        f.write(f"{i}\n")

# Находим минимум и максимум
min_num = None
max_num = None
with open('numbers.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        if min_num is None or num < min_num:
            min_num = num
        if max_num is None or num > max_num:
            max_num = num
print(f"Минимум: {min_num}, Максимум: {max_num}")  # Минимум: 1, Максимум: 9

5. Обработка строковых данных

При работе с большими текстовыми файлами нужно эффективно обрабатывать строки.

Задача ЕГЭ 9: Подсчет слов в большом файле

Условие: В файле text.txt содержится текст. Напишите программу, которая подсчитывает общее количество слов в файле.

Решение:
word_count = 0
with open('text.txt', 'r', encoding='utf-8') as f:
    for line in f:
        words = line.split()
        word_count = word_count + len(words)
print(word_count)

Объяснение:
- Читаем файл построчно
- Разбиваем каждую строку на слова с помощью split()
- Подсчитываем слова в каждой строке
- Накапливаем общее количество

Проверка в Python:
# Создаем тестовый файл
with open('text.txt', 'w', encoding='utf-8') as f:
    f.write("Привет мир\n")
    f.write("Python это язык программирования\n")
    f.write("Изучаем обработку больших данных\n")

# Подсчитываем слова
word_count = 0
with open('text.txt', 'r', encoding='utf-8') as f:
    for line in f:
        words = line.split()
        word_count = word_count + len(words)
print(f"Всего слов: {word_count}")  # 11

Задача ЕГЭ 11: Анализ и запись результатов

Условие: В файле input.txt каждая строка содержит число. Напишите программу, которая находит количество положительных чисел и записывает результат в файл output.txt.

Решение:
count = 0
with open('input.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        if num > 0:
            count = count + 1

with open('output.txt', 'w', encoding='utf-8') as f:
    f.write(str(count))

Объяснение:
- Читаем input.txt построчно
- Подсчитываем положительные числа
- Записываем результат в output.txt
- Не сохраняем все числа в память

Проверка в Python:
# Создаем тестовый файл
with open('input.txt', 'w', encoding='utf-8') as f:
    for i in [-5, 3, -2, 7, -1, 4, -3, 6]:
        f.write(f"{i}\n")

# Обрабатываем
count = 0
with open('input.txt', 'r', encoding='utf-8') as f:
    for line in f:
        num = int(line.strip())
        if num > 0:
            count = count + 1

# Записываем результат
with open('output.txt', 'w', encoding='utf-8') as f:

# Проверяем результат
with open('output.txt', 'r', encoding='utf-8') as f:

Задача ЕГЭ 12: Фильтрация и запись

Условие: В файле input.txt каждая строка содержит число. Напишите программу, которая записывает в файл output.txt только четные числа.

Решение:
with open('input.txt', 'r', encoding='utf-8') as f:
    with open('output.txt', 'w', encoding='utf-8') as out:
        for line in f:
            num = int(line.strip())
            if num % 2 == 0:
                out.write(str(num) + '\n')

Объяснение:
- Открываем оба файла одновременно
- Читаем input.txt построчно
- Фильтруем четные числа
- Записываем их в output.txt
- Не сохраняем все числа в память

Проверка в Python:
# Создаем тестовый файл
with open('input.txt', 'w', encoding='utf-8') as f:
    for i in range(1, 11):
        f.write(f"{i}\n")

# Фильтруем и записываем
with open('input.txt', 'r', encoding='utf-8') as f:
    with open('output.txt', 'w', encoding='utf-8') as out:
        for line in f:
            num = int(line.strip())
            if num % 2 == 0:
                out.write(str(num) + '\n')

# Проверяем результат
with open('output.txt', 'r', encoding='utf-8') as f:
    numbers = [int(line.strip()) for line in f]
    print(f"Четные числа: {numbers}")  # [2, 4, 6, 8, 10]

with open('large_file.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()  # Ошибка! Загружает весь файл
    for line in lines:
        # обработка

# ПРАВИЛЬНО - построчная обработка
with open('large_file.txt', 'r', encoding='utf-8') as f:
    for line in f:  # Читает построчно
        # обработка

Ошибка 2: Сохранение всех данных в список

# НЕПРАВИЛЬНО - сохраняет все числа в список
numbers = []
with open('numbers.txt', 'r', encoding='utf-8') as f:

11. Резюме урока

  • Построчная обработка - читай файлы построчно с помощью цикла for, не загружая весь файл в память
  • Минимизация памяти - используй переменные для накопления результатов, а не списки для хранения всех данных
  • Эффективные структуры - используй set() для уникальных элементов, одну переменную для максимума/минимума
  • Обработка пустых строк - всегда проверяй строку на пустоту перед преобразованием
  • Кодировка - всегда указывай encoding='utf-8' при работе с русским текстом
  • Одновременная работа - можно открывать несколько файлов одновременно с помощью вложенных with
  • Агрегация - вычисляй сумму, среднее, минимум, максимум за один проход по файлу
  • Фильтрация - проверяй условия при чтении и записывай только нужные данные
  • Практика - решай задачи построчно, не сохраняя все данные в память
