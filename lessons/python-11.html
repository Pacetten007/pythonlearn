Урок 16: Списки - Основы

Структуры данных • 45 минут

Введение

Представь, что тебе нужно хранить оценки за неделю: понедельник - 5, вторник - 4, среда - 5... Создавать переменную для каждого дня? day1 = 5, day2 = 4, day3 = 5... Неудобно! Для таких задач в Python есть списки (lists).

Список - это упорядоченная коллекция элементов. Как список покупок, плейлист музыки или список твоих друзей в соцсети. Все элементы хранятся вместе под одним именем!

Что мы изучим:

  • Создание списков разных типов
  • Доступ к элементам по индексу (как в строках!)
  • Срезы списков (slicing)
  • Изменение элементов (списки ИЗМЕНЯЕМЫЕ!)
  • Длина списка: len()
  • Проверка принадлежности: in и not in
  • Перебор элементов в цикле
  • Разница между списками и строками

Зачем нужны списки?

Сравни два подхода к хранению оценок:

# БЕЗ списков - много переменных
grade1 = 5
grade2 = 4
grade3 = 5
grade4 = 3
grade5 = 4
average = (grade1 + grade2 + grade3 + grade4 + grade5) / 5
print(average)  # 4.2

# СО списком - одна переменная!
grades = [5, 4, 5, 3, 4]
average = sum(grades) / len(grades)
print(average)  # 4.2

Список гораздо удобнее! Можно легко добавлять оценки, находить максимум, сортировать и многое другое.

Создание списков

Список создается с помощью квадратных скобок []. Элементы разделяются запятыми:

# Список чисел
numbers = [1, 2, 3, 4, 5]
print(numbers)  # [1, 2, 3, 4, 5]

# Список строк
fruits = ["яблоко", "банан", "апельсин"]
print(fruits)  # ['яблоко', 'банан', 'апельсин']

# Список может содержать разные типы данных!
mixed = [1, "текст", 3.14, True]
print(mixed)  # [1, 'текст', 3.14, True]

# Пустой список
empty = []
print(empty)  # []

Особенности списков:

  • Упорядоченные: элементы имеют строгий порядок (индексы)
  • Изменяемые: можно менять элементы после создания
  • Разнотипные: можно хранить числа, строки, другие списки вместе
  • Динамические: размер списка может меняться (добавлять/удалять)

Индексация списков

Как и в строках, каждый элемент списка имеет индекс (номер). Python считает с 0!

# Доступ к элементам по индексу
fruits = ["яблоко", "банан", "апельсин", "груша"]

# Индексы:  0          1        2           3

print(fruits[0])   # яблоко (первый элемент)
print(fruits[1])   # банан (второй элемент)
print(fruits[3])   # груша (последний элемент)

# Схема индексов:
#  яблоко  банан  апельсин  груша
#    0       1       2        3    (положительные индексы)
#   -4      -3      -2       -1    (отрицательные индексы)

Отрицательные индексы

Отрицательные индексы считают с конца списка (как в строках):

fruits = ["яблоко", "банан", "апельсин", "груша"]

print(fruits[-1])   # груша (последний элемент)
print(fruits[-2])   # апельсин (предпоследний)
print(fruits[-4])   # яблоко (первый = fruits[0])

# Это очень удобно, когда нужен последний элемент!
scores = [10, 20, 30, 40, 50]
last_score = scores[-1]
print(last_score)  # 50

Ошибка: IndexError

Обращение к несуществующему индексу вызовет ошибку!

fruits = ["яблоко", "банан", "апельсин"]  # Индексы: 0, 1, 2

# print(fruits[5])  # IndexError! Индекса 5 не существует
# print(fruits[3])  # IndexError! Последний индекс - 2

# Безопасная проверка
if len(fruits) > 5:
    print(fruits[5])
else:
    print("Элемента с индексом 5 нет")

Срезы списков (Slicing)

Срезы позволяют получить часть списка. Синтаксис точно такой же, как у строк!

Синтаксис срезов:

  • list[start:end] - от start до end-1 (end НЕ включается!)
  • list[:end] - с начала до end-1
  • list[start:] - от start до конца
  • list[:] - весь список (копия)
  • list[start:end:step] - с шагом step
# Срезы списков
numbers = [10, 20, 30, 40, 50, 60, 70]

# [start:end] - от start до end-1
print(numbers[1:4])    # [20, 30, 40] (индексы 1, 2, 3)
print(numbers[0:3])    # [10, 20, 30]

# [:end] - с начала до end-1
print(numbers[:3])     # [10, 20, 30] (первые 3 элемента)

# [start:] - от start до конца
print(numbers[4:])     # [50, 60, 70] (с 4-го до конца)

# [:] - весь список (создает копию!)
copy = numbers[:]
print(copy)  # [10, 20, 30, 40, 50, 60, 70]

# Последние 3 элемента
print(numbers[-3:])    # [50, 60, 70]

Срезы с шагом

Третий параметр среза - шаг. Можно брать каждый второй элемент или перевернуть список!

numbers = [10, 20, 30, 40, 50, 60]

# Каждый второй элемент
print(numbers[::2])     # [10, 30, 50] (индексы 0, 2, 4)

# Каждый второй с 1-го индекса
print(numbers[1::2])    # [20, 40, 60] (индексы 1, 3, 5)

# Переворот списка (шаг -1)
print(numbers[::-1])    # [60, 50, 40, 30, 20, 10]

# Практика: первые 3 элемента в обратном порядке
print(numbers[2::-1])   # [30, 20, 10]

Изменение элементов списка

Важное отличие от строк: списки ИЗМЕНЯЕМЫЕ (mutable)! Можно менять отдельные элементы:

# Списки можно изменять!
fruits = ["яблоко", "банан", "апельсин"]
print(fruits)  # ['яблоко', 'банан', 'апельсин']

# Изменить элемент по индексу
fruits[0] = "груша"
print(fruits)  # ['груша', 'банан', 'апельсин']

fruits[2] = "киви"
print(fruits)  # ['груша', 'банан', 'киви']

# Можно изменять несколько элементов
numbers = [1, 2, 3, 4, 5]
numbers[1] = 20
numbers[3] = 40
print(numbers)  # [1, 20, 3, 40, 5]

Сравнение: строки vs списки

# Строки НЕИЗМЕНЯЕМЫЕ (immutable)
text = "Python"
# text[0] = "J"  # TypeError! Нельзя изменить символ

# Списки ИЗМЕНЯЕМЫЕ (mutable)
letters = ["P", "y", "t", "h", "o", "n"]
letters[0] = "J"  # Можно!
print(letters)  # ['J', 'y', 't', 'h', 'o', 'n']

Длина списка: len()

Функция len() возвращает количество элементов в списке:

# Длина списка
fruits = ["яблоко", "банан", "апельсин"]
print(len(fruits))  # 3

numbers = [10, 20, 30, 40, 50]
print(len(numbers))  # 5

# Пустой список
empty = []
print(len(empty))  # 0

# Применение: получить последний индекс
last_index = len(fruits) - 1
print(fruits[last_index])  # апельсин

Проверка принадлежности

Операторы in и not in проверяют, есть ли элемент в списке:

# Проверка: есть ли элемент в списке?
fruits = ["яблоко", "банан", "апельсин"]

# Оператор in
print("банан" in fruits)      # True
print("киви" in fruits)        # False

# Оператор not in
print("киви" not in fruits)    # True
print("яблоко" not in fruits)  # False

# Применение в условиях
if "банан" in fruits:
    print("Есть банан!")
else:
    print("Банана нет")

# С числами
numbers = [1, 2, 3, 4, 5]
if 3 in numbers:
    print("Число 3 найдено!")  # Выведется

Перебор элементов списка

Список удобно перебирать в цикле for:

Способ 1: Перебор элементов напрямую

# Перебор элементов
fruits = ["яблоко", "банан", "апельсин"]

for fruit in fruits:
    print(fruit)

# Вывод:
# яблоко
# банан
# апельсин

# Можно обрабатывать элементы
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    print(num * 2)  # Умножаем каждый на 2

# Вывод: 2, 4, 6, 8, 10

Способ 2: Перебор с индексами

# Перебор с индексами
fruits = ["яблоко", "банан", "апельсин"]

for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")

# Вывод:
# 0: яблоко
# 1: банан
# 2: апельсин

# Это полезно, когда нужен и индекс, и значение
scores = [85, 90, 78, 92]
for i in range(len(scores)):
    print(f"Оценка {i+1}: {scores[i]}")

Способ 3: enumerate() - индекс и элемент

# enumerate() - получить индекс и элемент
fruits = ["яблоко", "банан", "апельсин"]

for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

# Вывод:
# 0: яблоко
# 1: банан
# 2: апельсин

# Можно начать с другого индекса
for i, fruit in enumerate(fruits, start=1):
    print(f"Фрукт #{i}: {fruit}")

# Вывод:
# Фрукт #1: яблоко
# Фрукт #2: банан
# Фрукт #3: апельсин

Практические примеры

Пример 1: Список оценок

# Анализ оценок студента
grades = [5, 4, 5, 3, 4, 5, 4]

# Статистика
total = sum(grades)
average = total / len(grades)
maximum = max(grades)
minimum = min(grades)

print(f"Всего оценок: {len(grades)}")
print(f"Сумма: {total}")
print(f"Средний балл: {average:.2f}")
print(f"Максимум: {maximum}")
print(f"Минимум: {minimum}")

# Подсчет пятерок
count_5 = grades.count(5)
print(f"Пятерок: {count_5}")

Пример 2: Список покупок

# Список покупок
shopping_list = ["молоко", "хлеб", "яйца", "сыр"]

print("Список покупок:")
for i, item in enumerate(shopping_list, start=1):
    print(f"{i}. {item}")

# Проверка
item = "хлеб"
if item in shopping_list:
    print(f"{item} есть в списке")
else:
    print(f"{item} нужно добавить")

Пример 3: Топ-5 фильмов

# Топ-5 любимых фильмов
movies = [
    "Матрица",
    "Начало",
    "Интерстеллар",
    "Бойцовский клуб",
    "Зеленая миля"
]

print("Мои топ-5 фильмов:")
for i, movie in enumerate(movies, start=1):
    print(f"{i}. {movie}")

# Первый и последний
print(f"\nСамый любимый: {movies[0]}")
print(f"Последний в топе: {movies[-1]}")

Пример 4: Температура за неделю

# Температура за неделю (градусы Цельсия)
temperatures = [22, 24, 23, 25, 26, 24, 23]
days = ["Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс"]

print("Температура за неделю:")
for i in range(len(days)):
    print(f"{days[i]}: {temperatures[i]}°C")

# Средняя температура
avg_temp = sum(temperatures) / len(temperatures)
print(f"\nСредняя температура: {avg_temp:.1f}°C")

# Самый жаркий день
max_temp = max(temperatures)
max_day_index = temperatures.index(max_temp)
print(f"Самый жаркий день: {days[max_day_index]} ({max_temp}°C)")

Типичные ошибки начинающих

Ошибка 1: Выход за границы списка

# НЕПРАВИЛЬНО
fruits = ["яблоко", "банан", "апельсин"]  # Индексы: 0, 1, 2
# print(fruits[3])  # IndexError! Индекса 3 нет

# ПРАВИЛЬНО - проверка
if len(fruits) > 3:
    print(fruits[3])
else:
    print("Элемента с индексом 3 нет")

# Или используй отрицательный индекс для последнего
print(fruits[-1])  # апельсин

Ошибка 2: Забыли, что индексы начинаются с 0

# НЕПРАВИЛЬНО - считаем с 1
days = ["Пн", "Вт", "Ср", "Чт", "Пт"]
# first_day = days[1]  # Это будет "Вт", а не "Пн"!

# ПРАВИЛЬНО - индексы с 0
first_day = days[0]   # Пн
second_day = days[1]  # Вт

# Запомни: индекс = номер - 1

Ошибка 3: Путаница в срезах [start:end]

# end НЕ включается!
numbers = [10, 20, 30, 40, 50]

# Хочу первые 3 элемента (10, 20, 30)
print(numbers[0:3])  # ПРАВИЛЬНО: [10, 20, 30]
# print(numbers[0:2])  # НЕПРАВИЛЬНО: [10, 20] (только 2!)

# Запомни: numbers[0:3] дает элементы 0, 1, 2 (3 не включен!)

Ошибка 4: Сравнение списка и строки

# Это разные типы!
list1 = ["a", "b", "c"]
string1 = "abc"

print(list1 == string1)  # False! Это разные типы

# Преобразования
list_from_string = list(string1)
print(list_from_string)  # ['a', 'b', 'c']

string_from_list = "".join(list1)
print(string_from_list)  # abc

Ошибка 5: Изменение списка во время перебора

# НЕПРАВИЛЬНО - изменяем список во время перебора
numbers = [1, 2, 3, 4, 5]
# for num in numbers:
#     if num == 3:
#         numbers.remove(num)  # Может дать неожиданные результаты!

# ПРАВИЛЬНО - создать копию
numbers = [1, 2, 3, 4, 5]
for num in numbers[:]:  # Перебираем копию
    if num == 3:
        numbers.remove(num)
print(numbers)  # [1, 2, 4, 5]

Ошибка 6: Копирование списка через присваивание

# НЕПРАВИЛЬНО - это не копия!
list1 = [1, 2, 3]
list2 = list1  # list2 ссылается на тот же список!
list2[0] = 999
print(list1)  # [999, 2, 3] - изменился и list1!

# ПРАВИЛЬНО - создать реальную копию
list1 = [1, 2, 3]
list2 = list1[:]  # Или list1.copy()
list2[0] = 999
print(list1)  # [1, 2, 3] - не изменился
print(list2)  # [999, 2, 3]

    • Работу с индексами и срезами
    • Обработку последовательностей чисел
  • Важно знать индексацию (с 0!) и разницу списков и строк
  • Часто проверяется умение работать со срезами и изменять элементы
  • Списки - основа для алгоритмов сортировки и поиска (будут в следующих модулях)

Резюме урока

  • Создание: my_list = [элемент1, элемент2, ...]
  • Индексация: my_list[0] - первый, my_list[-1] - последний
  • Срезы: my_list[start:end] - от start до end-1
  • Длина: len(my_list) - количество элементов
  • Изменение: my_list[i] = новое_значение
  • Проверка: элемент in my_list - True/False
  • Перебор: for item in my_list: или for i, item in enumerate(my_list):
  • Функции: sum(), max(), min() для анализа
  • Изменяемость: списки можно менять (в отличие от строк!)
  • Разнотипность: список может содержать разные типы данных
