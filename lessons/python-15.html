Урок 20: Множества (Sets)

Структуры данных • 40 минут

Введение

Множество (set) - это коллекция уникальных элементов без определенного порядка. Представь корзину с разноцветными шариками - каждый цвет встречается только один раз, и порядок не важен. Множества идеально подходят для удаления дубликатов, поиска общих элементов и проверки принадлежности!

Множества работают очень быстро (проверка x in set мгновенная!) и поддерживают математические операции: объединение, пересечение, разность - как на уроках математики!

Что мы изучим:

  • Создание множеств (фигурные скобки, но не для пустого!)
  • Свойства: неупорядоченность, уникальность, изменяемость
  • Методы: add(), remove(), discard(), pop(), clear()
  • Операции множеств: объединение |, пересечение &, разность -, симметричная разность ^
  • Практическое применение: удаление дубликатов, поиск общих элементов
  • Проверка подмножеств и надмножеств

Создание множеств

Множества создаются с помощью фигурных скобок {} или функции set():

# Создание множества с фигурными скобками
colors = {"red", "green", "blue"}
print(colors)  # {'green', 'red', 'blue'} - порядок может быть любым!
print(type(colors))  # 

# Множество чисел
numbers = {1, 2, 3, 4, 5}
print(numbers)  # {1, 2, 3, 4, 5}

# Множество с разными типами
mixed = {1, "text", 3.14, True}
print(mixed)  # {1, 3.14, 'text'} - True исчез (True == 1)!

# Создание из списка (убирает дубликаты!)
my_list = [1, 2, 2, 3, 3, 3, 4]
my_set = set(my_list)
print(my_set)  # {1, 2, 3, 4} - дубликаты удалились!

# Из строки (каждый символ - элемент)
letters = set("Hello")
print(letters)  # {'l', 'H', 'e', 'o'} - дубликаты 'l' убраны

ВАЖНО: Пустое множество!

Для создания пустого множества используй set(), НЕ {}!

# НЕПРАВИЛЬНО - это не множество!
empty = {}
print(type(empty))  #  - это пустой словарь!

# ПРАВИЛЬНО - пустое множество
empty_set = set()
print(type(empty_set))  # 
print(empty_set)  # set()

# Потом можно добавлять элементы
empty_set.add(1)
empty_set.add(2)
print(empty_set)  # {1, 2}

Свойства множеств

1. Неупорядоченность

Множества не хранят порядок элементов - они оптимизированы для быстрого поиска!

# Порядок элементов непредсказуем
numbers = {5, 2, 8, 1, 9}
print(numbers)  # Может быть {1, 2, 5, 8, 9} или другой порядок

# Нет индексации!
# print(numbers[0])  # TypeError! У множеств нет индексов

# Нет срезов!
# print(numbers[1:3])  # TypeError!

2. Уникальность элементов

Каждый элемент встречается только один раз - дубликаты автоматически удаляются:

# Дубликаты автоматически удаляются
numbers = {1, 2, 2, 3, 3, 3, 4, 4, 4, 4}
print(numbers)  # {1, 2, 3, 4} - все дубликаты исчезли!

# Добавление существующего элемента ничего не делает
numbers.add(2)  # 2 уже есть
print(numbers)  # {1, 2, 3, 4} - не изменилось

# Практика: удаление дубликатов из списка
my_list = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4, 5]
unique = list(set(my_list))
print(unique)  # [1, 2, 3, 4, 5]

3. Изменяемость (mutable)

Можно добавлять и удалять элементы после создания:

# Множество изменяемое
fruits = {"apple", "banana"}
fruits.add("orange")  # Добавить
print(fruits)  # {'apple', 'banana', 'orange'}

fruits.remove("banana")  # Удалить
print(fruits)  # {'apple', 'orange'}

# НО элементы множества должны быть неизменяемыми (hashable)
# valid_set = {1, "text", (1, 2)}  # OK: числа, строки, кортежи
# invalid_set = {[1, 2]}  # TypeError! Списки нельзя (они изменяемые)

Методы множеств

Добавление элементов

# add() - добавить один элемент
colors = {"red", "green"}
colors.add("blue")
print(colors)  # {'red', 'green', 'blue'}

colors.add("red")  # Уже есть - ничего не произойдет
print(colors)  # {'red', 'green', 'blue'}

# update() - добавить несколько элементов
colors.update(["yellow", "purple"])
print(colors)  # {'red', 'green', 'blue', 'yellow', 'purple'}

# Можно передать любую итерируемую структуру
colors.update("RGB")  # Добавит 'R', 'G', 'B'
print(colors)  # Теперь есть 'R', 'G', 'B'

Удаление элементов

# remove() - удалить элемент (ошибка, если нет)
fruits = {"apple", "banana", "orange"}
fruits.remove("banana")
print(fruits)  # {'apple', 'orange'}

# fruits.remove("kiwi")  # KeyError! Элемента нет

# discard() - удалить элемент (без ошибки, если нет)
fruits.discard("apple")
print(fruits)  # {'orange'}

fruits.discard("kiwi")  # Нет ошибки!
print(fruits)  # {'orange'}

# pop() - удалить и вернуть произвольный элемент
numbers = {1, 2, 3, 4, 5}
removed = numbers.pop()  # Удалит случайный элемент
print(f"Удален: {removed}")
print(f"Осталось: {numbers}")

# clear() - удалить все элементы
colors = {"red", "green", "blue"}
colors.clear()
print(colors)  # set()

Операции над множествами

Множества поддерживают математические операции из теории множеств:

1. Объединение (Union) - |

Все элементы из обоих множеств (без дубликатов):

# Объединение множеств
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Оператор |
union1 = set1 | set2
print(union1)  # {1, 2, 3, 4, 5, 6}

# Метод union()
union2 = set1.union(set2)
print(union2)  # {1, 2, 3, 4, 5, 6}

# Практика: объединить списки без дубликатов
list1 = [1, 2, 3]
list2 = [3, 4, 5]
combined = list(set(list1) | set(list2))
print(combined)  # [1, 2, 3, 4, 5]

2. Пересечение (Intersection) - &

Только элементы, которые есть в обоих множествах:

# Пересечение множеств
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Оператор &
intersection1 = set1 & set2
print(intersection1)  # {3, 4} - общие элементы

# Метод intersection()
intersection2 = set1.intersection(set2)
print(intersection2)  # {3, 4}

# Практика: найти общих друзей
alice_friends = {"Bob", "Charlie", "Diana"}
bob_friends = {"Alice", "Charlie", "Eve"}
common = alice_friends & bob_friends
print(f"Общие друзья: {common}")  # {'Charlie'}

3. Разность (Difference) - -

Элементы из первого множества, которых нет во втором:

# Разность множеств
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Оператор -
diff1 = set1 - set2
print(diff1)  # {1, 2} - есть в set1, но нет в set2

diff2 = set2 - set1
print(diff2)  # {5, 6} - есть в set2, но нет в set1

# Метод difference()
diff3 = set1.difference(set2)
print(diff3)  # {1, 2}

# Практика: кто прочитал только первую книгу?
book1_readers = {"Alice", "Bob", "Charlie"}
book2_readers = {"Bob", "Diana", "Eve"}
only_book1 = book1_readers - book2_readers
print(only_book1)  # {'Alice', 'Charlie'}

4. Симметричная разность (Symmetric Difference) - ^

Элементы, которые есть только в одном из множеств (не в обоих):

# Симметричная разность
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Оператор ^
sym_diff1 = set1 ^ set2
print(sym_diff1)  # {1, 2, 5, 6} - не общие элементы

# Метод symmetric_difference()
sym_diff2 = set1.symmetric_difference(set2)
print(sym_diff2)  # {1, 2, 5, 6}

# То же самое, что (set1 - set2) | (set2 - set1)
manual = (set1 - set2) | (set2 - set1)
print(manual)  # {1, 2, 5, 6}

Проверки подмножеств и надмножеств

# issubset() - является ли подмножеством?
set1 = {1, 2, 3}
set2 = {1, 2, 3, 4, 5}

print(set1.issubset(set2))  # True (set1 ⊆ set2)
print(set2.issubset(set1))  # False

# Оператор <=
print(set1 <= set2)  # True

# issuperset() - является ли надмножеством?
print(set2.issuperset(set1))  # True (set2 ⊇ set1)
print(set1.issuperset(set2))  # False

# Оператор >=
print(set2 >= set1)  # True

# isdisjoint() - нет общих элементов?
set3 = {6, 7, 8}
print(set1.isdisjoint(set3))  # True (нет общих)
print(set1.isdisjoint(set2))  # False (есть общие)

Практические примеры

Пример 1: Удаление дубликатов

# Удалить повторяющиеся элементы из списка
numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4, 5]
print(f"С дубликатами: {numbers}")

unique_numbers = list(set(numbers))
print(f"Уникальные: {unique_numbers}")

# Сохранить порядок при удалении дубликатов
def unique_ordered(items):
    seen = set()
    result = []
    for item in items:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result

numbers = [5, 2, 8, 2, 5, 1, 8]
print(unique_ordered(numbers))  # [5, 2, 8, 1] - порядок сохранен

Пример 2: Общие элементы двух списков

# Найти общие элементы
students_math = ["Alice", "Bob", "Charlie", "Diana"]
students_physics = ["Bob", "Diana", "Eve", "Frank"]

# Множества делают это легко!
common = set(students_math) & set(students_physics)
print(f"Учатся и на математике, и на физике: {common}")
# {'Bob', 'Diana'}

# Кто только на математике?
only_math = set(students_math) - set(students_physics)
print(f"Только математика: {only_math}")
# {'Alice', 'Charlie'}

# Все студенты
all_students = set(students_math) | set(students_physics)
print(f"Всего студентов: {len(all_students)}")

Пример 3: Проверка уникальности пароля

# Проверить что все символы пароля уникальны
password = "python123"
unique_chars = set(password)

if len(unique_chars) == len(password):
    print("Все символы уникальны")
else:
    print("Есть повторяющиеся символы")
    # Найти дубликаты
    duplicates = []
    seen = set()
    for char in password:
        if char in seen:
            duplicates.append(char)
        seen.add(char)
    print(f"Дубликаты: {set(duplicates)}")

Типичные ошибки начинающих

Ошибка 1: Пустое множество через {}

# НЕПРАВИЛЬНО - это словарь!
empty = {}
print(type(empty))  # 

# ПРАВИЛЬНО - пустое множество
empty_set = set()
print(type(empty_set))  #

Ошибка 2: Попытка индексации

# НЕПРАВИЛЬНО - у множеств нет индексов!
numbers = {1, 2, 3, 4, 5}
# print(numbers[0])  # TypeError!

# ПРАВИЛЬНО - перебор в цикле
for num in numbers:
    print(num)

Ошибка 3: Добавление изменяемых элементов

# НЕПРАВИЛЬНО - список нельзя добавить в множество!
# my_set = {[1, 2, 3]}  # TypeError!

# ПРАВИЛЬНО - использовать кортежи
my_set = {(1, 2, 3), (4, 5, 6)}  # OK
print(my_set)  # {(1, 2, 3), (4, 5, 6)}

Ошибка 4: remove() несуществующего элемента

# НЕПРАВИЛЬНО - элемента может не быть
colors = {"red", "green"}
# colors.remove("blue")  # KeyError!

# ПРАВИЛЬНО - использовать discard()
colors.discard("blue")  # Нет ошибки!

# Или проверить перед удалением
if "blue" in colors:
    colors.remove("blue")

Ошибка 5: Путаница в операциях

# Путаница & и |
set1 = {1, 2, 3}
set2 = {3, 4, 5}

# & - пересечение (AND - оба множества)
print(set1 & set2)  # {3} - общие элементы

# | - объединение (OR - хотя бы одно)
print(set1 | set2)  # {1, 2, 3, 4, 5} - все элементы

# Запомни: & = меньше, | = больше

Ошибка 6: Потеря порядка при преобразовании

# Множество не сохраняет порядок!
numbers = [5, 2, 8, 1, 3]
unique = list(set(numbers))  # Порядок может измениться!
print(unique)  # Например: [1, 2, 3, 5, 8] - НЕ как в исходном списке

# Сохранить порядок - не использовать set напрямую
def unique_ordered(items):
    seen = set()
    result = []
    for item in items:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result

print(unique_ordered(numbers))  # [5, 2, 8, 1, 3] - порядок сохранен

Резюме урока

  • Множество: коллекция уникальных неупорядоченных элементов
  • Создание: {1, 2, 3} или set([1, 2, 3])
  • Пустое множество: set(), НЕ {} (это словарь!)
  • Свойства: уникальность, неупорядоченность, изменяемость
  • Добавление: add(), update()
  • Удаление: remove() (с ошибкой), discard() (без ошибки), pop(), clear()
  • Объединение: set1 | set2 или union()
  • Пересечение: set1 & set2 или intersection()
  • Разность: set1 - set2 или difference()
  • Симметричная разность: set1 ^ set2 или symmetric_difference()
  • Применение: удаление дубликатов, поиск общих элементов, быстрая проверка принадлежности
