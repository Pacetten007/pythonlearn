Что такое цикл?

Цикл - это конструкция, которая повторяет блок кода несколько раз. Цикл while (пока) работает так:

# Общая структура
while условие:
    # Этот блок повторяется
    # пока условие True
    действие1
    действие2
    # ...

# После цикла (когда условие стало False)

Как работает while:

  1. Проверяется условие
  2. Если условие True - выполняется тело цикла
  3. Возврат к шагу 1 (проверка условия снова)
  4. Если условие False - цикл завершается

Первый пример цикла while

# Выводим числа от 1 до 5
counter = 1  # Начальное значение

while counter <= 5:  # Условие: пока counter меньше или равно 5
    print(counter)   # Вывод текущего значения
    counter = counter + 1  # Увеличение на 1

print("Цикл завершен!")

# Вывод:
# 1
# 2
# 3
# 4
# 5
# Цикл завершен!

Разберем пошагово:

  1. counter = 1 - устанавливаем начальное значение
  2. while counter <= 5: - проверяем условие (1 <= 5 это True)
  3. print(counter) - выводим 1
  4. counter = counter + 1 - теперь counter = 2
  5. Возврат к шагу 2, проверка условия (2 <= 5 это True)
  6. ...и так далее, пока counter не станет 6 (6 <= 5 это False)

Паттерн "Счетчик" (Counter)

Счетчик - это переменная, которая отслеживает номер итерации. Это самый распространенный паттерн в циклах.

# Подсчет от 1 до N
n = 10
counter = 1

while counter <= n:
    print(f"Итерация {counter}")
    counter += 1  # Краткая форма для counter = counter + 1

# Подсчет в обратном порядке (обратный отсчет)
countdown = 5

while countdown > 0:
    print(countdown)
    countdown -= 1  # Уменьшение на 1

print("Пуск!")

# Вывод:
# 5
# 4
# 3
# 2
# 1
# Пуск!

КРИТИЧЕСКИ ВАЖНО: Условие должно стать False!

Опасность бесконечного цикла!

Если условие никогда не станет False, цикл будет работать вечно (пока ты не остановишь программу).

# НЕПРАВИЛЬНО - Бесконечный цикл!
x = 1
while x <= 10:
    print(x)
    # Забыли увеличить x!
    # x всегда равен 1
    # Цикл никогда не закончится!

# ПРАВИЛЬНО - Цикл завершится
x = 1
while x <= 10:
    print(x)
    x += 1  # Обязательно изменяем переменную!

Совет: Если программа "зависла" - нажми Ctrl+C для остановки.

Паттерн "Аккумулятор" (Accumulator)

Аккумулятор - это переменная, которая накапливает результат (сумму, произведение, строку и т.д.).

# Сумма чисел от 1 до N
n = 10
counter = 1
total = 0  # Аккумулятор для суммы

while counter <= n:
    total = total + counter  # Добавляем текущее число к сумме
    counter += 1

print(f"Сумма чисел от 1 до {n} = {total}")
# Сумма чисел от 1 до 10 = 55

# Произведение (факториал)
n = 5
counter = 1
factorial = 1  # Аккумулятор для произведения (начинаем с 1, не с 0!)

while counter <= n:
    factorial = factorial * counter
    counter += 1

print(f"{n}! = {factorial}")
# 5! = 120 (5 * 4 * 3 * 2 * 1)

Валидация ввода с помощью while

Один из самых практичных случаев использования while - повторять запрос, пока пользователь не введет корректные данные.

# Запрашиваем положительное число
number = int(input("Введи положительное число: "))

while number <= 0:
    print("Ошибка! Число должно быть положительным!")
    number = int(input("Попробуй еще раз: "))

print(f"Отлично! Ты ввел {number}")

# Запрос числа в диапазоне
age = int(input("Введи возраст (1-120): "))

while age < 1 or age > 120:
    print("Некорректный возраст!")
    age = int(input("Введи возраст (1-120): "))

print(f"Твой возраст: {age} лет")

Практические примеры

# Пример 1: Таблица умножения
number = int(input("Введи число для таблицы умножения: "))
multiplier = 1

while multiplier <= 10:
    result = number * multiplier
    print(f"{number} × {multiplier} = {result}")
    multiplier += 1

# Пример 2: Сумма введенных чисел (до ввода 0)
total = 0
number = int(input("Введи число (0 для завершения): "))

while number != 0:
    total += number
    number = int(input("Введи число (0 для завершения): "))

print(f"Сумма всех чисел: {total}")

# Пример 3: Проверка пароля (максимум 3 попытки)
correct_password = "python123"
attempts = 3

while attempts > 0:
    password = input("Введи пароль: ")
    
    if password == correct_password:
        print("✓ Доступ разрешен!")
        break  # Выход из цикла (см. следующий раздел)
    else:
        attempts -= 1
        if attempts > 0:
            print(f"✗ Неверный пароль! Осталось попыток: {attempts}")
        else:
            print("✗ Доступ заблокирован!")

# Пример 4: Угадай число
import random
secret_number = random.randint(1, 100)
guess = 0

print("Я загадал число от 1 до 100. Угадай его!")

while guess != secret_number:
    guess = int(input("Твоя догадка: "))
    
    if guess < secret_number:
        print("Слишком маленькое!")
    elif guess > secret_number:
        print("Слишком большое!")
    else:
        print("✓ Правильно! Ты угадал!")

Оператор break - Досрочный выход из цикла

Иногда нужно прервать цикл до того, как условие станет False. Для этого используется break.

# Пример 1: Поиск числа
target = 7
counter = 1

while counter <= 10:
    if counter == target:
        print(f"Нашел число {target}!")
        break  # Выходим из цикла немедленно
    
    counter += 1

print("Цикл завершен")

# Пример 2: Бесконечный цикл с break
while True:  # Условие всегда True!
    answer = input("Продолжить? (да/нет): ")
    
    if answer.lower() == "нет":
        print("Выход из программы")
        break  # Единственный способ выйти из этого цикла
    
    print("Продолжаем работу...")

# Пример 3: Меню программы
while True:
    print("\n=== МЕНЮ ===")
    print("1. Вариант 1")
    print("2. Вариант 2")
    print("3. Выход")
    
    choice = input("Выбери вариант: ")
    
    if choice == "1":
        print("Выполняем вариант 1...")
    elif choice == "2":
        print("Выполняем вариант 2...")
    elif choice == "3":
        print("До свидания!")
        break
    else:
        print("Неверный выбор!")

Оператор continue - Пропуск итерации

Оператор continue пропускает оставшуюся часть текущей итерации и переходит к следующей проверке условия.

# Вывод только нечетных чисел от 1 до 10
number = 0

while number < 10:
    number += 1
    
    if number % 2 == 0:  # Если четное
        continue  # Пропускаем print и переходим к следующей итерации
    
    print(number)

# Вывод:
# 1
# 3
# 5
# 7
# 9

# Пример 2: Пропуск некорректных значений
counter = 0

while counter < 10:
    counter += 1
    
    if counter == 5 or counter == 7:
        continue  # Пропускаем 5 и 7
    
    print(counter)

# Выведет: 1, 2, 3, 4, 6, 8, 9, 10 (без 5 и 7)

Типичные ошибки начинающих

Ошибка 1: Забыли изменить переменную условия

# НЕПРАВИЛЬНО - Бесконечный цикл!
counter = 1
while counter <= 5:
    print(counter)
    # Забыли counter += 1
    # counter всегда 1!

# ПРАВИЛЬНО:
counter = 1
while counter <= 5:
    print(counter)
    counter += 1  # Обязательно!

Ошибка 2: Неправильное начальное значение

# НЕПРАВИЛЬНО - Цикл не выполнится!
counter = 10  # Начинаем с 10
while counter <= 5:  # 10 <= 5 это False!
    print(counter)
    counter += 1
# Ничего не выведется!

# ПРАВИЛЬНО:
counter = 1  # Начинаем с 1
while counter <= 5:
    print(counter)
    counter += 1

Ошибка 3: Изменение переменной в неправильном месте

# НЕПРАВИЛЬНО - Пропускает последнее значение
counter = 1
while counter <= 5:
    counter += 1  # Увеличили ДО print
    print(counter)
# Выведет: 2, 3, 4, 5, 6 (не то, что нужно!)

# ПРАВИЛЬНО:
counter = 1
while counter <= 5:
    print(counter)
    counter += 1  # Увеличили ПОСЛЕ print
# Выведет: 1, 2, 3, 4, 5

Ошибка 4: Неправильное условие

# НЕПРАВИЛЬНО - Лишняя итерация
counter = 1
while counter <= 5:  # <= вместо <
    print(counter)
    counter += 1
# При counter=5: 5 <= 5 это True, выполнится
# Затем counter=6, 6 <= 5 это False

# Если хочешь 5 итераций:
counter = 0
while counter < 5:  # < вместо <=
    counter += 1
    print(counter)
# Выведет: 1, 2, 3, 4, 5

Ошибка 5: Аккумулятор с неправильным начальным значением

# НЕПРАВИЛЬНО - Произведение
factorial = 0  # Начали с 0!
counter = 1
while counter <= 5:
    factorial *= counter  # 0 * что угодно = 0
    counter += 1
print(factorial)  # Всегда будет 0!

# ПРАВИЛЬНО:
factorial = 1  # Для произведения начинаем с 1!
counter = 1
while counter <= 5:
    factorial *= counter
    counter += 1
print(factorial)  # 120

Ошибка 6: Бесконечный цикл без break

# НЕПРАВИЛЬНО:
while True:
    print("Привет!")
    # Нет способа выйти из цикла!
    # Будет работать вечно!

# ПРАВИЛЬНО:
while True:
    answer = input("Продолжить? (да/нет): ")
    if answer == "нет":
        break  # Выход из цикла

Резюме урока

  • while условие: повторяет блок кода, пока условие True
  • Счетчик (counter): переменная для отслеживания номера итерации
  • Аккумулятор: переменная для накопления результата (сумма: начать с 0, произведение: с 1)
  • ОБЯЗАТЕЛЬНО изменять переменную условия в теле цикла!
  • Бесконечный цикл: когда условие никогда не становится False (ошибка!)
  • break: немедленный выход из цикла
  • continue: пропуск оставшейся части текущей итерации
  • while True: бесконечный цикл с выходом через break
  • Валидация ввода: повторять запрос до корректного ответа
