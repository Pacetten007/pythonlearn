Урок 26: Область видимости

Функции • 40 минут

Введение

Представь два дома рядом. В каждом доме свои жильцы, свои вещи. Гости одного дома не могут просто так пользоваться вещами из другого дома! В программировании работает похоже: переменные "живут" в определенных местах кода, и не везде к ним можно обратиться.

Область видимости (scope) - это "зона действия" переменной, где она существует и где к ней можно обращаться. Понимание scope критично для избежания ошибок и написания правильного кода!

Что изучим в этом уроке:

  • Что такое область видимости (scope)
  • Локальные переменные (внутри функций)
  • Глобальные переменные (вне функций)
  • Ключевое слово global
  • Почему global - плохая практика
  • Параметры как локальные переменные
  • Вложенные функции (preview)

Что такое область видимости?

Область видимости определяет где переменная существует и где к ней можно обращаться:

# Простой пример
x = 10  # Глобальная переменная

def my_function():
    y = 20  # Локальная переменная
    print(f"Внутри функции: x={x}, y={y}")

my_function()  # Работает: x=10, y=20

print(f"Вне функции: x={x}")  # Работает: x=10
# print(f"y={y}")  # ОШИБКА! y не существует здесь!

Локальные переменные

Переменные, созданные ВНУТРИ функции, называются локальными. Они существуют только внутри этой функции!

def my_func():
    """Функция с локальной переменной."""
    x = 10  # Локальная переменная
    print(f"Внутри функции: x = {x}")
    
my_func()  # Выведет: Внутри функции: x = 10

# Попытка использовать x ВНЕ функции
# print(x)  # NameError: name 'x' is not defined

# x существует только ВНУТРИ my_func!

Жизненный цикл локальной переменной:

  1. Создание: Когда функция вызывается
  2. Использование: Внутри функции
  3. Уничтожение: Когда функция завершается
def calculate():
    """Демонстрация жизненного цикла локальной переменной."""
    # Здесь переменная 'result' еще НЕ существует
    
    result = 5 + 3  # result СОЗДАЕТСЯ
    print(f"Результат: {result}")  # result ИСПОЛЬЗУЕТСЯ
    
    # Когда функция завершится, result УНИЧТОЖИТСЯ

calculate()  # result живет только во время выполнения
calculate()  # result создается заново (не помнит предыдущий вызов!)
# print(result)  # NameError - result уже уничтожен!

Каждый вызов - свои локальные переменные

def count():
    """Каждый вызов создает новую локальную переменную."""
    x = 0
    x = x + 1
    print(f"x = {x}")

count()  # x = 1
count()  # x = 1 (не 2! x создается заново)
count()  # x = 1 (снова новый x)

Глобальные переменные

Переменные, созданные ВНЕ функций, называются глобальными. Они видны везде в программе!

# Глобальная переменная
total = 0

def show_total():
    """Функция ЧИТАЕТ глобальную переменную."""
    print(f"Текущий total: {total}")  # Можем ЧИТАТЬ

show_total()  # Текущий total: 0

# Изменим глобальную переменную
total = 100

show_total()  # Текущий total: 100

# Глобальную переменную видно отовсюду
print(f"В основной программе: {total}")  # 100

Чтение глобальных - можно, изменение - нельзя!

counter = 0

def read_counter():
    """Читаем глобальную - ОК!"""
    print(f"Counter = {counter}")

read_counter()  # Работает!

def try_change_counter():
    """Пытаемся изменить глобальную - ОШИБКА!"""
    # counter = counter + 1  # UnboundLocalError!
    # Python думает что counter - локальная
    pass

# Чтобы ИЗМЕНИТЬ глобальную - нужен global!

Ключевое слово global

Чтобы ИЗМЕНИТЬ глобальную переменную из функции, используй global:

counter = 0  # Глобальная

def increment():
    """Увеличивает счетчик."""
    global counter  # Говорим Python: используем ГЛОБАЛЬНУЮ counter
    counter = counter + 1
    print(f"Counter увеличен до {counter}")

print(f"Начальный counter: {counter}")  # 0
increment()  # Counter увеличен до 1
increment()  # Counter увеличен до 2
increment()  # Counter увеличен до 3
print(f"Финальный counter: {counter}")  # 3

# Теперь изменения глобальной переменной сохраняются!
# Еще пример - игровой счет
score = 0

def add_points(points):
    """Добавляет очки к счету."""
    global score
    score = score + points
    print(f"+{points} очков! Всего: {score}")

def reset_score():
    """Сбрасывает счет."""
    global score
    score = 0
    print("Счет сброшен!")

add_points(10)  # +10 очков! Всего: 10
add_points(5)   # +5 очков! Всего: 15
add_points(20)  # +20 очков! Всего: 35
reset_score()   # Счет сброшен!
add_points(7)   # +7 очков! Всего: 7

Почему global - плохая практика?

Использование global обычно считается плохой практикой. Почему?

Проблемы с global:

  • Сложно отследить изменения: Любая функция может изменить переменную
  • Ошибки: Легко случайно изменить глобальную в неправильном месте
  • Тестирование: Сложно тестировать функции зависящие от global
  • Переиспользование: Функция с global не независима
  • Конфликты имен: Можно случайно перезаписать важную переменную
# ПЛОХО - использование global
total = 0

def add_bad(n):
    global total
    total = total + n

add_bad(5)
add_bad(3)
print(total)  # 8

# ХОРОШО - return и параметры
def add_good(current_total, n):
    return current_total + n

total = 0
total = add_good(total, 5)
total = add_good(total, 3)
print(total)  # 8

# Второй вариант лучше:
# - Функция независима
# - Легко тестировать
# - Понятен поток данных

Когда global допустим?

  • Константы (которые не меняются)
  • Настройки/конфигурация
  • Счетчики в простых скриптах
  • Учебные примеры
# Константы - ОК (обычно в ВЕРХНЕМ_РЕГИСТРЕ)
PI = 3.14159
MAX_SCORE = 100

def calculate_circle_area(radius):
    """Использует константу PI."""
    return PI * radius ** 2

print(calculate_circle_area(5))  # ОК!

Параметры функций - локальные переменные

Параметры функции - это тоже локальные переменные!

def greet(name):  # name - локальная переменная
    """Параметр name существует только внутри функции."""
    message = f"Привет, {name}!"  # message - тоже локальная
    print(message)

greet("Иван")  # name="Иван" внутри функции
greet("Мария") # name="Мария" внутри функции

# print(name)  # NameError! name не существует здесь
# print(message)  # NameError! message не существует здесь
# Изменение параметра не влияет на внешнюю переменную!
def change_value(x):
    """Изменяет локальную копию x."""
    print(f"До изменения: x = {x}")
    x = 100  # Изменяем ЛОКАЛЬНУЮ x
    print(f"После изменения: x = {x}")

number = 5
print(f"Начальное number: {number}")  # 5

change_value(number)
# До изменения: x = 5
# После изменения: x = 100

print(f"Финальное number: {number}")  # 5 (не изменилось!)

# number и x - РАЗНЫЕ переменные!
# x - локальная копия значения number

Локальная vs Глобальная с одинаковым именем

Если локальная и глобальная переменные имеют одно имя, внутри функции используется локальная!

x = 10  # Глобальная

def my_function():
    x = 20  # Локальная (затеняет глобальную!)
    print(f"Внутри функции: x = {x}")  # 20 (локальная)

print(f"До вызова: x = {x}")  # 10 (глобальная)
my_function()  # Внутри функции: x = 20
print(f"После вызова: x = {x}")  # 10 (глобальная не изменилась)

# Это называется "затенение" (shadowing)
# Локальная x "затеняет" глобальную x внутри функции

Избегай одинаковых имен!

Лучше использовать разные имена для локальных и глобальных переменных, чтобы избежать путаницы!

Вложенные функции (Preview)

Функции могут быть определены внутри других функций. У них своя область видимости:

def outer():
    """Внешняя функция."""
    x = 10  # Локальная для outer
    
    def inner():
        """Вложенная функция."""
        y = 20  # Локальная для inner
        print(f"Внутри inner: x={x}, y={y}")  # Видит x из outer!
    
    inner()  # Вызываем вложенную
    print(f"Внутри outer: x={x}")
    # print(y)  # Ошибка! y не видна в outer

outer()
# Внутри inner: x=10, y=20
# Внутри outer: x=10

# inner() - недоступна здесь! Она локальна для outer

Практические примеры

Пример 1: Счетчик вызовов (с global)

call_count = 0

def my_function():
    """Подсчитывает количество вызовов."""
    global call_count
    call_count += 1
    print(f"Функция вызвана {call_count} раз(а)")

my_function()  # 1
my_function()  # 2
my_function()  # 3
print(f"Всего вызовов: {call_count}")

Пример 2: Без global (лучший подход)

def count_calls(current_count):
    """Возвращает увеличенный счетчик."""
    return current_count + 1

calls = 0
calls = count_calls(calls)  # 1
calls = count_calls(calls)  # 2
calls = count_calls(calls)  # 3
print(f"Всего вызовов: {calls}")

Пример 3: Игровой персонаж

player_health = 100
player_score = 0

def take_damage(damage):
    """Уменьшает здоровье игрока."""
    global player_health
    player_health -= damage
    print(f"Получен урон {damage}! Здоровье: {player_health}")
    if player_health <= 0:
        print("Игрок погиб!")

def add_score(points):
    """Добавляет очки."""
    global player_score
    player_score += points
    print(f"+{points} очков! Счет: {player_score}")

take_damage(20)  # Здоровье: 80
add_score(10)    # Счет: 10
take_damage(30)  # Здоровье: 50
add_score(15)    # Счет: 25

Типичные ошибки начинающих

Ошибка 1: Попытка изменить глобальную без global

count = 0

def increment():
    # count = count + 1  # UnboundLocalError!
    # Python думает что count локальная, но она не определена
    pass

# ПРАВИЛЬНО:
def increment():
    global count
    count = count + 1

Ошибка 2: Использование локальной вне функции

def my_func():
    x = 10
    return x

result = my_func()
# print(x)  # NameError! x локальная, не существует здесь
print(result)  # Используй return!

Ошибка 3: Путаница с одинаковыми именами

x = 10

def test():
    x = 20  # Новая локальная, НЕ изменяет глобальную!
    print(x)  # 20

test()
print(x)  # 10 (глобальная не изменилась)

# Если хотел изменить глобальную - нужен global!

Ошибка 4: Забыли global при изменении

score = 0

def add_points(n):
    # Забыли global!
    # score = score + n  # UnboundLocalError
    pass

# ПРАВИЛЬНО:
def add_points(n):
    global score
    score = score + n

Ошибка 5: Излишнее использование global

# ПЛОХО - слишком много global
total = 0
count = 0
average = 0

def calculate():
    global total, count, average
    # ...

# ХОРОШО - используй return
def calculate(total, count):
    average = total / count if count > 0 else 0
    return total, count, average

Ошибка 6: Изменение изменяемых типов

# Списки - изменяемые! Можно менять без global
my_list = [1, 2, 3]

def modify_list():
    # НЕ нужен global для изменения содержимого!
    my_list.append(4)  # Работает

modify_list()
print(my_list)  # [1, 2, 3, 4]

# НО для переприсваивания нужен global
def replace_list():
    global my_list
    my_list = [10, 20]  # Создаем новый список

replace_list()
print(my_list)  # [10, 20]

Резюме урока

  • Область видимости - где переменная существует и доступна
  • Локальная - создана внутри функции, существует только там
  • Глобальная - создана вне функций, видна везде
  • Чтение глобальных: можно без ограничений
  • Изменение глобальных: нужно ключевое слово global
  • Жизненный цикл: локальные создаются при вызове, уничтожаются при завершении
  • Параметры: это локальные переменные
  • Затенение: локальная с тем же именем "скрывает" глобальную
  • Лучшая практика: избегай global, используй параметры и return
  • Независимость: функции без global легче тестировать и переиспользовать
