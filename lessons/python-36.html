1. Функция all()

Функция all() возвращает True, если все элементы итерируемого объекта истинны (truthy). Если хотя бы один элемент ложный (falsy), возвращает False.

Синтаксис:

all(iterable)  # Возвращает True, если все элементы истинны

Примеры использования:

# Все элементы True
print(all([True, True, True]))      # True

# Есть хотя бы один False
print(all([True, False, True]))     # False

# Работа с числами
print(all([1, 2, 3, 4]))            # True (все ненулевые)
print(all([1, 2, 0, 4]))            # False (есть 0)

# Работа со строками
print(all(["hello", "world"]))      # True (непустые строки)
print(all(["hello", "", "world"]))   # False (есть пустая строка)

# Пустой список
print(all([]))                      # True (важно: пустой список возвращает True!)

# Проверка условий
numbers = [10, 20, 30, 40]
all_positive = all(x > 0 for x in numbers)
print(f"Все числа положительные: {all_positive}")  # True

numbers = [10, -5, 30, 40]
all_positive = all(x > 0 for x in numbers)
print(f"Все числа положительные: {all_positive}")  # False

Важно!

Функция all() возвращает True для пустого списка! Это может быть неожиданным, но это стандартное поведение в Python.

2. Функция any()

Функция any() возвращает True, если хотя бы один элемент итерируемого объекта истинен (truthy). Если все элементы ложные (falsy), возвращает False.

Синтаксис:

any(iterable)  # Возвращает True, если хотя бы один элемент истинен

Примеры использования:

# Есть хотя бы один True
print(any([False, False, True]))    # True

# Все элементы False
print(any([False, False, False]))  # False

# Работа с числами
print(any([0, 0, 0, 5]))           # True (есть ненулевое число)
print(any([0, 0, 0, 0]))            # False (все нули)

# Работа со строками
print(any(["", "", "hello"]))       # True (есть непустая строка)
print(any(["", "", ""]))            # False (все пустые)

# Пустой список
print(any([]))                      # False (важно: пустой список возвращает False!)

# Проверка условий
numbers = [10, -5, 30, 40]
has_negative = any(x < 0 for x in numbers)
print(f"Есть отрицательные числа: {has_negative}")  # True

numbers = [10, 20, 30, 40]
has_negative = any(x < 0 for x in numbers)
print(f"Есть отрицательные числа: {has_negative}")  # False

3. Сравнение all() и any()

Давайте сравним эти функции на примерах:

Таблица сравнения:

# Примеры для понимания разницы
test_cases = [
    [True, True, True],
    [True, False, True],
    [False, False, False],
    [1, 2, 3],
    [1, 0, 3],
    [0, 0, 0],
    [],
]

for case in test_cases:
    print(f"{case:25} -> all: {all(case):5}, any: {any(case):5}")

Логическая связь:

# all() и any() связаны через отрицание
values = [True, False, True]

# not all() эквивалентно any(not x for x in values)
print(f"all(values) = {all(values)}")                    # False
print(f"not all(values) = {not all(values)}")            # True
print(f"any(not x for x in values) = {any(not x for x in values)}")  # True

# not any() эквивалентно all(not x for x in values)
print(f"any(values) = {any(values)}")                     # True
print(f"not any(values) = {not any(values)}")            # False
print(f"all(not x for x in values) = {all(not x for x in values)}")  # False

form_data = {

# Проверка, что все оценки положительные
grades = [5, 4, 5, 3, 4]

# Все оценки >= 3 (удовлетворительно)
all_passing = all(grade >= 3 for grade in grades)
print(f"Все оценки удовлетворительные: {all_passing}")  # True

# Есть хотя бы одна отличная оценка (5)

# Все оценки отличные

Пример 3: Проверка пароля

# Проверка сложности пароля
def is_strong_password(password):
    """Проверяет, что пароль сильный"""
    if not password:
        return False
    
    # Проверяем, что есть хотя бы одна заглавная буква
    has_upper = any(c.isupper() for c in password)
    # Проверяем, что есть хотя бы одна строчная буква
    has_lower = any(c.islower() for c in password)
    # Проверяем, что есть хотя бы одна цифра
    has_digit = any(c.isdigit() for c in password)
    # Проверяем, что есть хотя бы один спецсимвол
    has_special = any(c in "!@#$%^&*" for c in password)
    # Проверяем длину
    is_long_enough = len(password) >= 8
    
    # Все условия должны быть выполнены
    return all([has_upper, has_lower, has_digit, has_special, is_long_enough])

# Тестирование
passwords = ["MyPass123!", "mypass123", "MYPASS123!", "MyPass!"]

for pwd in passwords:
    print(f"'{pwd}' - сильный: {is_strong_password(pwd)}")

Пример 4: Фильтрация данных

# Найти студентов, у которых все оценки >= 4
students = [
    {"name": "Иван", "grades": [5, 4, 5, 4]},
    {"name": "Мария", "grades": [3, 4, 5, 4]},
    {"name": "Петр", "grades": [5, 5, 5, 5]},
]

# Студенты с хорошими оценками (все >= 4)
good_students = [
    student for student in students
    if all(grade >= 4 for grade in student["grades"])
]

print("Студенты с хорошими оценками:")
for student in good_students:
    print(f"  {student['name']}: {student['grades']}")

# Студенты, у которых есть хотя бы одна пятерка
excellent_students = [
    student for student in students
    if any(grade == 5 for grade in student["grades"])
]

print("\nСтуденты с пятерками:")
for student in excellent_students:
    print(f"  {student['name']}: {student['grades']}")

5. Создание собственных логических функций

Мы можем создавать собственные логические функции для проверки различных условий.

Пример 1: Функция проверки четности

def all_even(numbers):
    """Проверяет, что все числа четные"""
    return all(n % 2 == 0 for n in numbers)

def any_odd(numbers):
    """Проверяет, есть ли хотя бы одно нечетное число"""
    return any(n % 2 != 0 for n in numbers)

# Тестирование
numbers1 = [2, 4, 6, 8]
numbers2 = [2, 4, 5, 8]

print(f"Все четные в {numbers1}: {all_even(numbers1)}")  # True
print(f"Все четные в {numbers2}: {all_even(numbers2)}")  # False
print(f"Есть нечетное в {numbers2}: {any_odd(numbers2)}")  # True

Пример 2: Функция проверки диапазона

def all_in_range(numbers, min_val, max_val):
    """Проверяет, что все числа в заданном диапазоне"""
    return all(min_val <= n <= max_val for n in numbers)

def any_out_of_range(numbers, min_val, max_val):
    """Проверяет, есть ли числа вне диапазона"""
    return any(n < min_val or n > max_val for n in numbers)

# Тестирование
numbers = [10, 15, 20, 25, 30]
print(f"Все в диапазоне [10, 30]: {all_in_range(numbers, 10, 30)}")  # True
print(f"Есть вне диапазона [15, 25]: {any_out_of_range(numbers, 15, 25)}")  # True

6. Оптимизация с помощью генераторов

Функции all() и any() используют короткое замыкание, что делает их эффективными при работе с генераторами.

Пример с генератором:

# Проверка большого списка чисел
# Генератор не создает весь список в памяти
def check_large_list():
    # Генератор создает числа по требованию
    numbers = (x for x in range(1000000))
    
    # all() остановится на первом False
    # Не нужно проверять все миллион чисел!
    result = all(x < 100 for x in numbers)
    return result

# any() остановится на первом True
def find_first_positive():
    numbers = (x for x in range(-1000000, 1000000))
    result = any(x > 0 for x in numbers)
    return result

print(f"Все числа < 100: {check_large_list()}")  # False (остановится на 100)
print(f"Есть положительное: {find_first_positive()}")  # True (остановится на 1)

9. Типичные ошибки

Ошибка 1: Неправильное понимание пустого списка

# НЕПРАВИЛЬНО - неожиданное поведение
if all([]):  # Это True!
    print("Все элементы истинны")  # Это выполнится!

# ПРАВИЛЬНО - явная проверка на пустоту
def check_all(items):
    if not items:
        return False  # Или другое значение по умолчанию
    return all(items)

Ошибка 2: Использование списка вместо генератора

# НЕПРАВИЛЬНО - создает весь список в памяти
large_list = [x for x in range(1000000)]
result = all(x < 100 for x in large_list)  # Много памяти!

# ПРАВИЛЬНО - используй генератор
large_generator = (x for x in range(1000000))
result = all(x < 100 for x in large_generator)  # Эффективно!

Ошибка 3: Путаница между all() и any()

# НЕПРАВИЛЬНО - неправильная логика
# "Проверить, что все числа положительные"
numbers = [1, 2, 3]
result = any(x > 0 for x in numbers)  # Это вернет True для любого положительного!

# ПРАВИЛЬНО - используй all() для проверки всех элементов
numbers = [1, 2, 3]
result = all(x > 0 for x in numbers)  # Проверяет, что ВСЕ положительные

Ошибка 4: Неправильное использование с условиями

# НЕПРАВИЛЬНО - избыточная проверка
numbers = [1, 2, 3]
if all(x > 0 for x in numbers) == True:  # == True избыточно
    print("Все положительные")

# ПРАВИЛЬНО - просто используй результат
numbers = [1, 2, 3]
if all(x > 0 for x in numbers):
    print("Все положительные")

11. Резюме урока

  • all(iterable) - возвращает True, если все элементы истинны
  • any(iterable) - возвращает True, если хотя бы один элемент истинен
  • Пустой список - all([]) = True, any([]) = False (важно помнить!)
  • Короткое замыкание - функции останавливаются на первом решающем значении
  • Генераторы - эффективно использовать с all() и any() для больших данных
  • Практическое применение - валидация данных, проверка условий, фильтрация
  • Собственные функции - можно создавать логические функции на основе all() и any()
  • Оптимизация - генераторы вместо списков для экономии памяти
  • Логическая связь - not all() эквивалентно any(not x), и наоборот
