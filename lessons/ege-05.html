  • Типичные задачи ЕГЭ по рекурсии

1. Основы рекурсии

Рекурсивная функция должна иметь базовый случай (когда функция не вызывает себя) и рекурсивный вызов (когда функция вызывает сама себя).

Задача ЕГЭ 1: Факториал

Условие: Напишите рекурсивную функцию для вычисления факториала числа n.
Факториал n! = n × (n-1) × (n-2) × ... × 1
Например: 5! = 5 × 4 × 3 × 2 × 1 = 120

Решение:
def factorial(n):
    if n == 0 or n == 1:  # Базовый случай
        return 1
    else:  # Рекурсивный вызов
        return n * factorial(n - 1)

print(factorial(5))

Решение пошагово для factorial(5):
- factorial(5) = 5 * factorial(4)
  - factorial(4) = 4 * factorial(3)
    - factorial(3) = 3 * factorial(2)
      - factorial(2) = 2 * factorial(1)
        - factorial(1) = 1 (базовый случай)
      - factorial(2) = 2 * 1 = 2
    - factorial(3) = 3 * 2 = 6
  - factorial(4) = 4 * 6 = 24
- factorial(5) = 5 * 24 = 120

Ответ: 120

Проверка в Python:
def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        result = n * factorial(n - 1)
        print(f"factorial({n}) = {n} * factorial({n-1}) = {result}")
        return result

print(f"factorial(5) = {factorial(5)}")  # 120

Решение:
def sum_n(n):

print(sum_n(5))

Решение пошагово для sum_n(5):

  - sum_n(4) = 4 + sum_n(3)
    - sum_n(3) = 3 + sum_n(2)
      - sum_n(2) = 2 + sum_n(1)
        - sum_n(1) = 1 (базовый случай)
      - sum_n(2) = 2 + 1 = 3
    - sum_n(3) = 3 + 3 = 6
  - sum_n(4) = 4 + 6 = 10
- sum_n(5) = 5 + 10 = 15

Ответ: 15

Проверка в Python:
def sum_n(n):

2. Числа Фибоначчи

Числа Фибоначчи - это последовательность, где каждое число равно сумме двух предыдущих: F(n) = F(n-1) + F(n-2).

Задача ЕГЭ 3: Числа Фибоначчи

Условие: Напишите рекурсивную функцию для вычисления n-го числа Фибоначчи.
F(0) = 0, F(1) = 1, F(2) = 1, F(3) = 2, F(4) = 3, F(5) = 5, ...

Решение:
def fibonacci(n):
    if n == 0:  # Базовый случай
        return 0
    elif n == 1:  # Базовый случай
        return 1
    else:  # Рекурсивный вызов
        return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(6))

Решение пошагово для fibonacci(6):
- fibonacci(6) = fibonacci(5) + fibonacci(4)
  - fibonacci(5) = fibonacci(4) + fibonacci(3)
    - fibonacci(4) = fibonacci(3) + fibonacci(2)
      - fibonacci(3) = fibonacci(2) + fibonacci(1)
        - fibonacci(2) = fibonacci(1) + fibonacci(0) = 1 + 0 = 1
        - fibonacci(1) = 1
      - fibonacci(3) = 1 + 1 = 2
      - fibonacci(2) = 1
    - fibonacci(4) = 2 + 1 = 3
    - fibonacci(3) = 2
  - fibonacci(5) = 3 + 2 = 5
  - fibonacci(4) = 3
- fibonacci(6) = 5 + 3 = 8

Ответ: 8

Проверка в Python:
def fibonacci(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        result = fibonacci(n - 1) + fibonacci(n - 2)
        print(f"fibonacci({n}) = fibonacci({n-1}) + fibonacci({n-2}) = {result}")
        return result

print(f"fibonacci(6) = {fibonacci(6)}")  # 8

Задача ЕГЭ 4: Степень числа

Условие: Напишите рекурсивную функцию для вычисления a в степени n.
Например: power(2, 5) = 2^5 = 32

Решение:
def power(a, n):
    if n == 0:  # Базовый случай
        return 1
    else:  # Рекурсивный вызов
        return a * power(a, n - 1)

print(power(2, 5))

Решение пошагово для power(2, 5):
- power(2, 5) = 2 * power(2, 4)
  - power(2, 4) = 2 * power(2, 3)
    - power(2, 3) = 2 * power(2, 2)
      - power(2, 2) = 2 * power(2, 1)
        - power(2, 1) = 2 * power(2, 0)
          - power(2, 0) = 1 (базовый случай)
        - power(2, 1) = 2 * 1 = 2
      - power(2, 2) = 2 * 2 = 4
    - power(2, 3) = 2 * 4 = 8
  - power(2, 4) = 2 * 8 = 16
- power(2, 5) = 2 * 16 = 32

Ответ: 32

Проверка в Python:
def power(a, n):
    if n == 0:
        return 1
    else:
        result = a * power(a, n - 1)
        print(f"power({a}, {n}) = {a} * power({a}, {n-1}) = {result}")
        return result

print(f"power(2, 5) = {power(2, 5)}")  # 32

Рекурсия часто используется для обхода списков и других структур данных.

Задача ЕГЭ 5: Сумма элементов списка

Условие: Напишите рекурсивную функцию для вычисления суммы элементов списка.
Список: [1, 2, 3, 4, 5]

Решение:
def sum_list(arr):
    if len(arr) == 0:  # Базовый случай
        return 0
    else:  # Рекурсивный вызов
        return arr[0] + sum_list(arr[1:])

a = [1, 2, 3, 4, 5]
print(sum_list(a))

Решение пошагово для sum_list([1, 2, 3, 4, 5]):
- sum_list([1, 2, 3, 4, 5]) = 1 + sum_list([2, 3, 4, 5])
  - sum_list([2, 3, 4, 5]) = 2 + sum_list([3, 4, 5])
    - sum_list([3, 4, 5]) = 3 + sum_list([4, 5])
      - sum_list([4, 5]) = 4 + sum_list([5])
        - sum_list([5]) = 5 + sum_list([])
          - sum_list([]) = 0 (базовый случай)
        - sum_list([5]) = 5 + 0 = 5
      - sum_list([4, 5]) = 4 + 5 = 9
    - sum_list([3, 4, 5]) = 3 + 9 = 12
  - sum_list([2, 3, 4, 5]) = 2 + 12 = 14
- sum_list([1, 2, 3, 4, 5]) = 1 + 14 = 15

Ответ: 15

Проверка в Python:
def sum_list(arr):
    if len(arr) == 0:
        return 0
    else:
        result = arr[0] + sum_list(arr[1:])
        print(f"sum_list({arr}) = {arr[0]} + sum_list({arr[1:]}) = {result}")
        return result

a = [1, 2, 3, 4, 5]
print(f"sum_list({a}) = {sum_list(a)}")  # 15

Задача ЕГЭ 6: Максимальный элемент списка

Условие: Напишите рекурсивную функцию для нахождения максимального элемента списка.
Список: [3, 7, 2, 9, 1, 5]

Решение:
def max_list(arr):
    if len(arr) == 1:  # Базовый случай
        return arr[0]
    else:  # Рекурсивный вызов
        max_rest = max_list(arr[1:])
        if arr[0] > max_rest:
            return arr[0]
        else:
            return max_rest

a = [3, 7, 2, 9, 1, 5]
print(max_list(a))

Решение пошагово для max_list([3, 7, 2, 9, 1, 5]):
- max_list([3, 7, 2, 9, 1, 5]) сравнивает 3 и max_list([7, 2, 9, 1, 5])
  - max_list([7, 2, 9, 1, 5]) сравнивает 7 и max_list([2, 9, 1, 5])
    - max_list([2, 9, 1, 5]) сравнивает 2 и max_list([9, 1, 5])
      - max_list([9, 1, 5]) сравнивает 9 и max_list([1, 5])
        - max_list([1, 5]) сравнивает 1 и max_list([5])
          - max_list([5]) = 5 (базовый случай)
        - max_list([1, 5]) = max(1, 5) = 5
      - max_list([9, 1, 5]) = max(9, 5) = 9
    - max_list([2, 9, 1, 5]) = max(2, 9) = 9
  - max_list([7, 2, 9, 1, 5]) = max(7, 9) = 9
- max_list([3, 7, 2, 9, 1, 5]) = max(3, 9) = 9

Ответ: 9

Проверка в Python:
def max_list(arr):
    if len(arr) == 1:
        return arr[0]
    else:
        max_rest = max_list(arr[1:])
        result = arr[0] if arr[0] > max_rest else max_rest
        print(f"max_list({arr}) = max({arr[0]}, max_list({arr[1:]})) = {result}")
        return result

a = [3, 7, 2, 9, 1, 5]
print(f"max_list({a}) = {max_list(a)}")  # 9

4. Рекурсивный подсчет

Рекурсия часто используется для подсчета элементов по условию.

Задача ЕГЭ 7: Подсчет четных чисел

Условие: Напишите рекурсивную функцию для подсчета количества четных чисел в списке.
Список: [1, 2, 3, 4, 5, 6, 7, 8]

Решение:
def count_even(arr):
    if len(arr) == 0:  # Базовый случай
        return 0
    else:  # Рекурсивный вызов
        count = count_even(arr[1:])
        if arr[0] % 2 == 0:
            return 1 + count
        else:
            return count

a = [1, 2, 3, 4, 5, 6, 7, 8]
print(count_even(a))

Решение пошагово для count_even([1, 2, 3, 4, 5, 6, 7, 8]):
- count_even([1, 2, 3, 4, 5, 6, 7, 8]) проверяет 1 (нечетное) + count_even([2, 3, 4, 5, 6, 7, 8])
  - count_even([2, 3, 4, 5, 6, 7, 8]) проверяет 2 (четное) + count_even([3, 4, 5, 6, 7, 8])
    - count_even([3, 4, 5, 6, 7, 8]) проверяет 3 (нечетное) + count_even([4, 5, 6, 7, 8])
      - count_even([4, 5, 6, 7, 8]) проверяет 4 (четное) + count_even([5, 6, 7, 8])
        - count_even([5, 6, 7, 8]) проверяет 5 (нечетное) + count_even([6, 7, 8])
          - count_even([6, 7, 8]) проверяет 6 (четное) + count_even([7, 8])
            - count_even([7, 8]) проверяет 7 (нечетное) + count_even([8])
              - count_even([8]) проверяет 8 (четное) + count_even([])
                - count_even([]) = 0 (базовый случай)
              - count_even([8]) = 1 + 0 = 1
            - count_even([7, 8]) = 0 + 1 = 1
          - count_even([6, 7, 8]) = 1 + 1 = 2
        - count_even([5, 6, 7, 8]) = 0 + 2 = 2
      - count_even([4, 5, 6, 7, 8]) = 1 + 2 = 3
    - count_even([3, 4, 5, 6, 7, 8]) = 0 + 3 = 3
  - count_even([2, 3, 4, 5, 6, 7, 8]) = 1 + 3 = 4
- count_even([1, 2, 3, 4, 5, 6, 7, 8]) = 0 + 4 = 4

Ответ: 4

Проверка в Python:
def count_even(arr):
    if len(arr) == 0:
        return 0
    else:
        count = count_even(arr[1:])
        if arr[0] % 2 == 0:
            result = 1 + count
            print(f"count_even({arr}) = 1 + count_even({arr[1:]}) = {result}")
            return result
        else:
            print(f"count_even({arr}) = count_even({arr[1:]}) = {count}")
            return count

a = [1, 2, 3, 4, 5, 6, 7, 8]
print(f"count_even({a}) = {count_even(a)}")  # 4

Задача ЕГЭ 8: Рекурсивный поиск

Условие: Напишите рекурсивную функцию для проверки, есть ли элемент в списке.
Список: [1, 2, 3, 4, 5], элемент: 3

Решение:
def contains(arr, x):
    if len(arr) == 0:  # Базовый случай
        return False
    elif arr[0] == x:  # Базовый случай
        return True
    else:  # Рекурсивный вызов
        return contains(arr[1:], x)

a = [1, 2, 3, 4, 5]
print(contains(a, 3))

Решение пошагово для contains([1, 2, 3, 4, 5], 3):
- contains([1, 2, 3, 4, 5], 3) проверяет arr[0] = 1 != 3 → contains([2, 3, 4, 5], 3)
  - contains([2, 3, 4, 5], 3) проверяет arr[0] = 2 != 3 → contains([3, 4, 5], 3)
    - contains([3, 4, 5], 3) проверяет arr[0] = 3 == 3 → True (базовый случай)

Ответ: True

Проверка в Python:
def contains(arr, x):
    if len(arr) == 0:
        return False
    elif arr[0] == x:
        print(f"contains({arr}, {x}) = True (найден элемент {x})")
        return True
    else:
        result = contains(arr[1:], x)
        print(f"contains({arr}, {x}) = contains({arr[1:]}, {x}) = {result}")
        return result

a = [1, 2, 3, 4, 5]
print(f"contains({a}, 3) = {contains(a, 3)}")  # True

Задача ЕГЭ 9: Рекурсивная сумма цифр

Условие: Напишите рекурсивную функцию для вычисления суммы цифр числа.
Число: 12345

Решение:
def sum_digits(n):
    if n < 10:  # Базовый случай (одна цифра)
        return n
    else:  # Рекурсивный вызов
        return n % 10 + sum_digits(n // 10)

print(sum_digits(12345))

Решение пошагово для sum_digits(12345):
- sum_digits(12345) = 12345 % 10 + sum_digits(12345 // 10) = 5 + sum_digits(1234)
  - sum_digits(1234) = 1234 % 10 + sum_digits(1234 // 10) = 4 + sum_digits(123)
    - sum_digits(123) = 123 % 10 + sum_digits(123 // 10) = 3 + sum_digits(12)
      - sum_digits(12) = 12 % 10 + sum_digits(12 // 10) = 2 + sum_digits(1)
        - sum_digits(1) = 1 (базовый случай)
      - sum_digits(12) = 2 + 1 = 3
    - sum_digits(123) = 3 + 3 = 6
  - sum_digits(1234) = 4 + 6 = 10
- sum_digits(12345) = 5 + 10 = 15

Ответ: 15

Проверка в Python:
def sum_digits(n):
    if n < 10:
        return n
    else:
        result = n % 10 + sum_digits(n // 10)
        print(f"sum_digits({n}) = {n % 10} + sum_digits({n // 10}) = {result}")
        return result

print(f"sum_digits(12345) = {sum_digits(12345)}")  # 15

Задача ЕГЭ 10: Рекурсивный разворот строки

Условие: Напишите рекурсивную функцию для разворота строки.
Строка: "hello"

Решение:
def reverse_string(s):
    if len(s) <= 1:  # Базовый случай
        return s
    else:  # Рекурсивный вызов
        return reverse_string(s[1:]) + s[0]

print(reverse_string("hello"))

Решение пошагово для reverse_string("hello"):
- reverse_string("hello") = reverse_string("ello") + "h"
  - reverse_string("ello") = reverse_string("llo") + "e"
    - reverse_string("llo") = reverse_string("lo") + "l"
      - reverse_string("lo") = reverse_string("o") + "l"
        - reverse_string("o") = "o" (базовый случай)
      - reverse_string("lo") = "o" + "l" = "ol"
    - reverse_string("llo") = "ol" + "l" = "oll"
  - reverse_string("ello") = "oll" + "e" = "olle"
- reverse_string("hello") = "olle" + "h" = "olleh"

Ответ: "olleh"

Проверка в Python:
def reverse_string(s):
    if len(s) <= 1:
        return s
    else:
        result = reverse_string(s[1:]) + s[0]
        print(f"reverse_string('{s}') = reverse_string('{s[1:]}') + '{s[0]}' = '{result}'")
        return result

print(f"reverse_string('hello') = '{reverse_string('hello')}'")  # "olleh"

8. Типичные ошибки

Ошибка 1: Отсутствие базового случая

# НЕПРАВИЛЬНО - нет базового случая, бесконечная рекурсия
def factorial(n):
    return n * factorial(n - 1)  # Ошибка! Нет условия остановки

# ПРАВИЛЬНО - есть базовый случай
def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * factorial(n - 1)

Ошибка 2: Неправильный базовый случай

# НЕПРАВИЛЬНО - базовый случай не покрывает все случаи
def sum_n(n):
    if n == 0:
        return 0
    else:
        return n + sum_n(n - 1)  # Что если n отрицательное?

# ПРАВИЛЬНО - проверяй все граничные случаи
def sum_n(n):
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    else:
        return n + sum_n(n - 1)

Ошибка 3: Забыли вернуть значение в рекурсивном вызове

# НЕПРАВИЛЬНО - не возвращается результат
def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        factorial(n - 1)  # Ошибка! Не возвращается значение
        return n * factorial(n - 1)  # Двойной вызов!

# ПРАВИЛЬНО - возвращай результат рекурсивного вызова
def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * factorial(n - 1)

Ошибка 4: Неэффективная рекурсия для чисел Фибоначчи

# НЕПРАВИЛЬНО - экспоненциальная сложность
def fibonacci(n):
    if n <= 1:
        return n
    else:
        return fibonacci(n - 1) + fibonacci(n - 2)  # Много повторных вычислений

# ПРАВИЛЬНО - используй мемоизацию или итеративный подход
def fibonacci(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for i in range(2, n + 1):
        a, b = b, a + b
    return b

  • Базовый случай - условие, при котором функция не вызывает себя (остановка рекурсии)

  • Факториал - n! = n × (n-1)!, где 0! = 1 и 1! = 1
  • Числа Фибоначчи - F(n) = F(n-1) + F(n-2), где F(0) = 0, F(1) = 1
  • Обход списков - используй arr[0] и arr[1:] для рекурсивной обработки
  • Работа с числами - используй n % 10 и n // 10 для обработки цифр
  • Важно - всегда проверяй базовый случай, иначе будет бесконечная рекурсия
  • Эффективность - рекурсия может быть неэффективной для больших данных
  • Практика - решай задачи пошагово, отслеживай вызовы функции
