Урок 10: Ввод и вывод данных

Введение

До этого момента мы писали программы с фиксированными данными. Но настоящие программы должны взаимодействовать с пользователем! В этом уроке ты научишься получать данные от пользователя и красиво выводить результаты.

Представь калькулятор, который всегда считает только 2+3. Не очень полезно, правда? Нам нужен калькулятор, где пользователь сам вводит числа. Именно этому мы и научимся!

Что мы изучим:

  • Функцию input() для получения данных от пользователя
  • Преобразование типов данных (ОЧЕНЬ ВАЖНО!)
  • Форматирование вывода с помощью f-строк
  • Создание интерактивных программ
  • Лучшие практики ввода-вывода

Функция input() - получение данных

Функция input() останавливает программу и ждет, когда пользователь введет что-то с клавиатуры.

# Простейший ввод
name = input("Как тебя зовут? ")
print("Привет,", name)

# Пример работы:
# Программа: Как тебя зовут?
# Пользователь вводит: Иван
# Программа: Привет, Иван

Как работает input():

  • Показывает подсказку (prompt) на экране
  • Ждет, пока пользователь введет текст и нажмет Enter
  • ВСЕГДА возвращает строку (str)! Даже если ввели число!
  • Сохраняет введенный текст в переменную

Примеры использования input()

# С подсказкой
city = input("В каком городе ты живешь? ")
print("Круто! Я слышал, что", city, "- отличный город!")

# Без подсказки (не рекомендуется)
answer = input()  # Пользователь не знает, что вводить!

# Ввод нескольких данных
name = input("Имя: ")
age = input("Возраст: ")
hobby = input("Хобби: ")

print("Меня зовут", name, ", мне", age, "лет, я люблю", hobby)

ВАЖНО: input() всегда возвращает строку!

# Пользователь вводит: 15
age = input("Возраст: ")

print(type(age))  # <class 'str'> - это строка!
print(age)        # "15" - в кавычках!

# Это НЕ сработает для вычислений:
# next_year = age + 1  # TypeError! Нельзя складывать строку и число!

Чтобы работать с числами, нужно преобразование типов!

Преобразование типов при вводе

Поскольку input() возвращает строку, нам часто нужно преобразовать её в число.

int(input()) - ввод целого числа

# Правильный ввод целого числа
age = int(input("Сколько тебе лет? "))

# Теперь age - это число int!
print(type(age))  # <class 'int'>

# Можно использовать в вычислениях
next_year = age + 1
print("Через год тебе будет", next_year, "лет")

# Еще примеры
points = int(input("Сколько очков набрал? "))
total = points * 2
print("Удвоенный счет:", total)

float(input()) - ввод дробного числа

# Ввод дробного числа
price = float(input("Цена товара: "))
quantity = int(input("Количество: "))

total_cost = price * quantity
print("Итого к оплате:", total_cost, "руб.")

# Пример:
# Цена товара: 99.99
# Количество: 3
# Итого к оплате: 299.97 руб.

Зачем нужно преобразование?

# БЕЗ преобразования:
a = input("Первое число: ")  # Пользователь вводит: 10
b = input("Второе число: ")  # Пользователь вводит: 20
result = a + b
print(result)  # "1020" - объединение строк!

# С преобразованием:
a = int(input("Первое число: "))  # 10 как число
b = int(input("Второе число: "))  # 20 как число
result = a + b
print(result)  # 30 - математическое сложение!

Форматирование вывода

Есть несколько способов красиво вывести данные. Самый современный и удобный - f-строки!

Вывод через запятую (простой способ)

# Простое перечисление через запятую
name = "Иван"
age = 15
print("Меня зовут", name, ", мне", age, "лет")
# Меня зовут Иван , мне 15 лет

# Автоматически добавляются пробелы
score = 100
print("Ваш счет:", score, "очков")
# Ваш счет: 100 очков

F-строки (ЛУЧШИЙ СПОСОБ!)

F-строки - это самый современный и удобный способ форматирования в Python. Буква f перед строкой позволяет вставлять переменные прямо в текст!

# Базовое использование f-строк
name = "Мария"
age = 16

# Переменные в фигурных скобках {}
message = f"Меня зовут {name}, мне {age} лет"
print(message)  # Меня зовут Мария, мне 16 лет

# Можно сразу в print
city = "Москва"
print(f"Я живу в городе {city}")

# Выражения внутри {}
a = 10
b = 5
print(f"Сумма {a} и {b} равна {a + b}")
# Сумма 10 и 5 равна 15

Преимущества f-строк:

  • Читаемость - сразу видно, где какие переменные
  • Можно вставлять выражения: f"{2 + 2}"
  • Форматирование чисел (округление и т.д.)
  • Современный стандарт Python (с версии 3.6)

Форматирование чисел в f-строках

# Округление дробных чисел
price = 99.999
print(f"Цена: {price:.2f} руб.")
# Цена: 100.00 руб.
# :.2f означает "2 знака после запятой"

# Разные форматы
number = 1234.5678

print(f"{number:.1f}")  # 1234.6 (1 знак)
print(f"{number:.2f}")  # 1234.57 (2 знака)
print(f"{number:.0f}")  # 1235 (без дробной части)

# Процентные вычисления
score = 85
total = 100
print(f"Результат: {score}/{total} ({score/total:.1%})")
# Результат: 85/100 (85.0%)

Конкатенация строк (старый способ)

# Объединение строк через +
name = "Петр"
age = 17

# Нужно преобразовывать числа в строки!
message = "Меня зовут " + name + ", мне " + str(age) + " лет"
print(message)

# Неудобно и много кода!
# Лучше используй f-строки:
message = f"Меня зовут {name}, мне {age} лет"  # Проще!

Полные интерактивные программы

Программа 1: Приветствие

# Программа знакомства
print("=== Давай познакомимся! ===")

name = input("Как тебя зовут? ")
age = int(input("Сколько тебе лет? "))
city = input("Откуда ты? ")

print(f"\nПриятно познакомиться, {name}!")
print(f"Тебе {age} лет, и ты из города {city}.")

# Вычисления с возрастом
years_to_adult = 18 - age
if years_to_adult > 0:
    print(f"До совершеннолетия осталось {years_to_adult} лет.")
else:
    print("Ты уже совершеннолетний!")

Программа 2: Калькулятор

# Простой калькулятор
print("=== КАЛЬКУЛЯТОР ===")

num1 = float(input("Введите первое число: "))
num2 = float(input("Введите второе число: "))

# Вычисляем все операции
sum_result = num1 + num2
diff = num1 - num2
product = num1 * num2
quotient = num1 / num2

# Выводим результаты
print(f"\n{num1} + {num2} = {sum_result}")
print(f"{num1} - {num2} = {diff}")
print(f"{num1} × {num2} = {product}")
print(f"{num1} ÷ {num2} = {quotient:.2f}")

Программа 3: Вычисление площади

# Калькулятор площади прямоугольника
print("=== Площадь прямоугольника ===")

length = float(input("Введите длину (м): "))
width = float(input("Введите ширину (м): "))

area = length * width
perimeter = (length + width) * 2

print(f"\nРезультаты:")
print(f"Площадь: {area:.2f} кв. м")
print(f"Периметр: {perimeter:.2f} м")

# Дополнительная информация
if area < 10:
    print("Это небольшая комната")
elif area < 30:
    print("Это средняя комната")
else:
    print("Это большая комната")

Программа 4: Конвертер температуры

# Конвертер Цельсий → Фаренгейт
print("=== Конвертер температуры ===")

celsius = float(input("Температура в °C: "))

fahrenheit = celsius * 9/5 + 32

print(f"\n{celsius}°C = {fahrenheit:.1f}°F")

# Подсказки
if celsius < 0:
    print("Холодно! Температура ниже нуля")
elif celsius < 20:
    print("Прохладно")
elif celsius < 30:
    print("Комфортная температура")
else:
    print("Жарко!")

Задание 3: Конвертер величин

Создай программу, которая:

  1. Спрашивает рост в сантиметрах
  2. Конвертирует в метры (разделить на 100)
  3. Спрашивает вес в килограммах
  4. Вычисляет ИМТ по формуле: вес / (рост_в_метрах²)

Подсказка: Используй height_m = height_cm / 100 и f"{bmi:.1f}"

Лучшие практики

Правила хорошего ввода-вывода:

  1. Четкие подсказки: Всегда указывай, что нужно ввести 
    # Плохо:
x = input()

# Хорошо:
x = int(input("Введите число: "))
  2. Используй f-строки: Самый читаемый способ форматирования 
    # Старый способ:
print("Привет, " + name + "!")

# Современный способ:
print(f"Привет, {name}!")
  3. Преобразуй сразу: Делай int(input()) в одной строке 
    # Можно так:
age_str = input("Возраст: ")
age = int(age_str)

# Но лучше так:
age = int(input("Возраст: "))
  4. Разделяй вывод: Используй пустые строки для читаемости 
    print("=== Результаты ===")
print(f"Имя: {name}")
print(f"Возраст: {age}")
print("=" * 20)

Типичные ошибки начинающих

Ошибка 1: Забыли int() при вводе числа

# НЕПРАВИЛЬНО:
age = input("Возраст: ")
next_year = age + 1  # TypeError!

# ПРАВИЛЬНО:
age = int(input("Возраст: "))
next_year = age + 1  # Работает!

Ошибка 2: Пытаются сложить строку и число

# НЕПРАВИЛЬНО:
name = "Иван"
age = 15
print("Привет, " + name + ", тебе " + age)  # TypeError!

# ПРАВИЛЬНО - вариант 1 (f-строка):
print(f"Привет, {name}, тебе {age}")

# ПРАВИЛЬНО - вариант 2 (str):
print("Привет, " + name + ", тебе " + str(age))

Ошибка 3: Неясные подсказки в input()

# ПЛОХО:
x = input()  # Что вводить?
y = input("Число: ")  # Какое число? Для чего?

# ХОРОШО:
length = float(input("Введите длину прямоугольника (см): "))
width = float(input("Введите ширину прямоугольника (см): "))

Ошибка 4: Забыли букву f в f-строке

# НЕПРАВИЛЬНО:
name = "Мария"
print("Привет, {name}")  # Выведет: Привет, {name}

# ПРАВИЛЬНО:
print(f"Привет, {name}")  # Выведет: Привет, Мария
# Обрати внимание на букву f перед кавычками!

Ошибка 5: Неправильное форматирование чисел

# Некрасивый вывод:
price = 99.999999
print(f"Цена: {price}")  # Цена: 99.999999

# Красивый вывод:
print(f"Цена: {price:.2f} руб.")  # Цена: 100.00 руб.
# :.2f = 2 знака после точки

Ошибка 6: Путают float и int при вводе

# НЕПРАВИЛЬНО (если пользователь введет 5.5):
age = int(input("Сколько лет? "))  # ValueError при вводе 5.5!

# ПРАВИЛЬНО для целых чисел:
age = int(input("Сколько полных лет? "))

# ПРАВИЛЬНО для дробных:
height = float(input("Рост в метрах: "))

Связь с ОГЭ и ЕГЭ

Ввод и вывод - ключевые навыки для экзаменов:

  • ОГЭ: Задание 14 (практическое программирование - нужно считывать данные и выводить результат)
  • ЕГЭ: Задания 24-25 (программирование - обязательно нужен ввод данных), Задание 27 (обработка последовательностей)
  • На экзаменах ввод чаще всего числовой: n = int(input())
  • Важно помнить, что input() возвращает строку - частая ошибка на экзаменах!
  • F-строки упрощают форматированный вывод результатов

Резюме урока

  • input() - получает данные от пользователя, ВСЕГДА возвращает строку
  • int(input()) - преобразует ввод в целое число
  • float(input()) - преобразует ввод в дробное число
  • F-строки - лучший способ форматирования: f"Привет, {name}!"
  • :.2f - округление до 2 знаков после запятой
  • Всегда используй понятные подсказки в input()
  • Нельзя складывать строку и число без преобразования
  • print() через запятую автоматически добавляет пробелы
