Урок 33: Поиск в списке

Введение

Представь, что у тебя есть список из 1000 имен, и тебе нужно найти, есть ли там имя "Иван". Как ты будешь искать? Ты можешь просматривать список по порядку от начала до конца - это линейный поиск. А если список отсортирован по алфавиту, ты можешь использовать более умный способ - бинарный поиск.

Алгоритмы поиска - это одна из самых важных тем в программировании. Они используются везде: в базах данных, поисковых системах, играх, приложениях. Понимание разных алгоритмов поиска поможет тебе писать эффективные программы и решать задачи на экзаменах.

Что изучим в этом уроке:

  • Линейный поиск - простой и универсальный
  • Бинарный поиск - быстрый для отсортированных данных
  • Сравнение алгоритмов - когда какой использовать
  • Встроенные методы Python (in, index, find)
  • Сложность алгоритмов (O-нотация)
  • Практические задачи и примеры

Линейный поиск (Linear Search)

Линейный поиск - самый простой алгоритм поиска. Он проверяет каждый элемент списка по порядку, пока не найдет нужный или не дойдет до конца.

Как работает линейный поиск:

  1. Начинаем с первого элемента
  2. Сравниваем его с искомым значением
  3. Если совпадает - элемент найден!
  4. Если нет - переходим к следующему элементу
  5. Повторяем, пока не найдем или не закончится список
# Линейный поиск - простая функция
def linear_search(arr, target):
    """Ищет target в списке arr, возвращает индекс или -1"""
    for i in range(len(arr)):
        if arr[i] == target:
            return i  # Найден! Возвращаем индекс
    return -1  # Не найден

# Пример использования
numbers = [5, 2, 8, 1, 9, 3]
index = linear_search(numbers, 8)
if index != -1:
    print(f"Число 8 найдено на позиции {index}")
else:
    print("Число 8 не найдено")

Пошаговый пример:

Ищем число 8 в списке [5, 2, 8, 1, 9, 3]:

  1. Проверяем индекс 0: 5 == 8? Нет, идем дальше
  2. Проверяем индекс 1: 2 == 8? Нет, идем дальше
  3. Проверяем индекс 2: 8 == 8? Да! Найдено на позиции 2

Линейный поиск - поиск всех вхождений:

# Найти ВСЕ позиции элемента
def linear_search_all(arr, target):
    """Возвращает список всех индексов, где найден target"""
    indices = []
    for i in range(len(arr)):
        if arr[i] == target:
            indices.append(i)
    return indices

# Пример
numbers = [5, 2, 8, 2, 9, 2]
indices = linear_search_all(numbers, 2)
print(f"Число 2 найдено на позициях: {indices}")  # [1, 3, 5]

Бинарный поиск (Binary Search)

Бинарный поиск - это быстрый алгоритм, но работает только с отсортированными списками. Он делит список пополам и отбрасывает ту половину, где точно нет искомого элемента.

⚠️ Важно!

Бинарный поиск работает только с отсортированными данными! Если список не отсортирован, сначала отсортируй его или используй линейный поиск.

Как работает бинарный поиск:

  1. Находим средний элемент списка
  2. Сравниваем его с искомым значением
  3. Если совпадает - элемент найден!
  4. Если искомое меньше - ищем в левой половине
  5. Если искомое больше - ищем в правой половине
  6. Повторяем, пока не найдем или не останется элементов
# Бинарный поиск (итеративный вариант)
def binary_search(arr, target):
    """Ищет target в ОТСОРТИРОВАННОМ списке arr"""
    left = 0
    right = len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2  # Средний индекс
        
        if arr[mid] == target:
            return mid  # Найден!
        elif arr[mid] < target:
            left = mid + 1  # Ищем справа
        else:
            right = mid - 1  # Ищем слева
    
    return -1  # Не найден

# Пример (список ДОЛЖЕН быть отсортирован!)
numbers = [1, 2, 3, 5, 8, 9, 12, 15]
index = binary_search(numbers, 8)
print(f"Число 8 найдено на позиции {index}")  # 4

Визуализация бинарного поиска:

Ищем число 8 в отсортированном списке [1, 2, 3, 5, 8, 9, 12, 15]:

Шаг 1: [1, 2, 3, 5, 8, 9, 12, 15]
        left=0, right=7, mid=3, arr[3]=5
        5 < 8, ищем справа → left=4

Шаг 2: [8, 9, 12, 15]
        left=4, right=7, mid=5, arr[5]=9
        9 > 8, ищем слева → right=4

Шаг 3: [8]
        left=4, right=4, mid=4, arr[4]=8
        8 == 8 → НАЙДЕНО на позиции 4!

Бинарный поиск - рекурсивный вариант:

# Бинарный поиск (рекурсивный)
def binary_search_recursive(arr, target, left=0, right=None):
    """Рекурсивный вариант бинарного поиска"""
    if right is None:
        right = len(arr) - 1
    
    if left > right:
        return -1  # Не найден
    
    mid = (left + right) // 2
    
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, right)
    else:
        return binary_search_recursive(arr, target, left, mid - 1)

# Пример
numbers = [1, 2, 3, 5, 8, 9, 12, 15]
index = binary_search_recursive(numbers, 8)
print(f"Найдено на позиции {index}")

Сравнение алгоритмов

Характеристика Линейный поиск Бинарный поиск
Сложность O(n) - линейная O(log n) - логарифмическая
Требования Любой список Отсортированный список
Скорость Медленнее Быстрее
Память O(1) - константная O(1) - константная
Когда использовать Небольшие списки, неотсортированные данные Большие отсортированные списки

Пример производительности:

  • Список из 1000 элементов: Линейный поиск - до 1000 проверок, Бинарный - до 10 проверок
  • Список из 1 000 000 элементов: Линейный поиск - до 1 000 000 проверок, Бинарный - до 20 проверок

Видишь разницу? Бинарный поиск намного быстрее для больших списков!

Встроенные методы Python

В Python есть встроенные способы поиска, которые используют оптимизированные алгоритмы:

1. Оператор in

# Проверка наличия элемента
numbers = [5, 2, 8, 1, 9]
if 8 in numbers:
    print("Число 8 найдено!")
else:
    print("Число 8 не найдено")

2. Метод index()

# Найти индекс элемента
numbers = [5, 2, 8, 1, 9]
try:
    index = numbers.index(8)
    print(f"Число 8 на позиции {index}")
except ValueError:
    print("Число 8 не найдено")

3. Метод count()

# Подсчитать количество вхождений
numbers = [5, 2, 8, 2, 9, 2]
count = numbers.count(2)
print(f"Число 2 встречается {count} раз")  # 3

⚠️ Важно понимать:

Встроенные методы Python (in, index) используют оптимизированные алгоритмы. Для небольших списков они работают быстро, но для больших отсортированных списков бинарный поиск может быть быстрее.

Типичные ошибки начинающих

Ошибка 1: Бинарный поиск на неотсортированном списке

# НЕПРАВИЛЬНО - список не отсортирован!
numbers = [5, 2, 8, 1, 9]
index = binary_search(numbers, 8)  # Может не найти или найти неправильно!

# ПРАВИЛЬНО - сначала отсортируй
numbers = [5, 2, 8, 1, 9]
sorted_numbers = sorted(numbers)
index = binary_search(sorted_numbers, 8)

Ошибка 2: Забыл обработать случай "не найдено"

# НЕПРАВИЛЬНО - не обработал случай, когда элемент не найден
index = linear_search(numbers, 100)
print(numbers[index])  # Ошибка, если index = -1!

# ПРАВИЛЬНО - проверь результат
index = linear_search(numbers, 100)
if index != -1:
    print(numbers[index])
else:
    print("Элемент не найден")

Ошибка 3: Неправильные границы в бинарном поиске

# НЕПРАВИЛЬНО - неправильные границы
while left < right:  # Может пропустить элемент!
    mid = (left + right) // 2
    # ...

# ПРАВИЛЬНО - используй <=
while left <= right:
    mid = (left + right) // 2
    # ...

Резюме урока

  • Линейный поиск - простой алгоритм, проверяет каждый элемент по порядку, сложность O(n)
  • Бинарный поиск - быстрый алгоритм для отсортированных данных, сложность O(log n)
  • Бинарный поиск требует отсортированный список, иначе не работает корректно
  • Встроенные методы Python (in, index, count) используют оптимизированные алгоритмы
  • Для небольших списков разница в скорости незначительна
  • Для больших отсортированных списков бинарный поиск намного быстрее
  • Всегда проверяй результат поиска на случай, если элемент не найден
