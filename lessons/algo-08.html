1. Проверка на простое число

Простое число - это число, которое делится только на 1 и на само себя (например, 2, 3, 5, 7, 11, 13).

Алгоритм проверки:

  1. Если число меньше 2, оно не простое
  2. Проверяем делители от 2 до √n
  3. Если нашли делитель, число не простое

Пример: Проверка на простое число

def is_prime(n):
    """Проверяет, является ли число простым"""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    
    # Проверяем только нечетные делители
    for i in range(3, int(n ** 0.5) + 1, 2):
        if n % i == 0:
            return False
    return True

# Примеры использования
print(is_prime(7))   # True
print(is_prime(10))  # False
print(is_prime(17))  # True
print(is_prime(1))   # False

💡 Почему проверяем до √n?

Если число n имеет делитель больше √n, то у него обязательно есть делитель меньше √n. Например, для 36: если есть делитель 9 (больше √36=6), то есть и делитель 4 (меньше 6).

2. Нахождение НОД (алгоритм Евклида)

НОД (Наибольший Общий Делитель) двух чисел - это наибольшее число, на которое оба числа делятся без остатка.

Например, НОД(12, 18) = 6, потому что 12 = 6×2, а 18 = 6×3.

Алгоритм Евклида - эффективный способ нахождения НОД:

  1. Если одно число равно 0, НОД = второе число
  2. Иначе: НОД(a, b) = НОД(b, a % b)
  3. Повторяем до тех пор, пока одно из чисел не станет 0

Пример: Нахождение НОД

def gcd(a, b):
    """Находит НОД двух чисел (алгоритм Евклида)"""
    while b != 0:
        a, b = b, a % b
    return abs(a)  # abs нужен для отрицательных чисел

# Примеры
print(gcd(12, 18))    # 6
print(gcd(48, 18))    # 6
print(gcd(17, 5))     # 1 (взаимно простые)
print(gcd(100, 25))   # 25

Рекурсивная версия

def gcd_recursive(a, b):
    """НОД рекурсивно"""
    if b == 0:
        return abs(a)
    return gcd_recursive(b, a % b)

print(gcd_recursive(12, 18))  # 6

3. Нахождение НОК

НОК (Наименьшее Общее Кратное) двух чисел - это наименьшее число, которое делится на оба числа.

Например, НОК(4, 6) = 12, потому что 12 - наименьшее число, которое делится и на 4, и на 6.

Формула: НОК(a, b) = |a × b| / НОД(a, b)

Пример: Нахождение НОК

def lcm(a, b):
    """Находит НОК двух чисел"""
    return abs(a * b) // gcd(a, b)

# Примеры
print(lcm(4, 6))      # 12
print(lcm(12, 18))    # 36
print(lcm(5, 7))      # 35
print(lcm(10, 15))    # 30

4. Работа с цифрами числа

Часто нужно работать с отдельными цифрами числа. Рассмотрим основные операции:

4.1. Сумма цифр

def sum_of_digits(n):
    """Находит сумму цифр числа"""
    total = 0
    n = abs(n)  # Работаем с положительным числом
    while n > 0:
        total += n % 10  # Берем последнюю цифру
        n //= 10         # Убираем последнюю цифру
    return total

# Примеры
print(sum_of_digits(123))    # 6 (1+2+3)
print(sum_of_digits(4567))   # 22 (4+5+6+7)
print(sum_of_digits(100))    # 1

4.2. Количество цифр

def count_digits(n):
    """Считает количество цифр в числе"""
    if n == 0:
        return 1
    count = 0
    n = abs(n)
    while n > 0:
        count += 1
        n //= 10
    return count

# Или через логарифм (быстрее для больших чисел)
import math
def count_digits_log(n):
    if n == 0:
        return 1
    return int(math.log10(abs(n))) + 1

print(count_digits(12345))   # 5
print(count_digits(0))      # 1

4.3. Переворот числа

def reverse_number(n):
    """Переворачивает число"""
    reversed_num = 0
    n = abs(n)
    while n > 0:
        reversed_num = reversed_num * 10 + n % 10
        n //= 10
    return reversed_num

# Примеры
print(reverse_number(123))   # 321
print(reverse_number(100))   # 1
print(reverse_number(5678))  # 8765

4.4. Проверка на числовой палиндром

Палиндром - число, которое читается одинаково слева направо и справа налево (например, 121, 1331, 12321).

def is_palindrome(n):
    """Проверяет, является ли число палиндромом"""
    return n == reverse_number(n)

# Примеры
print(is_palindrome(121))    # True
print(is_palindrome(123))    # False
print(is_palindrome(1331))   # True
print(is_palindrome(12321))  # True

5. Разложение на простые множители

Любое число можно представить как произведение простых чисел. Например, 12 = 2×2×3, 60 = 2×2×3×5.

Пример: Разложение на простые множители

def prime_factors(n):
    """Разлагает число на простые множители"""
    factors = []
    d = 2
    while d * d <= n:
        while n % d == 0:
            factors.append(d)
            n //= d
        d += 1
    if n > 1:
        factors.append(n)
    return factors

# Примеры
print(prime_factors(12))   # [2, 2, 3]
print(prime_factors(60))   # [2, 2, 3, 5]
print(prime_factors(17))   # [17] (простое число)
print(prime_factors(100))  # [2, 2, 5, 5]

8. Типичные ошибки начинающих

Ошибка 1: Забыли обработать граничные случаи

# НЕПРАВИЛЬНО - не обработаны случаи n < 2
def is_prime(n):
    for i in range(2, n):
        if n % i == 0:
            return False
    return True

# ПРАВИЛЬНО - проверяем граничные случаи
def is_prime(n):
    if n < 2:
        return False
    # ... остальной код

Ошибка 2: Неэффективная проверка простоты

# НЕПРАВИЛЬНО - медленно для больших чисел
def is_prime(n):
    for i in range(2, n):  # Проверяем все числа до n
        if n % i == 0:
            return False
    return True

# ПРАВИЛЬНО - проверяем только до √n
def is_prime(n):
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

Ошибка 3: Неправильная работа с отрицательными числами

# НЕПРАВИЛЬНО - бесконечный цикл для отрицательных!
def sum_of_digits(n):
    total = 0
    while n > 0:
        total += n % 10
        n //= 10
    return total

# ПРАВИЛЬНО - работаем с модулем
def sum_of_digits(n):
    total = 0
    n = abs(n)  # Работаем с модулем
    while n > 0:
        total += n % 10
        n //= 10
    return total
