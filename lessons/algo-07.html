Пузырьковая сортировка (Bubble Sort)

Пузырьковая сортировка - самый простой алгоритм сортировки. Он работает как пузырьки в воде: большие элементы "всплывают" наверх, а маленькие "тонут" вниз.

Как работает пузырьковая сортировка:

  1. Сравниваем соседние элементы
  2. Если они в неправильном порядке - меняем их местами
  3. Повторяем для всех пар элементов
  4. После первого прохода самый большой элемент окажется в конце
  5. Повторяем процесс для оставшихся элементов
# Пузырьковая сортировка
def bubble_sort(arr):
    """Сортирует список по возрастанию методом пузырька"""
    n = len(arr)
    
    # Проходим по списку n-1 раз
    for i in range(n - 1):
        # В каждом проходе сравниваем соседние элементы
        for j in range(n - 1 - i):
            # Если текущий элемент больше следующего - меняем местами
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    
    return arr

# Пример
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = bubble_sort(numbers.copy())
print(f"Исходный: {numbers}")
print(f"Отсортированный: {sorted_numbers}")

Визуализация пузырьковой сортировки:

Сортируем список [64, 34, 25, 12, 22, 11, 90]:

Проход 1: [64, 34, 25, 12, 22, 11, 90]
          Сравниваем 64 и 34 → меняем → [34, 64, 25, 12, 22, 11, 90]
          Сравниваем 64 и 25 → меняем → [34, 25, 64, 12, 22, 11, 90]
          ... продолжаем ...
          Результат: [34, 25, 12, 22, 11, 64, 90] (90 на месте!)

Проход 2: [34, 25, 12, 22, 11, 64, 90]
          ... продолжаем ...
          Результат: [25, 12, 22, 11, 34, 64, 90] (64 и 90 на месте!)

... и так далее, пока весь список не отсортирован

Почему "пузырьковая"?

Большие элементы постепенно "всплывают" к концу списка, как пузырьки воздуха в воде!

Сортировка выбором (Selection Sort)

Сортировка выбором работает по принципу: находим минимальный элемент и ставим его на первое место, затем находим следующий минимальный и ставим на второе место, и так далее.

Как работает сортировка выбором:

  1. Находим минимальный элемент в неотсортированной части
  2. Меняем его местами с первым элементом неотсортированной части
  3. Повторяем для оставшихся элементов
# Сортировка выбором
def selection_sort(arr):
    """Сортирует список выбором минимального элемента"""
    n = len(arr)
    
    for i in range(n):
        # Находим индекс минимального элемента в неотсортированной части
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        
        # Меняем местами минимальный элемент с первым неотсортированным
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    
    return arr

# Пример
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = selection_sort(numbers.copy())
print(f"Исходный: {numbers}")
print(f"Отсортированный: {sorted_numbers}")

Визуализация сортировки выбором:

Сортируем список [64, 34, 25, 12, 22, 11, 90]:

Шаг 1: Находим минимум (11) → ставим на позицию 0
       [11, 34, 25, 12, 22, 64, 90]

Шаг 2: Находим минимум в оставшихся (12) → ставим на позицию 1

Шаг 3: Находим минимум в оставшихся (22) → ставим на позицию 2

Сортировка вставками (Insertion Sort)

Сортировка вставками работает как сортировка карт в руке: берем каждый элемент и вставляем его в правильное место среди уже отсортированных элементов.

Как работает сортировка вставками:

  1. Первый элемент считаем отсортированным
  2. Берем следующий элемент
  3. Вставляем его в правильное место среди отсортированных
  4. Повторяем для всех элементов
# Сортировка вставками
def insertion_sort(arr):
    """Сортирует список методом вставок"""
    n = len(arr)
    
    for i in range(1, n):
        # Текущий элемент, который нужно вставить
        key = arr[i]
        j = i - 1
        
        # Сдвигаем элементы, которые больше key, вправо
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        
        # Вставляем key в правильное место
        arr[j + 1] = key
    
    return arr

# Пример
numbers = [64, 34, 25, 12, 22, 11, 90]
sorted_numbers = insertion_sort(numbers.copy())
print(f"Исходный: {numbers}")
print(f"Отсортированный: {sorted_numbers}")

Визуализация сортировки вставками:

Сортируем список [64, 34, 25, 12, 22, 11, 90]:

Шаг 1: [64] | [34, 25, 12, 22, 11, 90]
       Вставляем 34 → [34, 64] | [25, 12, 22, 11, 90]

Шаг 2: [34, 64] | [25, 12, 22, 11, 90]
       Вставляем 25 → [25, 34, 64] | [12, 22, 11, 90]

Шаг 3: [25, 34, 64] | [12, 22, 11, 90]
       Вставляем 12 → [12, 25, 34, 64] | [22, 11, 90]

... и так далее

Сравнение алгоритмов

Алгоритм Сложность Преимущества Недостатки
Пузырьковая O(n²) Простота, легко понять Очень медленная
Выбором O(n²) Минимум обменов Медленная
Вставками O(n²) Быстрая для почти отсортированных данных Медленная для больших списков

⚠️ Важно!

Все три алгоритма имеют сложность O(n²), что означает, что для списка из n элементов нужно примерно n² операций. Для больших списков (1000+ элементов) эти алгоритмы работают очень медленно!

В следующем уроке мы изучим быстрые сортировки (Quick Sort, Merge Sort), которые работают за O(n log n).

Встроенная функция sorted() в Python

В Python есть встроенная функция sorted(), которая использует эффективный алгоритм Timsort (комбинация сортировки слиянием и вставками):

# Встроенная сортировка Python
numbers = [64, 34, 25, 12, 22, 11, 90]

# sorted() возвращает новый отсортированный список
sorted_numbers = sorted(numbers)
print(f"Исходный: {numbers}")
print(f"Отсортированный: {sorted_numbers}")

# Метод sort() сортирует список на месте
numbers_copy = numbers.copy()
numbers_copy.sort()
print(f"После sort(): {numbers_copy}")

# Сортировка по убыванию
descending = sorted(numbers, reverse=True)
print(f"По убыванию: {descending}")

Когда использовать встроенную сортировку?

  • Всегда в реальных проектах - она быстрая и оптимизированная
  • Для изучения - полезно понимать, как работают алгоритмы
  • На экзаменах - могут попросить реализовать алгоритм вручную

Типичные ошибки начинающих

Ошибка 1: Изменение исходного списка

# НЕПРАВИЛЬНО - исходный список изменится!
numbers = [3, 1, 4, 2]
bubble_sort(numbers)
print(numbers)  # [1, 2, 3, 4] - исходный список изменен!

# ПРАВИЛЬНО - используй копию
numbers = [3, 1, 4, 2]
sorted_numbers = bubble_sort(numbers.copy())
print(numbers)  # [3, 1, 4, 2] - исходный не изменен
print(sorted_numbers)  # [1, 2, 3, 4]

Ошибка 2: Неправильные границы циклов

# НЕПРАВИЛЬНО - выйдет за границы списка
for i in range(n):  # i может быть n-1
    for j in range(n):  # j может быть n-1, arr[j+1] выйдет за границы!
        if arr[j] > arr[j + 1]:

# ПРАВИЛЬНО - учитывай границы
for i in range(n - 1):
    for j in range(n - 1 - i):
        if arr[j] > arr[j + 1]:

Ошибка 3: Использование простых сортировок для больших данных

# НЕПРАВИЛЬНО - очень медленно для больших списков
big_list = list(range(10000, 0, -1))  # 10000 элементов
bubble_sort(big_list)  # Будет работать очень долго!

# ПРАВИЛЬНО - используй встроенную sorted()
big_list = list(range(10000, 0, -1))
sorted_list = sorted(big_list)  # Быстро!

Резюме урока

  • Пузырьковая сортировка - простой алгоритм, сравнивает соседние элементы, сложность O(n²)
  • Сортировка выбором - находит минимальный элемент и ставит на место, сложность O(n²), минимум обменов
  • Сортировка вставками - вставляет элементы в правильное место, сложность O(n²), эффективна для почти отсортированных данных
  • Все три алгоритма имеют сложность O(n²) и медленные для больших списков
  • Встроенная sorted() в Python использует эффективный алгоритм Timsort
  • Для реальных проектов всегда используй встроенную сортировку
  • Для изучения и экзаменов важно понимать, как работают алгоритмы
  • Не забывай делать копию списка перед сортировкой, чтобы не изменить исходный
