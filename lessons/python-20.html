Урок 25: Возврат значений

Функции • 45 минут

Введение

До этого наши функции только выводили результаты на экран с помощью print(). Но что если нужно использовать результат функции в других вычислениях? Представь калькулятор: ты вводишь "5 + 3", и он не просто показывает "8", но и позволяет использовать этот результат дальше!

Оператор return - это как кнопка "Отправить" в функции. Он возвращает результат работы обратно тому, кто вызвал функцию. Это делает функции по-настоящему мощными!

Что изучим в этом уроке:

  • Что такое return и зачем он нужен
  • Разница между print и return (ВАЖНО!)
  • Как использовать возвращенные значения
  • Возврат нескольких значений
  • Ранний выход из функции
  • Функции без явного return
  • Возврат разных типов данных

Оператор return

Самая простая функция с возвратом значения:

def square(n):
    """Возвращает квадрат числа."""
    return n ** 2

# Вызываем функцию и сохраняем результат
result = square(5)
print(result)  # 25

# Используем напрямую
print(square(7))  # 49

# В вычислениях
total = square(3) + square(4)
print(total)  # 9 + 16 = 25

Как работает return:

  1. Функция выполняет свой код
  2. Доходит до return
  3. Вычисляет выражение после return
  4. Возвращает это значение вызывающему коду
  5. Функция завершается (код после return не выполняется!)

print() vs return - КРИТИЧЕСКИ ВАЖНО!

Это самая частая ошибка начинающих! Запомни разницу:

# Функция с print
def add_print(a, b):
    """Выводит сумму, НО НЕ ВОЗВРАЩАЕТ!"""
    result = a + b
    print(result)  # Показывает на экране
    # Функция возвращает None!

# Функция с return
def add_return(a, b):
    """Возвращает сумму."""
    result = a + b
    return result  # Возвращает значение

# Сравним:
x = add_print(5, 3)   # Выведет: 8
print(f"x = {x}")     # x = None (функция ничего не вернула!)

y = add_return(5, 3)  # Ничего не выведет
print(f"y = {y}")     # y = 8 (функция вернула значение!)

Запомни навсегда!

  • print() - выводит на экран, но НЕ возвращает значение
  • return - возвращает значение, но НЕ выводит на экран
  • print() для показа пользователю
  • return для передачи результата в программу
# print - не можем использовать результат
def bad_double(n):
    print(n * 2)

result = bad_double(5)  # Выведет: 10
x = result + 10  # ОШИБКА! result = None, нельзя сложить None + 10

# return - можем использовать результат
def good_double(n):
    return n * 2

result = good_double(5)  # Ничего не выведет
x = result + 10  # Отлично! result = 10, x = 20

Использование возвращенных значений

Возвращенное значение можно использовать по-разному:

1. Сохранить в переменную

def add(a, b):
    return a + b

result = add(10, 20)
print(result)  # 30

2. Использовать в выражении

def multiply(a, b):
    return a * b

# В арифметике
total = multiply(5, 3) + multiply(2, 4)
print(total)  # 15 + 8 = 23

# В условии
if multiply(7, 2) > 10:
    print("Больше 10!")  # Выведет

# В другой функции
print(multiply(6, 7))  # 42

3. Передать в другую функцию

def square(n):
    return n ** 2

def double(n):
    return n * 2

# Композиция функций
result = double(square(5))
# Сначала: square(5) = 25
# Затем: double(25) = 50
print(result)  # 50

# Можно писать сложные цепочки
value = square(double(3))
# double(3) = 6
# square(6) = 36
print(value)  # 36

4. Использовать в циклах

def cube(n):
    return n ** 3

# Список кубов
cubes = []
for i in range(1, 6):
    cubes.append(cube(i))
print(cubes)  # [1, 8, 27, 64, 125]

# Или с list comprehension
cubes = [cube(i) for i in range(1, 6)]
print(cubes)  # [1, 8, 27, 64, 125]

Список

def get_evens(numbers):
    """Возвращает список четных чисел."""
    evens = []
    for n in numbers:
        if n % 2 == 0:
            evens.append(n)
    return evens

numbers = [1, 2, 3, 4, 5, 6, 7, 8]
even_numbers = get_evens(numbers)
print(even_numbers)  # [2, 4, 6, 8]

def create_range(start, end):
    """Создает список чисел от start до end."""
    return list(range(start, end + 1))

nums = create_range(5, 10)
print(nums)  # [5, 6, 7, 8, 9, 10]

student = create_student("Иван", 16, 10)

Возврат нескольких значений

Python позволяет вернуть несколько значений через запятую!

def min_max(numbers):
    """Возвращает минимум и максимум списка."""
    return min(numbers), max(numbers)

# Возвращается кортеж (tuple)
result = min_max([3, 1, 7, 2, 9, 4])
print(result)  # (1, 9)
print(type(result))  # 

# Распаковка в переменные
minimum, maximum = min_max([3, 1, 7, 2, 9, 4])
print(f"Минимум: {minimum}")  # 1
print(f"Максимум: {maximum}")  # 9
# Несколько значений разных типов
def analyze_number(n):
    """Анализирует число."""
    is_positive = n > 0
    is_even = n % 2 == 0
    square = n ** 2
    return is_positive, is_even, square

pos, even, sq = analyze_number(-4)
print(f"Положительное: {pos}")  # False
print(f"Четное: {even}")  # True
print(f"Квадрат: {sq}")  # 16

# Трюк: можно вернуть три и больше значений!
def divide_with_remainder(a, b):
    """Возвращает частное и остаток."""
    quotient = a // b
    remainder = a % b
    return quotient, remainder

q, r = divide_with_remainder(17, 5)
print(f"17 ÷ 5 = {q} (остаток {r})")  # 17 ÷ 5 = 3 (остаток 2)

Ранний выход из функции

return завершает функцию немедленно. Код после return не выполнится!

def divide(a, b):
    """Делит a на b с проверкой."""
    if b == 0:
        return "Ошибка: деление на ноль"
        print("Эта строка НИКОГДА не выполнится!")
    
    return a / b

print(divide(10, 2))  # 5.0
print(divide(10, 0))  # Ошибка: деление на ноль

# Еще пример - проверка возраста
def check_age(age):
    """Проверяет возраст для входа."""
    if age < 0:
        return "Ошибка: возраст не может быть отрицательным"
    
    if age < 18:
        return "Доступ запрещен: вам нет 18 лет"
    
    if age > 120:
        return "Ошибка: введите реальный возраст"
    
    return "Доступ разрешен"

print(check_age(16))   # Доступ запрещен: вам нет 18 лет
print(check_age(25))   # Доступ разрешен
print(check_age(-5))   # Ошибка: возраст не может быть отрицательным

Использование для упрощения логики

# БЕЗ раннего return - громоздко
def get_grade_bad(score):
    if score >= 90:
        result = "Отлично"
    else:
        if score >= 70:
            result = "Хорошо"
        else:
            if score >= 50:
                result = "Удовлетворительно"
            else:
                result = "Неудовлетворительно"
    return result

# С ранним return - чисто и понятно!
def get_grade_good(score):
    if score >= 90:
        return "Отлично"
    if score >= 70:
        return "Хорошо"
    if score >= 50:
        return "Удовлетворительно"
    return "Неудовлетворительно"

print(get_grade_good(85))  # Хорошо
print(get_grade_good(95))  # Отлично

Функции без явного return

Если функция не имеет return, она возвращает None:

def print_hello():
    """Функция без return."""
    print("Привет!")
    # Неявно: return None

result = print_hello()  # Выведет: Привет!
print(f"Результат: {result}")  # Результат: None

# Проверка на None
if result is None:
    print("Функция ничего не вернула")

# Функции с побочными эффектами (side effects)
def add_to_list(item, lst):
    """Добавляет элемент в список."""
    lst.append(item)
    # Нет return - изменяет список, но ничего не возвращает

my_list = [1, 2, 3]
result = add_to_list(4, my_list)
print(my_list)  # [1, 2, 3, 4] - список изменен
print(result)   # None - функция ничего не вернула

Пример 1: Математические функции

def factorial(n):
    """Вычисляет факториал числа."""
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print(factorial(5))  # 120

def fibonacci(n):
    """Возвращает n-е число Фибоначчи."""
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

print(fibonacci(10))  # 55

Пример 2: Валидация данных

def validate_email(email):
    """Проверяет корректность email."""
    if "@" not in email:
        return False
    if "." not in email:
        return False
    if len(email) < 5:
        return False
    return True

print(validate_email("user@example.com"))  # True
print(validate_email("invalid"))  # False

def is_strong_password(password):
    """Проверяет надежность пароля."""
    if len(password) < 8:
        return False
    has_digit = any(c.isdigit() for c in password)
    has_upper = any(c.isupper() for c in password)
    return has_digit and has_upper

print(is_strong_password("Weak1"))      # False (короткий)
print(is_strong_password("Strong123"))  # True

Пример 3: Обработка списков

def sum_positive(numbers):
    """Возвращает сумму положительных чисел."""
    total = 0
    for n in numbers:
        if n > 0:
            total += n
    return total

nums = [-5, 10, -3, 7, 2, -1]
print(sum_positive(nums))  # 19

def find_max(numbers):
    """Находит максимальное число в списке."""
    if not numbers:
        return None
    
    max_num = numbers[0]
    for n in numbers:
        if n > max_num:
            max_num = n
    return max_num

print(find_max([3, 7, 2, 9, 1]))  # 9
print(find_max([]))  # None

Пример 4: Работа со строками

def count_vowels(text):
    """Подсчитывает количество гласных."""
    vowels = "аеёиоуыэюяАЕЁИОУЫЭЮЯ"
    count = 0
    for char in text:
        if char in vowels:
            count += 1
    return count

print(count_vowels("Привет мир"))  # 3

def reverse_words(sentence):
    """Переворачивает порядок слов."""
    words = sentence.split()
    reversed_words = words[::-1]
    return " ".join(reversed_words)

print(reverse_words("Python это круто"))  # круто это Python

Типичные ошибки начинающих

Ошибка 1: Путаница print и return

# НЕПРАВИЛЬНО - функция ничего не возвращает
def add(a, b):
    print(a + b)  # Только выводит!

# total = result + 10  # TypeError! None + 10

# ПРАВИЛЬНО - функция возвращает значение
def add(a, b):
    return a + b

result = add(5, 3)  # result = 8

Ошибка 3: Забыли return

# НЕПРАВИЛЬНО - забыли return

    # Забыли: return result

Ошибка 4: return в цикле (слишком рано)

# НЕПРАВИЛЬНО - return прерывает цикл после первой итерации!
def sum_numbers(numbers):
    for n in numbers:
        return n  # Вернет только первое число!

print(sum_numbers([1,2,3,4,5]))  # 1 (не сумма!)

# ПРАВИЛЬНО - return после цикла
def sum_numbers(numbers):
    total = 0
    for n in numbers:
        total += n
    return total  # Вернет сумму всех

print(sum_numbers([1,2,3,4,5]))  # 15

Ошибка 6: Изменение вместо возврата

# НЕПРАВИЛЬНО - изменяет параметр, но не возвращает
def double_list(lst):
    for i in range(len(lst)):
        lst[i] *= 2
    # Нет return!

nums = [1, 2, 3]
result = double_list(nums)

# ПРАВИЛЬНО - возвращаем новый список
def double_list(lst):
    return [x * 2 for x in lst]

nums = [1, 2, 3]
doubled = double_list(nums)
print(nums)    # [1, 2, 3] - не изменен
print(doubled) # [2, 4, 6] - новый список

Связь с ОГЭ и ЕГЭ

Возврат значений - центральная концепция функций на экзаменах:

  • ОГЭ Задание 14: Функции должны возвращать результат обработки данных
  • ЕГЭ Задания 24-27: Сложные функции с возвратом списков, словарей, кортежей
  • ЕГЭ Задание 16: Рекурсивные функции обязательно используют return
  • Применение на экзаменах:
    • Функции поиска - возвращают найденный элемент или индекс
    • Функции валидации - возвращают True/False
    • Функции обработки - возвращают новый список/словарь
    • Математические функции - возвращают вычисленное значение
    • Композиция функций - результат одной передаем в другую
  • Критически важно понимать разницу между print и return!
  • Умение возвращать несколько значений через кортеж
  • Ранний выход (early return) упрощает код на экзаменах

Резюме урока

  • return - возвращает значение из функции
  • print vs return: print показывает, return передает значение
  • Использование: результат можно сохранить, использовать в выражениях
  • Типы: можно вернуть число, строку, список, словарь, bool, любой тип
  • Несколько значений: return a, b, c → возвращает кортеж
  • Ранний выход: return завершает функцию немедленно
  • Без return: функция возвращает None
  • Код после return: не выполняется никогда!
  • Композиция: результат одной функции в другую
  • Чистота: функции с return - чистые, без побочных эффектов
