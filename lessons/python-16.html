Урок 21: Словари - Основы

Структуры данных • 50 минут

Введение

Словарь (dictionary) - это коллекция пар ключ-значение, как настоящий словарь: слово (ключ) и его определение (значение). В Python словари используются для хранения связанных данных: имя-возраст, товар-цена, логин-пароль, слово-перевод!

Словари - одна из самых мощных структур данных в Python. Поиск по ключу мгновенный (O(1))! Они изменяемые, но ключи должны быть неизменяемыми (строки, числа, кортежи).

Что мы изучим:

  • Концепция пар ключ-значение
  • Создание словарей фигурными скобками
  • Доступ к значениям: dict[key] vs dict.get(key, default)
  • Добавление и изменение элементов
  • Удаление элементов: del и pop()
  • Проверка наличия ключа: key in dict
  • Перебор: keys(), values(), items()
  • Практические примеры: оценки, телефонная книга, переводчик

Что такое словарь?

Словарь - это неупорядоченная коллекция пар ключ-значение. Как настоящий словарь связывает слова с определениями:

# Настоящий словарь:
# "apple" -> "яблоко"
# "book" -> "книга"
# "cat" -> "кошка"

# Словарь в Python
eng_rus = {
    "apple": "яблоко",
    "book": "книга",
    "cat": "кошка"
}

print(eng_rus["apple"])  # яблоко
print(eng_rus["book"])   # книга

# Другие примеры словарей
ages = {"Иван": 16, "Мария": 15, "Петр": 17}
prices = {"хлеб": 30, "молоко": 65, "яйца": 90}
grades = {"математика": 5, "русский": 4, "физика": 5}

Создание словарей

Способ 1: Фигурные скобки {}

# Создание словаря с фигурными скобками
student = {
    "name": "Иван",
    "age": 16,
    "grade": 10,
    "city": "Москва"
}

print(student)
# {'name': 'Иван', 'age': 16, 'grade': 10, 'city': 'Москва'}

# Пустой словарь
empty_dict = {}
print(type(empty_dict))  # 

# Разные типы ключей и значений
mixed = {
    1: "one",
    "два": 2,
    3.14: "пи",
    (1, 2): "tuple key"
}
print(mixed[1])  # one
print(mixed["два"])  # 2

Способ 2: Функция dict()

# Создание через dict()
student = dict(name="Иван", age=16, grade=10)
print(student)  # {'name': 'Иван', 'age': 16, 'grade': 10'}

# Из списка кортежей
pairs = [("apple", "яблоко"), ("book", "книга"), ("cat", "кошка")]
dictionary = dict(pairs)
print(dictionary)  # {'apple': 'яблоко', 'book': 'книга', 'cat': 'кошка'}

# Из двух списков с помощью zip()
keys = ["Иван", "Мария", "Петр"]
values = [16, 15, 17]
ages = dict(zip(keys, values))
print(ages)  # {'Иван': 16, 'Мария': 15, 'Петр': 17}

ВАЖНО: Ключи должны быть неизменяемыми!

# Можно использовать как ключи (неизменяемые типы)
valid_dict = {
    "string": 1,      # Строка - OK
    42: 2,            # Число - OK
    3.14: 3,          # Float - OK
    (1, 2): 4,        # Кортеж - OK
    True: 5           # Bool - OK
}

# НЕЛЬЗЯ использовать изменяемые типы
# invalid = {[1, 2]: "value"}  # TypeError! Список изменяемый
# invalid = {{1, 2}: "value"}  # TypeError! Множество изменяемое

# Ключи должны быть hashable (неизменяемые)

Доступ к элементам

Способ 1: Квадратные скобки []

# Доступ через []
student = {"name": "Иван", "age": 16, "grade": 10}

print(student["name"])   # Иван
print(student["age"])    # 16
print(student["grade"])  # 10

# ВАЖНО: KeyError если ключа нет!
# print(student["city"])  # KeyError: 'city'

# Проверка перед доступом
if "city" in student:
    print(student["city"])
else:
    print("Ключа 'city' нет")

Способ 2: Метод get()

# get() - безопасный доступ
student = {"name": "Иван", "age": 16}

# get(key) - вернет None если ключа нет
print(student.get("name"))  # Иван
print(student.get("city"))  # None (нет ошибки!)

# get(key, default) - вернет default если ключа нет
print(student.get("city", "Неизвестно"))  # Неизвестно
print(student.get("age", 0))  # 16 (ключ есть, default не используется)

# Практика: безопасное получение оценки
grades = {"математика": 5, "русский": 4}
math_grade = grades.get("математика", 0)
physics_grade = grades.get("физика", 0)  # Нет такого предмета
print(f"Математика: {math_grade}, Физика: {physics_grade}")

Когда использовать [] vs get():

  • dict[key] - когда уверен что ключ есть (или хочешь получить ошибку)
  • dict.get(key) - когда ключа может не быть (безопасно)
  • dict.get(key, default) - когда нужно значение по умолчанию

Добавление и изменение элементов

Словари изменяемые - можно добавлять новые пары и менять существующие:

# Добавление нового ключа
student = {"name": "Иван", "age": 16}
print(student)  # {'name': 'Иван', 'age': 16}

# Добавить новый ключ
student["grade"] = 10
print(student)  # {'name': 'Иван', 'age': 16, 'grade': 10}

student["city"] = "Москва"
print(student)  # {'name': 'Иван', 'age': 16, 'grade': 10, 'city': 'Москва'}

# Изменение существующего ключа (синтаксис тот же!)
student["age"] = 17  # Был 16, стал 17
print(student["age"])  # 17

# Практика: счетчик слов
word_count = {}
text = "apple banana apple orange banana apple"
for word in text.split():
    if word in word_count:
        word_count[word] += 1  # Увеличить счетчик
    else:
        word_count[word] = 1   # Первое появление
print(word_count)  # {'apple': 3, 'banana': 2, 'orange': 1}

Удаление элементов

1. Оператор del

# del - удалить пару ключ-значение
student = {"name": "Иван", "age": 16, "grade": 10, "city": "Москва"}

del student["grade"]
print(student)  # {'name': 'Иван', 'age': 16, 'city': 'Москва'}

# Ошибка если ключа нет
# del student["phone"]  # KeyError!

# Безопасное удаление
if "phone" in student:
    del student["phone"]

2. Метод pop()

# pop(key) - удалить и вернуть значение
student = {"name": "Иван", "age": 16, "grade": 10}

grade = student.pop("grade")
print(f"Удалена оценка: {grade}")  # Удалена оценка: 10
print(student)  # {'name': 'Иван', 'age': 16}

# pop(key, default) - не вызовет ошибку если ключа нет
phone = student.pop("phone", "нет телефона")
print(phone)  # нет телефона (ключа не было)
print(student)  # {'name': 'Иван', 'age': 16} - не изменился

3. Метод clear()

# clear() - удалить все элементы
student = {"name": "Иван", "age": 16, "grade": 10}
student.clear()
print(student)  # {} - пустой словарь

Проверка наличия ключа

# Оператор in - проверка наличия ключа
student = {"name": "Иван", "age": 16, "grade": 10}

# Проверка ключа
print("name" in student)     # True
print("city" in student)     # False
print("Иван" in student)     # False! Проверяются ключи, не значения

# Оператор not in
print("phone" not in student)  # True

# Использование в условиях
if "grade" in student:
    print(f"Класс: {student['grade']}")
else:
    print("Класс неизвестен")

# Проверка значения (нужен метод values())
print("Иван" in student.values())  # True - значение есть
print(16 in student.values())      # True

Перебор словаря

1. Перебор ключей

# По умолчанию перебираются ключи
student = {"name": "Иван", "age": 16, "grade": 10}

for key in student:
    print(key)
# name
# age
# grade

# Или явно через keys()
for key in student.keys():
    print(f"{key}: {student[key]}")
# name: Иван
# age: 16
# grade: 10

2. Перебор значений

# values() - перебор значений
student = {"name": "Иван", "age": 16, "grade": 10}

for value in student.values():
    print(value)
# Иван
# 16
# 10

# Практика: сумма оценок
grades = {"математика": 5, "русский": 4, "физика": 5, "химия": 3}
total = sum(grades.values())
print(f"Сумма оценок: {total}")  # 17

3. Перебор пар ключ-значение

# items() - перебор пар (key, value)
student = {"name": "Иван", "age": 16, "grade": 10}

for key, value in student.items():
    print(f"{key} = {value}")
# name = Иван
# age = 16
# grade = 10

# Практика: красивый вывод словаря
prices = {"хлеб": 30, "молоко": 65, "яйца": 90, "масло": 120}
print("Прайс-лист:")
for product, price in prices.items():
    print(f"{product:10} - {price} руб.")

Практические примеры

Пример 1: Журнал оценок

# Журнал оценок по предметам
grades = {
    "математика": 5,
    "русский": 4,
    "физика": 5,
    "химия": 3,
    "история": 4
}

# Вывести все оценки
print("Оценки студента:")
for subject, grade in grades.items():
    print(f"{subject}: {grade}")

# Средний балл
average = sum(grades.values()) / len(grades)
print(f"\nСредний балл: {average:.2f}")

# Количество пятерок
count_5 = sum(1 for grade in grades.values() if grade == 5)
print(f"Пятерок: {count_5}")

# Самый низкий балл
min_subject = min(grades, key=grades.get)
print(f"Самая низкая оценка: {min_subject} ({grades[min_subject]})")

Пример 2: Телефонная книга

# Телефонная книга
phonebook = {
    "Иван": "+7-999-123-45-67",
    "Мария": "+7-999-234-56-78",
    "Петр": "+7-999-345-67-89"
}

# Найти телефон
name = "Мария"
if name in phonebook:
    print(f"Телефон {name}: {phonebook[name]}")
else:
    print(f"Контакта {name} нет")

# Добавить новый контакт
phonebook["Анна"] = "+7-999-456-78-90"

# Изменить телефон
phonebook["Иван"] = "+7-999-111-22-33"

# Удалить контакт
del phonebook["Петр"]

# Вывести всю книгу
print("\nТелефонная книга:")
for name, phone in phonebook.items():
    print(f"{name:10} : {phone}")

Пример 3: Переводчик

# Англо-русский словарь
dictionary = {
    "apple": "яблоко",
    "book": "книга",
    "cat": "кошка",
    "dog": "собака",
    "house": "дом",
    "car": "машина"
}

# Перевести слово
word = "book"
translation = dictionary.get(word, "Перевод не найден")
print(f"{word} -> {translation}")

# Перевести предложение
sentence = "cat book apple"
translated = []
for word in sentence.split():
    translation = dictionary.get(word, word)
    translated.append(translation)
print(" ".join(translated))  # кошка книга яблоко

# Добавить новое слово
dictionary["tree"] = "дерево"

Пример 4: Подсчет частоты слов

# Подсчитать сколько раз встречается каждое слово
text = "apple banana apple orange banana apple banana orange"

word_count = {}
for word in text.split():
    word_count[word] = word_count.get(word, 0) + 1

print("Частота слов:")
for word, count in word_count.items():
    print(f"{word}: {count} раз")

# Самое частое слово
most_common = max(word_count, key=word_count.get)
print(f"\nСамое частое слово: {most_common} ({word_count[most_common]} раз)")

Типичные ошибки начинающих

Ошибка 1: KeyError при доступе

# НЕПРАВИЛЬНО - ключа может не быть!
student = {"name": "Иван", "age": 16}
# print(student["city"])  # KeyError!

# ПРАВИЛЬНО - использовать get()
city = student.get("city", "Неизвестно")
print(city)  # Неизвестно

# Или проверить перед доступом
if "city" in student:
    print(student["city"])

Ошибка 2: Использование изменяемых ключей

# НЕПРАВИЛЬНО - список нельзя использовать как ключ!
# my_dict = {[1, 2]: "value"}  # TypeError!

# ПРАВИЛЬНО - использовать кортеж
my_dict = {(1, 2): "value"}  # OK
print(my_dict[(1, 2)])  # value

Ошибка 3: Путаница in для ключей и значений

student = {"name": "Иван", "age": 16}

# in проверяет КЛЮЧИ, не значения!
print("name" in student)  # True (ключ есть)
print("Иван" in student)  # False! Это значение, не ключ

# Для проверки значений
print("Иван" in student.values())  # True
print(16 in student.values())      # True

Ошибка 4: Изменение словаря во время перебора

# НЕПРАВИЛЬНО - изменяем словарь во время перебора
grades = {"математика": 5, "русский": 3, "физика": 4}
# for subject in grades:
#     if grades[subject] < 4:
#         del grades[subject]  # RuntimeError!

# ПРАВИЛЬНО - перебрать копию или список ключей
for subject in list(grades.keys()):
    if grades[subject] < 4:
        del grades[subject]
print(grades)  # {'математика': 5, 'физика': 4}

Ошибка 5: Путаница между [] и get()

student = {"name": "Иван", "age": 16}

# [] вызывает ошибку если ключа нет
try:
    print(student["city"])
except KeyError:
    print("Ошибка! Ключа нет")

# get() возвращает None или default
print(student.get("city"))  # None
print(student.get("city", "Неизвестно"))  # Неизвестно

# Используй get() когда ключа может не быть!

Ошибка 6: Дублирование ключей

# Дублирующиеся ключи - останется последнее значение!
student = {
    "name": "Иван",
    "age": 16,
    "name": "Петр"  # Перезапишет первое "name"!
}
print(student)  # {'name': 'Петр', 'age': 16}

# Ключи уникальны - каждый может быть только один раз

Резюме урока

  • Словарь: коллекция пар ключ-значение
  • Создание: {"key": "value"} или dict()
  • Доступ: dict[key] (с ошибкой) или dict.get(key, default) (безопасно)
  • Добавление: dict[key] = value (новый или изменить существующий)
  • Удаление: del dict[key] или dict.pop(key, default)
  • Проверка: key in dict - есть ли ключ
  • Перебор: keys(), values(), items()
  • Ключи: должны быть неизменяемыми (строки, числа, кортежи)
  • Значения: могут быть любыми (включая списки, словари)
  • Применение: подсчет частоты, хранение связанных данных, быстрый поиск
